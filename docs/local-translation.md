# 桌面离线翻译

macOS、现代 Windows x64 和当前 Linux 构建可在输入法进程内加载 PLaMo 0.8B 模型，将候选文本翻译成所选语言。安装模型后，翻译无需联网，也不需要另外启动 Ollama 或其他服务。Win7 和 Linux legacy 构建不包含此运行库。

## 使用

1. 打开「本地模型翻译」：macOS 使用输入法菜单；Linux 使用 IBus/Fcitx5 菜单；Windows 使用原生设置的翻译页，点击「管理模型与语言…」。
2. 点击「下载模型」，或从文件导入官方 `plamo-3-translate-0.8b-Q4_K_M.gguf`。下载约 573 MB；导入时会校验文件，只接受当前版本固定的官方权重。
3. 选择目标语言，勾选「启用本地翻译」。候选译文沿用输入法原有的显示与选择方式。

目标语言目录包含英语、日语、法语、德语、韩语等 53 种语言或变体，包括简体中文和繁体中文。列表以当前模型能力为准，模型不保证覆盖所有语言，译文质量也会随语言而变化。

启用时会切换到本地翻译，保留原云服务凭据。关闭本地翻译后不会自动恢复云服务；需要在线翻译时再选择对应服务。模型缺失、校验失败或推理失败不会把这次翻译发给云端。

## 管理模型

安装过程中可以取消；删除前会关闭本地翻译，之后需要重新下载或导入。模型首次使用时加载，连续翻译复用模型，空闲约一分钟后释放。首次加载需要读取和校验完整权重；低配置电脑的 CPU 推理可能较慢。

模型来源、摘要和许可证见[第三方组件清单](third-party.md#桌面本地翻译)；维护者验证范围与实现约束见[决策笔记](../.agents/notes/implemented/feature/2026-11-06-plamo-embedded-translation.md)。

原草稿的 HY-MT2 权重不能继续使用，需重新下载或导入 PLaMo；旧文件不会自动删除。葡萄牙语、土耳其语、捷克语、乌克兰语、藏语、蒙古语、维吾尔语、粤语不在当前模型目录中，先重新选择受支持目标再启用。源语言由模型识别；单次输入最多 256 字，不接受控制字符或 `<|plamo:` 模型保留标记。

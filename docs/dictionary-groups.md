# 词库分组

命名词库是可单独启停的本地分组。分组按自建、文件导入、社区来源展示，可以改名、多选启用或停用，也可以确认后批量删除。

| 平台 | 入口 |
| --- | --- |
| Android | 词库 → 已安装 → 管理；选择批量操作或导入 |
| iOS | 词库 → 词库分组 |
| macOS | 输入菜单 → 词库分组 |
| Linux | IBus / Fcitx5 输入菜单 → 词库分组，需 GTK 4.8+；legacy 构建不含此窗口 |
| Windows | 原生设置 → 词库 → 词库分组，现代设置与 Win7 共用管理窗口 |
| HarmonyOS | 设置顶部 → 词库分组，完成首次授权与启动后显示 |

导入时可以新建分组，名称默认取文件名，也可以自定义名称，或选择相同词库类型的已有分组。导入已有分组不会更改其名称或启停状态，重复的编码与词条自动跳过。社区分组的内容由资源版本决定，不能接收普通文件；搜狗细胞词库须新建分组或导入同来源分组，以保留第三方来源标记和社区发布保护。

停用或删除分组只撤回它拥有的词条。仍被其他已启用分组使用的词，以及导入前就已存在的个人词条，继续保留。词条按原有队列写入输入词库，输入法繁忙时保留待写入项，稍后继续。iOS 需要键盘完全访问才能写入共享目录；清除学习记录后，已启用分组会重新排队，在键盘空闲时写回。

最多保存 32 个分组，每组最多 50000 条。分组元数据只在本机保存；账号和 WebDAV 仍按原有个人词条边界同步，不同步分组名称、来源与开关。已有未分组的个人词条不自动迁入新分组。

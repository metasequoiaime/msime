# Agent Note: 自动纠错弱位置使用位掩码

Status: implemented

## Problem

自动纠错规划每次为输入切分创建 `Vec<bool>`，只为记录哪些音节位置由单字词覆盖。正常输入的纠错长度有界，这个位置状态不会超过 64 个元素，却仍然在每次规划中触发一次堆分配。

## Decision

弱位置状态在 64 个位置以内使用 `u64` 位掩码；超过这个范围的内部调用保留 `Vec<bool>` 回退。`set`、`clear` 和 `get` 封装两种存储，使规划的弱位置优先顺序、路径不完整时清空标记和长输入行为与原实现一致。

## Alternatives considered

- 继续分配 `Vec<bool>`：逻辑简单，但正常输入每次纠错规划都会产生一个固定的临时分配。
- 对所有输入强制使用位掩码：可以更短，但会为超过 64 个位置的内部调用引入截断或额外边界规则，不能保持原有通用性。
- 使用新的小向量依赖：能把短状态放在栈上，但扩大依赖面；`u64` 已覆盖产品输入边界，长输入回退也足够明确。

## Verification

收紧多位置规划的分配预算测试，旧实现失败，位掩码实现通过；新增 64 位边界零分配测试和超过边界的堆回退测试。实现后运行完整 `msime-engine` 单元与 golden 测试、Clippy、格式与差异检查、笔记检查和 quick 门禁。

## Consequences

正常输入的弱位置标记不再分配堆内存；超出 64 个位置的内部输入仍按原方式使用 `Vec<bool>`。位操作增加了一个明确的边界分支，但不改变纠错键规划的顺序、预算或候选结果。

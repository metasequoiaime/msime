# Agent Note: 本地命令表短表去重

Status: implemented

## Problem

本地命令表通常只有少量行，但 `usable_command_table` 每次都创建容量最多 256 的 `HashSet` 来记录触发词。短表因此承担了不必要的哈希桶分配。

## Decision

命令表不超过 64 行时，在线性扫描原始表中此前的有效触发词；更大的表继续使用借用触发词的 `HashSet`。线性路径会检查模板无效的历史行，保持旧路径已记录触发词后再验证模板的行为。

## Alternatives considered

始终线性扫描会让较大的宿主表退化为平方级；始终创建哈希表则无法消除常见短表的临时状态。按 64 行分流保留大表的线性期望复杂度，并覆盖短表常见场景。

## Verification

新增短表触发词扫描零临时分配测试，以及无效模板仍占用触发词的语义测试；完整引擎单元测试、Clippy、Rustfmt、差异检查、笔记检查和 quick 门禁覆盖实现。

## Consequences

64 行以内的命令表不再创建临时哈希表；超过边界的命令表保持原有哈希去重和最多 256 行限制。

# Agent Note: 日文矩阵精确词条流式消费

Status: implemented

## Problem

矩阵每个读音跨度的精确查询先按成本筛选 ID，再把借用词条收集为临时 Vec，只消费一次；待定补全与最长前缀的精确词条也有相同容器。简单和密集单假名各有两个命中查询，因此保留两份不需要的视图向量。排名 ID 与句子节点仍需要自己的存储，本片只消除借用视图结果容器。

## Decision

沿用 decoder 已有的前缀流式模式，新增 crate 内部 `for_each_exact_lemma_view`，复用 `exact_lemmas_with` 的筛选与排序，访问闭包返回 `()`，结果是无需元素存储的 `Vec<()>`，这是 [Rust 标准库 Vec 的保证](https://doc.rust-lang.org/std/vec/struct.Vec.html#guarantees)。矩阵三个精确查询直接消费词条，保留原读音跨度、限额、lemma→previous 遍历、同分顺序、EOS、输出去重和拥有文本。视图生命周期仅绑定词库。

最长前缀的外层页满停止条件保持，闭包对本次已排名的剩余词条执行原输出判定；原流程在循环前也会构造所有这些视图。不存在新的查询或文本物化，没有逐起点整行移动变化，也不采用已否决的固定数组。

## 既有笔记审计

[完整读音预测流式消费](../../implemented/testing/2026-10-09-japanese-prediction-stream.md) 部分重叠，复用零大小映射的既有 OSS 实现，但消费方是 matrix 精确查询，互链而保留 provider 决定。[词条借用](../../implemented/testing/2026-10-09-japanese-lemma-borrow.md) 与[空排名存储](../../implemented/testing/2026-10-09-japanese-empty-ranking.md) 部分重叠，继续约束借用生命周期和空查询不分配，互链。[固定八槽行否决](../../rejected/testing/2026-10-09-japanese-inline-matrix-rows.md) 保留无稳定延迟收益的证据，行仍用 Vec；其固定 Vec 完整查询仅扩大测试可见性以复用独立对照，不改正文。[句子结果容器复用](2026-10-09-japanese-sentence-output-buffer.md) 在变基时纳入已合并的独立容器决定，部分重叠并互链；冷查询历史对照和生产复用入口共用同一搜索核心。节点筛选、末行文本转移和待定查询键属于另外的存储层，部分重叠，原流程继续有效。其余日文读音扫描、转换及 provider 缓冲属于别层，无关且保留。活跃笔记检索 for_each_exact、精确词条流式、exact_lemma_views 和矩阵流式，没有相同决定。

## Alternatives considered

- 保留临时视图 Vec：循环可直接 break 且接口简单，但每次命中都为只消费一次的视图结果分配。
- 新建独立 exact 排名迭代器：消费方自然使用 for 和 break；需要封装排名 ID 所有权与词库借用，已有泛型映射即可实现无结果向量消费，不增加另一套筛选。
- 保存查询视图到 matrix 或 provider 常驻缓冲：可复用容量，但增加跨查询状态与词库视图生命周期管理；局部消费不需要长期存储。

## Consequences

每个非空精确命中省去一份借用视图结果向量，不增加长期状态、依赖或 unsafe。排名 ID、Vec 句子行与最终拥有文本仍保留原存储，词库生命周期、排序、连接成本和所有查询限额保持。分配下降是确定收益；release 多数路径的第二轮改善支持采用，首轮波动和单项小回退仍作为限制保留。

代价是多一个 crate 内部同步回调入口，旧精确视图入口只在测试中维持历史对照。最长前缀本次已排名但页满的剩余词条仍执行不物化文本的接纳判定；若后续稳定隔离环境显示这段额外访问造成显著回退，再考虑具有停止语义的消费接口，并重新验证排名与限额边界。固定八槽行仍被否决，不把本片结果当作采用数组的理由。

[已消费行提前释放](2026-10-10-japanese-consumed-row-release.md) 进一步让起点完成全部跨度与未知回退后释放前驱行，取消无后续读者的历史行恢复。Vec 行布局、原排名、文本拥有和本篇历史验证保留；峰值请求字节下降不等于 RSS 或延迟改善。

[前缀词条流式消费](2026-10-09-japanese-prediction-stream.md) 也覆盖空读音矩阵分支。精确词条对照的空读音控制路径现按页满之前实际命中的前缀数核算这一独立视图分量，零限额和未命中仍无差值；冻结 Vec 查询正文保持；非空读音的未命中控制路径在加回[矩阵滚动行](2026-10-10-japanese-rolling-rows.md)独立减少的行容器分量和[滚动字节边界](2026-10-10-japanese-rolling-boundaries.md)实测旧位置 Vec 的 alloc/realloc 分量后保持次数等值。本篇两轮 release 数字继续只对应当时的精确流式切片。

[滚动字节边界](2026-10-10-japanese-rolling-boundaries.md)省去热 provider 的一份位置容器，当前完整行热预算为 7，完整预测为 10；历史 8/11 预算与两轮精确流式计时保留，不把边界收益归入精确词条消费。

[排名堆成本键复用](2026-10-10-japanese-ranked-heap-output.md) 将项存储由 `((cost, id), id)` 收为 `(cost, id)`，最终对保存键不稳定排序，避免重读成本；继续保留本篇的空查询、流式消费、重复项与词库借用边界。历史分配次数和单项计时保留，当前排名请求字节与独立选型证据由新篇核算。

# Agent Note: 全拼冷路径缓存页压缩

Status: implemented

## Problem

[工作集诊断](../../implemented/testing/2026-10-23-quanpin-path-cache-working-set.md)在固定公开九键集合中观察到 183332 次路径页未命中、1162724 行及 3505616 次缓存页复制申请。扩大容量会延长首字母展开页的存活，不能把固定序列的命中估计直接接入产品。冷查询页的每一行都有相同匹配读音，来源和其余元数据由 `WordItem::new` 固定，却逐行保存独立字符串及完整结构。

## Decision

容量仍为 128，原 FIFO、键、清空和展开写入时机不变。仅 `query_single_path_miss` 的普通词典页采用私有压缩表示，保存规范键、词面、权重；匹配读音等于缓存键时借查询键恢复，否则每页只存一次。默认元数据在构造拥有型输出时还原。首字母展开及其它完整页原样保存 `Vec<WordItem>`，不压缩状态页。

压缩页的拥有型容器用 `Box` 保持缓存值尺寸受控。只有省下的匹配读音申请严格多于新增容器申请时才压缩：匹配缓存键至少 2 行，其余至少 3 行。空页使用独立无负载变体，单行及小控制页保留原深复制。空匹配读音没有逐行字符串申请可省，仍保存完整页。每次输出继续拥有独立字段，容量与旧克隆相同；热短前缀直接向最终容器追加，热备选合并使用惰性拥有型行迭代。

## Historical audit

已检索路径页、缓存压缩、共享读音及紧凑候选，没有相同表示。[工作集](../../implemented/testing/2026-10-23-quanpin-path-cache-working-set.md)部分重叠，继续持有扩容及展开边界；[短前缀追加](../../implemented/testing/2026-10-16-quanpin-prefix-row-stream.md)与[备选行流](../../implemented/testing/2026-10-16-quanpin-alternative-row-stream.md)继续保持输出容器规则；[短键实验](../../rejected/testing/2026-10-23-quanpin-inline-path-key.md)只否决键表示，不否决候选页表示。没有完全吸收或过时提案。

## References

Rust 官方 [Vec](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.with_capacity) 与 [Box](https://doc.rust-lang.org/std/boxed/index.html)给出拥有型存储和容量边界；逻辑请求容量与分配器物理存储分开计量。复用仓库 `matched_items` 的字段映射与既有 FIFO，不增加依赖、共享可变状态或不安全转换。

## Alternatives considered

- 直接将路径容量升到 256：固定序列中可减少约 46% 的缓存页复制，但会延长首字母展开页寿命；本片保留原 128 槽状态契约。
- 增加第二层完整候选缓存：可以继续复用被淘汰页，但要处理展开页、完整查询参数、词典版本和双层持有内存，新增跨查询状态较多。
- 所有页均增加压缩容器：表示统一，但单行和读音不匹配的两行页没有确定性申请节省，不采用。
- 每行共享字符串：可以减少更多复制，但会改变通用 `WordItem` 及公开拥有型候选契约，不在本片实施。

## Verification

真实 SQLite 的旧冷页申请预算先失败，再通过；新增三项专项通过，字段、顺序、外层和嵌套容量、所有权、空/单行/别名/不匹配参数及完整展开页均对照固定旧入口。展开页经原 FIFO 淘汰后恢复有限页。静态表示和缓存持有量计入局部矩阵，128 行匹配 8 字节键的页请求字节从 20626 降到 9410，匹配 64 字节键从 27794 降到 9410，包含 48 字节 Box 主体，不称为 RSS。

普通分配器的局部交替线程 CPU 矩阵预定包含空页、单行、2/3/4/32/128 行，匹配/不匹配读音及冷插入/热复制/追加；大页冷插入目标为候选/旧版中位比不高于 0.98，其余控制不高于 1.05，全部收齐后统一判断。修正固定预算后的全量 engine 2521 项、golden 31 项、runtime 365 项全部通过，56 项手动测量/外部资源用例保持原忽略状态；三网格 81 例完整质量报告及全部候选逐字节相同。产品 engine/runtime 测试、fmt、Clippy、notes、quick 及原 16 ms 九键 ABBA 的结果分别保留在[测量目录](../../../../docs/measurements/2026-10-23-quanpin-path-page-compaction/README.md)，不修改门槛或已知失败基线。

本地完整 quick 在 5250.894 秒后退出 0：Rust workspace、Android target、两种 WASM 配置、Android 宿主 Java、Linux 桌面壳与原生宿主构建、Linux 111 项测试、macOS 原生宿主构建及 Apple 共享桥接层通过；本机 Windows 原生逻辑测试 164 项通过。Windows 完整构建和 HarmonyOS 真工程因环境缺失跳过；没有设备装机或界面验收。Clippy 全 targets、格式和笔记检查通过。

随后普通 push 复跑门禁时，先遇到容器 I/O 极慢导致的主题测试超时，单项复测通过；第二次遇到宿主调度迟到触发监督器测试的墙钟上界。顺带修正的[监督器时钟夹具](2026-10-24-ibus-supervisor-controlled-clock.md)保留精确退避与信号生命周期断言，两次失败、复测和追加完整门禁记录另存于[追加验证目录](../../../../docs/measurements/2026-10-24-ibus-supervisor-controlled-clock/README.md)。

## Experiments

首轮普通分配器的 84 格完整矩阵中，4 个空页热复制格回退 7.80%–11.89%，超过预定 1.05 上限。符号表未见独立的 `copy_rows`，据此推断已内联；在空页上仍需分辨完整页与压缩页并检查 Vec 长度。保留原结果，增加专门的 `Empty` 变体后重跑全部 84 格、每格 21 对，不筛选复测格。第二轮所有格通过：32/128 行冷插入中位比 0.6755–0.7033，热复制 0.8940–0.9076，追加 0.8917–0.9088，其余控制最大 1.0456。两轮实际 `PathPage` 均为 24 字节，等于旧 Vec。

首次产品全量回归仅会话光标测试的固定预算失败（121 对旧 125），golden 31 项及 runtime 365 项通过。该夹具在 `ni` 后输入 `h`，冷 `ni'h` 页匹配 5 行；本片省 5 份读音申请，新增 1 个 Box，净少 4 次。对照实际输出行数后将此预算精确收紧到 `125 - (5 - 1)`，保留固定等式，不新增已知失败。原失败日志保留。

九键 ABBA 的 180 秒启动预检未满足空闲条件（load1 165.69–230.00，监测到 22–65 个外部构建/评测进程），程序退出 1，没有启动任何计时臂。保持原 16 ms 预算与 5 例预热；默认九键 16 ms 仍未验证。

## Consequences

每个压缩页新增一个 Box 和一次元数据校验遍历，减少逐行重复读音及完整行存储；小页和非默认元数据没有收益时回退完整表示。枚举本身不增加槽尺寸，间接访问及跨函数分支仍可能影响端到端 CPU。紧凑行必须完整重建原字段，新增字段由穷尽匹配要求显式处理，并由元数据回退测试核对。旧专项若依赖冷页布局，需保留其隔离目标并另有本片完整旧入口，不能修改断言掩盖回退。局部申请减少不证明默认九键 16 ms 达标。

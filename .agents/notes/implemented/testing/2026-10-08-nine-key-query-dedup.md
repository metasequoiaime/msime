# Agent Note: 九宫格查询键有界去重

Status: implemented

## Problem

九宫格刷新会为每组替代切分建立 `HashSet<String>`，只为避免重复查询相同的拼音键。替代路径数量受 `PATH_LIMIT` 和固定的 421 个完整音节表约束，短批次不需要哈希桶；但原实现每次刷新都会分配临时集合。

## Decision

替代路径不超过 64 条时，按已有路径线性扫描判断重复；超过边界时继续使用 `HashSet<String>`，避免路径数量扩展后退化为平方复杂度。查询键仍在词典查询结束后才加入集合，保持借用键期间不移动字符串；首次出现顺序和查询结果不变。

## Alternatives considered

始终改用 `Vec<String>` 可以删除哈希桶，但会让最多数百条替代路径的刷新退化为平方级字符串比较。始终保留 `HashSet<String>` 能保持查找复杂度，却不能消除短批次的临时堆分配。按 64 条边界分流同时覆盖短输入和扩展音节列表。

## Verification

新增短批次零临时分配测试，以及边界以上哈希回退和重复路径测试；`nine_key` 测试、完整引擎单元测试和格式检查覆盖实现。

## Consequences

常见短九宫格刷新不再为查询键去重分配哈希桶；较大的替代路径仍保持近似常数时间查找。小批次增加有界线性比较，边界为 64 条路径。

# Agent Note: 候选追加的小列表去重路径

Status: implemented

## Problem

`append_unique_words` 在查询结果、字面候选和模糊候选合并时，为一次追加建立 `HashSet` 和临时保留标记数组。小结果合并只需要检查正在增长的结果列表。

## Decision

当结果与待追加行合计不超过 64 时，预留结果容量后边追加边线性扫描已有词；超过边界仍使用哈希表路径。这样保持结果及输入行的首次出现顺序，并把真实结果存储分配与临时去重状态分开。

## Alternatives considered

所有追加都改成线性扫描会让大词典结果退化为平方复杂度；只缩小集合容量仍保留两次临时分配，不能解决候选页路径的开销。

## Verification

新增 37 行小合并的分配预算测试，确认追加零临时分配并保留 19 个首次出现词；既有重复词、容量预留和空输入测试继续覆盖行为。

## Consequences

64 行以内的追加时间复杂度为平方级，但候选页规模受控；更大的追加继续走哈希表和标记数组路径。

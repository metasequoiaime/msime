# Agent Note: 注音九键完成音节保留数字缓冲

Status: implemented

## Problem

注音九键按声调结束音节时通过 `mem::take` 取走待定数字，成功后却直接释放该向量，下一音节首个数字必须重新分配。索引初始化出错时，提前返回也会丢掉取出的数字。

## Decision

完成音节的按键文本构造后，清空数字向量并放回编辑器；无匹配读音和索引出错时都恢复原数字向量，再按原方式返回结果。其他转换、提交和按键处理流程保持不变。

## Alternatives considered

每次预先分配一个新数字向量只能掩盖容量丢失，仍会重复分配。改为固定数组会扩大待定数字操作和读音索引调用的改动范围，当前切片复用已有存储，并补齐所有取出缓冲的返回路径。

## Consequences

完成音节后下一音节首键从一次分配降至零次，数字缓冲地址和容量保持不变。索引初始化失败会返回原错误并保留原待定数字、组字状态和读音。

## Verification

旧实现的首键零分配测试在一次分配处失败，索引失败回归测试因数字从 `28` 变为空而失败。优化后验证首键零分配、地址和容量复用、转换文字，以及失败后的数字和组字状态。注音单测、引擎全量单测、golden、Clippy、Rustfmt、笔记校验、差异检查和 quick 门禁覆盖本切片。

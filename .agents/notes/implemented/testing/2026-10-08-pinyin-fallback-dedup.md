# Agent Note: 混输拼音回退短批次去重

Status: implemented

## Problem

五笔混输没有候选时，拼音回退仍为一次候选批次建立 `HashSet`；有五笔候选时也会为短的合并列表创建哈希集合和重复索引。常见回退批次很短，这些集合只服务于一次合并。

## Decision

当拼音回退批次或合并总量不超过 64 条时，直接原地扫描已保留词并复用输入批次缓冲；超过边界继续使用借用词键的 `HashSet`，保持大列表复杂度。空五笔列表的重复拼音批次也在原缓冲中压缩，首次出现顺序不变。

## Alternatives considered

始终线性扫描会让大词典结果退化为平方复杂度；始终创建哈希集合会保留短批次的临时分配。固定数组会复制候选行的生命周期管理，且不适合无界词典返回，因此采用按实际批次大小分流。

## Verification

新增 16 行重复拼音批次的零分配测试；拼音回退测试、完整引擎单元测试（1159 项）、Clippy、Rustfmt、差异检查和 quick 门禁覆盖实现。

## Consequences

短回退直接复用输入 `Vec`，不再为去重创建临时哈希状态；超过 64 条时保留哈希查找，避免无界结果退化。

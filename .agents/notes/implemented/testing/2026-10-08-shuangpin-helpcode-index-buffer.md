# Agent Note: 双拼辅助码候选合并复用单一索引缓冲

Status: implemented

## Problem

双拼辅助码的大列表合并路径把 `whole` 和 `unmatched` 两组候选分别计算重复索引，再用外层 `Vec` 保存这些索引；启用辅助码时会产生不必要的临时堆分配。

## Decision

先将两组行移动到预留好的结果缓冲，只记录一份统一的唯一索引，释放词面借用后原地压缩结果。结果仍按 `whole` 再 `unmatched` 的顺序保留每个词的首次出现。

## Alternatives considered

保留两组重复索引会继续产生与输入组数相关的分配；复制词面到拥有型哈希键会为每个候选增加字符串分配；全量线性扫描会使大列表去重复杂度退化。

## Verification

新增大列表分配回归测试：旧实现产生 8 次临时分配并按预期失败，单一索引缓冲实现降至不超过 2 次并通过。随后运行双拼 dictionary 测试、完整引擎测试、Clippy、格式检查、笔记检查和 quick 门禁。

## Consequences

辅助码大列表仍保持哈希去重的复杂度和候选顺序，但两组临时索引合并为一份，结果缓冲也只按最终增量预留一次。

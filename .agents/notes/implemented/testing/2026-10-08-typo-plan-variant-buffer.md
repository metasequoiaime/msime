# Agent Note: 自动纠错规划复用变体缓冲

Status: implemented

## Problem

自动纠错规划为每个输入位置创建一个新的变体 `Vec`，把静态纠错变体和个人接受次数放入其中后排序。一次规划会访问多个位置，因此同一查询反复申请和释放同样形状的临时列表；这些分配叠加在范围键自身的分配上。

## Decision

在 `plan_keys_with`（全拼的 `plan_keys` 和双拼的纠错整句共用它，见 [双拼的纠错整句](../feature/2026-10-09-shuangpin-typo-sentence.md)）的位置循环外建立一个变体缓冲。每个位置开始时清空并重新填充，排序后借用其中的 `(变体, 接受次数)` 元组继续生成规划键；缓冲容量跨位置保留。变体来源、稳定排序、预算截断和键去重顺序保持不变。

## Alternatives considered

- 每个位置继续创建独立 `Vec`：代码最直接，但会重复分配，且变体数据只在当前位置使用。
- 为每个位置使用固定数组：可以避免堆分配，但需要预估并维护静态变体最大数量，超出时仍需额外路径，复杂度高于复用已有 `Vec`。
- 引入新的小向量依赖：可把小列表放在栈上，但会增加依赖和跨平台构建面；现有循环缓冲已能消除重复堆分配。

## Verification

新增多位置规划的分配预算测试；旧实现分配 96 次并失败，复用缓冲后通过。完整 `msime-engine` 单元与 golden 测试、Clippy、Rustfmt 差异检查、笔记检查和 `scripts/verify-local.sh --quick` 覆盖实现与行为回归。

## Consequences

一次规划只为变体列表首次扩容，后续位置复用其容量，减少临时堆分配和释放。缓冲在函数结束时仍释放，生命周期和内存上限没有变化；较大的位置变体会让同一查询后续位置暂时保留相同容量。

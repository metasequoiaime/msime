# Agent Note: 双拼辅助码候选去重的小列表路径

Status: implemented

## Problem

双拼单字辅助码过滤会把整句结果和未匹配结果先合成中间列表，再创建 `HashSet` 和重复索引列表去重。常见短候选批次只需检查少量词，却仍产生临时集合、索引和中间列表的堆分配。

## Decision

整句结果、未匹配结果与已有结果的总量不超过 64 条时，按词面线性扫描并直接追加唯一行；超过边界时，对两个输入列表的迭代链使用借用词面的 `HashSet` 和重复索引回退。整句结果仍先于未匹配结果，已有结果和首次出现顺序保持不变。

## Alternatives considered

所有批次都改用线性扫描会让较大的辅助码结果退化为平方级比较；始终保留哈希路径则无法消除短批次的集合分配。保留大批次哈希回退，并在线性路径直接消费两个输入列表，避免额外中间 `Vec`。

## Verification

新增短批次零临时分配测试，以及超过 64 条时首次出现顺序测试；双拼字典测试、完整引擎单元测试（1163 项）、Clippy、Rustfmt、差异检查、笔记检查和 quick 门禁覆盖实现。

## Consequences

64 条以内的辅助码合并不再创建临时哈希集合、重复索引或合并列表；较大的结果仍使用哈希去重，保持大批次查找复杂度。

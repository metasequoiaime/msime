# Agent Note: 词网格按唯一结果预算停止路径回溯

Status: implemented

## Problem

`decode_graph` 已经把末列剪枝、排序，通常只返回 `nbest = 6/12` 条唯一句子，却先为最多 32 条假设逐条回溯、克隆词串并拼接句子和读音，再去重截断。预算用完后的路径不会参与三元重排，也不会返回，仍承担全部输出构造成本。

## Decision

沿用现有 64 条小列表边界，在末列假设不超过此上限时，按原排序逐条回溯、跳过空句子并检查已保留句子；收齐 `take = min(nbest, last.len())` 个唯一结果后停止。重复句子仍保留第一条路径，重复项不再拼接读音。大末列继续原批次物化及哈希回退，避免自定义大束宽退化成平方查重。保持原输出向量容量、评分位模式、排序与剪枝，以及先唯一截断再三元重排的顺序。

## Historical audit

已按回溯、`nbest`、终点去重、路径输出检索活跃笔记。[终点小列表去重](../../implemented/testing/2026-10-07-lattice-sentence-dedup.md)持有 64 条线性/哈希边界；本项在同一边界内提前应用唯一预算，减少其上游物化，两者部分重叠并互链。[默认行移交](../../implemented/testing/2026-10-14-generated-lattice-row-ownership.md)和[神经行移交](../../implemented/testing/2026-10-15-neural-lattice-row-ownership.md)管理已经解出的路径向候选交接，不管理被截断路径的创建。[假设布局](../../implemented/testing/2026-10-15-lattice-hyp-layout.md)与[列容量](../../implemented/testing/2026-10-15-lattice-column-capacity.md)管理搜索存储，本项不改变假设。[回溯错字计数实验](../../rejected/testing/2026-10-15-lattice-traceback-typo-count.md)因原入口短图回退被否决，本项保持累计字段，不恢复该方案。

## Alternatives considered

- 先把 `last` 截到 `nbest`：几乎不增加分支，回溯次数也最少；但同句的不同切分会占预算，导致少返回本来可用的唯一句子，不能采用。
- 所有束宽都在线性查重后停止：逻辑最统一，任意预算均可提前结束；但自定义大束宽且大预算可能出现平方复杂度，保留现有大列表回退。
- 建立拥有句子的流式哈希集合：可覆盖任意束宽并提前结束；但集合需复制句子或重新组织路径所有权，默认小列表不值得引入额外堆状态与生命周期复杂度。

## Verification

旧版在四条单词路径、返回一条的精确分配预算中真实失败：减少次数为 0，预算为 15。改后每条不再物化的单词非空路径精确少五次申请（词向量、键向量、词串、句子及读音）；不是只断言“更少”。重复但未凑够预算的 32 条路径仅有四种句子，另有精确少 28 次无用读音拼接的预算。

独立固定 `0b522ddc5cab9d7c9b95cbbf347ceeebf365444d` 的假设、比较器、容量、完整解码和去重，除注释与格式外机械核对一致。四种种子、五种列数、四种边宽、四种束宽、六种 `nbest` 和 32 种二元/三元/个人/备忘/附加图配置，共 61440 组各跑冷/热两轮，比较完整路径字段、顺序、评分位模式与输出向量容量。另有 84 组空句子、同句不同字段及 64/65/128 边界组合。显式三元表给预算外第三条路径很高奖励，仍只对前两条唯一路径重排，证明没有改变先截断再重排的规则。已有跨切分同句、空词面边和独立穷举测试继续通过。

首轮完整测试只有旧布局内存等式失败：四列八边从 231 次降为 44 次，其余 2124 项通过。旧布局预算现用固定四十字节且完整物化的参考，继续保持原分配等式与峰值要求，不叠加本次物化收益；产品 `Hyp` 大小仍由原布局断言守住，当前提前停止由新增精确预算独立守住，没有把旧等式放宽为不等式。

最终完整 release 测试通过引擎 2125 项、golden 31 项及 runtime 288 项，24 项按既有设置忽略。指定固定资源为 `MSIME_NEURAL_MODEL_DIR`，键盘模型对照实际执行；历史 `dict-v2.0.1` 专用夹具没有提供，按既有逻辑跳过。两 crate 全 targets 的 Clippy 通过。

创建时基线 `0b522ddc5cab9d7c9b95cbbf347ceeebf365444d` 上，本地 `bash scripts/verify-local.sh --quick` 退出 0，Linux 原生 87 项、macOS 原生构建与共享 Apple bridge 通过；HarmonyOS 缺少完整工具链、Windows 缺少原生/交叉构建配置，按门禁说明跳过对应编译，未作设备验收。下列质量、分配和配对计时均在该共同基线上完成。

整合 `origin/develop` 的 `207ac014dc7503b1ed4760da1491d05d95117900` 后，engine/runtime 源码未受上游修改；工作区及 client-core 依赖有更新。重新运行带固定模型资源的完整 release 测试，引擎 2125、golden 31、runtime 288 项通过，24 项保持忽略；两 crate 全 targets Clippy（`-D warnings`）通过。整合后 quick 退出 0，Linux 原生 87 项、macOS 和共享 Apple bridge 构建通过，Windows/HarmonyOS 等工具链跳过范围同前；没有将旧基线配对计时冒作整合后的端到端收益。

## Consequences

默认末列可以少克隆和拼接不会返回的路径，返回候选、存储容量和模型输入保持。小列表每个已访问假设多检查一次唯一预算，最短热备忘图约有 0.97% 回退，仍在事前上限内；大图保留批次物化和哈希回退，不改变其渐进复杂度。未来若把三元重排移到唯一截断之前，或要让重复路径参与下游模型，这个提前停止条件必须重访。保持假设中的累计错字边数，不采用先前被否决的布局方案。没有生产文件读写、目录遍历、权限或 Android 资源改动，本项没有设备验收结论。

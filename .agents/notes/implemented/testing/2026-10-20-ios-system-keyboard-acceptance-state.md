# Agent Note: iOS 系统键盘验收显式准备状态

Status: implemented

## Problem

系统键盘界面用例复用模拟器的 App Group 和已启用键盘列表。前一项留下的输入模式、默认未启用的十四键、已登记但未允许完全访问的扩展都会影响后一项；控件更新后，旧用例仍查找 `Key` 类型的字母键与手机上已隐藏的独立句号键，失败不能直接归为产品回归。

## Decision

模拟器安装使用 ad-hoc 签名，保留 App Group 与钥匙串权限。系统设置准备不因扩展已登记而跳过完全访问核对。需要全拼的用例自行选择方案与中文模式，字母按当前 `Button` 节点点击；英文句号通过手机逗号键的长按功能输入。十四键先经原生设置显式选择，等待选项面板退场并确认选中状态后，再进入真实系统编辑器，在方案横向分页中查找，不用隐藏调试入口伪造键面。小鹤键面提示先通过原生设置开启，结束后恢复原值。数字侧栏按目标相对位置短拖动并停稳，避免快速 swipe 直接甩到底后越过乘号；失败截图实际显示除号与扩展符号，证明原测试没有停在目标位置。已有设置遍历返回契约由[对话页隐藏标签栏](../../implemented/feature/2026-10-17-mobile-chat-hides-tabs.md)记录。

## Alternatives considered

- 重置整个模拟器能消除状态污染，但会反复丢失系统键盘登记并增加验收耗时；只准备每项实际依赖的状态。
- 把找不到旧控件、未启用可选方案全部跳过能让套件看起来更稳定，但无法证明功能可用；修正真实操作路径，环境跳过单独报告。

- 本轮导航修复的真机 Release 签名构建与 `codesign --verify --deep --strict` 通过；XcodeGen 工程需先重新执行 `pod install --deployment` 以恢复 CocoaPods 接入，缺少接入时的 ML Kit 模块构建失败不算产品通过。设备 USB 仍未枚举到，未安装新包。

- 统计说明弹层、开发者选项与诊断日志真实入口检查通过，34.186 秒，日志开关前后一致；润色服务入口与返回通过，89.755 秒，临时启用的润色设置在重启后恢复。四张页面截图已查看，没有开启日志、导出诊断或调用润色服务。

- 在专用模拟器的 `.xctestrun` 副本中显式注入 `EnvironmentVariables.MSIME_TEST_RESOURCE_DOWNLOAD=1`，不改默认离线套件。首轮实际等待语言词库下载完成，并由系统键盘产生粤拼候选，通过，32.801 秒；补充候选提交断言后再跑，汉字跨进程上屏通过，31.446 秒。第二轮复用已下载词库，不宣称重复验证了下载传输。该用例也按当前 `Button` 类型与双向方案分页操作。

- 四项二级设置定向遍历通过，合计 114.993 秒，覆盖九键双拼预览、辅助码、翻译服务、词库信息、背单词、候选栏、工具栏、语音设置与本地模型目录，并检查返回来源页。十张页面截图已人工检查，未点击下载、导入、发送或删除。

- ad-hoc 签名的 iPhone 17 / iOS 27.0 模拟器中，英文纠错 84.978 秒、全拼输入 70.286 秒、开启小鹤提示后检查键面 64.873 秒、十四键选择并上屏「你好」64.263 秒，均通过。
- 数字页原样结束拼音后逐项输入字面值通过，76.135 秒；全拼与九键连续算式、侧栏乘除号及扩展符号往返通过，173.619 秒。最初乘号失败截图实际显示侧栏已滚到除号及 `#+=`，短拖动修正测试的越过目标问题，没有因此修改产品布局。
- 设置持久化遍历按当前二级对话页的顶部返回契约结束，通过；新增隐私、剪贴板历史、快捷模式、帮助、诊断日志与许可页面的真实入口和返回遍历也通过，两项合计 153.558 秒。只检查这些页的导航与关键控件，不代表所有业务动作完成验收。
- 添加语言的宿主跳转确实存在产品缺陷，由[设置路由请求与导航状态隔离](../../implemented/bug-fix/2026-10-20-ios-settings-route-stack-generation.md)单独修复；扩展入口在该修复后通过，44.771 秒。
- 本地 quick 与 `pnpm run verify-notes` 通过。各结果来自有界的多次定向回归，没有把中断或存在失败的整轮套件写成全部通过。

## Consequences

显式准备模式和等待设置保存避免不同用例互相污染，截图保留用于区分操作问题与产品问题。UI 用例仍有意保留上屏内容断言，不用放宽语义来换取通过。真机 USB 当前断开；普通 XCTest 等待空闲后的点按不能证明快速手打延迟改善。模拟器允许准备完全访问；用户真机不重新登记键盘、不修改信任或清空数据。

- iPad 设备族修复后，iPad Air 13 英寸 regular width 的设置分栏与平板专属控件通过 `OnboardingUITests/testTabletSettingsSidebarSelectsPagesAndShowsTabletControls`（9.197 秒），截图已人工查看；iPad mini 竖屏为 compact width，继续使用手机设置栈。该项不改变真机系统键盘九键连续输入仍未完成的结论。

- 设置布局验收用例改为按实际宽度分支：regular width 检查 `NavigationSplitView` 侧栏和两个平板控件，compact width 检查手机导航栈进入「输入」页。这样同一套验收可在 iPhone、iPad mini 和 iPad Air 上运行，不会把合法的 compact 回退误报成产品失败。

- 未登录账号页入口验收通过 `OnboardingUITests/testSignedOutAccountActionsExplainLoginAndStayUnavailable`（12.924 秒）：云剪贴板、手动同步和 QQ 群助手显示登录后可用且保持禁用，我的发布与收藏不伪造登录入口；未开启云剪贴板、未提交绑定码，也未访问需要真实账号的子页。

# Agent Note: 本地目录页去重的小列表路径

Status: implemented

## Problem

emoji、符号和颜文字目录分页在启用去重时，每页都创建 `HashSet` 和重复索引列表。常见候选页只有几十行，却仍产生临时堆分配。

## Decision

目录页不超过 64 行时，按文本线性扫描并原地保留首次出现项；超过边界时继续使用借用文本的哈希集合和重复索引回退。分页游标、空文本处理、首次出现顺序和目录字段保持不变。

## Alternatives considered

始终线性扫描会让允许 4096 行的大页退化为平方级；始终使用哈希表则无法消除常见小页的临时状态。按 64 行边界分流覆盖通常的候选页，并保留大页复杂度。

## Verification

新增短目录页零临时分配测试；完整引擎单元测试（1168 项）、Clippy、Rustfmt、差异检查、笔记检查和 quick 门禁覆盖实现。

## Consequences

64 行以内的本地目录去重直接复用结果 `Vec`，不再创建哈希表或重复索引；大页继续使用哈希回退。

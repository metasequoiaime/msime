# Agent Note: 九键中间切分路径只保存后继索引

Status: implemented

## Problem

固定 `465204211a` 的二十秒、1 ms 九键采样中，`split_paths` 与路径复制、分配释放仍出现在实际按键调用树。每个数字偏移为所有可行前缀复制整条后缀的字符串向量，排序后只保留 48 条；这些中间拥有字符串不会被词典消费。排序键缓存已降低重复扫描，继续减少排序键不能消除这些路径复制。

## Decision

中间偏移保存借用音节、路径长度、频度分、末尾完整标记与后继的列/行索引。后继只引用更大数字偏移已经完成排序、截断的页；构建当前页和排序时不修改它们，索引从不指向尚未定序的当前页。路径字典序用音节迭代器逐项比较，评分仍是当前音节分加原后缀分，保留稳定排序、全部比较项和每偏移 48 条上限。只为最终保留路径构造拥有字符串的 `Path`；缓存状态、公开接口和位数支持不变。

## Historical audit

已按 `split_paths`、SpellingTable、音节路径和切分路径检索活跃笔记。[路径页延后预留](../../implemented/testing/2026-10-11-nine-key-path-lazy-buffer.md)部分重叠，继续保留死路不申请页的规则；[候选查询去重](../../implemented/testing/2026-10-08-nine-key-query-dedup.md)、[候选去重](../../implemented/testing/2026-10-08-nine-key-candidate-dedup.md)只约束切分完成后的候选；锁定切分、全拼单片纠错和结果键复用与路径存储无关。没有完全吸收或过时提案。相邻旧 worktree 的拼写顺序 PR #6733 已关闭，没有复制其未提交内容。

词网格 `Hyp.prev` 已采用定序后前驱索引，本片使用相同的局部所有权模式。[Rust Iterator::cmp](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.cmp)按元素字典序比较，与当前 `Vec<String>` 的比较一致；不引入依赖、unsafe 或固定数组位数上限。

## Alternatives considered

- 中间路径改成 `Vec<&str>`：改动最小，省掉字符串复制，但仍为每个被截掉的中间路径申请向量；后继索引可以同时消除该项成本。
- 每条路径使用固定数组：可直接比较连续音节且无路径堆申请，但 32 项引用让每个排序元素变大，也会限制现有超过 32 位的纯函数测试。
- 只按需复制保留的 48 条：需要先保存可排序的轻量描述；后继索引就是该描述，不再额外维护一套获胜者标记。

## Verification

冻结 `465204211a` 完整旧函数，仅替换接收者并移除注释。旧生产路径的红测试为旧、新各 4285 次申请，无法满足密集路径申请减半；接入后密集路径申请少于一半，空、死路和短路径不增加申请。三项功能测试通过：九键、十四键、Migala2 九键双拼，对照无频度同分和非均匀频度、显式切分、末尾完整、32/42 位及确定随机输入，逐项比较全部输出顺序。

完整函数 release 每形状 40 对，交替先后，旧臂批次校准至少 10 ms，两臂都包括完整构造、排序、逐偏移截断、最终物化和析构。一、两位控制预算小于 1.05，其余形状小于 0.95。首次 16 形状全部通过，但起跑后发现另一个编译进程，保留记录、不作为独占证据；确认无编译进程后原样重跑整套，仍全部通过，未挑样本或放宽预算。

## Consequences

后继索引消除被截掉的中间路径的字符串和向量申请，最终路径仍使用原来的拥有字符串接口。代价是比较字典序时逐节点追链，中间节点元数据也比原元组大；一位默认频度形状耗时增加约 2.3%，仍在预先设定的 5% 控制预算内。索引只指向已定序的后页，根页用 `mem::take` 取出，后页保持原位。

本机 quick 通过，含 Android/WASM、Android Java、macOS 原生与共享 Apple bridge，以及 151 项 Windows 原生测试；Docker、MinGW、HarmonyOS 完整前置不足的阶段跳过。这是编译与单测检查，不是设备 GUI 验收。

局部配对不能推断九键 16 ms 达标；只有完整逐键模型运行能判断该预算。无公开接口、持久缓存、依赖和 unsafe 变化。

后续[种子尾段按采用上限选择与物化](../../implemented/testing/2026-10-17-nine-key-seed-tail-materialization.md)只在根页选择前3条并物化；非根页仍保留完整48条搜索宽度，种子数量与采用条数不变。

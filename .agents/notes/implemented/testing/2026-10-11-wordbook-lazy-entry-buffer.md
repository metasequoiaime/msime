# Agent Note: 单词本空解析延后条目缓冲

Status: implemented

## Problem

插件单词本解析在扫描文件前固定为最多 20,000 条单词预留 `Vec` 和去重 `HashSet`。只有注释或空白行的文件会被拒绝，但在确认没有有效条目前已经申请了整页存储。

## Decision

解析缓冲从空容器开始，首条通过字段校验的单词出现时再按 `wordbook::MAX_ENTRIES` 一次预留条目和去重存储。空解析保持零容量；有效单词本仍保留原有容量提示、重复检查、条数上限和错误语义。

## Verification

新增空词书解析回归测试。旧实现容量为 20,000 时测试先失败，延后预留后通过；单词本原有容量契约、`msime-client-core` 1,262 项测试、Clippy、Rustfmt 和差异检查均通过。

## Alternatives considered

- 继续在扫描前预留：有效单词本路径简单，但空文件和注释文件会申请整页未使用存储。
- 让向量和集合自然增长：空文件同样零容量，但大词书会多次扩容并失去原有的一次性容量提示。
- 根据文件字节数估算容量：需要依赖行长分布，估算不稳定，不能替代首条有效记录后的明确上限。

## Consequences

空或仅含注释的单词本不再申请未使用的 20,000 条存储；有效单词本在首条有效记录出现时仍一次准备最大容量。解析结果和拒绝原因保持不变。

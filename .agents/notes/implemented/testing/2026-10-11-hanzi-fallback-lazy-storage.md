# Agent Note: 汉字反查失败路径延后回退读音缓冲

Status: implemented

## Problem

汉字整词没有精确读音时，逐字回退路径先按整段字符数申请 `Vec`。只要其中一个字没有单字读音，函数就返回空字符串，已经申请的回退缓冲全部浪费；这条路径用于词库标注和批量校验。

## Alternatives considered

继续在逐字循环中边查边写可以少一次哈希查找，但缺少读音的失败路径仍会先申请整段缓冲；按实际已读字符逐步扩容会在成功路径引入多次增长，不能保留现有的一次精确预留。

## Decision

先扫描所有字符，确认每个字符都有单字读音后，再按字符数一次预留并收集借用读音。任何字符缺少读音时在申请结果向量前返回空结果；成功路径继续使用精确容量和原有连接、排序及拼接行为。

## Verification

新增测试在缺少单字读音时确认回退收集不产生堆分配；汉字反查模块测试、完整引擎测试、Clippy、Rustfmt、差异检查和 quick 门禁覆盖提交。

## Consequences

失败回退不再为整段结果申请指针缓冲；成功回退增加一次哈希表预检，但保留一次精确结果分配和原有读音顺序。

# Agent Note: 九宫格候选去重的小列表路径

Status: implemented

## Problem

九宫格候选排序后会按词面去重。旧实现即使只有少量候选也创建临时 `HashSet` 和重复索引列表，短查询因此产生不必要的堆分配。

## Decision

候选不超过 64 条时，按排序后的顺序线性扫描已保留词并原地压缩；超过边界时继续使用哈希集合和重复索引回退，避免大候选集退化为平方级比较。首次出现顺序和后续候选上限保持不变。

## Alternatives considered

始终线性扫描会让九宫格候选扩展到上百条时退化；始终保留哈希路径则无法消除常见短查询的临时状态。按 64 条边界分流覆盖短列表并保留大列表复杂度。

## Verification

新增短候选零临时分配测试；完整引擎单元测试（1167 项）、Clippy、Rustfmt、差异检查、笔记检查和 quick 门禁覆盖实现。

## Consequences

64 条以内的九宫格候选去重复用原有 `Vec`，不再创建哈希表或重复索引；大候选集继续使用哈希回退。

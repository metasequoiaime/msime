# Agent Note: 固定位置入口借用候选行

Status: implemented

## Problem

`InputSession::set_candidate_position` 在判断候选是否可编辑前无条件克隆完整 `WordItem`。不可编辑的临时英文或在线行会在操作被拒绝前复制词、拼音和其它字段，成功路径也只需要借用这些字段。

## Decision

固定位置入口直接借用候选行，先完成来源校验，再用借用的来源、拼音、规范拼音和词文本执行固定位置读写。可变刷新仍在所有借用结束后调用，固定位置和诊断行为保持原有顺序。

## Alternatives considered

- **继续克隆完整候选行**：代码最简单，但拒绝操作也会为不会使用的字段分配内存。
- **只在通过来源校验后克隆**：能消除拒绝路径的分配，却仍复制成功路径实际可以借用的文本。
- **让固定位置存储接口接管候选行借用**：会扩大用户词典接口的借用边界，并把会话刷新生命周期带进存储层。

## Verification

新增不可编辑候选的固定位置回归测试：旧实现分配 2 个缓冲，借用后为 0。189 个会话测试、31 个 golden 测试、Clippy、Rustfmt、差异检查和 `bash scripts/verify-local.sh --quick` 均通过。

## Consequences

拒绝固定位置操作不再克隆完整候选行，成功操作也只在固定位置接口需要时读取候选字段；来源判断、固定位置写入、刷新和错误诊断保持不变。

# Agent Note: 学习句子长度判断复用分隔符计数

Status: implemented

## Problem

选择候选并准备写入学习词库时，只需要判断规范化拼音是否超过七个音节，却通过 `split_segments` 创建所有音节字符串和向量。长句选择会为一个只读长度检查支付不必要的临时分配。

## Decision

学习路径使用私有 `segment_count` 直接统计撇号分隔符，空输入仍返回零，并保留原有句子长度上限和规范化语义。分配计数测试覆盖连续、首尾和空分隔符输入与既有分割结果一致。

## Alternatives considered

继续调用 `split_segments` 代码更短，但每次选择都会复制音节文本。把计数函数放进共享分段模块可以复用，但本次只有学习路径需要该判断，会扩大公共接口而没有跨模块收益。

## Consequences

句子长度检查不再创建临时音节字符串，候选学习行为和七音节上限保持不变。分隔符计数依赖规范化函数已经保证的拼音格式；真正需要音节内容的学习逻辑仍继续使用 `split_segments`。

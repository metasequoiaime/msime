# Agent Note: 五笔拼音回退大批次去重单次扫描

Status: implemented

## Problem

五笔没有候选而拼音回退批次超过短列表边界时，旧实现先创建 `HashSet` 检查批次是否全唯一；发现重复后又创建第二个哈希表和重复索引来完成原地去重，重复批次因此扫描并分配两次哈希状态。

## Decision

候选为空时统一调用批次去重函数：不超过 64 行继续线性扫描，超过边界直接使用一次哈希表和重复索引原地保留首次出现的行。全唯一的大批次仍复用输入缓冲，含重复词的大批次不再先做全唯一预检。

## Alternatives considered

保留全唯一预检可以让全唯一批次少建重复索引，但重复批次会重复创建哈希表；统一一次去重在全唯一输入上仍只有一次哈希扫描，在重复输入上消除第二次集合分配。把所有大批次改成线性扫描会让词典结果退化为平方级比较。

## Verification

新增 65 行批次含一个重复词的分配计数测试；旧实现测试记录 9 次分配，新实现不超过 2 次。完整引擎单元测试（1166 项）、Clippy、Rustfmt、差异检查、笔记检查和 quick 门禁覆盖实现。

## Consequences

五笔无候选的重复拼音回退批次只建立一次大批次哈希状态，同时保留 64 行以内的零临时状态路径和首次出现顺序。

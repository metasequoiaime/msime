# Agent Note: 全拼路径缓存工作集诊断

Status: implemented

## Problem

[短键实验](../../rejected/testing/2026-10-23-quanpin-inline-path-key.md)记录了公开九键集合中 183332 次路径页未命中，其中 165888 次为空。只知道未命中总量，不能判断重复距离、空页对非空页的挤占、扩容代价或负缓存是否值得独立保存。

## Decision

固定 `11cdc33ba64dc95adb3c4621a185ddd26088a524`，保留原始 release 程序。诊断工具临时包装私有路径缓存，转发原 `FifoCache` 的全部操作，记录无碰撞的进程内数字键编号、查询/探测/插入/清空、完整候选内容摘要及真实请求容量。编号只在内存中对应完整键，日志不输出输入或词面。诊断源码在构建后逐字恢复，程序只运行固定公开合成集。

离线重放首先逐事件核对原 128 槽的实际命中，再估算固定访问序列下的容量矩阵、空页分流和跳过空页。统计缓存持有的键与候选堆请求字节，不将其称为 RSS。跨查询命中核对候选内容摘要。探测命中会影响上层去重，因此改变容量的重放只是候选筛选证据，不能替代真实执行或质量验证。产品容量与所有缓存规则保持原样。

## Historical audit

按路径缓存、`CACHE_CAPACITY`、FIFO、负缓存及工作集检索活跃笔记。[短键实验](../../rejected/testing/2026-10-23-quanpin-inline-path-key.md)部分重叠，继续持有三种键表示的否决理由；[短前缀追加](../../implemented/testing/2026-10-16-quanpin-prefix-row-stream.md)继续约束借用页及冷页所有权；[淘汰页复用](../../implemented/testing/2026-10-23-quanpin-evicted-page-reuse.md)只作用于外层系列页，不扩展其适用范围。没有相同工作集工具或需要吸收的过时提案。

## Alternatives considered

- 直接扩大 128 槽：改动最小，可能减少页重建；缺少重复距离和峰值内存证据，先不改产品常数。
- 直接删除空页缓存：能省空键和淘汰操作；负查询可能被反复执行，须先量出固定序列上的读库代价。
- 从采样比例推算容量：无需插桩，但采样无法恢复键的重复顺序，不能判断命中或内存代价。

## Verification

原 128 槽的 657892 次查询逐事件核对通过，183332 次未命中与前片数字诊断一致，4 个实例均正常析构，实际只有两个实例收到查询。没有前缀可选探测或外部展开插入。12 个资源逐项核对大小与 SHA-256，诊断与原程序的九键 81 例完整质量 JSON、全部候选 JSONL 逐字节相同。手工序列核对插入年龄、清空、内容变化、错误轨迹拒绝及请求字节口径。

固定访问序列中 90894 次未命中是同一清空周期内重复查询；正式两臂的 3582 次刷新里，400 次超过 128 个不同查询键。256 槽重放的未命中降至 128588，缓存页复制申请从 3505616 降至 1909250。键与候选页峰值请求字节从 1412959 增至 1413701；该数字不包括节点、哈希表和诊断编号表。更大容量及空页分流的全部预定配置均保留在[测量目录](../../../../docs/measurements/2026-10-23-quanpin-path-cache-working-set/README.md)。

首轮诊断构建因 `sha2 0.11` 输出不实现 `LowerHex` 失败，恢复后改用现有 `hex::encode` 重建通过。未更改依赖。诊断运行因原 16 ms 预算失败而退出 1，不作为产品延迟成绩。源码逐字恢复，产品与依赖没有差异；格式、Python 语法、证据摘要和笔记检查通过。完整本地 quick 在 382.816 秒后退出 0，契约、1749 篇活跃笔记与 4 篇归档封印、Rust 工作区及共享 Apple 桥接层通过；原生平台阶段按文档范围跳过，没有设备验收。

## Consequences

诊断的全键编号表、摘要及输出会增加分配和调度成本，所有诊断计时无效。候选页、键与节点/哈希表元数据必须分别报告。固定序列不包含改变容量后可能省去的后续查询，不能将估算未命中数当成完整按键收益。

256 槽的固定序列收益尚未接入产品。[冷页压缩](2026-10-23-quanpin-path-page-compaction.md)保留 128 槽及展开页寿命，只减少普通页的持有字段。`expand_initial_candidates` 会向路径缓存写入首字母展开页，延长其存活可能改变候选行为，而本集合没有触发该写入；不能仅凭当前摘要一致扩大产品缓存。后续须核对展开、重置、词典与个人资料变更及不同输入网格，补齐元数据内存代价，并测真实执行。默认九键 16 ms 目标仍未验证。

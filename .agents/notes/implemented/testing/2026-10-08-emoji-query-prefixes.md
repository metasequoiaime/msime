# Agent Note: 表情查询复用前缀存储

Status: implemented

## Problem

`local::emoji::query` 的全拼查询只有一个前缀，却会克隆小写字符串并创建 `Vec<String>`；双拼查询也只需要原始前缀和一个可选的归一化前缀。

## Decision

使用借用的小写前缀和可选的归一化字符串组成 `QueryPrefixes`，通过迭代器传给数据库读取逻辑。全拼路径不再创建前缀 `Vec` 或额外字符串克隆，双拼路径仍按原顺序查询两个前缀。

## Alternatives considered

继续保留动态前缀 `Vec` 会为最多两个元素的固定查询状态分配堆内存；复制所有前缀到固定拥有数组仍会保留不必要的字符串克隆。借用原始前缀、仅在双拼归一化确实不同的时候拥有第二个字符串，能保持数据库接口和结果排序不变。

## Verification

新增全拼前缀零分配测试；完整表情模块测试、引擎完整测试、Clippy、Rustfmt、差异检查、笔记检查和 quick 门禁覆盖实现。

## Consequences

常规全拼表情/颜文字查询少一次前缀字符串分配和一次 `Vec` 分配；双拼匹配、去重、排序和结果权重保持不变。

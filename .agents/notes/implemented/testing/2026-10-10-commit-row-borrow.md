# Agent Note: 临时模式提交借用候选行

Status: implemented

## Problem

`InputSession::commit` 在所有方案和候选来源上先克隆完整 `WordItem`。临时输入模式中的生成或回退候选只需要提交显示文本、执行一次学习入口并清空组合，复制行内拼音、纠错信息和句子词列表没有用途。

## Decision

在完整候选克隆前识别临时模式中的非英语词典候选，借用其词文本生成提交结果，并先调用原有学习入口，再重置链和组合。临时英文的英语词典候选保留原路径，因为非首位候选仍可能需要英语频率调整；普通拼音候选和其它方案继续走原有完整提交流程。

## Alternatives considered

- **继续为所有候选克隆完整行**：逻辑统一，但临时模式的生成候选会为不会读取的字段分配内存。
- **把所有方案改成字段级提交状态**：可以进一步拆分复制，但会把候选生命周期改动扩展到词典学习、个人上下文和组字推进。
- **仅复制 `word` 后跳过学习入口**：分配更少，却会改变临时辅助码、快速短语或英语候选的学习行为。

## Verification

新增临时英文 `Fallback` 候选提交的分配回归测试：旧实现为 5 次分配，借用早退后不超过 3 次；现有全拼、双拼、前缀、混合五笔、长词和学习测试均通过。

## Consequences

临时模式的非英语词典候选不再克隆完整 `WordItem`；提交文本、学习调用、链重置和组合清空顺序保持不变。英语词典候选和普通候选仍使用原有路径。

# Agent Note: 自动纠错范围键直接拼接

Status: implemented

## Problem

自动纠错规划每个候选键时先复制音节范围到临时 `Vec<String>`，再替换一个音节并调用通用拼接；短范围中的每个音节和替换文本都会产生多余复制。

## Decision

新增直接拼接替换范围的辅助函数，按目标位置写入纠错音节，其余位置直接借用原始字符串；预留最终键的精确字节容量。

## Alternatives considered

继续构造临时音节向量会保留每个候选键的中间分配；复用可变范围缓冲会与输入切片的借用和嵌套循环冲突。直接构造最终键只保留调用方需要的拥有型字符串。

## Verification

新增分配计数测试，旧范围复制实现分配 6 次，新实现仅分配最终字符串 1 次；另逐一验证所有短范围及替换位置、空替换和不同长度替换的内容与容量。自动纠错相关测试、引擎完整单元测试、Clippy、Rustfmt、差异检查、笔记检查和 quick 门禁覆盖实现。

## Consequences

每个计划中的纠错键只分配最终 `String`，不再为短音节范围创建临时 `Vec<String>` 或克隆替换音节。

词网格跨度的固定别名规范化采用[独立的借用查询键规划](2026-10-10-pinyin-lattice-span-key-plan.md)，保留本篇纠错替换位置和范围拼接行为。

# Agent Note: 学习排名借用候选列表

Status: implemented

## Problem

频率学习在每次调整前先把完整排序列表克隆到临时 `Vec<WordItem>`，随后又按英语来源或混输方案筛选出实际参与排名的行，导致完整列表和筛选列表重复分配与复制。

## Decision

学习流程直接借用 `ranking_list()`，只为实际参与排名的行调用一次 `clone_matching_rows`。选中行仍单独拥有自己的副本，排名请求仍收到独立的拥有型筛选列表。

## Alternatives considered

让排名接口改为接受借用并行过滤器会扩大用户词典 API 的生命周期约束；复用一个会话级工作缓冲则需要处理学习期间的重入和借用冲突。局部借用排序列表并只复制筛选结果，保持现有接口和写入语义不变。

## Verification

新增测试验证筛选复制只保留匹配行；旧实现没有该局部复制路径，测试先因辅助函数不存在而失败，改造后通过。频率学习回归、引擎完整单元测试、Clippy、Rustfmt、差异检查、笔记检查和 quick 门禁覆盖实现。

## Consequences

频率学习不再为未参与排名的候选行创建中间副本；排名请求仍拥有其筛选列表，后续数据库写入和候选顺序保持不变。

# Agent Note: 词网格假设复用图边的起点标记

Status: implemented

## Problem

九键最新栈采样中，`decode_graph` 是最大的引擎计算热点。每条展开假设的 `prev: Option<(usize, usize)>` 与 `edge: Option<&Edge>` 都标记是否为搜索起点，构造处始终同时为空或同时非空。独立的前驱判别占据额外机器字，并随每条扩展写入、排序和预留列存储传播。

## Decision

前驱改为普通列号与行号对，起点填 `(0, 0)`，只由 `edge` 判定是否需要访问前驱。个人上下文仍只在前驱列大于零时读取更早词，回溯先检查图边再访问前驱。候选顺序、束宽、前驱索引、评分算术和表缓存保持。

检索活跃树未找到相同假设布局决定。[二元评分缓冲](../../implemented/testing/2026-10-11-lattice-bigram-lazy-reserve.md)管理同一解码入口的评分行，不替代其生命周期与评分决定；[桶内键切片](../../implemented/testing/2026-10-15-ngram-bucket-key-slice.md)管理查表循环，本项不改变查表次数或键。

列预留条数由后续的[可达假设容量](../../implemented/testing/2026-10-15-lattice-column-capacity.md)收紧；本篇的四十八字节布局参考同时冻结原列容量函数，避免共享新容量而漂移。下列堆数据保留本次布局改动时的测量，后续容量收益单独计量。

[回溯错字边计数实验](../../rejected/testing/2026-10-15-lattice-traceback-typo-count.md)尝试进一步移除派生字段，虽减少逻辑存储，但原生产入口的无表单边短图超过事前回退预算而被否决；产品继续保留四十字节假设和本篇已经落地的决定。

[唯一预算回溯](2026-10-15-lattice-return-budget.md)随后减少未返回路径的物化；本篇内存预算改以固定四十字节、完整物化参考保持原有测量边界，保留严格分配等式，当前产品输出减少由该篇独立精确预算守住。

## Alternatives considered

- 保留两个 `Option`：每个字段可独立表意，阅读最直接；但当前所有构造都遵守同一不变量，无须重复保存判别状态。
- 改为前驱引用：回溯可减少一次索引，但列向量排序和移动会改变对象地址；为了稳定地址另行分配或引入不安全访问会扩大生命周期边界，本项保留索引。
- 缩小整数或减少假设数量：可以更大幅度降低存储，但分别引入输入上限或改变搜索质量，不采用。

## Verification

旧实现布局预算先失败：macOS arm64 的 `Hyp` 实测 48 字节，预算 40 字节。改用普通索引对后为 40 字节，单条假设减少六分之一。测试按 `f64` 加四个机器字计算预算，不把所有目标硬编码为四十字节。

测试保留固定 `2446934521` 的旧 `Hyp`、比较器、剪枝及完整 `decode_graph`，除注释与格式外逐字核对。四个合成种子、0/1/4/8/16 列、0/1/4/16 边、0/1/4/32 束宽、0/1/5/12 路径预算、32 种二元表/三元表/个人模型/备忘/附加图组合，共 40960 组分别重复两次，检查完整输出字段、顺序和评分位模式；新旧使用独立备忘，覆盖冷、热两轮。旧独立穷举对照继续覆盖内侧空列与跨列错字边。

## Quality and integration

固定资源代次 `7356c4a452d8ba15475c0e57f134fccf7b7cbe267440461541c74d09b11b6ffe`、模型 pin `0f19789abbad5aa887e3b27088bf168acf6e9098`，旧新版分别构建 release 评测程序。全拼组合（`sentences-v1` 与 `sentences-nine-key-v1`）141 条和九键 81 条，在默认模式及 `--keyboard-neural` 两种设置下，四份完整 JSON 逐字段相同；没有更改质量基线。默认设置的全拼 top1/top9 为 0.801/0.830，九键为 0.617/0.728；开启该选项后分别为 0.801/0.816 与 0.605/0.728，两组设置不能混用。旧程序所在 `6795b78c` 与本分支起点 `2446934521` 的 engine/runtime 源码无差异。

指定同一固定资源为 `MSIME_NEURAL_MODEL_DIR`，release 完整测试：引擎 2116 项、golden 31 项、runtime 288 项通过，21 项按既有设置忽略；两 crate 的全部 target 通过 Clippy。Clippy 修正仅是新增测试生成器按当前工具链使用 `is_multiple_of`，不影响生产代码。fmt、差异检查和笔记门禁通过。模型专用变量让键盘模型对照实际执行；没有提供历史 `dict-v2.0.1` 专用资源，相关夹具按既有逻辑跳过，当前词库由上述四份质量报告覆盖。

本地 quick 通过：Windows 本机 149 项、Linux 原生宿主 87 项，以及 Rust workspace、Android Rust/Java、WASM、Linux 设置外壳、macOS 原生宿主与 Apple bridge 编译。当前 worktree 缺前端依赖，HarmonyOS 设置 bundle 跳过；ArkTS 暂存输入、Windows MinGW/x86 和 pipe-only 环境缺失的阶段按脚本跳过。没有把这些编译与单测写成设备验收。

不带采样的 `rerank_latency --set resources/eval/sentences-nine-key-v1.tsv --nine-key` 按旧／新／新／旧运行，资源和模型同上，每臂 1791 键，丢弃五条预热。计时期间没有本任务的构建、测试或其它 benchmark。

## Consequences

本机假设列存储减少六分之一；最短有表图在本机配对中出现约 3.04% 回退，仍在事前 5% 上限内，不声称所有图都加速。前驱对不再单独表示起点，未来构造必须继续通过 `edge` 判定有效性。布局依赖目标机器字宽度，测试按字段所需机器字计算，不硬编码所有平台为四十字节。没有生产文件读写、目录遍历、权限或 Android 资源改动，本项没有设备验收结论。合成图和进程内评测不覆盖宿主绘制或设备延迟，不能由存储减少宣布九键十六毫秒已通过。

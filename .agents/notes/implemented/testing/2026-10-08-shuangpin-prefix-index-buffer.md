# Agent Note: 双拼前缀候选合并复用单一索引缓冲

Status: implemented

## Problem

双拼前缀候选总量超过短列表阈值时，合并逻辑为每个前缀行建立重复索引 `Vec`，再建立外层索引集合，临时堆分配随前缀组数增长。

## Decision

先为所有前缀行预留最终候选容量并把行移动到同一缓冲，只建立一个跨组去重索引缓冲；释放借用词面后按索引原地压缩，保持已有候选和每组首次出现的顺序。

## Alternatives considered

继续为每组保存重复索引会保留多次临时分配；改成全量线性扫描会让大列表去重退化为平方复杂度；把词面复制进哈希键会增加每个候选的字符串分配。

## Verification

新增大列表分配回归测试：旧实现产生 13 次临时分配并按预期失败，单一索引缓冲实现降至不超过 2 次并通过。双拼 dictionary 测试、完整引擎测试、Clippy、格式检查、笔记检查和 quick 门禁覆盖提交。

## Consequences

大前缀列表仍使用哈希去重，复杂度不变，但临时索引从每组一份降为合并过程一份；结果容量一次预留，后续按唯一行压缩。

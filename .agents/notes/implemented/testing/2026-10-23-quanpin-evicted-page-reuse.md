# Agent Note: 全拼冷页复制复用 FIFO 淘汰页

Status: implemented

## Problem

`6fa568ce12fa7d6c129fce7c4428eb4e8a1717d1` 的九键诊断采样在输入阶段记录 47607 个主线程样本，其中分配和释放 10031 个；7237 个分配样本归属全拼，完整缓存插入和 `WordItem::clone` 都在主要调用链中。采样与外部构建重叠且负载很高，只能定位热点，不能作为延迟成绩。冷页全保留时复制完整页入缓存，满 FIFO 同时丢弃旧页；同形状字符串和向量缓冲区可供本次复制复用。

## Decision

只有无模糊的冷页全保留路径延后复制。谓词仍按原顺序对每行调用一次，全部执行成功后才插入缓存。插入通过 `lru::LruCache::push` 回收旧值并复用节点，不先删除节点。新槽填入独立完整副本，原页继续作为输出。缓存中的每个向量、字符串只在旧容量等于新内容长度时复用，否则按普通 clone 申请，保持原有缓存容量。没有额外持久回收池，不扩大容量，不改其它冷页、热页、模糊、失效或个人计分登记。

## Historical audit

[冷页投影](../../implemented/testing/2026-10-16-nine-key-cold-cache-projection.md)部分重叠：保留其完整缓存、全留返回原页、部分筛选缩容规则，新增淘汰页复用。[排名前置](../../implemented/testing/2026-10-16-nine-key-dominated-row-projection.md)仅管热页，继续保留。[全拒绝延后申请](../../rejected/testing/2026-10-18-nine-key-empty-projection.md)曾未通过门槛，本方案不改变全拒绝结果页预留。[前缀组装](../../implemented/testing/2026-10-16-quanpin-prefix-row-stream.md)及[原始行投影](../../implemented/testing/2026-10-14-quanpin-row-cache-projection.md)管其它层，保留。检索未发现已有淘汰页复制复用实现或可吸收的提案。

## Alternatives considered

标准库 [String::clear](https://doc.rust-lang.org/std/string/struct.String.html#method.clear) 保留容量，[Vec](https://doc.rust-lang.org/std/vec/struct.Vec.html) 的容量与长度相互独立；本方案只在容量等于新长度时覆写。固定依赖 [lru 0.18.5](https://docs.rs/lru/0.18.5/lru/struct.LruCache.html#method.push) 的 `push` 返回淘汰值，源码 `replace_or_create_node` 在满容时复用节点。接口及节点复用行为均以锁定的本地依赖为准。真实查询的形状命中率与净延迟收益仍需独立测量。

- 使用字段和向量的 `clone_from`：代码少且可复用容量，但会保留超过新内容长度的旧缓冲区，增加缓存持有量；派生 `WordItem::clone_from` 也不能保证逐字段复用。
- 先移除最旧页，再复制后插入：容易取得拥有值，但丢失 `lru` 已有节点复用，增加节点分配，且谓词 panic 时可能改变缓存。
- 缓存只存筛选结果：能减少更多复制，但后续其它过滤条件需要完整页，不能采用。
- 共享 `Arc` 字段：能减少整个链路的复制，但会扩大类型、快照和学习边界的修改范围。

## Verification

冻结的两个完整函数与 `6fa568ce12fa7d6c129fce7c4428eb4e8a1717d1` 机械核对一致：去掉注释、还原私有方法名并统一 rustfmt 后比较，不借用修改后的投影核心。有效红测中，一行满缓存的旧入口仍有 22 次申请，无法省去完整副本的 4 次申请。修改后专项 6 项通过，1/4/32/128 行的满缓存全保留分别从 22/40/208/784 次降到 18/27/111/399 次，精确省下 4/13/97/385 次；未满时仍为 23/41/209/785 次。

专项同时核对冷/热、全留/全拒绝/部分筛选、模糊、标记、清缓存、数据库更新、逐行访问与独立输出；形状矩阵核对全部字段及内外层容量。四次被捕获的合成谓词 panic 均发生在淘汰前，原 FIFO 各页与年龄保持不变。嵌套字段同容量复制为零申请，并核对实际指针复用。全拼、九键和 14 键各 81 例的完整质量 JSON 与全部候选 JSONL 均与固定基线逐字节相同。`convert_eval` 关闭英文混输，这部分只验证中文控制。完整引擎 2505 项、golden 31 项、运行时 364 项及文档测试通过；56 项沿用忽略。严格 engine/runtime all-targets Clippy 通过。最终门禁与运行证据见[测量目录](../../../../docs/measurements/2026-10-23-quanpin-evicted-page-reuse/README.md)。

完整本地 `--quick` 重跑退出 0，原检查和超时保持不变。首次运行唯一失败为语音目录生成器的 Cargo 命令超过 120 秒；预构建后，未修改的独立检查和完整门禁均通过。两次结果均保留。Linux 原生 111 项测试、Linux 桌面外壳、macOS 原生宿主和 Apple 桥接层编译通过；Windows 交叉编译及 HarmonyOS ArkTS 因环境缺失跳过，没有设备或原生界面验收。

ABBA 只有一次启动尝试：180.462 秒内的 161 次观察均有外部工具，load1 为 120.354–162.353，没有取得连续 30 秒空闲条件。结果为 `timed=false`、0 个计时臂，退出后程序哈希仍与启动前一致。没有由此推断净耗时改善，默认九键 16 ms 目标仍未验证。

## Consequences

逐字段复制容易遗漏未来新增字段，因此使用穷尽解构和结构体字面量，让字段增加触发编译错误。复用只覆盖冷页全保留且有淘汰页的情况；形状不匹配时仍会分配，不能把局部申请减少推断为完整按键的确定提速。

容量断言针对缓存持有的逻辑请求容量，不等同于进程 RSS。若真实查询的形状命中率很低，应重新评估这条路径的收益；默认九键 16 ms 目标继续保留。

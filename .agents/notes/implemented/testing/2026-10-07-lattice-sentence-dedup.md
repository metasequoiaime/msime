# Agent Note: 词网格终点路径的小列表去重

Status: implemented

## Problem

词网格终点默认只保留 `beam = 32` 个假设，神经重排也只请求有限的 n-best 路径，但终点句子去重仍为每次解码建立 `HashSet` 和重复索引数组。

## Decision

终点去重沿用 64 条边界：小列表扫描已保留句子，大列表使用哈希表回退，均保留原有路径顺序和重复句子的首条路径。批次去重 helper 继续执行原地压缩及 `take` 上限。

[唯一预算回溯](2026-10-15-lattice-return-budget.md)把不超过 64 条末列的查重移到物化过程中，收齐唯一 `take` 条路径就停止；大末列仍完整物化并调用本篇 helper。上限按剪枝后假设数判断，因此不会把本篇的大列表回退改成无界线性扫描。

## Alternatives considered

所有终点路径都改用线性扫描会让调用方传入大 `beam` 时退化为平方复杂度；只限制集合容量仍会保留临时堆状态。

## Verification

新增 32 条终点路径的零分配测试，确认去重后保留 12 条路径；既有词网格排序、n-best 上限和重复句子测试继续覆盖行为。

## Consequences

64 条以内的去重时间复杂度为平方级，但默认 beam 有明确小上限；更大的自定义 beam 继续走哈希表路径。

[默认整句行所有权转移](2026-10-14-generated-lattice-row-ownership.md)直接把默认分支路径字段交给候选，沿用解码唯一性、去重和块容量规则；神经分支继续借用并复制实际输出字段。

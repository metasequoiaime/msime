# Agent Note: 粤语首选分段避免收集无用路径

Status: implemented

## 问题

`CantoneseScheme` 每次读取当前输入时只需要首选分段，但 `best` 先收集最多 16 条完整分段，再取第一条，完整读音路径因此多了一次结果向量分配。

## 决策

为 `best` 增加只寻找第一条路径的递归遍历，沿用原有最长片段优先、前缀处理和不可达位置缓存。只有公开的 `segment` 接口继续收集全部分段，首选读音不再建立无用的结果向量。

## Alternatives considered

- **继续调用 `segment` 后取第一条**：改动最小，但每次完整读音仍会为其余路径建立结果向量。
- **改变公开的 `segment` 返回值**：可以避免内部重复遍历，但会破坏需要全部备选分段的调用方契约。

## 验证

新增完整粤语读音的分配计数回归，确认首选结果正确且分配不超过 3 次；粤语分段测试全部通过。提交前继续运行引擎全量测试、golden、Clippy、Rustfmt、差异检查、笔记校验和 quick 门禁。

## 影响

完整读音的 `best` 路径少一次临时堆分配，回退到最长完整前缀和公开的多路径 `segment` 行为保持不变。

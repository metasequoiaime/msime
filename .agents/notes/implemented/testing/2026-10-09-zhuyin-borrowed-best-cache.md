# Agent Note: 注音词频查询借用缓存词条

Status: implemented

## Problem

注音九键重算读音排名和歧义权重下限时只读取词频，但 `cached_best` 每次命中都会克隆整个词条及其键。三条读音的热缓存刷新因此仍分配九次，其中六次来自马上丢弃的字符串副本。

## Decision

让 `cached_best` 返回缓存词条的借用，使用 `HashMap::entry` 在未命中时查询并直接保存结果。只有转换路径需要持有通过权重下限的词条时才克隆；只读词频以及被权重下限过滤的词条不再复制字符串。

## Alternatives considered

单独增加词频缓存会重复维护最重词条并扩大失效边界。引入共享所有权会改变转换结果类型。借用现有缓存即可消除只读词频的复制，同时保留当前转换接口。

## Consequences

缓存仍保存命中和缺失结果，查询错误不写入缓存。词频、排名、转换文字和错误传播保持不变；热缓存读音刷新仍为三个缓存键分配，词条文本与读音键不再额外克隆。

## Verification

收紧原有热缓存刷新分配预算后，旧实现在九次分配处失败；优化后预算为不超过三次。缓存回归测试覆盖首次查询、命中、缺失结果与重复查询错误。注音单测、引擎全量单测、golden、Clippy、Rustfmt、笔记校验、差异检查和 quick 门禁用于验证本切片。

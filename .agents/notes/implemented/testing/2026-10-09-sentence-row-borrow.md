# Agent Note: 句子学习借用候选行

Status: implemented

## Problem

真正可学习的生成拼音句子在 `learn_candidate` 中先完整克隆 `WordItem`，再执行句子学习；句子学习只需要读取候选字段，直到调用可变的用户词典写入接口前都不需要拥有整行。

## Decision

让句子学习入口接收排名索引并在内部借用 `ranking_list()` 中的候选行。错拼记录改用共享借用，规范读音和长度校验期间继续借用候选字段；在在线读音校验和用户词典写入前仅复制 `word`，让候选行借用结束后再进行可变操作。无 canonical 读音的在线候选仍按原逻辑生成会话分段，原有可学习条件、错拼诊断顺序和在线字典校验保持不变。

## Alternatives considered

- **继续克隆完整 `WordItem`**：实现简单，但每次选择可学习句子都会复制未参与写入的来源、拼音和关联字段。
- **让词典写入接口接受候选行借用**：会扩大可变会话借用范围，影响在线校验和其它学习写入的现有接口。
- **只复制需要写入的 canonical 与 word**：仍会复制 canonical 的拥有型字符串，且无法覆盖错拼检查阶段的整行克隆；使用 `Cow` 只在在线无 canonical 时拥有分段结果。

## Verification

新增混合五笔中生成拼音句子的提交回归，确认文本提交、会话清空、无诊断和用户词典写入。旧实现为 202 次分配，借用实现为 196 次。`cargo test -p msime-engine`（1342 个单元测试、31 个 golden 测试）、Clippy、Rustfmt 和差异检查通过。

## Consequences

可学习句子提交减少候选行克隆和相关分配，同时保留原有学习、错拼记录、在线校验和诊断行为。句子学习入口改为索引参数，调用方不再需要先拥有候选副本。

相关决定：[本地生成候选跳过学习行克隆](2026-10-10-sentence-learning-guard.md)、[提交借用候选行](2026-10-10-commit-row-borrow.md)。

候选规范读音校验由[借用音节校验](2026-10-10-canonical-reading-borrow.md)独立消除临时音节容器，保留本篇调用行为与长度规则。

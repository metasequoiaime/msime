# Agent Note: 搭配评分按假设复用上下文尾窗

Status: implemented

## Problem

`decode_graph_with_terminal` 为同一假设的每条出边重新调用 `collocation_tail`，沿相同的 `prev` 链回溯并截取最后八个码点。出边只改变评分器的词和句尾标志，不改变上下文尾窗；宽列将这部分工作重复几十次。默认未启用搭配模型的九键 16 ms 超预算不由这项修复解决。

## Decision

保持 `Hyp` 大小、图边和评分顺序，在每个有出边且搭配评分激活的假设中只计算一次尾窗。尾窗的最终 UTF-8 校验也在循环前完成，所有出边借用同一个字符串；无出边、没有评分器、权重不大于零时不计算。评分器的调用次数、次序、参数和浮点累加分组保持。

## Historical audit

[octagram 读取与逐边评分](../../implemented/feature/2026-10-21-octagram-grammar-model.md)部分重叠：继续沿用激活时回溯及 `Hyp` 不增字段的决定，本篇只改变同一假设内的重复计算。检索 `collocation_tail`、搭配尾窗和假设尾窗，只有该篇直接持有当前机制，没有完全吸收或过时提案。前缀增量解码仍需独立证明跨界词边、束顺序和失效，不在此接入。

## Alternatives considered

- **把尾窗存进每个 `Hyp`**：展开时可以常数访问，但所有未开启搭配模型的假设也增大，原 octagram 决策已明确避免这项成本，不采用。
- **评分器内部缓存尾窗**：能省部分编码，却不能省调用前的重复回溯，还引入缓存身份和失效，不采用。
- **保持逐边回溯**：代码简单且不增加假设字段，但相同 `done`、`pos`、`index` 在出边循环内不变，重复工作可以用一个栈上临时值去掉。

## Testing

固定 `6d9cb3da7fa6cd85baf7abce937b4fa7a252cb5a` 的完整旧解码入口随测试保留，去注释、私有函数改名和空白后的机械对照一致。debug 红测试在扇出 2 时观察到 3 次回溯，超过每假设一次的 2 次上限；修改后三项专项测试通过。两列扇出 1/2/8/32/128 的冻结旧回溯次数分别为 2/3/9/33/129，新入口均为 2。无出边、没有评分器、权重为零、负数或 NaN 时均不构造尾窗。审查第一版发现 `as_str()` 仍逐边校验 UTF-8：扇出 2 的第二轮红测实测 4 次，目标 3 次。最终代码一并外提字符串借用；同组扇出旧入口校验 3/5/17/65/257 次，新入口均为 3（含短词拼接时内部的一次校验）。

640 组完整对照覆盖空图、单列与长图、不同束宽和终点预算、相等分、主图与附加纠错图、多字节和八码点尾窗、搭配关闭/零权重/开启，以及 bigram/trigram/个人模型组合。全部路径字段与分数位模式相同，评分器回调的尾窗、词、句尾标志和调用顺序相同。普通分配器的 release 程序也通过这项完整对照；debug 计数代码不进入 release。

完整引擎 2480 项、golden 31 项、runtime 362 项测试通过，54 项既有及显式性能测试忽略。未提供真实 `.gram` 或神经模型路径，不把按环境跳过的模型检查称为实测。

本机 ARM64 / Rust 1.97.1 release 的两处旧尾窗调用与最终 UTF-8 校验均在评分器调用的最内层自然循环内，新入口两处均在循环外；编译器未自动完成这次外提。普通分配器完整解码的 18 形状 × 21 对脚本已构建，但第一版连续 180 秒未满足空闲启动条件，未执行计时；最终版未重试计时。没有耗时比值或性能预算失败，不把指令位置或 debug 次数换算为产品提速。[证据与复现](../../../../docs/measurements/2026-10-23-lattice-collocation-tail/README.md)保存完整反汇编、等待、红绿测试和源码恢复记录。

最终代码经 fmt、全目标 Clippy（`-D warnings`）和本地 quick 门禁核对；门禁中的平台跳过与覆盖边界以证据 README 及日志为准。

## Consequences

开启搭配评分时省去同一假设多条出边的重复回溯及最终 UTF-8 校验，仍对每条出边执行评分器并沿原顺序加分；无常驻缓存、失效策略或 `Hyp` 体积成本。每个激活的假设增加一个栈上尾窗临时值，空列必须维持零次回溯。合成局部计时不代表真实 `.gram` 模型或整机按键延迟，默认九键 16 ms 超预算仍待解决。没有改产品 I/O、目录、权限或 Android 资源；测试与构建覆盖不等于原生设备验收。

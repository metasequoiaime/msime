# Agent Note: 整句候选恒等排列避免临时分配

Status: implemented

## Problem

`runner_up_order` 在整句候选已经按规则连续排列、无需移动时，仍会构造完整的 `Vec<usize>`，随后才发现排列是恒等映射并返回 `None`。

## Decision

先用两次线性扫描复现排列的输出顺序并检查是否为恒等映射；只有确实需要移动时才分配并构造最终排列。保留原有整句候选保留数量、非整句行位置和后移顺序。

## Alternatives considered

始终构造排列会让常见的无变化路径承担一次候选数规模的堆分配；使用固定上限数组会给候选总数引入不必要的硬上限。先扫描恒等性只增加线性比较，不改变公开结果接口。

## Verification

新增单个整句候选零临时排列分配测试；排序模块测试、引擎完整测试、Clippy、Rustfmt、差异检查、笔记检查和 quick 门禁覆盖实现。

## Consequences

无需移动整句候选时直接返回 `None`，不再创建临时排列；需要移动的路径仍按原算法返回相同排列。

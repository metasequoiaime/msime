# Agent Note: 全局语音把录音与自动交付许可分开

Status: implemented

## Problem

真实可编辑输入框也可能暂时无法经 Accessibility 取得焦点。全局入口把这种失败当作不支持文本框而拒绝录音；用户明确要求移除开始录音前的输入框要求，保留交付验证，必要时提供复制。

## Decision

快捷键只需要有效的用户手势、宿主运行许可和录音服务，不要求开始前存在输入框。原应用和焦点身份若可验证则只记录一次；没有原始身份时不在后来补授予自动插入权限，最终结果进入显式复制。录音期间不反复依赖未知焦点；已有目的地失效或应用切换时仍停止并保留结果，不向其他字段插入。睡眠、锁屏及取消继续终止本轮。

菜单、工具栏和全局键控制同一轮；提交前安全完成原客户端的组字。socket 传输租约采用宿主进程内唯一身份，与核心 apply 的会话代次分开。版本派生同步改写后台 plist；原生开发宿主和隔离配置不管理正式后台项。

## 旧笔记审计

[先录音后 IMK 交付](../../implemented/architecture/2026-11-03-global-voice-capture-before-imk-delivery.md)保留不等待 IMK、提供商及取消边界，本篇仅取代启动必须有原焦点的要求；[跨输入法快捷键](../../implemented/feature/2026-11-02-macos-global-voice.md)保留键位、后台批准和输入源恢复边界。其他语音笔记不改变这一目的地授权规则。

## Alternatives considered

- 短暂重试焦点可减少暂时性拒绝，但仍不能覆盖用户主动在无输入框时开始说话的需求。
- 最终识别完成时才选当前字段可提高自动插入率，但无法证明那是用户开始时选择的字段，会把文字发到新位置。

## 最终交付的防御性检查

IMK／AX 同步查询前后比较原客户端、核心会话、录音令牌、输入序列与 apply 序列。准备原组字时，只允许本方法预期的一次 apply；查询、核心完成命令或 apply 期间出现新的输入、会话或组字，返回 `Changed`，本轮立即进入既有复制恢复，不再轮询并尝试结束新组字。`Retry` 只表示暂时没有可用客户端，沿用已有等待预算；`Accepted` 表示准备或插入已完成。

这是对合成重入探针揭示的时序风险加防御，不声称已经复现真实 IMK 的触发时机或频率。原字段已有且在校验期间没有变化的组字仍正常完成，再追加语音。英文透传且关闭英文在线候选时，交付控制器合法地没有核心会话；稳定的空会话也允许交付，核验期间从空变为非空仍被视为变化。

## 兼容性与恢复边界

按用户确认的范围，继续尽力向原目的地提交。已知身份失效或交付明确失败时使用既有 Copy 恢复；模拟按键投递成功不是编辑器接受文本的确认，不能把文本 role 或缺失的 AX 可编辑属性当成成功上屏的保证。此限制写明在文档与 PR，不新增更严格的录音前置条件、最近结果缓冲、历史记录或完成浮层。

同应用焦点切到被查询过滤的控件时，现有采集可能继续。用户接受这是录音策略取舍，本轮不改变录音时的焦点处理，也不把它作为合并阻塞；最终插入仍绑定原应用与字段。

## Testing

无初始焦点时可开始并持续录音；任何晚到焦点都只能复制。已验证原字段未变时仍能提交，字段或应用变化不能误插入。双向入口控制、跨局部与全局租约、原组字、六版本 agent 和开发隔离都有聚焦回归。

六版本派生检查、18 项聚焦 macOS 原生套件与原生输入法目标构建通过；测试前后已安装偏好文件哈希相同。真实恢复面板使用合成文字导出改前／改后文案预览。复用现有构建缓存，未安装新版，也未运行真实录音或全平台本地检查。

新增聚焦回归覆盖查询重入新组字、会话／客户端／令牌／输入序列变化、原组字完成命令期间重入，以及 Changed 后立即恢复且不再插入。真实 NSTextView 保存合成 marked text，检查它没有被语音覆盖；普通插入及原组字完成保留对照。

## Consequences

录音成功不保证自动交付，复制是明确后备；合成回归不能替代真实麦克风、系统批准迁移与编辑器验收。

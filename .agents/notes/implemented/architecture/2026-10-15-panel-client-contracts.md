# Agent Note: 面板宿主契约独立于 JSX 实现

Status: implemented

## Problem

共享键盘、手写、语音、云剪贴板、云词库和表情面板的宿主契约定义在 `keyboard/panels.tsx` 中。手写采样与设置窗口的剪贴板逻辑反向引用这个大型 JSX 模块；继续拆分面板实现时，也会被迫依赖聚合页面来取得类型。

## Decision

`KeyboardInputRequest`、笔画与识别请求、`PanelClient` 及各面板的动作、回答和扩展客户端原样归入 `keyboard/panel-client.ts`。该模块只导入类型，不拥有运行时状态、校验器或宿主动作。面板、手写采样和设置剪贴板逻辑直接引用它；旧 `panels.tsx` 重导出全部旧类型，包入口直接重导出原有的公开子集。

保留所有可选能力、请求操作名、字面量联合、回答中的 `unknown`、快照修订字段和原接口继承关系。云剪贴板的加密与设备批准仍遵循 [端到端加密决定](../../implemented/feature/2026-10-11-cloud-clipboard-e2e.md)，本片不改变协议、宿主实现或面板生命周期。

## Alternatives considered

- 直接从 `panels.tsx` 取类型不增加文件，但纯逻辑仍依赖面板聚合模块，后续拆分难以保持单向依赖；仅保留旧路径作为兼容重导出。
- 按每种面板分别创建契约文件能让文件更小，但当前所有面板都继承 `PanelClient`，一次搬迁到一个契约模块能明确共同边界，避免为没有单独消费需求的类型建立更多跳转；以后面板有独立演进需求时可以在此边界继续拆分。

## Verification

25 个契约声明在排除注释、空白后逐字一致，包入口公开符号集合保持不变。迁移前后相同的 51 个面板相关测试文件、242 项测试通过；临时类型探针核对 25 个旧路径类型、17 个包入口类型及最小宿主实现。契约编译产物只有 `export {};`，没有运行时依赖；桌面构建的资源哈希与迁移前一致。另修复社区插件测试辅助函数未等待详情请求完成的竞态，避免 `detailBusy` 禁用安装按钮时误点击。类型探针、模块编译、桌面构建、HarmonyOS 类型检查、lint、格式、笔记与本地 quick 是验证门禁。

## Consequences

可选方法与联合分支很多，遗漏会改变宿主能力判断，必须保留完整声明及旧导出。`ResourcePackClient`、`ModelMirrorClient`、`EmojiCatalogGroup` 和 `CloudDictionaryKind` 仅作为类型依赖；契约模块不得反向加载 React 组件。收益是后续实现可直接消费共同契约，代价是一层旧路径重导出。

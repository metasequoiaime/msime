# Agent Note: Windows 模型错误提示的公共归属

Status: implemented

## Problem

语音模型和整句模型资源包需要一致的错误分类，但语音设置同时持有服务配置、模型选择等专属规则。资源包页面借用语音设置的提示函数会让通用展示规则依附于一个业务入口。

## Decision

`platforms/windows/settings/ModelErrorMessages.h` 独立提供错误码归一化与文案生成，语音和整句模型界面直接使用它。模块只依赖标准库；错误详情不进入提示，正常取消返回空结果，未知错误使用通用文案。是否展示通知及其严重程度由调用界面决定。

大小、校验值和格式不匹配均归一化为校验错误，与 Tauri 的 `local_model_error_code` 分类一致；导入场景据此保留专属校验提示。

导入专属措辞留在[语音设置](../feature/2026-10-11-windows-settings-voice-page.md)侧，其余错误委托公共模块。模型进度、状态刷新、网络请求和安装流程不属于该模块。

## Alternatives considered

- 在各下载回调分别分类，修改位置直观，但相同错误需要维护多套文案与取消规则。
- 让资源包页面调用语音设置函数，改动文件更少，但无法表达两类入口对公共规则的平等依赖。
- 单独展示 Windows 格式错误可以提供更细的原因，但会偏离现有 Tauri 分类，也会绕过导入专属校验提示，因此复用校验错误类别。

## Testing

`windows-model-error-messages` 只包含公共头文件，验证归一化、分类文案、详情隐藏、取消和未知错误。`windows-voice-settings` 保留导入专属文案与公共兜底的回归，包括带诊断后缀的格式错误归一化后仍使用导入校验提示。

`windows7-voice` 从原生窗口的下载按钮注入合成失败响应，核对分类提示、取消、重试按钮恢复和偏好修订号不变；离线导入按钮另覆盖格式错误的专属校验提示。现代设置的整句模型入口另需在实际窗口验收通知与异步刷新；公共映射单测不能替代这一层。

## Consequences

公共映射修改会同时影响使用它的模型界面，需要回归通用规则与语音导入适配；各界面仍独立持有状态和通知行为。宿主错误协议与下载策略保持原样。

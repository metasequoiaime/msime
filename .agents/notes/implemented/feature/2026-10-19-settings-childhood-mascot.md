# Agent Note: 设置页采用幼年水杉娘素材

Status: implemented

## Problem

已有水杉娘插画只在更新完成、社区空状态或下载时出现，普通设置页面几乎看不到角色。用户提供幼年水杉娘素材，希望把角色元素加入设置。

## Decision

桌面常用设置页在内容区页首显示 80px 的场景插画与一行简短功能引导，通过 `settingsMascotIntro` 按页面语义选择图像：输入与快捷键用拼音积木，词库用书本，统计用记笔记，外观用欢迎，账号用云同步，维护与工具栏用修设置，数据说明用隐私保护。布局保留原来的标题、返回按钮、页内标签与表单，不在标题栏仅放一个难以看清的小图。

语音、键盘手写、剪贴板页首和内容共用窗口内的 `introTabs`：输入法与录音行为分别用记笔记、修设置，键盘与手写分别用拼音积木、记笔记，剪贴板与历史记录分别用云同步、记笔记，并更新对应说明。点击、方向键和宿主路由使用同一份选择；离页回来保留选择，不写偏好。不提供手写合并页或剪贴板列表能力时，页首回退到实际可用的默认内容。独立语音与剪贴板组件仍可自行管理选择。

窗口高度不超过 700px 或进入手机宽度时，桌面页首插画缩至 56px，同时收紧最小高度、列间距与下方留白；其他桌面窗口保留 80px。切换标签不更改图片盒子尺寸，避免内容跳动。

关于页标准品牌卡使用 112px 欢迎插画；已有四个状态图统一为同一套幼年素材。手机不加桌面页首插画区，HarmonyOS 关于页头沿用原有标志圆与更新布局。对话等需要完整操作空间的工具页不增加引导区。所有图为透明 256px WebP，显示不超过 128px，对辅助技术隐藏且不拦截点击。不增加角色对话、动画或新偏好，不进入候选窗口。

## Historical audit

[设置页低频状态配水杉娘插画](2026-10-18-settings-mascot-illustrations.md)部分重叠：复用场景组件、装饰语义及四个状态接入点，本次扩展到常用设置页首与关于品牌卡，并替换素材来源；不扩大到高频输入区域。

## Alternatives considered

**只替换原四张状态图**：布局完全不变、增加体积最少，但常规打开设置仍看不到水杉娘，未满足本次品牌露出的目的。

**通过 DOM 或子组件副作用回报当前标签**：不用提升选择状态即可让页首观察现有标签，但会产生额外同步时序，路由和隐藏面板更容易让页首读到旧值，因此让模型显式持有选择，由标签和页首共同消费。

**悬浮角色或侧栏大插画**：角色更显眼，但会遮挡控件或压缩本已较长的导航，因此采用内容区页首独立排版的插画与关于卡片。

## Verification

十张透明 WebP 合计 145,924 字节（约 143KiB），从原图以质量 70 重新编码，比质量 80 的版本减少 22,384 字节，逐像素确认透明通道一致；图片在深色底联系表中检查透明边缘，保留浅色衣服、门框和零散叶片。HarmonyOS 单文件设置构建后为 2,025,491 字节（余量 71,661 字节），低于 2,048KiB 预算。组件与页面相关测试共 113 项通过，覆盖装饰可访问性、状态出现条件、各常用桌面页首的场景与说明及手机标题不加装饰，新增三个页面的点击、Home/End、保留面板节点、路由返回与导航不保存偏好检查；桌面类型检查、生产构建、HarmonyOS 单文件构建与 quick 门禁通过。

合成 Chromium 检查 macOS 1000×780 浅色的输入、词库、语音、剪贴板、外观与关于页面，以及 800×600 深色输入页与 360×600 深色语音页，iOS 页面投影 320×640，以及 Linux 800×600 深色。图片均解码成功，无横向溢出；目视检查关于卡片、原有标志与标题均正常。手机投影只用于共享组件布局，不代表原生手机产品验收。

补充合成 Chromium 检查 1000×780、800×600、360×540 的语音页，800×600 的键盘手写与剪贴板页，以及 Linux 剪贴板页。验证 80/56px 的实际尺寸、标签与页首同步、切换前后页首高度不变、明暗布局无横向溢出、图片可解码。

本机 macOS 设置组件重新打包、签名验证并安装。原生窗口可被工具列出，但读取可访问性状态与截图均返回 `window_not_found`，本轮未完成原生窗口内的交互验收；新增布局和标签同步由上述合成浏览器与集成测试验证。未更改真实偏好，未做其他平台的设备验收。

CI 的全量共享 UI 测试暴露五处旧断言：输入语言仍按旧名查找、语音标签与组标题重名、能力测试未进入服务配置、云剪贴板发送按钮位于历史标签，以及 AI 提示词说明已改写。相关测试按用户实际可见的页面、标签与控件角色定位，保留能力正反例和中继保存后重新检查可用状态的断言；三份测试共 57 项在本地通过；完整共享 UI 回归 779 个文件、4,795 项全部通过。与最新 develop 的相同测试修复合并时保留可见控件角色定位与能力正反例。

## Consequences

常用设置页首与关于卡片常态显示角色；原来的状态语义和功能保留。素材替换增加少量资源，HarmonyOS 单文件设置会内联图片；未来追加插画仍需核对体积。

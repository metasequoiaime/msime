# Agent Note: Android 键盘设备信息子面板与中英单项插入

Status: implemented

## Problem

#10045：在论坛发帖或给开发者反馈问题时，用户想不离开正在写的输入框，就把机型、系统版本、内存、屏幕参数这些设备参数一项一项插进去，而且有时要英文标签，好给外国开发者看。键盘里原来只有功能菜单的「设备信息」磁贴，它把十一项白名单拼成一整段中文放进剪贴板（见[设备信息白名单](2026-10-08-android-device-info-copy.md)）：不能直接插入，不能只取其中一项，没有英文，也没有 CPU 名称和刷新率、HDR 这类屏幕参数。

报告者的草图是在符号面板底部加一个「系统信息变量」分类，左侧竖排中文和英文两个二级分类，下面九个按键：品牌、型号、系统版本、处理器架构、存储空间、运行内存、Android System WebView 版本、CPU 名称、屏幕参数。

## Decision

不加符号分类。功能菜单的「设备信息」磁贴改为打开一个子面板，和「本地输入」「AI 辅助」的子面板用同一个标题栏与网格。入口换成子面板、不收亮度这两处偏离了 issue 的清单，维护者 2026-10-28 在 issue 里的核对仍列着「分类导航」，两处都还没有维护者认可，所以 PR 写 `Refs #10045`，不自动关闭 issue，留给维护者决定是否接受或补上。

- 标题栏左边是「返回工具」，右边是「中文」「English」两个切换按钮，按键角色是 KEY：选中的那个铺实心强调色、文字用 onAccent，和简繁开关、回复面板分段的选中态一样。不用 TILE 角色：选中的 TILE 底色是 accentSoft，自定义皮肤的 `KeyboardSkinKeyDrawable` 把它当 action 绘制，`paint.setAlpha` 覆盖掉自带的 0x24 透明度，底色成了实心 accent，文字 accentText 又是同一个 accent，按钮成了看不见字的色块（功能面板「开启态深色块」的同一个根因，见 `ImeFunctionPanel` 类注释）。语言只记在键盘进程里，默认中文，不写进偏好。
- 标题栏下一行说明用途：插入设备参数，不含账号、输入内容和设备标识。这一行固定 20dp 高，只显示一行、放不下用省略号，免得大字体或窄屏上折行后下半截被截掉。
- 四列三行的网格：九个字段各一格，顺序和 #10045 列的一致；第十格「全部」插入整段；第十一格「复制全部」保留原来复制到剪贴板的做法，复制后照旧关闭工具面板，剪贴板预览和提示的行为见[复制预览](../bug-fix/2026-10-22-device-info-copy-preview.md)。
- 磁贴标签不随语言变，变的是插进去的文字：中文「运行内存：8.0 GB」，英文「RAM: 8.0 GB」。值本身（型号、版本号、包名）不翻译；括号、冒号、列举分隔和「未知 / Unknown」「支持 / Supported」这类词跟着语言走。英文整段的标题是「Metasequoia IME device information」。
- 插入走 `InputConnection.commitText`，不经过剪贴板；有组字时先按原样上屏（`command(2)`），和世界时钟、剪贴板插入一致。插入后子面板不关，方便接着插下一项。光标前已有文字且不是换行时，多行输入框先换行、单行输入框先空一格，免得连续插入的几项粘成一行；为此只读光标前一个字符，读到的不保存、不进报告。
- 插入格一直可点，点按时才判断：没有输入框时提示「没有可插入的输入框」，密码框里提示「密码框里不插入设备信息」，「复制全部」照常可用。不按渲染时的状态置灰，因为子面板开着时输入框会变（WebView 里焦点移到密码框、连接晚一步才到），置灰的状态会过时，点了没反应也没有说明。
- 收集在点击时进行：主线程从 IME 已附着的视图读 Display，其余在偏好工作线程读，结果回主线程后才写。复制和插入各有一个代次：复制是最后一次点击说了算；插入互不取消，连点「品牌」「型号」两项都会插进去，偏好工作线程是串行的，结果按点按顺序回来。读的过程中换了输入框就不写，服务销毁时两个代次都作废，之后的回调直接丢弃。

### 字段白名单（键盘子面板）

在原十一项白名单的基础上扩展，格式和读取都在 `DeviceInfoReport` 与 `DeviceInfoCollector.keyboard`：

- 原有：应用版本、品牌、型号、系统版本、系统构建、处理器架构、存储空间、运行内存、Android System WebView、键盘是否启用与默认。
- 新增 CPU 名称：照系统原文，不换算成市面上的叫法。Android 12 起取 `Build.SOC_MANUFACTURER` 加 `Build.SOC_MODEL`（型号已带厂商名时不重复），更早的系统或厂商没填时退回 `Build.HARDWARE`；字面的 `unknown` 当作读不到。
- 原来单行的「屏幕分辨率」换成一组「屏幕参数」，放在整段最后，每项一行：分辨率（真实像素与 HD、FHD、1.5K、QHD、UHD 档位，比 16:9 更长的加「+」，平板常见的 1600、1800 短边不归档）、密度（由 `xdpi`/`ydpi` 算出的 ppi，加系统的 dpi 与 LDPI 到 XXXHDPI 档）、字体缩放（`Configuration.fontScale` 原值）、尺寸大小（对角线英寸）、宽高比（离常见比例 1.5% 以内用它的名字，否则写成「2.35:1」）、刷新率（`Display.getSupportedModes` 去重升序）、HDR 与 HDR 能力（`HdrCapabilities` 的 Dolby Vision、HDR10、HLG、HDR10+）、广色域（`Display.isWideColorGamut`）。
- 不收亮度和亮度模式：它们随环境光和用户拖动随时在变，贴进报告时多半已经不是出问题那一刻的值，对排错没有帮助。

这些读取都不需要权限，也不构成设备标识。依旧不读账号、输入内容、已安装的其他应用或任何能标识设备的 id，什么都不上传。

设置 App 的「关于」页和反馈页的插入、复制不变，仍是原来的十一项中文文本；本次只扩展键盘子面板。

## Alternatives considered

- **照草图在符号面板加「系统信息变量」分类**：入口和其他符号一样在底部分类栏，左右滑动就能到，用户最熟悉。但符号分类是固定枚举，id 会写进用户自定义的分类顺序（`SymbolCategoryOrderPolicy`）；分类内容是静态字形或与 iOS、桌面共用的 `msime-others.db` 目录；点过的条目还会记进「常用」历史（`SymbolPanelModel.commonSymbols`）。把随设备变化的值塞进去，「常用」会存下运行内存、型号这些动态文字，分类排序设置里多出一个只有 Android 才有的 id，几处都要为它开例外。功能菜单本来就有「设备信息」入口，在那里展开不碰这些数据。
- **左侧竖排、上下滑动切换中英文的二级分类**：草图的交互，和符号面板的布局一致。放进功能菜单子面板后，标题栏的两个按钮一眼能看出当前语言，点一下就切，不用再占一列宽度，也不用处理竖滑和面板横向翻页的手势冲突。
- **收亮度和亮度模式**：报告者截图里的设备信息应用都列了这两项。但它们是瞬时状态，见上文，这次不收。这是本 PR 的取舍，维护者在 issue 里没有表态，#10045 仍按 issue 的完整清单保留，是否补上由维护者决定。
- **每次点击后关闭子面板**：和世界时钟、宣传磁贴一致，插完回到键盘。但这个面板的典型用法是连着插几项（品牌、型号、系统版本），每插一项都要重新打开菜单、翻页、进子面板，太绕。

## Consequences

- **收益**：反馈时不用切应用、不用粘贴，单项或整段直接进输入框；英文标签可以直接贴给外国开发者；CPU 名称和屏幕参数组补上了显示相关问题最常被问的几项。
- **代价**：键盘的「复制全部」文本比设置页的复制多了 CPU 名称和屏幕参数组，两处的白名单不再完全相同；功能菜单的「设备信息」从一点即复制变成先进子面板，复制要多点一次。中文 / English 的选择在键盘进程重建后回到中文。
- **平台范围**：只做 Android。iOS 键盘扩展和 HarmonyOS 键盘里都没有「设备信息」入口（两端源码里搜不到键盘侧的设备信息功能），没有可以展开的磁贴，这次不新增入口。

## Verification

`platforms/android/tests/settings/DeviceInfoReportSmoke.java` 由 `check-host.sh` 的 JVM 冒烟覆盖：原有中文格式逐字不变；九项可插入字段和顺序；中英单行、读不到时的「未知 / Unknown」；英文的版本、系统版本、ABI、存储、WebView 和键盘状态；CPU 名称的拼接与回退；连续插入的换行与空格；中英整段含屏幕参数组；屏幕参数的分辨率档位、ppi 与密度档、字体缩放原值、英寸、宽高比、刷新率去重、HDR 名称、全部读不到时的回退，并断言没有亮度。

`platforms/android/tests/device/keyboard/CopyDeviceInfoDeviceSmoke.java` 改为先进子面板再点「复制全部」，按扩展后的白名单逐行核对（十二项加九行屏幕参数），并新增插入流程：在多行编辑器里先插中文「运行内存」，再不等读完连点「品牌」「型号」、断言两行都按顺序进来，然后切到 English 插屏幕参数和全部，核对编辑器文本、换行和系统剪贴板没有被改动。本次没有在模拟器或真机上运行这个设备专项；SoC 型号、HDR 和刷新率在模拟器上多为空值，要靠真机抽查。

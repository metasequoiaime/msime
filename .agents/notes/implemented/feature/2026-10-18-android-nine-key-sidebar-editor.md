# Agent Note: Android 九键符号栏改为可视化编辑

Status: implemented

## Problem

「键盘 › 布局 › 九键左侧符号」和「九键数字键盘左侧符号」点击后直接打开一个输入框，要求用户用空格拼出整张符号表。这个界面把顺序、删除和添加混成一串配置文本，用户无法直观看到每个符号在键盘上的位置。

## Decision

两项设置都打开 `NineKeySidebarSheet` 可视化编辑面板。面板用统一的设置卡片承载当前顺序，每个符号以强调色小牌显示；只在拖动把手上按住并上下拖动来调整草稿顺序，删除使用图标按钮；「恢复默认符号」恢复对应键面的默认表；「添加符号」打开固定的常用符号选择面板，已加入的选项从选择面板中排除；「保存」才把规范化后的整张表写入原有本地设置。面板关闭或取消不会写入草稿。原来的空值回退、最多 30 项、单项最多 4 个码位和本机存储契约保持不变。

旧的整串 `InputDialog` 方案记录在[九键左侧符号栏、数字键面与滑动出数字](../../implemented/feature/2026-10-08-android-nine-key-number-pad.md)，本篇取代它的编辑交互，不改变键盘运行时的符号表协议。

固定候选包含 `()`、`（）` 两个完整括号项，分别保留原有的单独前半个和后半个，用户可直接把整对括号放进字母或数字侧栏（#8625）。点击整对后的光标行为归[Android 成对标点](2026-10-08-android-paired-punctuation.md)，不在编辑面板另存光标位置或模板格式。

2026-10-29 起两张表存在共享偏好里、随账号同步，编辑页挪进「按键布局」，并补上手动输入一项的入口（[九键左侧符号栏三端共享](2026-10-29-nine-key-sidebar-shared.md)）；本篇的编辑交互沿用。2026-10-31 起每项前有序号，拖动改成被拖行跟手、其余行让位、松手才改表，并补上读屏的「上移」「下移」（[序号与跟手拖动](2026-10-31-nine-key-sidebar-order-drag.md)）。

## Alternatives considered

- 继续保留整串输入框：实现最小，也能表达任意符号和顺序；但用户需要记住空格分隔格式，无法直接理解当前键位排列，正是这次反馈的问题。
- 只提供固定符号的选择面板：比输入框直观，但不能覆盖任意自定义字符串；当前选择集覆盖常用中文标点、数学和运算符，也保留 `……`、`:-)` 等原先示例里的短串，任意未收录字符串仍需后续单独设计入口。
- 保留上移、下移按钮：按按钮调整可预测，也更容易实现；但连续调整需要反复点击，用户明确要求直接拖动，因此改成每行一个拖动手柄，并限制拖动触点避免和删除按钮、外层滚动手势冲突。
- 用文字胶囊同时承载拖动和删除：占用空间少，但两个动作都像普通按钮，符号本身在长列表中没有清晰的视觉锚点；改用卡片内的符号牌和图标按钮，与 Android 设置页其他行的层级一致。
- 保留单项输入框作为兜底：能覆盖任意字符串，但在常用符号已经有明确候选时仍要求用户输入，和设置页的选择式交互不一致；本面板改用固定选择集，后续若要支持未收录符号应另做独立入口。
- 每次调整立即写入本地设置：交互更短，但上下移动多次时容易留下半成品，取消也无法撤销；采用草稿到保存的边界。

## Verification

Gradle `compileFullDebugJavaWithJavac`、Android 主机门禁（248 项 JVM 冒烟、156 项设备套件源码编译）和 `git diff --check` 通过；随后构建签名 APK，安装到 Android 设备并打开键盘设置页，确认两项符号栏入口打开的是逐项编辑面板，没有上下箭头，并通过拖动手柄改变了行顺序。固定候选改为可滚动的网格 `ChipGroup`，点击候选立即加入并关闭选择面板；真机确认加入 `:-)` 后返回编辑页，重新打开添加面板时该候选已被排除，滚动到底部可见取消按钮。

#8625 补充验收：在 API 35 模拟器的原生「键盘 → 布局」设置页，分别打开字母和数字侧栏编辑面板，实际点选添加 `()`、`（）`，保存后重新打开确认两项仍在。随后移除测试添加项并保存。两台模拟器上的键盘输入与光标回归由 `NineKeySidebarPairDeviceSmoke` 覆盖；本次没有 vivo 真机验收。

## Consequences

用户可以直接看到和拖动调整符号顺序，删除和恢复默认不需要编辑格式字符串；添加常用符号改为网格点选，已加入的符号不会重复出现在选择面板。网格比纵向长列表更容易扫读，保留面板滚动以容纳完整候选集，点击后立即回到编辑页减少返回层级。符号牌让短符号在列表里有稳定的视觉落点，拖动把手和删除图标分别表达两个动作。当前新增入口只覆盖固定常用候选，任意未收录字符串暂时不能从本面板加入。拖动只作用于把手，保留删除按钮的点击和面板的滚动行为。面板新增一层草稿状态和保存动作，设置写入仍复用原有 `KeyboardSheets.saveLocal`，键盘端不需要改动。

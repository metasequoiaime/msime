# Agent Note: Android 符号滑动可滑回取消

Status: implemented

## Problem

#11822 第 1、2 项。Android 上滑出符号的手势一旦滑过阈值就锁定：26 键和 14/18 键字母键的角标、九键和 123 / #+= 页 ！ 上滑出 0、逗号滑出句号，手指滑回按下点再松手仍然上屏，滑到一半发现按错只能事后删。14/18 键的决策笔记把这一点写成规则（「先触发的那一种锁定这次按压」）。同一个仓库里已有能滑回放弃的手势：删除键上滑快速删除滑回待命线以下松手不删（[Android 快速删除](2026-10-08-android-backspace-quick-delete.md)），14/18 键横滑限定字母回到起点不输入，长按选项滑进再滑出松手不输入。

提示也不够：关掉「按键弹出」时滑出角标没有任何提示；！ 和逗号的滑动在任何设置下都没有气泡，看不出这次会输入什么，也就看不出能不能取消。

## Decision

- 新增 `keyboard/SymbolSwipe`（纯状态，没有依赖）：沿方向的位移严格超过阈值待命（`ARMED`，松手输入符号）；待命后沿方向的位移退回到阈值的一半以内（含）就取消（`DISARMED`，松手什么都不输入）；再滑过阈值又待命。只看沿方向的位移，横向漂移不取消。滑过一次之后不再回到 `IDLE`，这次按压不会再变回点按、长按、选项或横滑，与删除键快速删除「弹出后不再收回」相同。阈值和一半之间的距离就是防抖区，手指停在阈值附近时状态不闪。
- 距离从按下点量，不看键帽边界：默认 14 dp 时角标在手指还在键帽里时就已滑出，「滑回键上」不能当判据；按下点也不随键距、键宽变化。
- 字母键：`GridKeyGesturePolicy` 增加 `Mode.DISARMED`，待命用原来的纵向为主规则（`SymbolSwipe.arms`），取消用 `SymbolSwipe.disarms`，阈值是「滑动距离」，所以默认 14 dp 时退到 7 dp、48 dp 时退到 24 dp。按大小写写字的方案长按直接出的角标（`holdSymbol`）不能取消。26 键和 14/18 键松手在 `DISARMED` 时不输入、不记按键、不给反馈。
- ！ 出 0（九键与 123 / #+= 页，`bindSuperscriptShortcut`）和逗号出句号（`ImeBottomRow.bindCommaSwipe`）改用 `SymbolSwipe` 实例，阈值仍是固定 14 dp（退到 7 dp 取消）；！ 仍只看纵向，逗号仍是上下都算、纵向为主、长按时限过后不再起滑动。
- 气泡：`ImeLetterRows.showSwipePreview` 在待命时显示符号（逗号是当前标点下的句号），取消时把字画淡（`KeyboardKeyPreview.setDimmed`，不透明度 0.38，与设置页置灰的控件相同），再待命时恢复。它不看「按键弹出」：关掉时按下不画，滑出符号后才画，这是滑动已触发、还能取消的唯一提示，与长按不看这项设置相同。！ 和逗号因此第一次有了滑动气泡。横滑限定字母的气泡仍跟随「按键弹出」。
- 九键 flick 字母不变，仍是首次超过阈值的方向锁定（[三端九键四向 flick](2026-11-11-nine-key-four-way-flick.md)）。iOS、鸿蒙不变。

## Alternatives considered

- **取消后松手输入字母（回到点按）**：和日文九键 flick 回到中心输入中间的假名一样；滑回多半是在纠正误触时少删一次。不用：滑回是有意放弃，输入字母又要删一次；仓库里删除键快速删除、横滑限定字母、长按选项的滑回都是不输入；日文 flick 的中心本来就是提示里印着的一个选项。
- **以键帽边界判定「滑回键上」**：直观。不用：默认距离下符号在键帽里就已滑出；键距、键宽和键距外的触摸归属还在改（键边对齐），按下点不受这些影响。
- **固定的防抖距离（如 6 dp）**：每个距离下手感相同。不用：「滑动距离」调到 48 时要退回 42 dp 才算取消，几乎回不去；按一半算随用户的距离设置一起变。
- **取消时隐藏气泡、或显示字母**：不加新的视觉状态。不用：气泡中途消失像这次触摸丢了；显示字母暗示松手会输入字母，而实际什么都不输入。
- **九键 flick 一起可取消**：同一套手势模型。不用：九键 flick 的首次方向锁定是三端刚定下的决定（#11244），要改另开 issue。
- **等待浮层窗口（键盘面板布局 B-1）再做淡化的气泡**：气泡将来放进常驻的预览窗口，第一行不再被读音行上沿裁掉。不用（用户决定先画）：淡化只是气泡上的一个绘制开关，跟着气泡一起搬；先画能让取消现在就完整可用。第一行的气泡在那之前仍会被裁掉一截。

## Consequences

收益：滑出的符号可以在松手前反悔，不用再删；关掉「按键弹出」的用户和 ！、逗号也看得到滑出的是什么、取消了没有。

代价：改变现有手感，滑出符号后滑回起点的那一下以前输入符号、现在什么都不输入，需要维护者在 #11822 确认。多了一种气泡状态（变淡）；关掉「按键弹出」的用户滑出符号时会看到气泡。第一行的气泡仍被读音行上沿裁掉一截，要等键盘面板布局把气泡移进预览窗口。

验证：`SymbolSwipeSmoke` 钉住严格超过阈值待命、一半（含）以内取消、防抖区、横移不取消、再次待命、反方向也算取消、上下都算、不要求纵向为主和新按压；`GridKeyGesturePolicySmoke` 的「回到起点仍输入符号」改为取消，并加上取消后不开选项、不补点按、再滑出又出符号、距离 30 时退到 15 dp 取消。设备上 `LetterHintPunctuationDeviceSmoke -e letter-swipe true` 加 26 键滑回取消与再次滑出、`FourteenKeyDeviceSmoke -e grid_symbols true` 把「回到起点仍输入符号」改为取消并加再次滑出、`SuperscriptShortcutDeviceSmoke` 加九键和 #+= 页 ！ 滑回不出 0、`ToolbarEdgesDeviceSmoke` 加逗号滑回不出句号。气泡变淡只在截图上看，没有自动断言（气泡对读屏隐藏）。

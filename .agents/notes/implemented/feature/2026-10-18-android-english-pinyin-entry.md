# Agent Note: Android 英文键盘进入拼音

Status: implemented

## Problem

#8610 需要在英文键盘中快速进入拼音输入，长按 `o` 后还要保持在拼音键盘，避免选字后自动切回英文。

## Decision

英文 26 键的 `o` 长按提供一个带箭头的「切换到拼音键盘」选项。选择后复用现有中英切换和输入会话收尾路径进入中文拼音键盘；不改变英文键轻点输入，也不在中文候选提交后自动切回英文。用户通过原有中英键手动返回英文。

英文其他键只显示角标、O 只有切换项的限制由[英文字母长按变体](2026-10-21-android-english-letter-options.md)取代；本篇保留 O 的切换和选字后留在中文的决定。

## Alternatives considered

- **直接把长按 `o` 提交数字 9**：保留原有提示语义，但无法满足从英文键盘进入拼音的快捷入口。
- **新增独立设置或永久混合键盘**：能让入口更显眼，但会增加设置状态和键盘布局契约；该需求只需要一次性进入现有中文键盘。

## Consequences

英文键盘的 `o` 长按弹窗保留拼音入口，与字符变体共存。入口依赖现有中英切换会话，因此不会复制 Engine 方案逻辑，也不会自动改变用户返回路径。

## Verification

Android 宿主检查与 JVM 冒烟应覆盖长按入口的编译契约；设备专项需在专用 AVD 的完整产品启动流程中验证弹窗、进入拼音、选字后停留和手动返回。

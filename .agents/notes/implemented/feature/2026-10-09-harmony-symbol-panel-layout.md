# Agent Note: 鸿蒙触屏符号面板改为分类栏加符号键，底行是真键

Status: implemented

## Problem

鸿蒙触屏的符号面板（`KeyboardView.symbolPanelFace`）和键盘其他部分不是一个样子：

- 分类是顶上一行横向滚动的纯文字。
- 符号格高 46vp、间距 1vp，没有按下态。第三行被截掉一半，又没有滚动条，看不出下面还有内容。
- 底下一行是三个文字链接：「返回」、「连续输入：开/关」、「删除」，不像按键，也不好按。

Android 的 `SymbolPanelView` 早就是左边分类栏、右边五列符号键、底行是「返回」「锁定」⌫ 三个按键，两个平台的同一个面板差得很远。

## Decision

照 Android 的结构重画，按键外观沿用触屏表情面板（`touchEmojiFace`）已有的写法：

- 左边是 56vp 宽的分类栏。五类平分整列高度，每类不高于 40vp。选中的类用字母键底色，没选中的类透明、文字半透明，和表情面板的分类标签一样。
- 右边是五列符号键，键高 42vp、键距 6vp。每个键用字母键的底色、材质渐变、圆角、描边、阴影和按下态，与字母键共用一套外观。三行之外还露出第四行的上沿，加上滚动条，一眼看得出能往下滚。滚动条在网格右侧 6vp 的空隙里，不压在键上。换分类时网格回到顶部。
- 「@gmail.com」这类网址片段放不下 20vp 时自动缩小字号，最小到 8vp，不截断。
- 底行与表情面板的底行同高，三个功能键平分宽度：
  - 「返回」回到打开面板之前的键盘。
  - 「锁定」打开后显示「已锁定」，换成回车键的强调色，点符号不会回到键盘。
  - ⌫ 沿用表情面板的按住连删（`startBackspace`/`finishBackspace`）。原来的「删除」只能点一下删一个字。
- 每次打开面板，锁定都会重新关上；这一点原来就是这样，没有变。

## Alternatives considered

- **照搬 Android 的标题行（‹、「符号」、⌫）。** 最强的理由是和 Android 逐像素一致。不用它，是因为鸿蒙的面板上方一直有工具栏，而面板只有键盘那么高，再加一行标题会挤掉一行符号。标题里的返回和删除，底行里也有。
- **只调大原来的网格行高、把底行文字换成按钮。** 改动最小。不用它，是因为顶部的横向分类行仍然占掉一行。五类竖排在左边不需要滚动，网格还能多露出一行。

## Consequences

- **收益**：符号面板的外观跟随皮肤，与字母键、表情面板一致；长网址片段完整可见；删除可以按住连删。
- **代价**：这次改动只在模拟器上验证过（打开、切换分类、滚动、锁定后连续输入、重新打开时锁定复位）。分类栏的高度按五类算，以后分类变多就要改回可滚动的列。

# Agent Note: 鸿蒙手机每次冷启动都播开屏，启动过程从头到尾不闪白、不换色

Status: implemented

## Problem

鸿蒙手机冷启动的过程很粗糙：系统启动窗是浅灰底上一个透明底的 logo；然后网页还没画出来时 WebView 默认的白色闪一下；桥接就绪前是一页转圈加「正在打开设置 / 冷启动可能需要稍等片刻」；最后直接跳进设置。欢迎流程里那段设计好的开屏动画（白色圆盘落下、标志描线、进度条）只在首次启动时播一次。状态栏在页面调用 `setSystemBars` 之前是系统默认的浅色，底部手势条那一块露出窗口的白色底，设置页标签栏下面也一直有一条白。

第一版让开屏用品牌绿，结果开屏是绿色调、设置页是季节蓝，两套配色硬切。

## Decision

- 鸿蒙宿主（`apps/harmony`）在页面一加载就画 `HarmonyLaunchSplash`（与欢迎流程同一段 `HarmonySplash`），不等桥接，动画盖住冷启动的等待；播完（2.8 秒，点一下可跳过）且桥接就绪才进设置。首次启动时欢迎流程不再重播开屏。二合一（按与 `max-phone` 相同的宽度判断，桥接就绪前只能这样判断）照旧显示共享的启动页。
- 开屏的圆盘、标志、光晕和进度条用设置页将要使用的应用主题的季节强调色：桥接就绪时同步解析当前主题，重画开屏，并缓存进页面的 `localStorage`；下次冷启动在桥接就绪前用缓存。实测冷启动时页面加载比桥接慢，第一帧开屏就已是季节色，缓存是兜底。
- 系统启动窗和原生页面底色（`start_window_background`、`settings_page_background`）改成不带色调的近黑 #0A0B0A：启动窗写死在资源里跟不了季节。开屏的底色后来也固定成这个颜色，启动窗图标换成开屏第一帧的圆盘，见 [启动窗、盖板和开屏画同一个画面](2026-10-11-harmony-launch-one-picture.md)。
- Web 组件自身的底色取同一个颜色，页面画出第一帧前不再闪白。
- `EntryAbility` 加载内容时先把系统栏和窗口底色设成 #0A0B0A；`setSystemBars` 除了系统栏，也把窗口底色设成导航栏的颜色，底部手势条那一块和开屏或标签栏连成一片。

## Alternatives considered

- **只在首次启动播开屏（原来的做法）。** 不用它，是因为用户要的是每次打开都有动画和背景；冷启动本来就要等桥接，动画只是把等待换成了品牌画面，点一下可以跳过。
- **开屏固定用品牌绿。** 第一版就是这样，和设置页的季节色硬切，被否了。

## Consequences

- **收益**：从点图标到进设置是一段连续的深色开屏，配色和设置页一致，没有白闪、转圈页和白边。
- **代价**：每次冷启动至少 2.8 秒才进设置（可点一下跳过）；从后台切回不重播。`localStorage` 对从应用资源加载的页面不保证保留，缓存失效时只是那次开屏在桥接就绪前用平台默认色。

# Agent Note: Android 符号面板的「常用」改为使用记录

Status: implemented

## Problem

#5671：Android 符号面板的「常用」是写死在 `SymbolPanelModel` 里的 30 个中文标点和全角符号，每个人常用的符号不同，用户反复点 `＞` 也不会出现在「常用」里。用户拿表情面板对比：表情面板的「最近」就是按实际使用记录的。

## Decision

- 「常用」的内容就是用户在符号面板里实际点过并成功上屏的符号，最近点的在前，重复点只移到最前不重复出现，最多 30 个（`SymbolPanelModel.RECENTS_LIMIT`，正好六行）。规则在无 Android 依赖的 `SymbolPanelModel.recordRecent` / `normalizeRecents`，`tests/keyboard/SymbolPanelModelSmoke.java` 覆盖。
- 记录只存在本机：`SharedPreferences` 文件 `android-symbol-recents` 的 `items` 键，一个 JSON 字符串数组，格式与表情的 `android-emoji-recents` 相同；读回时丢掉空串、超过 32 个码位的条目和重复项。不随账号同步。
- 隐私模式和不许个性化学习的输入框（`MSIMEInputService.learningSuppressed()`）里点的符号不记，否则「常用」会把在密码管理器、隐身标签页里输入过什么带到别的输入框。
- 原先写死在「常用」里的中文标点和全角符号（，。？！、；：…—·“”‘’（）《》【】～＆＃＠％＋－＝／）挪到「中文」最前面，不从面板里消失。
- 还没有任何记录时，面板打开在「中文」，「常用」里显示一行提示「点过的符号会出现在这里」；有记录时打开在「常用」。
- 刚上屏一个符号后只更新数据，不重排正在显示的网格：锁定连续输入时格子不会在手指底下挪动，下次点「常用」或重新打开面板时才按新顺序显示。

## Alternatives considered

- **按使用次数排序（真正的「最常用」）**：更贴合「常用」这个名字，但要存计数并处理衰减，否则很久以前高频用过的符号永远占着前排；而用户参照的表情面板就是按最近使用排的，两处行为一致更好理解。
- **记录排在前、原来的 30 个默认符号补在后面**：新用户第一次打开不会看到空白，用户点过的符号也会排到最前。但 issue 明确要求清空原有内容、只放点过的符号；补在后面的默认符号仍会让「常用」看起来是写死的。改成打开在「中文」、把默认符号挪进「中文」，同样避免了空白首屏。
- **把记录写进共享偏好、随账号同步**：多设备可以共享「常用」，但要在 `crates/client-core` 的设置同步表和服务端各登记一个字段，表情的最近使用也没有同步，先与它保持一致。

## Consequences

- **收益**：「常用」反映的是这个用户自己的习惯；规则可在 JVM 上测试；不新增共享契约。
- **代价**：老用户升级后第一次打开面板时「常用」是空的、面板停在「中文」，要点过几个符号后才有内容。记录不跨设备、不随重装保留。这次只在 JVM 冒烟和 `check-host.sh` 上验证，没有在真机上点过。

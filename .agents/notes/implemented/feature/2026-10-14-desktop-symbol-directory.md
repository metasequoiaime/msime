# Agent Note: 桌面符号大全采用分类侧栏和本机最近使用

Status: implemented

## Problem

用户希望 PC 端提供类似符号大全的分类、搜索、最近使用和点选输入。现有 Engine 的符号目录已有两千多个符号和十二个上级分类，桌面符号页却用横向图标或分类条，分类多时难辨认。共享页每组分页 48 项，macOS 单击只复制，输入需要再按按钮。

## Decision

Windows/Linux 的共享符号页和 macOS 的原生符号页都在现有「表情与符号」窗口的「符号」标签中展示「符号大全」：顶部搜索和最近使用，左侧可滚动中文分类，右侧紧凑符号网格。共享页符号分类不分页，整组显示并滚动；macOS 用八列网格，其他表情页的几何保持原有规则。共享符号页固定在窗口高度内，分类与网格分别滚动；搜索和内容保留键盘导航识别标记，Ctrl+F 聚焦搜索、下方向键进入网格。

分类和资源沿用 Engine，不修改数据库中的英文标识；界面翻译内置分类与分组，插件包名称原样显示，同名插件仍使用包 id 区分。搜索跨符号分类，点分类会清除搜索。共享页也接受分类的中文显示名搜索。

符号页默认请求输入到原应用，继续走现有宿主 `sendText` / `onSelect`。共享页保留复制选择，macOS 保留「复制所选符号」。宿主接受后才记最近使用：共享页的 Promise 完成代表原输入通道返回成功；macOS 的 Bool 仅表示请求入队，不表示编辑器已完成插入，原有接受后关窗规则保持不变。

符号记录与表情记录分开，本机存储最多 28 项，重复使用移到最前，可清空。共享页使用 `msime.symbols.recent`，macOS 使用宿主偏好域的 `MSIMESymbolRecentItems`。不加入共享偏好与账号同步。

叶分类的直接选择与共享桌面面板缩放由[子分类与缩放](2026-10-21-desktop-symbol-leaf-categories-and-resize.md)部分取代本篇的上级分类选择；其余资源、输入通道与最近使用规则保留。

## Alternatives considered

- 启用 Windows 的原生 EmojiPanel 原型：它已有网格与原生文本输入接口，能减少 WebView。但该实现没有 `.cpp`，不参与产品构建，真正入口使用共享面板；只改原型用户无法看到，也覆盖不了 Linux 和本机 macOS。
- 新建符号数据表：可以完全照参考窗口拆出音标、注音等分类。但已有目录覆盖标点、序号、数学、单位、拉丁、希腊、日文和韩文，复制数据会与其他平台和词库更新分叉。此处沿用资源实际包含的类别，不宣称尚未收录的类别。
- 只保留横向分类条：改动最少，也与 Emoji 页一致。但符号有十二个上级分类，原生图标不显示名称，左侧文字分类更容易寻找。

## Consequences

现有桌面宿主入口即可打开，无新增路由和 IPC。数据随词库更新，插件继续出现在内置分类后。共享页一次展示更多符号按钮，目录仅约两千项，仍在面板内滚动；以后目录明显变大时应考虑虚拟列表。最近记录在本机保存，不同步；macOS 接受请求后关闭面板，所以连续插入需要重新打开。Windows/Linux 由共享 UI 测试和构建验证，系统输入目标的实机投递仍需各自宿主验收。

已检索的相关笔记：[Android 目录接入](2026-10-08-android-symbol-catalog-and-emoji-candidates.md) 与本次部分重叠，继续遵守 Engine 拥有目录的边界；[Android 最近记录](2026-10-08-android-symbol-panel-recents.md) 只归属移动宿主，存储与焦点规则不迁移到桌面；[符号候选](2026-10-13-symbol-candidates.md) 归属拼音混输，此次面板不改候选行为。

## Verification

- 本机共享前端：`pnpm --filter @msime/desktop test tests/emoji`，12 项通过；类型检查和生产构建通过，格式与 lint 校验通过。新增用例验证分类切换、中文分类搜索、完整长分类、输入成功与拒绝、持久化与清空、复制以及键盘导航。
- 编译机最终源码：`bash scripts/verify-local.sh --quick` 通过；原生 macOS 宿主与共享 Apple bridge 编译通过，Linux 共享外壳检查通过。Windows 工具链未配置，编译机没有 pnpm，前端验证由本机补齐。
- 编译机原生面板：`ctest --test-dir target/macos-isolated -L emoji-local --output-on-failure`，18 项通过；`clipboard-copy-recents` 通过。插件目录测试同时验证全部分类包含插件、内置分类排除插件和搜索跨包匹配。
- 本机原生 Swift 后端与相关组件测试通过，560×560 的中文侧栏和紧凑网格组件快照已检查。原生输入法通过安装脚本签名安装，签名校验通过，中文输入源启用且可选。
- 本机临时空白编辑器未能经系统输入源拉出真实符号窗口，因此没有把组件快照或输入请求测试视作编辑器插入验收。Windows/Linux 的实际编辑器投递也仍需各平台验收。

# Agent Note: 输入、标点与翻译、语音设置的顶部功能标签

Status: implemented

## Problem

三个桌面设置页的分组堆成长列表，用户要求沿用候选窗口页的顶部子标签，按功能拆分内容。

## Decision

桌面输入页分为方案、中英文、选词与翻页、候选与联想、输出、进阶；标点与翻译分为标点、候选与释义、候选翻译、翻译服务，服务选择框与当前服务凭据位于同一分区；语音分为识别服务、录音与结果、润色、快捷键、录音设备，后三项随宿主能力过滤。顶部标签沿用平台分段控件样式，只隐藏非当前分区并保留挂载，方向键与 Home/End 同步选中和焦点。选择属于窗口状态，不保存为用户偏好。

手机继续使用原有布局；自定义双拼编辑器仍代替输入整页，不因切换标签丢失编辑状态。共享页面搜索只筛主页面标题，不引入逐行搜索契约。

## 历史审计

[正常候选设置入口标签](../../implemented/bug-fix/2026-10-13-macos-primary-settings-tabs.md) 部分重叠，沿用桌面隐藏面板、手机直列和键盘导航决定，候选预览不变。[原生候选标签](../../implemented/feature/2026-10-13-macos-candidate-settings-tabs.md) 只负责备用 AppKit 窗口，与本次共享页无关。

## Alternatives considered

- 只渲染选中分组：DOM 更少，但会丢失凭据草稿、自定义设置与模型列表的局部状态，并触发重复挂载请求。保留分区挂载符合现有候选页生命周期。
- 把输入各分组复制到独立页：可直接组装页面，但会重复手机的偏好处理逻辑。共享输入与翻译分组通过可选分区渲染函数组合，手机保持现有结构。

## Verification

新交互用例覆盖三页分区、当前面板可见性、方向键与 Home/End、切换和离页保留草稿、能力过滤、手机继续直列。输入、语音、翻译及凭据的相关测试使用合成配置，最终翻译与新标签回归 65 项通过。全量回归的 570 个文件通过；旧的集中设置测试按新分区补齐导航后单独复核，368 项通过。合计 571 个文件、3048 项分批通过，最后的服务选择分组调整另由 65 项相关回归确认。

前端类型检查与构建、lint、本次文件格式检查、笔记校验和 quick 门禁通过。仓库全量格式检查仍报未修改的 `local-modes-section.test.tsx`，本次不改其内容。设置组件构建、打包、安装与 deep strict 签名校验通过，已安装执行文件与签名后的构建产物一致。原生宿主沿用已安装 bundle，只更新正常入口使用的共享设置组件。设置窗口的 AX 可访问性不稳定，未完成三页本机点击验收，不将截图中已有的候选页视为三页验证。

本机安装额外保留此前已安装、待合入的 AI 配置探测修复：本地构建暂用其固定提交 `289b17aac3` 的探测实现，构建后恢复本分支源码；此实现仍由独立 PR #7685 审查，不纳入本篇的 UI 改动。

## Consequences

既有桌面测试需先选择对应子标签；隐藏分区仍有原来的后台读取生命周期。安装时保留已安装的 AI 探测修复与默认只注册中文的原生宿主。

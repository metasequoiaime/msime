# Agent Note: 鸿蒙注音输出简体

Status: implemented

## Problem

鸿蒙的注音方案固定输出繁体，简繁按钮当前在注音下不可用。#11128 需要提供「注音输入、简体输出」，同时保持现有注音词库、候选序号和默认繁体行为不变。

## Decision

新增默认关闭的 `Preferences::zhuyin_simplified_output`，只由 HarmonyOS 宿主使用。鸿蒙在注音方案下复用现有简繁按钮：按钮读写该偏好，候选显示和 Engine 提交的繁体文字在宿主边界使用共享 `traditional_to_simplified` 转换；Engine 的注音候选身份、词库原文和选词下标保持不变。转换失败时保留原文。旧版本缺少该字段时按关闭读取，不接共享设置页和账号同步，避免改变其他平台的默认行为。

## Alternatives considered

- **把注音转换下沉到 Engine**：可让所有宿主共享候选转换，但需要扩展注音编辑器和会话选项，还要处理注音候选列表的原文与显示文字映射；本 issue 只要求 HarmonyOS，宿主边界已经有简繁转换契约，暂不扩大共享引擎改动。
- **复用 `traditional_chinese_output`**：不增加字段，但全局开关语义是普通中文方案的简转繁，直接复用会让注音跟随其他方案的选择，且账号同步和跨宿主行为不清晰；不采用。
- **新增独立设置页开关**：能明确表达选项，但 HarmonyOS 当前设置页是共享页面，且已有简繁按钮是即时入口；新增入口会重复设置并扩大 UI 迁移范围，不采用。

## Consequences

注音在鸿蒙可以沿用已有简繁按钮切换为简体输出，默认行为和其他平台不变；共享偏好增加一个默认关闭字段，鸿蒙 NAPI 暴露反向 OpenCC 转换。转换在宿主边界执行，因此 Engine 的注音候选身份、词库原文和选词下标不变；代价是预编辑阶段仍可能暂时显示词库原文，需真机验收确认。

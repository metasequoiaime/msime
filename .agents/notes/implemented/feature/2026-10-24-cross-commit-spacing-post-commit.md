# Agent Note: macOS 跨次上屏中英文空格

Status: implemented

## Problem

#9423 要求普通写作的「用」→英文直通「Rust」→中文「写」得到「用 Rust 写」，也覆盖临时英文候选。既有开关只改一次上屏内部，无法处理这条路径。

## Decision

保留草稿的共享偏好 `cross_commit_spacing`（默认关）与 `cross_commit_spacing_excluded_apps`（默认空），仅 macOS 提供入口与消费。沿用应用名单的 32 条、64 字节、ASCII 不分大小写去重校验。共享 Rust 判断应用排除、上屏模式和汉字／ASCII 边界，提供不创建会话的纯 C ABI；宿主只读实际文档并写入。

补的是新输入与前文的接缝：只在新文本前加一个 U+0020。没有尾随空格，不移动光标，不改右侧已有文本；连续输入 Rust 不被拆成 R ust。旧单次内部开关保持独立。普通中文、快捷短语、超级简拼、临时英文和英文直通可触发，网址、日期、计算等专用模式、全角与安全输入不触发。网址／邮箱／代码的自由输入无法单凭一个字符准确识别，由独立开关和应用排除控制。

先按原文上屏，再核对折叠光标前恰好等于本次实际提交的文本，读取其左侧标量；包含待闭合标点时校验完整插入文本。通过共享规则后，用显式文档范围把这段新文本替换为「空格＋原文」，光标仍在其末尾。选择替换和真实 marked text 由原本的第一次上屏处理，不猜组字起点。未知范围、不匹配、非折叠选区、超过 4096 个 UTF-16 单元均跳过；支持代理对与 SDK 允许的扩展返回。不缓存、持久化或记录文档，替换不重复计入打字统计。

英文接管先用激活时缓存的应用标识调用共享策略，排除或未知应用维持原直通语义，不为判断路由新增同步查询。原始写入前捕获焦点、派发和事件代次。`handleEvent:` 最早入口、每次 `apply:`、激活／停用都会让旧令牌失效；同步查询每一步之后检查令牌、客户端、安全输入、配置未变与当前全角状态。新按键已经能在落地原文后正常处理，所以失效时只放弃可选格式化，不丢字，不排队或重放返回 `NO` 的事件。英文路径启用时由宿主原样写字母数字，再做相同格式化，不需要引擎会话。非中文或未知方案不退回全拼。

提交观察器位于原文插入之后、旧预编辑写入之前，也在观察器之后检查令牌。格式化令牌与旧转换写入所有权分开：普通抬键让格式化过期，但不阻止已经完成的上屏清理旧候选。写后保护与成对标点提前发布状态沿用远端 PR #9405 固定提交 `e3821cfbccac8c97ad64169b390caec9ceac056a` 的方法，再增加观察器与事件代次保护；没有复制相邻 worktree 的未提交内容。该 PR 单独不能解决提交前查询的保序问题，故不把它当成解锁条件。

补空格多一次显式替换，可能增加撤销步骤；设置说明展示这个代价。真实应用的撤销合并、IMK 往返延迟仍需装机验收。客户端拒绝范围或抛出异常时原字保留，只放弃格式化。

本决定替代[初版跨次空格](2026-10-24-cross-commit-spacing.md)的提交前查询和会话内边界接口；保留其持久化字段、独立设置组件与真实引擎会话测试。策略请求的 `config` 对象只用于 ABI，不改变两个落盘字段。

### API 与参考

本机 Xcode SDK `HIToolbox.framework/Headers/IMKInputSession.h` 明确 `selectedRange`、`markedRange` 为文档坐标，客户端可返回未知；截取代理对可扩展返回。参考 `ShunmeiCho/cmd-ime` 固定提交 `4dd4035ff3d4b113dc104ce5cad8ec3ed8c0b189` 的 `AutoSpace.swift`，同样默认关、只补前面的接缝。未复制上游代码，不引入 AX 权限或事件注入。

## Alternatives considered

- 提交前同步读文档：可以一次写入最终文字，也更易合并撤销。但查询会同步派发下一键，字母队列不能保留空格／退格／快捷键顺序；在重入事件入口先补旧字的 continuation 也会在补写再次重入时乱序，公开 IMK API 没有完整事件重放入口。因此先落原文再查询，令牌失效只放弃格式化。
- 在提交末尾也补空格：中间插入时两侧立即齐全。但 IMK 无通用移动光标接口，英文直通时每个字母后补空格会拆开单词，因此只处理新输入之前的边界。
- 使用上次上屏 shadow：兼容不可读客户端且快。但鼠标移动、选择、外部编辑会让它过时，可能在错误位置插空格，故未知时原样。
- 各宿主自行实现规则：接线简单，但与现有共享变换分叉；规则和偏好仍归 Rust。

## Verification

- 默认关且省略默认配置，启用、排除名单和非法值验证可回归。
- 中文／英文两向、数字、临时英文、已有空白、标点、全角、排除模式和未知上下文覆盖。
- 原生文档测试覆盖实际上屏范围、尾段不匹配、代理对和不可读接口；控制器覆盖英文无会话、查询／写入／替换重入、选择替换和真实 AppKit marked text。
- 整合远端草稿后的 Rust 验证通过：`msime-client-core` 偏好测试 194 项，`msime-host-api` 中英文空格相关测试 8 项及跨次 ABI 边界测试 1 项；Clippy 与完整本地 quick 仍作为提交门禁执行。
- macOS 原生 CMake 重建后，`text-client`、`shortcut`、`shortcut-english-punctuation`、`shortcut-cross-commit-spacing` 和 `cross-commit-spacing` 五组 CTest 全部通过（5/5，40.34 秒）。桌面设置页 Vitest 824 个文件、5188 项测试全部通过，TypeScript 类型检查和 Vite 构建也通过。
- 尚未在真实 IMK 应用中装机验收；显式替换可能增加一次撤销步骤，真实应用的撤销合并和延迟仍需后续验收。

## Consequences

某些应用不提供文档上下文，此时跳过。此功能不推断 URL／邮箱／代码语义，用户应排除相应应用或关闭。旧版偏好解析器可能不接受非默认的新键。未装机验证不声称真实编辑器通过。

# Agent Note: Windows 7 原生语音设置与模型管理

Status: implemented

## Problem

兼容语音运行库已有独立构建，但 Windows 7 仍缺少语音设置承载。服务接入、麦克风、模型管理、润色和快捷键都需要用户可操作的入口，不能只让录音后台读取现存配置。

## Decision

原生设置复用共享服务目录、换服务补丁、接口和凭据预检、配置测试、本地模型与资源包 C ABI。表单只映射字段，保存仍使用同一 CAS 偏好库，不翻转默认值。凭据按服务分别保存，切换服务不把旧密钥发给新服务；测试结果绑定发出请求时的配置，修改配置即失效。麦克风与模型目录读取、下载、导入和删除均在串行工作线程，取消安装可从界面独立调用共享取消接口。

## Alternatives considered

- **只提供配置文件编辑。** 能复用全部字段，但无法替代服务切换的凭据隔离、模型校验与安装操作，因此提供原生控件和共享接口。

## Verification

Windows 11 服务会话中，full x64／x86、五笔 x64、日文 x64 四组 MSVC `/W4 /WX` 构建和每组 11 套 CTest 通过；设置程序通过现有 PE 已知阻断导入检查。补充损坏麦克风条目提示、模型元数据呈现与缺少新目录时禁用旧选择后，四组独立语音测试再次通过。

实际 HWND 和真实共享偏好验证只读打开与无改动保存不增加修订，明确修改语言时保留旧文档同时启用多个长按键和两项润色开关差异；服务独立凭据槽切换、非法地址拒绝、配置测试与草稿绑定、明确选择长按键、麦克风切换和失败保留现有选择。模型目录来自真实共享清单，展示语言、流式与热词能力、大小及许可来源；传输注入只替换下载和设备边界，检查文件选择取消、离线请求、安装后空路径填入、选用与删除、损坏目录禁用、安装期间独立取消和首次进度登记后真实共享接口取消。测试使用合成数据，不读取私人音频、不下载模型、不发真实网络配置请求。全部源码 quick 尚需随本轮快照补验。

## Consequences

Windows 7 的语音设置、独立服务凭据、润色、麦克风和模型管理有了可操作的原生承载；偏好规则、测试与模型安装仍归共享 Rust。兼容运行库由最终安装包配套，本页不下载普通运行库覆盖它。代价是原生控件与共享页面能力需要持续核对，独立语音面板与最终安装已集成，双架构原生窗口和本地模型推理已在 Win7 SP1 验证；VM100 的 HDA 虚拟声卡已通过双架构核心与同源 Server 录音、播放渲染及提示音，物理麦克风／扬声器和在线识别服务未验收，详细证据见[产品构建](2026-10-24-windows7-product-build.md)；打开页面不自动录音、测试服务或安装资源。

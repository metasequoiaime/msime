# Agent Note: Android 长按语音按按钮命中并支持锁定编辑

Status: implemented

## Problem

#10327 要求长按空格的取消、锁定和发送按可见按钮命中，锁定后松手继续录音，并允许插入标点、编辑及打开符号面板。原实现按上滑距离取消，没有与命中区域对应的按钮，也没有锁定状态。

## Decision

长按面板覆盖字母区与原功能行；原行保留挂载和测量，用于接收原空格的触摸流，重建键行时显式取消旧录音。面板最下一行是 🔓｜松开发送｜发送，与原功能行同高、正好盖在它上面，按住原空格的手指就落在「松开发送」上，水平左滑到锁定、右滑到发送；取消和符号、标点等编辑行在它上方。面板用屏幕坐标命中当前面板上实际排版的取消、锁定、发送按钮。移出按钮立即清除高亮；其余位置松开发送，系统取消事件丢弃。锁定后空格和锁定按钮不再操作，取消、发送、符号、标点和其他编辑按钮继续生效。符号面板覆盖聆听面板，返回只撤下符号层。

按住和锁定都抑制本地停顿结束。服务自行结束时保留结果并明确显示录音已经结束，等用户发送或取消，不伪称麦克风仍在采集。锁定期间允许用户调整当前输入框的光标与内容，点发送时显式重新捕获插入位置；发送后继续复用原来的文本、选区和代次检查，编辑器变化不能让迟到结果直插。切换输入框、隐藏键盘与销毁服务照旧取消。

复用已有角色位图与音量回调，不引入新图片或动画线程。分类签与语音共用的后台缩略图按 64 dp 上限解码，缩放绘制启用位图过滤。问候语只用于长按入口；自定义问候语是 issue 的可选建议，本次不增加配置格式。狭窄或矮键盘优先保留操作按钮和识别文字，插图在矮面板中与文字并排，保留一行最新文字与可容纳的状态说明。

## Alternatives considered

- **仍按上滑距离取消，只把按钮画出来**：手势更宽容，但按钮与真正生效范围不符，重现 issue 指出的问题。
- **锁定后仍以开始录音时的文本快照直插**：保护最严格，但用户按要求改了标点或光标就必然只能转存结果。显式发送重新授权当前位置，之后的异步保护保留。
- **自动延长或重启系统识别服务**：可能延长一次口述，但各服务的时长、分段与权限边界不同，不能把界面锁定当作无限采集承诺。

## Consequences

取消区的大小与实际按钮一致，移出后松手恢复发送；这比原来的整片上滑取消区更精确，也要求用户滑到可见按钮。锁定编辑重新授权发送瞬间的位置，之后发生的编辑仍由原有异步上下文保护拦住。长按结果发送成功后立即恢复拼音键盘，点按入口保留原完成提示。

操作区占三行，每行 44 dp。剩余高度不足 130 dp 时角色和一行最新文字横排；否则保持竖排。关闭系统动画时红线归零，不另建动画线程。角色资源读取失败时保留麦克风回退。

# Agent Note: Android 剪贴板历史多选删除

Status: implemented

## Problem

剪贴板历史只能逐条删除或全部清空，用户无法一次选择若干条记录并在误删后撤销。

## Decision

本机历史面板增加多选模式和顶行操作。选中的文字集合只作为 UI 状态，删除通过共享存储的原子批量契约执行；共享层返回被删条目的完整快照（文字、时间戳和固定状态），Android 在内存保留五秒，面板显示撤销入口，撤销通过原子恢复接口写回原始元数据。

## Alternatives considered

直接在 Android 层维护另一份历史快照可以一次写入，但会复制共享存储的排序、固定和容量规则，设置页与键盘容易分叉，因此沿用共享入口。逐条调用共享删除再用 `add` 撤销无法保证一次操作的原子性，也会丢失时间戳和固定状态；新增 `remove_many` / `restore_many` 让共享层同时完成锁定、持久化和容量处理。

## Consequences

用户可以选择性清理并短时间撤回，且撤销会保留删除前的排序元数据。恢复时已有同文条目不覆盖，避免撤销误删掉用户随后新增的内容；容量规则仍由共享层处理。撤销窗口只在当前输入法进程内有效，进程退出或超过五秒后不保留待恢复数据；设备测试应使用合成剪贴板内容覆盖选择、删除和撤销。

# Agent Note: 手机底行保留逗号并以长按输入句号

Status: implemented

## Problem

#7835 要求符号键替换原逗号的位置，逗号替换原句号的位置，并通过逗号的次级操作输入句号。主线后来把手机 26 键底行改为「符、123、空格、中、回车」，两个标点键均已移除，与旧需求冲突。产品方在本轮明确选择「保留独立逗号，长按或上滑输入句号」，取代删除逗号的决定。

## Decision

按 issue 原键位关系，iOS、Android、HarmonyOS 手机 26 键字母层底行采用「123、符、空格、逗号、中/英、回车」；系统要求的地球键保留，宽度跟随既有份额。点逗号走原标点路由，长按输入句号，不再放独立句号键。此次选择长按作为次级操作，兼容未开启滑动符号的用户，避免引入新的滑动识别规则。符号键仍打开原符号面板。

九键侧栏、数字与符号层、iPad/2in1、14 键和手写等自带底行的键面保留各自已有规则。热力图必须跟随实际底行，不再把句号画成独立键。

## Related decisions

- [26 键底行符号键](../../implemented/feature/2026-10-16-26key-bottom-row-symbol-key.md)：部分取代去掉逗号及最左符号键的安排，保留原符号面板动作、九键和其他键面边界；新决定来自产品方对冲突的明确答复。
- [手机底行](../../implemented/feature/2026-10-09-mobile-bottom-row-symbols-and-return-yield.md)：保留语言键靠近回车与回车让位规则。
- [热力图跟随键盘](../../implemented/bug-fix/2026-10-16-mobile-key-heatmap-follows-keyboard.md)：复用同一布局或同步其原生静态描述。
- 其余检索命中涉及九键双拼、14 键、字母角标或词义插入，和这次 26 键底行的决定无关。

## Alternatives considered

- 保留主线五键底行能让空格更宽、与九键一致，但每次输入逗号都要先切层，产品方已选择恢复独立逗号。
- 同时保留独立逗号和句号最直接，但底行多一键会压缩空格，且不符合 issue 以次级操作取代独立句号的要求。
- 上滑输入句号可以更快，但三端都要识别滑动方向、取消普通点按并兼顾现有光标和手势规则；本轮先用长按满足次级输入，保持规则一致。

## Verification

Android 宿主检查通过（238 项 JVM 冒烟、145 个设备套件源文件编译），共享热力图 13 项通过；补齐移动统计整页对逗号位置、计数及九键其他键列表的断言后，共享 UI 完整 681 文件、4060 项测试通过。初轮完整运行另有云剪贴板按钮状态断言失败，独立重跑及完整重跑均通过，未修改该功能，首次原因未确认。桌面类型检查与 HarmonyOS 逻辑套件通过。arm64 原生库与实际 ArkTS HAP 编译通过；iPhone 17 / iOS 27 模拟器中 50 项键盘测试和 14 项共享统计测试通过；远端全量检查发现韩文测试仍期待旧标点菜单，改为检查 ASCII 句号角标和长按回调后，韩文整组 14 项本地回归通过。初轮脚本省略日语资源导致日语布局检查实际选到回退方案，补齐固定资源后重跑通过；热力图回归同步补齐逗号的无障碍标识与“其他键”断言。Android API 28/35 安装后的核心验收通过，覆盖七种数字页方案、输入、候选与剪贴板生命周期。初轮 Android 包未暂存固定语言词库，笔画回退全拼；补齐锁文件校验后的词库并从全新模拟器状态重跑后通过。逗号专项在生命周期验收强停宿主后曾找不到键盘，测试启动时先拉起宿主并重新绑定输入法后，API 28/35 的真实长按专项均通过，覆盖一次句号、组字提交、中英标点与符号入口。API 35 的九键切英文逗号、14 键和符号面板回归通过；最终 `scripts/verify-local.sh --quick`、lint、格式检查、前端生产构建与笔记门禁通过；quick 完成 Windows x64 原生链接与共享壳检查，Linux 桌面壳因本机无 Docker 明确跳过。

## Consequences

三端手机 26 键恢复直接输入逗号，长按沿用原标点路由输入句号；数字和符号面板入口各有独立键。新六键底行比原五键底行略窄，空格和回车保留原权重，紧凑宽度由原生布局回归覆盖。

Android 消费长按回调，iOS 复用角标触摸取消机制，HarmonyOS 复用既有长按手势仲裁，长按后不得追加普通逗号。其他布局继续使用原标点菜单，iPad 与 2in1 独立底行不改。Android 逗号可见性跟随实际键面，九键切到独立英文的 26 键后也会显示，不再被原中文方案隐藏。Android 没有单独的平板底行，本改动随其现有 26 键底行同时生效。

构建与组件测试不能替代未连接设备的真实操作验收；本次不记 HarmonyOS 设备或 iPhone 实机通过。

# Agent Note: Android 剪贴板记录详情

Status: implemented

## Problem

#9963 希望在键盘里的本机剪贴板面板直接打开单条记录的详情，查看记录时间、来源应用和包名，并从详情插入原文或返回原列表。现有卡片只显示相对时间，长按打开的是全文预览和管理操作。

## Decision

本机历史卡片左侧增加独立详情入口。详情仍画在原剪贴板面板内，返回时重新读取同一分类的列表，不弹出可取焦点的窗口；插入沿用原记录的插入动作。详情只持有打开时的记录快照，面板关闭或重新打开即清理。记录时间由共享存储已经保存的毫秒时间戳按设备本地时区显示，缺失时明确写“时间未知”。

Android 公开的 `ClipboardManager` 和 `ClipDescription` 没有提供复制来源应用包名的可靠字段。详情对这两项显示“系统未提供”，不把当前编辑器的包名误当复制来源，也不从剪贴板标签猜测。这两个字段只有未来取得可信来源并写入共享记录后才能填充。

## Alternatives considered

- **沿用长按全文浮层加元信息**：能复用窗口，但它是覆盖键盘上方的阅读入口，返回到列表与插入操作的状态不如面板内详情明确，而且仍不能得到来源。
- **用当前输入框的应用包名代替来源**：容易得到字符串，但复制和粘贴可能发生在不同应用，记录会产生错误归属，因此不用。

## Consequences

用户可以在键盘内查看完整记录时间和正文，并直接插入或回到之前的列表；多选、左滑删除和长按管理保持原有入口。每条记录左侧的详情键占用一些卡片宽度，双列布局下正文可见行更短。来源应用和包名仍是 #9963 的未完成部分，不能把本改动标为完整关闭该 issue。

## Verification

`ClipboardDetailPolicySmoke` 用合成时间验证本地日期与未知值；`platforms/android/check-host.sh` 验证 JVM 冒烟和宿主契约。由于本机空闲磁盘低于仓库规定的 50 GiB 新构建门槛，未在 Android 模拟器上装包；PR 合并前仍需设备验收入口、返回、插入及双列布局。

# Agent Note: 数字拼音混输带圈序号

Status: implemented

## Problem

#9088 的参考截图输入 `yi`，在普通中文候选后给出 `①`。原有内置符号表没有数字序号，用户必须离开组字去符号面板寻找。

## Decision

在既有 `symbol_candidates.tsv` 中补充 Unicode 已编码的带圈数字 1–50；1–20 同时给出括号和点号形式。使用自然中文数字名称及其完整拼音，沿用 `mixed_input.symbols` 开关、全拼/双拼归一化与九键读法查询，不新增候选来源、偏好或宿主规则。

一至十作为单音节名称，仅当对应数字汉字在候选中时才出现，最早排第 4 位，保留前三个普通词。两位数沿用现有多音节名称的放置规则，但数字名称不建立首字母索引：`ss` 同时指十三、十四、三十、四十等多个序号，真实词库探针已证明会耗尽符号候选上限。只查询完整拼音名称，首字母和输入前缀不能把其他数字一并带出。符号选中后整段提交，不参与学习或调频。

当前提供数字序号候选；候选窗里的「更多特殊符号」动作尚未实现，PR 使用 `Refs #9088`，不自动关闭 issue。

## 历史检索

- [符号混输](2026-10-13-symbol-candidates.md)直接持有本功能的数据和放置规则，原篇以缺少自然名称为由未收录带圈序号。参考截图提供「一」这类数字名称的明确用例，本决定只翻转其数字序号排除，其他名称、放置和学习规则沿用。
- [桌面符号目录](2026-10-14-desktop-symbol-directory.md)持有面板入口与类别，不持有普通拼音候选，不在该篇加入引擎规则。
- 检索 proposed、implemented、rejected 后没有其他数字序号候选提案。

## 已完成的实验

新增两项混排与双拼/九键读法回归在旧实现上失败，确认缺少序号；补表后完整引擎单测 2399 通过、50 既有忽略、0 失败。首轮真实词库探针发现 `ss` 的多个数字别名触及上限，四十的符号缺失；因此数字名称不继承首字母匹配。所有 12 个资源的大小与 SHA-256 已按 `desktop-dictionary.lock.json` 校验。码位对照 Unicode 的[封闭字母数字](https://unicode.org/Public/18.0.0/charts/nameslist/2460/)与[带圈中日韩符号](https://unicode.org/Public/18.0.0/charts/nameslist/3200/)清单。

## Alternatives considered

- 只在符号面板补序号：不增加常用音节中的符号候选；无法满足截图中的普通拼音候选，因此本次通过既有符号混输表补充，面板职责独立。
- 单独建立序号输入模式或新候选来源：语义与动作扩展清楚；需要新增触发方式和多端契约，现有符号来源已有整段提交且不学习的语义，因此不新建。
- 单音节无条件给出序号：更容易发现；常用拼音可能表示许多字，沿用锚定与最早第 4 位规则降低干扰。
- 两位数也认首字母：减少输入量并完全复用旧索引；数字前后颠倒和同音首字母组合过多，实测会耗尽符号上限，因此数字仅认完整拼音，不修改非数字符号的首字母规则。

## Verification

- 新增回归在未补表时失败，证实序号缺失；补表后完整引擎单测 2399 通过、50 既有忽略、0 失败。
- 首轮真实词库探针暴露 `ss` 别名冲突；数字不建立首字母索引后，完整 `symbol_candidates_dictionary` 探针通过。数字专用探针校验 50 个名称的 90 个序号，逐个选中后整段提交且组字清空，关闭符号混输后没有本次来源的序号；额外小鹤双拼与九键各验证三个符号，上屏、清空和开关均通过，合计 96 次选择。
- 资源的全部 12 个文件按固定锁校验大小与 SHA-256；严格 `cargo clippy -p msime-engine --all-targets -- -D warnings` 通过。
- 最终 `bash scripts/verify-local.sh --quick` 通过，包括 Linux 108 项原生测试、macOS 原生编译和 Apple 桥接编译；完整引擎单测及笔记校验通过。Windows 原生编译和 HarmonyOS HAP 未在本轮本机门禁执行，交由对应 PR CI 检查。真实词库探针属于引擎会话验收，不等同于六个平台候选窗的字体显示验收。

## Consequences

收益是全拼、双拼和九键使用同一套数字序号数据与既有的提交、开关、学习规则；代价是引擎内置表增加 50 行，数字名称需要完整拼音，不提供首字母缩写。

旧系统字体可能不包含 21–50 的码位，本次没有对六个平台的候选窗逐一检查字形。候选直接跳转符号面板尚未完成，issue 保持开放。

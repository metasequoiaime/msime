# Agent Note: 一句话开头不出句尾语气词，回车记成上文里的换行

Status: implemented

## Problem

聊天里一条消息开头单打 `ma` 想要「妈」，Mac 上自动打字验收 52 次全成了「吗」。整句开头的「爸」也常被「吧」顶掉（「吧肯定很开心」）。

原因有两层：

- **不看位置**：「吗」的词频是「妈」的 51 倍，「吧」比「爸」高两成，可这些词频几乎全来自句尾，排序时却不看位置。逐键模型也碰不到单打的情形：词典首选是可信的，`rerank_needs_model` 不交给它比较。
- **不知道新消息开始了**：消息之间的回车直接交给了应用，从没进上文，输入法分不清哪里是一条新消息的开头。

## Decision

- **runtime：回车记成换行。** 没有组字时派发的 `Command::CommitRaw`（宿主按回车时发的命令），引擎什么都没上屏也没处理时，`Runtime::remember_commit("\n")`：回车交给了应用，在上文里记一个换行。凡是把回车交给会话的宿主都用得上，不必改宿主。
- **判断句首：`msime_engine::lattice::decode::opens_sentence`。** 上文为空，或者最后一个字是换行或句末标点（。！？!?…），就是一句话的开头。
- **整句解码：开头扣分。** 句首时，第一条边是只出现在句尾的语气词（`SENTENCE_ONLY_FINAL_PARTICLES`：吧、呢、吗、啦、嘛、呗、咯、喽）就扣 `SENTENCE_OPENING_PARTICLE_PENALTY`（3.0，与句尾语气词加分对称）。整句解码缓存的键里加了「是不是句首」。
- **单字：首选让开。** 单打一个音节时不走整句解码，由排序决策的 `opening_particle_pick` 处理，它在 runtime 的呈现排序里、逐键重排之前调：句首、首选是这类语气词时，提到首位的是第一页里第一个不是语气词、同样回答按键的单字词典行。挂着逐键打分器时，由它在这些单字里挑。
- **叹词不算。** 啊、呀、哦、哇常作叹词放在句首（「啊，忘了」），不在这张表里；第一版连它们一起让开，`rime_collection_keeps_shipped_single_character_order_when_disabled` 因此失败。

## 评测

2026-11-03 用 `convert_eval` 对比 develop 和本分支，资源去掉随包模型，分只用引擎、6x256 配 32 条两组。聊天集是 typing-chat-v1 按标点切出的句段，上文里消息之间加了换行（`\n` 转义，`convert_eval` 读上文时还原）。

六个集合、两组的首选准确率全部不变，没有改对的，也没有改错的。逐条看：

- 会话开头单打的「妈」从「吗」变成「马」：没有任何上文，模型在「马」「妈」之间按常见程度猜了「马」。
- 「爸肯定很开心」在挂模型时，develop 上本来就对。只用引擎时「吧」退到第三，可领先的是「把」。
- 「你和爸注意身体」的「爸」在句中，不归这条规则管。

这一篇只保证句首不再出「吗」「吧」，并让上文分得出消息的边界。「妈」要靠学习：用户选过一次就排前面，验收的自动打字关着学习，所以测试里总是错。

## Alternatives considered

- **宿主在发送消息时把上文清空。** 也能让下一句成为开头，但要逐个平台改宿主，而且清空会丢掉上一条消息这个对模型有用的上文。记换行两样都保住了。
- **句首时让逐键模型在全部单字里挑，不先把语气词挪开。** 模型在空上文时同样会选高频字。挪开语气词是确定的：句首的「吗」不会对。
- **把叹词也算进去。** 句首的「啊」「哦」是常见用法，不让。

## Consequences

- **收益**：句首不再以句尾语气词开头；上文里有了消息的边界，后续按句首调排序（以及逐键模型看到的上文）都能用上。
- **代价**：上文多了换行。在编辑器里按回车也会被当作句子的边界，大多数情况下也确实如此。
- **已知没解决**：会话开头单打 `ma` 现在是「马」，不是「妈」。

## Verification

- `crates/input-runtime/src/tests/sentence_start.rs`：没有组字时回车记一个换行；句首单打 `ma`、`ba` 首选是「妈」「爸」，`a` 仍是「啊」；句中（上文是「好」）仍是「吗」，回车之后又是「妈」。
- `crates/engine/src/lattice/decode.rs` 的 `a_sentence_does_not_open_with_a_final_particle`：用锁定词库的权重，句首 `ba'ken'ding` 解成「爸肯定」，句中仍是「吧肯定」；`opens_sentence` 的几种上文。

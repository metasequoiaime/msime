# Agent Note: 候选窗口设置通过顶部标签切换

Status: implemented

## Problem

桌面候选窗口设置把布局、字体、窗口样式和预编辑串成一条长页，预览预留纵向候选高度后，后面的设置需要连续滚动才能找到。用户要求这四组通过顶部标签切换。

## Decision

桌面共享候选窗口页在预览上方提供「布局、字体大小、窗口样式、预编辑」四个标签，默认显示布局。预览共用且保持挂载，各组通过隐藏切换，保留字体输入等局部状态。标签支持左右方向键和 Home、End，并关联对应面板。触屏候选栏沿用当前布局。

## Alternatives considered

按标签卸载非当前组可以减少 DOM，但字体输入和字体列表读取状态也会被重置；保留挂载可避免切换丢失编辑状态和重复请求。

## Consequences

四组设置有直接入口，只有当前组参与布局和可访问性树。切换不会清空草稿、重置字体输入状态或重新挂载预览，离开再返回本页也保留选择。所有组仍挂载，初次打开页面的组件数量没有减少。原有按可访问性角色查找非默认组控件的测试先选标签；手机不增加面板包装，保持原有分组间距和顺序。

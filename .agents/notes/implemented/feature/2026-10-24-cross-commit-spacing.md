# Agent Note: macOS 跨次上屏的中英文空格

Status: implemented

## Problem

#9423 要求分次提交中文、Shift 英文直通、再提交中文时自动隔开，也覆盖 Shift+Y 临时英文。现有单次文本内部的开关不能读取文档边界。旧决定见[中英文之间加空格](../../implemented/feature/2026-10-12-chinese-english-spacing.md)，该开关及默认值继续保持；本篇单独补充跨次能力。

本篇记录 PR #9481 初版方案；提交时序与 ABI 已由[提交后校验方案](2026-10-24-cross-commit-spacing-post-commit.md)替代。以下验证缺口为初版阶段事实，当前验收以新篇和 PR 为准。

## Decision

提供独立的 `cross_commit_spacing`，默认关闭；`cross_commit_spacing_excluded_apps` 允许按 macOS Bundle ID 排除编写代码、网址和邮箱的应用。应用名单复用共享偏好的标识、去重和数量校验。设置入口仅在已接入的 macOS 展示。

共享 Host API 复用现有汉字与 ASCII 字母数字边界谓词，并读取最新请求的偏好与排除名单。macOS 同时接入候选上屏和英文直通，不把输入算法放进宿主。只传前文的一个 Unicode 标量，不保留输入历史。宿主从当前文档读取前文，预编辑存在时从标记范围起点读取，避免把拼音末尾误当作文档前文。无法读取、存在选区或标记位置不明时保持原样，不借用智能标点的历史缓存。

普通中文、快捷短语、超级简拼和临时英文允许跨次处理，特殊网址、计算、指令、语音和非中文方案排除。全角输出不满足 ASCII 边界。此功能只对当前插入点左侧与新上屏首字符的边界添加一个半角空格，不改写已有文本。密码字段和系统回送事件不参与。

## Alternatives considered

- 复用智能标点的末字符缓存，能够覆盖终端等不提供文档的应用；但鼠标移动和应用自改文本会让缓存失效，自动加空格没有足够证据，因此仅用真实文档读取。
- 自动识别所有代码、网址和邮箱，用户无需配置；但普通文字中的产品名、数字与代码片段无法可靠区分，跨次英文尚未输入完整时更无法预判，因此提供应用排除名单。
- 在引擎连续提交之间记住末字符，可以共用六个平台实现；但看不到英文直通、鼠标移动、替换选区和宿主修改，因此由宿主提供实际边界，共享层统一判断。

## Verification

已运行：前端类型检查；跨次空格、原单次空格、Vim 应用名单共 8 项交互测试与设置页完整 400 项回归（共 408 项）；`CrossCommitSpacingContextTest.mm` 直接链接当前 `TextClient.mm` 后运行，覆盖标记范围之前的扩展区汉字、选区、未知范围、不可读文档、异常范围和非法代理项；修改的四个原生实现与完整控制器测试均通过 Clang 严格语法检查。仓库 `scripts/run-checks.sh` 全部通过或按已有前置条件跳过。

新增 Rust 回归覆盖默认关及独立序列化、排除名单校验、即时读取尚未应用的偏好，以及两种方向、数字、空白、非法标量和未知会话。完整 macOS 控制器回归接入 CTest，包含真实会话的中文候选上屏、外层英文直通、临时英文上屏模式和网址模式豁免。

PR #9481 首轮 CI 已通过 Android、Linux、Windows、HarmonyOS、Wasm、共享设置页、契约与笔记检查；macOS 原生构建及前文适配测试通过，178 项 CTest 中仅新增完整控制器测试失败在会话创建。夹具误把输入框预编辑枚举 `raw` 写入只接受 `pinyin` / `empty` 的 `candidate_preedit_style`，共享层正确拒绝了配置，尚未执行到空格断言。夹具现在直接沿用共享层发布的合法默认值，并分别断言创建与聚焦，避免再次混淆这两个预编辑字段；修正后的完整控制器测试待 CI 重跑。缓存诊断库可复现原配置被拒、删除无效字段后可创建并聚焦，但它不是本分支构建，不能替代当前源码验收。

尚未执行新增 Rust 回归、修正后的完整控制器回归、clippy、完整 quick 或装机输入验收：本机及远端构建卷均低于仓库 50 GB 门槛。可单独构建运行的前文适配测试体积不足 1 MB，不创建 Rust 或 CMake 依赖树；不将它视为完整宿主验收。此缺口需要补齐后才能将 PR 转为可合并。

## Consequences

跨次处理需要读取应用文档，有一次上下文查询成本。无法提供真实范围的应用不会添加空格。独立开关允许用户选择此行为，应用排除依赖用户维护。当前磁盘低于仓库完整构建门槛，不能将静态检查当作原生运行验收。

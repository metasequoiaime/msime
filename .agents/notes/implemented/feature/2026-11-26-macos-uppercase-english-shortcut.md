# Agent Note: macOS 单按 Shift 的大写英文与快捷键转交

Status: implemented

## Problem

macOS 输入法的单按 Shift 会切到英文模式，但后续字母仍按普通英文模式输出小写。用户需要输入连续的大写字母时必须继续按住 Shift，带 Shift 的游戏快捷键又会被英文直写路径当成字符消费。

## Decision

单按 Shift 从中文切到英文时进入本次会话的大写英文模式。无修饰字母直接输出大写 ASCII 字母，带 Shift 且没有 Command、Control、Option 的组合键交给前台应用。通过菜单、Caps Lock、Ctrl+空格和其它英文入口进入的英文模式保持原有大小写和按键路由。再次单按 Shift 回到中文时清除本次大写英文状态。

大写英文状态只保存在输入法控制器的运行时，不写入共享偏好，也不改变普通英文模式的默认行为。游戏快捷键的判断发生在英文直写前，避免字符转换先消费按键。

## Alternatives considered

- **让所有英文模式都输出大写**：实现最简单，但会改变菜单和其它入口进入英文模式的既有行为，放弃。
- **增加一个持久化的大写英文设置**：能让用户选择，但会把一次性按键需求变成跨平台设置，还需要迁移共享设置页和原生设置，当前需求不需要这层持久化，放弃。

## Consequences

单按 Shift 后可以直接输入大写字母，Shift 组合快捷键在这个运行时模式下回到应用。普通英文入口仍保持原行为。回归测试覆盖单按 Shift 后的大写输出和 Shift 组合键不被输入法消费。该状态在输入法重启、切换到中文或从其它入口进入英文时清除。

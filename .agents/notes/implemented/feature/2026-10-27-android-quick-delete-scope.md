# Agent Note: Android 快速删除范围可选

Status: implemented

## Problem

退格键上滑快速删除原本只清除光标前文字。用户在光标位于输入框中间时无法一次清除光标后的内容，同时扩大默认范围会改变已有手势习惯。快速删除已有一次性撤回能力，需要让全框清除也能恢复。

## Decision

新增只保存在本机的 `quick_delete_scope` 选择，默认 `before`，可选 `all`。设置页明确标出两种范围。选择 `all` 时，宿主读取光标前后有界文本，显式选中整段并提交空文本；成功后用同一份内存撤回机制保存一次备份。普通退格和左滑连续删除保持原路径，密码、无痕、禁止学习和超出有界读取范围的输入不提供全框清除。

## Alternatives considered

- **直接把上滑快速删除改为全框清除**：会静默改变现有用户的手势行为，因此不采用。
- **把光标后的内容加入现有“光标前”删除循环**：会让范围无法由用户选择，也难以在编辑器拒绝跨区选择时保持可恢复，因此不采用。

## Consequences

用户可以明确选择全框清除并在短时间内下滑撤回；默认行为和其他删除手势不变。全框模式依赖编辑器支持 `setSelection`，读取超过有界上限时安全放弃而不误删。合成 InputConnection 和 Android host 检查覆盖策略接线，真实远程编辑器和模拟器操作仍需后续设备复验。

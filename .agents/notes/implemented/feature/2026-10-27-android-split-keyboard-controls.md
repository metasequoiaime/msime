# Agent Note: Android 分离键盘启用条件与中间空隙可调

Status: implemented

## Problem

大屏和折叠屏用户只能使用固定的 600dp 分离阈值与自动中间空隙比例，无法按设备外屏、内屏或握持习惯调整分离开始宽度和左右两半的间距。

## Decision

Android 本地设置新增两个有界整数：分离启用宽度为 480–1000dp、步进 20dp，默认 600dp；分离中间空隙为 10–40%、步进 5%，默认 25%。键盘策略在每次布局重建时读取这两个值，仍保留当前屏幕宽度为键区提供的最低空隙，避免宽屏上键区被拉得过宽。设置仅保存在本机，不进入账号同步；旋转、折叠和本地设置重载都沿用现有重算路径。

## Alternatives considered

- **只把常量改成新的产品默认值**：无法满足不同设备的调整需求，也会改变已有用户的键盘手感，因此保留原默认值并增加有界控件。
- **允许任意 dp 和百分比**：会产生不可用的窄键区或过大的中缝，故使用固定步进和范围。

## Consequences

用户可在大屏设置页分别调整阈值与中间空隙；窄外屏仍由阈值自动禁用分离，默认行为保持不变。设置页保存后输入法重新布局，分离键盘的行断点、重复键和空格拆分规则不变。

## Verification

`bash platforms/android/check-host.sh` 通过；`SplitKeyboardPolicySmoke` 新增阈值上下界、空隙上下界、宽屏最低键区和自定义空隙计算断言。当前磁盘空间低于仓库要求的 50GiB，未启动 API 28/35 模拟器完整验收。

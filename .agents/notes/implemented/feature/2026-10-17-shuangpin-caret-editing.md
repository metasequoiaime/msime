# Agent Note: macOS 双拼按音节移动预编辑光标

Status: implemented

## Problem

双拼预编辑中，左右键在候选高亮变化后可能被解释为选词移动，用户难以回到中间音节修改。

## Decision

在 macOS 双拼且候选栏开启时，左右键优先发送共享运行时的按音节移动命令；全拼和其他方案继续使用原有的光标与候选导航规则。

## Alternatives considered

只改变候选栏高亮样式不会改变按键归属，仍可能把编辑动作送成选词动作，因此直接在宿主分派双拼的音节编辑命令。

## Consequences

双拼用户可以用左右键逐个音节定位并修改，编辑语义由共享运行时保持一致。双拼候选栏的左右键不再承担候选切换，候选选择仍可通过数字、空格和上下键完成。

# Agent Note: Android 单款皮肤导出文件名

Status: implemented

## Problem

#9967：从「我的」皮肤卡导出的 JSON 仅以设计名称命名。用户保存多款皮肤、跨版本分享时，仅看文件列表无法确认来源应用和版本，也无法区分同名设计的不同时次导出。

## Decision

皮肤页为系统文件选择器预填 `<应用名>-<皮肤名>-<版本名>-<yyyyMMdd-HHmm>.json`。应用名、皮肤名和版本名使用本地备份已有的安全文件名片段规则；皮肤名取当前卡片标题，空名称回退为「皮肤」。导出内容和导入格式不改变。

## Alternatives considered

- 沿用 `<皮肤名>.json`，由用户自行重命名：实现简单，但每次分享前都要手动补版本和时间，无法满足在文件列表中直接辨认的需求。

## Consequences

文件选择器中的建议名称能标明设计、来源版本和时间。用户仍可在选择器里修改名称；同一分钟导出同名皮肤时，由文档提供方处理重名。文件名不成为导入校验依据，旧 JSON 仍可导入。

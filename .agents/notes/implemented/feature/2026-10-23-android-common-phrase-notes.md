# Agent Note: Android 常用语的独立备注

Status: implemented

## Problem

#9348：命令或其他常用语缺少用途说明，用户需要另开笔记查找。备注要在键盘中帮助辨认，但不能随着正文插入输入框。设置页需要新增、修改、删除备注。

## Decision

在 client-services 的 `CommonPhrase` 中增加缺省为空、空值不写入的备注字段。正文和备注独立校验，正文的去重、插入及现有云同步仍只使用正文；Android 设置页同时编辑两者，清空备注即可删除说明。键盘条目保留两行正文，下面的次要文字最多显示两行备注，点正文或备注都只插入原正文。

本片按 issue 的安卓范围提供本机备注；云端目前只有 `AccountPhrase.text`，不把备注编码进正文或旁借其他字段。备注可为空，长度及允许的控制字符复用常用语正文的上限与规则；备注空白时按空值保存。没有备注的原文件和旧操作仍可读写，新版对未传备注的正文修改保留原备注。

本地备份的 `phrases.json` 保留正文数组，新增按完整正文索引的可选 `notes` 映射；旧版本可忽略这个附加字段，新版恢复旧备份按空备注添加。本机已有相同正文时继续跳过，保留本机备注，不在恢复过程中覆盖已有说明。

## Existing notes

检索常用语、`CommonPhrases` 和同步：与[常用语锁绑定父目录句柄](../../implemented/bug-fix/2026-10-09-common-phrases-lock-directory.md)部分重叠，继续使用其锁和原子发布，不另存 Java 文件。[剪贴板一步存为常用语](../../implemented/feature/2026-10-09-android-clipboard-to-phrases.md)继续只提交正文，缺省备注为空；[Android 云同步接入 Rust](../../implemented/architecture/2026-10-18-android-cloud-sync-through-rust.md)的同步边界不变。与[Android 本地备份](../../implemented/feature/2026-10-08-android-local-backup.md)部分重叠，同步其备注格式描述。本片没有完全吸收或需要作废的旧笔记。

## Alternatives considered

- 把备注写进正文并在插入前拆分：沿用旧文件与同步协议，但任何漏掉拆分的入口都会把说明发给对方，用户原文也可能与分隔符冲突，无法保证正文原样插入。
- 单独保存一份 Android 注释映射：原文件可以直接回退旧版，但引入第二份落盘数据及删除、安装短语包、恢复备份时的身份一致性问题；归入现有共享记录可复用锁、原子写和生命周期。
- 本片同时扩展云端同步协议：多设备可以直接共享说明，但云端及旧客户端目前只认识正文；在安卓备注需求中修改服务端协议会扩大独立交付范围，不把备注悄悄拼入正文作为兼容方式。

## Verification

- 设置页能创建带备注的常用语、修改或清空备注；重启后保留。
- 键盘分别显示正文和备注，各最多两行；点击任一部分只上屏完整正文，备注不会进入输入框。
- 旧文件、未传备注的既有调用仍可用；修改正文时未传备注不清空说明；删除记录同时删除备注。
- Rust 覆盖校验、旧格式、独立字段和损坏文件保护。`SettingsDeviceSmoke -e phrase-notes true` 走原生 `HomeActivity` 的增改删、跨进程键盘插入、重启保留、旧正文修改以及真实 ZIP 导出、目标写入与常用语恢复入口；截图只使用合成数据。
- 原生 APK 构建、API 28/35 专项以及截图核对通过；两套设备核心测试的 client-base、client-core、client-providers、client-services 分别通过 36、504、254、1240 项（既有忽略和硬链接过滤保持不变）。专项也进入 `smoke.sh` 的常规与最低 API 核心验收，复用原 runner 参数，不增加清单条目。
- Rust 常用语 20 项及 Clippy、Android JVM 与源码门禁通过；远端 quick（`20261023-060848`）通过，包含 Linux 111 项宿主测试、macOS 原生宿主与共享 Apple 桥接层编译；Windows 完整宿主和 HarmonyOS 打包因缺依赖跳过。

## Consequences

带非空备注的文件包含新字段，回退至严格拒绝未知字段的旧客户端时会报告格式不支持并保留原文件；需要先由新版清空备注再回退。备注暂不跨设备同步，也不改变云端正文协议。本地备份只收录自己的常用语，备注随独立映射保留；旧客户端恢复新备份时只恢复正文。对云端或社区短语包重新安装替换记录时沿用现有记录替换语义。

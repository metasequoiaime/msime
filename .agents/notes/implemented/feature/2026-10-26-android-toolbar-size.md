# Agent Note: Android 空闲工具栏独立尺寸

Status: implemented

## Problem

Android 空闲工具栏直接沿用读音行与候选行的合计高度。调整候选字号、释义行数会连带改变工具栏，键盘高度设置也没有独立的工具栏控件。

## Decision

本机设置新增工具栏尺寸选项。缺省和「跟随候选栏」时这一行与读音行加候选行同高，随「候选栏大小」变化；按钮最高 44 dp，行高不足时按钮和图标随行高等比缩小（[三端候选栏大小](2026-10-29-touch-candidate-bar-size.md)）；用户选择 90% 到 150% 后，以默认 56 dp 为基准计算空闲工具栏高度，按钮尺寸、图标和点击区同步按比例调整。中间按钮继续横向滚动。

工具栏、最近复制和系统内联填充共用空闲行高度。候选条保持自己的尺寸；两种状态中较矮的一种增加不可点击的顶部预留，让从空闲切入组字时键区位置稳定。隐藏工具栏时不预留其尺寸。

## Alternatives considered

直接把工具栏高度改为固定 56 dp，代码最少，却会改变现有用户调过候选字号后的空闲布局；缺省继续跟随候选栏。

把尺寸并入键盘高度或候选字号可以复用已有控件，却仍无法独立调整，因此另设本机项。

## Consequences

默认布局与现状一致，选择独立尺寸后由 Android 本机设置跨重启保存。空闲工具栏图标、按钮点击区及滚动容器随尺寸变化，候选栏与键区的原有设置不被写入；最近复制和内联填充与工具栏共用空闲行高度。切换空闲与组字时键区位置稳定，隐藏工具栏不产生空白行。

缩小到 90% 时按钮高度仍至少为 44 dp；候选字号极大时，预留高度随较高的一侧增加。真机上的无障碍与厂商字体仍需报告者复验。

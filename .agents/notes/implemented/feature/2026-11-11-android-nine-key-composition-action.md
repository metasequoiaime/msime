# Agent Note: Android 九键组字按钮可选动作

Status: implemented

## Problem

拼音九键在组字时把 1 键固定显示为「分词」，但部分用户希望沿用右列「重输」的清空组字行为。两种动作都只属于 Android 九键键面，不能改变其他平台或已有用户的默认手感。

## Decision

Android 增加本机设置 `platform.android.nine_key_composition_action`，默认值 `separate`，可选 `rewrite`。组字时 1 键分别显示并执行「分词」或「重输」；空闲时始终显示 `@#` 并打开常用标点。设置不进入共享 Rust 偏好、账号同步或其他平台。键帽、无障碍描述和点击动作共用同一策略，设置变化会触发键区重画。

## Alternatives considered

- 把选项加入共享 Rust 偏好并同步到 iOS、鸿蒙：能保持跨端设置一致，但当前需求只针对 Android，且会未经授权扩大行为和同步协议范围，因此不采用。
- 直接把默认动作改成「重输」：能满足提出需求的用户，但会改变现有用户的九键手感；保留默认「分词」，把「重输」作为明确可选项。
- 复用右列按钮而不增加设置：实现简单，但无法满足希望把 1 键改成重输的用户，也会让键帽与动作不一致。

## Consequences

设置文件增加一个只在 Android 本机保存的选择项，旧用户读取到缺省值时仍得到原来的「分词」。九键渲染和行为测试覆盖默认、重输和空闲状态；设备模拟器验收因本机磁盘不足暂未运行，需在 PR 的设备 job 或维护者环境补验。

# Agent Note: Android 云剪贴板自动上传

Status: implemented

## Problem

#11154 要求云剪贴板开启后复制内容自动同步。Android 输入法服务已经监听系统剪贴板变化，但监听只写本机历史，用户还要在面板逐条点「发到云剪贴板」。

## Decision

Android 的复制监听在现有隐私闸门、敏感剪贴板过滤和文本边界之后，异步查询当前云剪贴板状态；服务端确认云剪贴板已开启且本机不是待批准设备时，沿当前选路（账号、中继或 WebDAV）上传这条文本。自动上传不依赖云端面板已打开，也不新增独立开关；云剪贴板开关就是授权。失败静默放弃，下一次新的复制重新读取状态并尝试，不写待上传队列。云端条目不自动写回系统剪贴板。

## Alternatives considered

- 复用面板的上传方法：它依赖面板最近一次列表和会话绑定，面板未打开时不能上传；自动监听应独立于可见 UI。
- 为失败内容建立持久重试队列：能提高最终送达率，但会保存用户明确复制过的内容并在之后联网，扩大隐私和生命周期边界；本次只在新的复制事件上重试。
- 自动把其他设备条目写回系统剪贴板：更接近跨设备剪贴板，但会覆盖用户当前剪贴板并触发系统隐私提示；本 issue 只授权本机复制自动上传。

## Consequences

复制事件会在输入法服务存活且当前输入框允许云剪贴板时产生一次后台列表请求和必要的上传请求；服务未登录、云剪贴板关闭、设备待批准、密码框、隐私模式、敏感剪贴板和非法文本都不会上传。服务端负责去重，宿主不重复保存文本。iOS 与 HarmonyOS 的系统剪贴板监听仍未实现，后续按平台独立 PR 继续引用 #11154。

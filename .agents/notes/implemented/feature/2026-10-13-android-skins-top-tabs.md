# Agent Note: Android 皮肤分类改为固定顶部 Tab

Status: implemented

## Problem

皮肤页把内置、我的设计和社区皮肤全部堆在同一滚动列中。保存的设计较多时社区入口藏在下面，滚动以后分类位置不明确。

## Decision

`SkinsPage` 在标题下复用 `SegmentedControl` 的圆角分段样式固定显示「内置 / 我的 / 社区」，一次只渲染当前分类。内置和我的皮肤卡复用社区的 `item_community_skin` 布局与 `KeyboardPreview`，按相同宽高比绘制完整键盘和键面文字；AI 设计卡放在「我的」开头并使用相同卡片尺寸；社区缓存、获取和完整列表入口继续复用原逻辑。分类切换使用已加载模型，不重新读取数据；异步刷新和皮肤选择完成后仍保留当前分类，分类序号随 Fragment 状态保存。

`DetailPage.fixedNavigation` 是可选入口，提供该控件的页面使用固定标题和导航，滚动区按导航实际高度留出上边距；其他详情页继续使用原来的折叠标题，默认没有固定导航。

「我的」里保存的皮肤卡支持长按删除，先用 `MessageDialog.confirm` 显示名称并确认，取消或关闭对话框不写盘。确认后通过 `HostTask` 在工作线程调用 `CustomSkinLibrary.remove`：沿用添加、导入的进程内排队与跨进程文件锁，在锁内重新读取库，只按 id 移除目标，原子替换 `library.json`，保留其余条目的顺序、设计和时间戳。删除成功标记 `SyncSwitch.SKINS`，并重新读取列表；删除失败也重读，避免继续显示过期卡片。内置主题和 AI 入口不提供删除。

删除只移除本机保存项，不改正在使用的皮肤：`KeyboardSheets.applyDesign` 和键盘的 `saveKeyboardSkin` 已把完整设计复制进 `custom_theme.keyboard`，运行时不引用库项 id，因此不存在删除后引用悬空的问题。确认文案明确保留当前皮肤。皮肤库继续使用既有 Java 存储与锁，原因见 [Android 设置页接入共享 Rust 服务](../architecture/2026-10-18-android-settings-pages-through-rust.md)。云同步仍沿用按 id 合并的契约；本次不引入删除墓碑，也不承诺从其他设备删除同款皮肤。

删除的设备回归由现有 `SettingsDeviceSmoke` 的显式 `skin-delete` 参数转给原生检查，`smoke.sh` 在 `--core` 返回之前运行，因此最低 API 和 CI 的设备门禁也能覆盖。复用入口避免超过 Android instrumentation 清单的 100 项上限；检查经安装产品的 `CustomSkinLibrary` 准备合成保存项，再长按真实皮肤卡并操作确认框，结束后恢复原皮肤库和偏好。未带参数的设置回归保留原入口行为。

检索审计：[Android 社区内容并进功能页](2026-10-11-android-community-into-feature-pages.md)的皮肤列表排布与本篇部分重叠，社区加载和使用的决定继续成立；皮肤明暗过滤和 AI 视图生命周期笔记与本次分类位置无关，不修改。


皮肤社区预览和「浏览更多皮肤」入口已由[社区 Tab 直接承载完整列表](2026-10-13-android-skin-community-tab-list.md)取代，固定分类导航和其他功能页的社区入口继续成立。

## Alternatives considered

- **只在滚动列顶部添加 Tab**：实现简单，但滚动后分类再次消失，用户仍要回到顶部寻找类别。
- **把各分类做成独立详情页**：能复用导航栈，但每次切类别都增加一层返回行为，无法在当前皮肤页直接比较类别。
- **修改所有详情页的布局资源**：固定导航容器可以通用，但无分类的页面也需要解释新增层级；使用可选的原生控件入口，把行为限定在皮肤页。
- **删除正在使用的皮肤时回退到之前的主题**：能立即看到该皮肤已经删除，但运行时使用的是独立的完整快照，回退没有存储上的必要，还会把清理保存项变成一次意外换肤，因此保留当前外观。
- **单独注册皮肤删除 instrumentation**：入口名称直观，专项也能独立运行；但默认清单已经达到系统允许的 100 项，新增入口会使测试 APK 无法安装。由现有设置 runner 按参数分派，保留独立检查类与原设置测试。

## Consequences

皮肤类别始终可见，列表长度缩短；AI 入口归到个人设计类别。页面模型在当前视图存活期间保留，销毁视图时释放；分类切换回到列表顶部，不保存各分类的独立滚动位置。

长按删除能够释放皮肤库的 12 项容量；无障碍描述说明长按动作。删除不会修改共享偏好或按键反馈，已经应用的设计在重启后继续可用。开启云同步时，其他副本仍可能按既有合并规则把保存项带回本机。

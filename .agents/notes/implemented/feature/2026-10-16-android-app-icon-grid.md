# Agent Note: Android 主屏图标选择改为图标网格

Status: implemented

## Problem

“通用 · App 图标”面板把五种主屏图标配色显示成纵向文字列表。用户需要在选择时直接看到实际图标，文字描述既占空间，也不能直观表达切换后的主屏效果。

## Decision

Android 使用单独的 `AppIconSheet`，在现有 M3 bottom sheet 外壳中以两列网格展示五个自适应图标。每个图标保留完整的无障碍名称和描述，当前选项叠加勾选标记；底部取消行和切换逻辑沿用原有行为。预览直接引用与 launcher alias 相同的五个 `app_icon_*` 资源，避免维护第二套图片。

## Alternatives considered

- **继续使用文字列表，只在文字左侧增加小缩略图**：改动较小，但仍保留长文本列表，不能达到直接比较图标的目的，也不符合截图中的网格布局，因此不采用。
- **在 `OptionSheet` 中加入通用图标网格模式**：能复用更多代码，但会把只适合主屏图标的固定两列布局和资源语义扩散到所有选择面板，因此采用独立的 `AppIconSheet`。

## Consequences

五种配色在同一屏内可比较，长描述不再挤占视觉空间；无障碍用户仍能通过节点名称和描述区分每个图标。新增面板只改变 App 图标入口，其他选项面板保持原来的文字列表。API 28 模拟器安装后的 UI dump 确认面板包含五个可点击图标节点、当前选中状态和取消行；Android host 门禁通过 234 个 JVM smoke 与 123 个设备套件源码检查。

# Agent Note: 安卓英文键盘 X/C 角标使用英文常用符号

Status: implemented

## Problem

安卓 26 键字母角标的 `X` 和 `C` 在英文键盘下仍显示省略号 `…` 和中文顿号 `、`。这两个字符属于中文标点习惯：英文输入需要更常用的下划线 `_` 和反引号 `` ` ``。同一张角标表也服务中文键盘，不能顺手改变中文模式的键面。

## Decision

`LetterHintTable` 的英文角标将 `x` 映射为 `_`、`c` 映射为反引号。`face()` 在中文标点模式下对这两个键保留原来的 `…` 和 `、` 键面；英文模式直接显示 ASCII 角标。下划线和反引号不交给中文标点路由，仍按字面上屏。

回归测试同时验证完整 26 键映射、英文键面、中文 X/C 兼容键面，以及标点路由边界。

## Alternatives considered

- **只改英文模式的视图层，不改角标表**：可以避免改共享表，但会让长按、滑动、无障碍描述和键面提示使用不同来源，容易再次漂移，因此没有采用。
- **把中文 X/C 也改成新的 ASCII 符号**：实现更简单，但会改变现有中文键盘的输入手感，超出 issue 的英文范围，因此没有采用。

## Consequences

英文键盘的 X/C 角标与建议的常用符号一致，中文键盘保持原有省略号和顿号。Android 主机检查新增的回归断言；没有改变符号层的独立按键布局。

验证：`bash platforms/android/check-host.sh` 通过，运行 281 个 Android JVM 冒烟并编译 245 个设备套件源文件。

# Agent Note: 桌面符号直接选择子分类并允许调整面板大小

Status: implemented

## Problem

#9097 需要经常输入希腊字母与特殊字符。共享符号页虽然已有中文名称和分类侧栏，但仍将希腊、拉丁等子分类收在「字母与文字」中，定位需要滚动寻找；宿主的面板窗口统一禁止缩放。

## Decision

共享符号侧栏直接列出资源目录的叶分类，内置分类身份包含父级与名称，插件继续按包分组。中文显示名、父级名称搜索、最近使用、复制和原应用输入复用现有逻辑，不改词库资源。

Windows/Linux 的 `emoji-panel` 保留默认 720×720，最小允许 560×480，开放窗口缩放及标题拖动；复用设置窗口的八方向边缘判定与面板拖动手势。两项 Tauri 权限仅授予该窗口；设置页内嵌面板与独立剪贴板不透传几何能力。macOS 使用自己的原生符号窗，此项不改其几何。

- 检索命中的 Android 符号分类和浮动键盘笔记归属原生移动宿主，与本次窗口契约无关；没有待废弃的同题提案。

## Alternatives considered

- 保留上级分类并增加展开树：长目录更紧凑，但希腊、拉丁等常用入口仍需额外展开。现有目录规模适合可滚动的单层中文侧栏。
- 给所有面板开放缩放：能统一宿主代码，但屏幕键盘、手写等面板各自有尺寸契约。本次只开放表情与符号窗口。

## Consequences

叶分类数量增加，需要侧栏独立滚动。最小尺寸下搜索、分类和内容仍可访问；共享组件预览不能替代 Windows WebView 的实际缩放与输入投递验收。

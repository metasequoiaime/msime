# Agent Note: Android 键盘里开启剪贴板历史与语音输入引导

Status: implemented

## Problem

用户反馈 Android 上「语音、剪贴板、词库调不出」。在 API 28 模拟器上逐项走过：

- 剪贴板：`clipboard_history` 默认关。关着时面板直接打开到「云端」（`CloudClipboardPanelPolicy.initialTab`），没登录的用户只看到「登录水杉账号后可在设备间同步剪贴板」；切到「本机」只有一句「剪贴板历史未开启，可在设置中开启」，开关要到 App 的「隐私 → 本机」里找。复制的内容在开启之前不会记录，看起来就是剪贴板调不出来。
- 语音：没有系统语音识别服务、也没配置服务商时（多数不带 Google 服务的国产手机，以及这台模拟器），长按空格只在读音行写一行小字「设备没有可用的系统语音识别服务，可在设置中配置识别服务商」，看起来就是没反应。
- 词库：功能面板的「词库」正常打开 App 的词库页，没有复现；本篇不改它。

## Decision

剪贴板面板在本机历史关着时也先停在「本机」，那里有「开启剪贴板历史」按钮。`initialTab` 去掉 `localEnabled` 参数，只在敏感输入框回到本机、其余按用户上次选的分段，缺省是本机。按钮经 `MSIMEInputService.enableClipboardHistory` 走 `savePanelPreference` 写共享偏好 `clipboard_history`，与「隐私」里的开关是同一项；保存成功后 `applyPreferencesSnapshot` 发现它刚打开，原有的 `clipboardTurnedOn` 分支重画面板，换成「复制的文字会自动出现在这里」。默认值不变，仍是关：记录复制内容要用户自己点开。

语音输入还不能用时（`voice_input` 关着，或没有系统识别服务也没有服务商），`showVoiceSetup` 在键区上打开引导：说明原因，按钮「设置语音输入」直达 App「语音输入」页的「服务」分区，在那里选「本地模型」后出现模型下载，或者选在线服务商。本地模型的下载、按流量计费网络的确认和语音运行库都留在那一页，键盘里不另做一套。引导复用语音结果面板（`voiceResultScroll`），`voiceSetupReason` 不为 null 时画引导，关面板或打开语音结果时清掉。面板的 `ScrollView` 加 `setFillViewport(true)`：底色画在内容上，内容只有几行时下面的键原来会露出半行，语音结果面板也一样。

直达分区靠新的深链参数 `HostDeepLink.ARG_SECTION`（`section`）：`DetailPage` 首次打开时它优先于 `initialSection()`，不是这一页的分类时忽略，旋转和进程恢复仍用用户已选的分类。

## Alternatives considered

- **默认打开剪贴板历史。** 一步到位，用户什么都不用点。但它记录用户复制的一切，包括验证码、地址之类的内容，「隐私」页把它列在「本机」里正是因为这是用户自己做的决定；默认值改动还会落到所有已安装用户身上。
- **在键盘里直接下载本地语音模型。** 少跳一次 App。但下载要选模型、在按流量计费的网络上先确认、可能还要先下载语音运行库，`VoicePage` 已经把这些做完；键盘进程里再做一套，失败和取消的处理都要重复。
- **语音引导只打开 App 的「语音输入」页，不带分区。** 不用新加深链参数。但那一页默认停在「识别」，用户还要自己找到「服务」才看得到本地模型，引导就少了最关键的一步。

## Consequences

开启剪贴板历史从「退出键盘、进 App、找到隐私 → 本机」缩成在面板里点一下；云端分段仍可切过去，选过云端的用户下次照旧打开云端。语音不可用时长按空格会盖住键区，需要点「返回键盘」或去设置；原来那句小提示不会挡住打字。`section` 深链参数对所有详情页都可用，页面不需要各自处理。

## Verification

- `check-host.sh` 通过；`CloudClipboardPanelPolicySmoke` 改为断言本机历史关着时仍打开本机、选过云端则保留云端、敏感输入框回到本机。
- 发布签名 APK 装在 API 28 模拟器上：从功能面板打开剪贴板，停在「本机」并显示说明和按钮，点按后面板换成本机历史（0/200）；长按空格出现「语音输入」引导，面板铺满键区，点「设置语音输入」打开 App「语音输入」的「服务」分区。测完已把模拟器的剪贴板历史关回去。同一 APK 覆盖安装到 Pixel 3 XL，没有在真机上逐项点过。

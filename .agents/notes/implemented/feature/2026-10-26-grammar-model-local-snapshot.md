# Agent Note: 语法模型保留本地快照

Status: implemented

## Problem

#9839 发现语法模型的下载描述、安装状态和离线使用绑在同一份应用内嵌锁文件上。上游替换同名 LTS 资产后，已安装且完整的旧模型会因摘要不再匹配当前锁文件而被当成不可用，输入功能随应用更新静默降级。

## Decision

语法模型的 `msime-model.json` 作为安装时快照保存。读取语法模型时，当前锁文件仍用于新下载和更新提示；如果本地快照的资源包 ID、文件名集合、长度、SHA-256 和实际文件字节自洽，就继续离线使用，即使它与当前锁文件不同。原生宿主调用的 `verify_installed` 与 `installed_file` 共用这条快照规则，并额外核对 `.gram` 格式。资源包列表仍显示 `Outdated`，让用户知道有可选更新。其他资源包继续严格匹配当前锁文件，避免扩大未审计文件的信任范围。

## Alternatives considered

- 发现锁文件变化就删除或禁用旧模型：会让应用更新强制联网，直接破坏报告者要求的离线使用。
- 只相信 `msime-model.json` 而不重新校验文件：本地清单可被损坏或替换，不能作为模型完整性证明。
- 对所有资源包放宽摘要匹配：词库和运行库也可能被替换，扩大信任边界；本次只放宽语法模型。

## Consequences

已安装的旧语法模型在当前锁文件变化后继续可用，列表可以同时表达“当前可离线使用”和“有新版本可更新”。读取时会重新校验快照记录的文件字节，因此首次使用旧模型可能增加一次哈希开销。在线目录、主动检查更新和兼容性格式检查仍未包含在本次改动中，后续需要单独设计服务协议与用户流程。

## Verification

- 新增合成快照测试，验证锁文件变化后旧语法模型仍能由 `installed_file` 找到，同时列表状态为 `Outdated`。
- 同一测试验证原生宿主校验入口接受完整的旧快照，拒绝被篡改的文件及摘要虽自洽但格式无效的 `.gram`。
- `cargo test -p msime-client-providers --lib resource_packs::tests::` 通过，33 个资源包测试全部通过。

# Agent Note: Android 关于页隐藏彩蛋

Status: implemented

## Problem

#9929 要求用户从 Android「我的」页长按「关于」触发一张本地彩蛋画面：气泡显示 2026 年 6 月 6 日入住手机后的相处天数，画面包含草地、树和坐在树下刷手机的水杉妹。原页面只有普通关于入口，没有长按动作或彩蛋内容。

## Decision

「关于」导航行保留原来的点击行为，另加长按监听并消费长按事件，打开独立的 Material 对话框。彩蛋场景由 `AboutEasterEgg` 在 Canvas 中绘制，草地、树、人物、手机和红色气泡都使用本地几何与颜色，不请求网络，也不新增图片资源。气泡天数由 `AboutEasterEggPolicy` 按设备本地自然日计算，起点固定为 `2026-06-06`，时钟回拨时显示零。

## Alternatives considered

- **新增一张插画资源**：画面表现力更高，但当前没有经审核的插画素材；临时生成或借用现有站立角色会把错误素材固化进 APK，因此采用可审查的矢量绘制。
- **把彩蛋做成新页面**：可提供更多空间，但会破坏“长按后立即出现”的隐藏反馈，也需要新增导航和返回状态；对话框足以承载单张场景。
- **把长按改成点击**：更容易发现，但不符合 issue 指定的隐藏触发路径，因此保留普通点击和长按两条行为。

## Consequences

彩蛋不增加 APK 的图片体积和网络权限，日期文案可由纯 Java 冒烟测试覆盖；Canvas 场景在不同屏幕宽度上按比例布局。由于画面是几何绘制，角色细节和原画插图不同，后续若有正式美术资源可只替换场景视图，不改变入口和日期契约。

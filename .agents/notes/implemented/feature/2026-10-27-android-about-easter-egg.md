# Agent Note: Android 关于页隐藏彩蛋

Status: implemented

## Problem

#9929 的指定路径是点击键盘左上角水杉图标、长按功能菜单里的「关于」，触发本地彩蛋画面：气泡显示 2026 年 6 月 6 日入住手机后的相处天数，画面包含草地、树和坐在树下刷手机的水杉妹。只给设置应用「我的」页接长按会漏掉这条路径。

## Decision

键盘功能菜单的「关于」保留普通点击打开关于页，长按消费事件并在同一输入法面板中呈现场景。返回回到功能菜单；关闭面板或重建输入视图会清除彩蛋状态，下次从品牌键打开仍是菜单，避免旧场景重复挂到新容器。设置应用「我的」页也复用同一场景，通过原有 Material 对话框显示，输入法服务不创建 Activity 对话框或抢走编辑器焦点。Material 对话框适配留在 `home/AboutEasterEgg`，键盘场景只依赖系统 View API，使宿主 JVM 编译也覆盖入口接线。

彩蛋场景由 `AboutEasterEgg` 在 Canvas 中绘制，草地、树、人物、手机和红色气泡都使用本地几何与颜色，不请求网络，也不新增图片资源。气泡天数由 `AboutEasterEggPolicy` 按设备本地自然日计算，起点固定为 `2026-06-06`，时钟回拨时显示零。场景按文本测量高度，气泡随换行和系统字号增长，插图按宽度等比缩放；不能用默认 View 测量把对话框允许的高度全部占满。每帧显式重置笔宽，避免上一帧人物的粗线改变下一帧草叶；IME 背景直接取键盘皮肤颜色，不依赖 Material 主题属性。

## Alternatives considered

- **新增一张插画资源**：画面表现力更高，但当前没有经审核的插画素材；临时生成或借用现有站立角色会把错误素材固化进 APK，因此采用可审查的矢量绘制。
- **把彩蛋做成新页面**：可提供更多空间，但会破坏“长按后立即出现”的隐藏反馈，也需要新增导航和返回状态；对话框足以承载单张场景。
- **把长按改成点击**：更容易发现，但不符合 issue 指定的隐藏触发路径，因此保留普通点击和长按两条行为。
- **从输入法服务弹 Material 对话框**：可复用设置应用的窗口，但服务没有 Activity 令牌，还可能抢走编辑器焦点；键盘入口复用已有工具面板，不增加独立窗口。

## Consequences

彩蛋不增加 APK 的图片体积和网络权限，日期文案可由纯 Java 冒烟测试覆盖；Canvas 场景在不同屏幕宽度上按比例布局。由于画面是几何绘制，角色细节和原画插图不同，后续若有正式美术资源可只替换场景视图，不改变入口和日期契约。

设备回归直接创建安装包内的输入法服务视图，点击实际品牌键、长按实际关于磁贴，检查彩蛋、普通刷新保留、返回、关闭重开与同服务重建输入视图；独立渲染 240/320/600dp、1/2 倍字号的场景，比较连续两帧像素相同并检查内容测量。旧实现分别在键盘长按、占满对话框高度及重复绘制像素三处失败，新增重建回归也先复现了旧场景已有父容器异常。这是设备上的产品视图验证，不等于已在报告者真机或真实编辑器中验收。

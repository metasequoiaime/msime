# Agent Note: 鸿蒙冷启动的启动窗、盖板和开屏画同一个画面，开屏从启动窗接着往下播

Status: implemented

## Problem

[每次冷启动都播开屏](2026-10-11-harmony-launch-splash-every-start.md) 之后，仓库负责人看到的是「启动有两段，设计完全割裂」。在 HarmonyOS 6.0 phone 模拟器上逐帧截图（`snapshot_display` 连拍）看到的过程：

1. 系统启动窗：#0A0B0A 底，屏幕正中一个 256px 的深色圆角方块图标。
2. 启动窗撤掉后，WebView 还没画出东西，纯黑好几帧。
3. 网页开屏：底色换成季节色（强调色 20% 混进 #0A0B0A），图标不见了，一个灰色小圆点长成白色圆盘，标志方块旋转入场，再描笔画。圆盘和下面的文字作为一组居中，圆盘中心比屏幕中心高 116px。

底色、图标、位置都不一样，动画还从零重来一遍，看起来就是两个不相干的开屏拼在一起。

## Decision

三层画同一个画面：#0A0B0A 底，正中一个 180vp 的浅色圆盘（#EDF0F0），盘上是还没描笔画的标志方块（#2E3A40）。

- **系统启动窗**：`start_window_icon.png` 就是这个圆盘。实测启动窗按图片的像素尺寸画图标、中心对准屏幕中心，所以图标是 585px（180vp × 密度 3.25）。网页区域避开了状态栏和底部手势条，中心比屏幕中心低 18px，所以图标顶上留 36px 透明，总尺寸 585 × 621。
- **原生盖板**：`Settings.ets` 用 `Stack` 在 Web 上面叠一层 `launchCoverView`，用 ArkUI 的 `Circle` 和 `Rect` 按 vp 画同一个圆盘，按网页区域居中。启动窗撤掉时露出的就是它，不再露出空白的 WebView。页面第一帧上屏后调用新加的桥接方法 `launchPainted`，盖板 120ms 淡出；页面一直没报告（脚本出错、桥接没连上）时，4 秒后自己撤掉。
- **网页开屏**（`HarmonySplash`）：
  - 圆盘绝对定位在页面正中，名字和英文名排在它下面，不参与居中。
  - 不再播设计稿里圆盘落下（`splash-circ-in`）和标志旋转入场（`splash-logo-in`）这两段：启动窗已经画好了它们落定的样子，再播就是从头重来。
  - 圆盘和标志方块上各盖一层启动窗颜色的图层（`hSplashDiscVeil`、`hSplashFrameVeil`），0.1 秒后用 0.6 秒淡出，露出下面的当季颜色。笔画描绘提前到 0.3 秒开始，后面的涟漪、文字、进度条不变。
  - `apps/harmony/src/main.tsx` 用 `AfterFirstPaint` 包住开屏（二合一包住启动页），提交后等两帧再调用 `launchPainted`。桥接就绪后的重画包着同一个子树，开屏不会重新挂载。
- **开屏底色固定是 #0A0B0A**，不再随季节变：`hSplash`、`hSplashShell` 和开屏期间的系统栏（`useHarmonyWelcomeSystemBars`）都是这个颜色。启动窗只能用一种颜色；开屏要是季节色，桥接就绪时系统栏会先变色，页面还是黑底，上下出现色带。季节色由光晕、圆盘、标志方块和进度条带出来，所以开屏仍跟设置页的配色一致。
- `scripts/test-harmony-launch-continuity.py` 守住五处底色、两处圆盘色、两处方块色相同，启动图标的尺寸，以及桥接注册了 `launchPainted`。

## Alternatives considered

- **直接对颜色做动画**（`@keyframes` 只写 `from { background-color: #0a0b0a }`，终点是元素自己的 `color-mix()` 颜色）。第一版就是这样写的，在 ArkWeb 上中间帧算出了纯黄、纯红的整屏。改成遮罩层的透明度动画，透明度插值没有这个问题。
- **开屏底色保持季节色，从 #0A0B0A 淡入。** 桥接就绪时系统栏和窗口底色立刻换成季节色，淡入还没走完时状态栏和页面之间是一条色带，截图里看得见。
- **启动窗只画圆盘，网页开屏保留标志旋转入场。** 启动窗通常要停留一两秒，单独一个空圆盘认不出是什么；把方块也画上，它就是认得出的水杉标志。
- **按密度提供多份启动图标。** 启动窗按像素画图标，密度不是 3.25 的设备上圆盘会比 180vp 大或小几个百分点，盖板和网页用 vp 画，接上时会轻轻跳一下。HarmonyOS 的密度目录（`xxldpi`、`xxxldpi`）对启动窗图标怎么取、要不要缩放没有验证过，没有设备不好确认，所以只给了一份。

## Consequences

- **收益**：从点图标开始（桌面的展开动画里已经是这个圆盘）到进设置是同一个画面接着动，没有黑屏帧，没有从头重来的动画。模拟器上逐帧测量：启动窗、盖板、网页三层的圆盘中心分别在 1359~1361、1361、1363（屏幕高 2688px），方块颜色从 (47,58,64) 平滑过渡到冬季的 (41,86,115)。
- **代价**：
  - 开屏底色不再带季节色调。
  - 加载慢时，静止的圆盘会停留到页面画出来为止，模拟器上大约两三秒。
  - 圆盘位置依赖实测的 18px 偏移，这个值由状态栏和手势条的高度决定，状态栏更高的设备（挖孔屏）上会差几个像素。
  - 三层颜色写在五个文件里，改一处要改全部，靠契约脚本守着。

## Verification

- HarmonyOS 6.0.2(22) phone 模拟器，冷启动连拍 26~44 帧，测量每帧圆盘位置和颜色，结果见上；开屏播完后正常进入设置页。
- `apps/desktop/tests/account/onboarding-page.test.tsx`：开屏期间系统栏是 #0A0B0A。
- `python3 scripts/test-harmony-launch-continuity.py`。
- 没有在真机、其他密度的设备或深色模式下验证。

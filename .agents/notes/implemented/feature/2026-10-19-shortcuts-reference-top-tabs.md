# Agent Note: 桌面按键速查改为顶部标签

Status: implemented

## Problem

桌面「按键设置」把只读的「按键速查」放在页尾「更多选项」里，用户需要先滚动再展开才能查看，希望通过顶部标签直接进入。

## Decision

共享桌面按键页复用 `useSettingsTabs`，提供「按键设置」「按键速查」两个标签。前者保留模式切换和可编辑的候选操作，后者直接展示当前生效的候选与面板快捷键，不再折叠。只改变页面入口，不改变快捷键值或保存行为；手机保持现有布局。

## Historical audit

- [精简输入与快捷键页](../../implemented/simplification/2026-10-16-macos-input-settings-prune.md)：部分重叠。本决定取代其中桌面速查收在页尾折叠区的选择，继续保留设置与只读说明分开、手机原有布局的理由。
- `useSettingsTabs` 已被桌面输入、候选、关于等页面采用，复用其键盘导航、面板可访问性与挂载策略。

## Alternatives considered

- **默认展开原来的折叠区**：改动最少且无需切换页面，但仍把速查放在长页底部，不能满足顶部入口的要求。
- **把每条速查平铺到设置后面**：所有说明一目了然，但重新拉长按键页；顶部标签让两类内容各自完整可见。

## Verification

- 桌面默认显示按键设置，顶部可切换到直接展开的按键速查；复用已有候选速查组件，数据来源不变。
- 相关组件与页面组合 20 项测试通过，覆盖能力过滤和手机原有布局；已有设置集成用例改为实际点击速查标签并确认无折叠。
- 前端类型检查与生产构建通过，相关设置集成用例 1 项通过。
- quick 的编译和契约阶段通过；唯一失败为本篇初稿缺少 `Consequences` 小节，补齐后重跑 `pnpm run verify-notes` 通过。
- 本机设置应用重新打包并安装，Developer ID 严格签名校验通过；通过应用无障碍树和窗口截图确认顶部两个标签，点击速查后选词、翻页、编辑、面板快捷键直接可见且无「更多选项」，切回设置后输入模式控件可见。

## Consequences

共享组件也用于其他桌面宿主，应保留其能力位过滤；这里只验收 macOS 本机和共享组件测试，不宣称其他平台装机通过。

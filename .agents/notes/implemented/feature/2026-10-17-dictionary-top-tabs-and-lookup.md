# Agent Note: 词库页顶部标签与词条查询

Status: implemented

## Problem

桌面词库页把本地查询、编辑、导入导出、云词库和学习数据连续堆在同一页，查询入口埋在长列表中。原查询接口只接受个人词库的五种类型，日语、粤语、注音、笔画和韩语汉字表不在下拉中；多数类型空查询也只列个人词条，不能浏览基础词库。

## Decision

桌面共享词库页使用三个窗口级顶部标签：「查词库」「管理词库」和「云词库」。查词库标签进入时先显示当前类型的全部词条，输入词条文字或编码前缀后再按查询筛选，并支持分页；用户新增词条可编辑和删除，基础词条不显示写入操作；管理词库标签承载导入导出、社区词库、词库信息、背单词和学习数据；云词库标签嵌入原有云词库面板，并在同一设置窗口内切换完整目录、候选排序、导入导出和应用到本机子页。查询框输入后经过 280ms 防抖实时筛选，不设搜索按钮；类型或条件变化后旧响应立即失效，结果在宿主筛选后分页。手机继续使用平台自己的词库列表与详情布局，不显示桌面标签。

## 查询范围与契约

桌面宿主提供只读 `browse`，类型覆盖拼音、86/98 五笔、英文、快捷短语、日语、粤语、注音、笔画和韩语汉字表。个人编辑、导入导出与云同步仍只接受原五种个人类型，语言资源不扩展个人日志协议。旧宿主未提供 `browse` 时继续使用 `list`；`list` 的个人分页与导出语义保持兼容。

日语直接复用引擎校验过的 MSJPDT1 映射，在文件顺序中按假名读音前缀（兼容片假名）或词条文字筛选并分页；同读音同词条的不同词性模型行保留；页面按固定列显示读音与词条，不展示模型内部成本。粤语、注音、笔画复用引擎只读 SQLite 入口，韩语汉字表复用内嵌表，不复制词库到页面、不通过输入会话搜候选。缺失资源返回 `available: false`，页面提示去「输入」设置下载，区别于零匹配结果。越南语和藏语是规则转换，没有独立词库。

嵌入云词库的容器按设置内容区宽度布局，搜索与管理按钮分成两行，输入后经过 280ms 防抖。共享面板原有的 `100vw` 和视口最小高度只适用于独立窗口，嵌入时明确覆盖，不能用裁切掩盖溢出。设置窗口的云词库请求复用已有的[共享账号回退](../bug-fix/2026-10-18-macos-cloud-dictionary-account-fallback.md)，不依赖仅独立面板启动时提供的 socket 或原生会话。完整快照复用 host-api 的队列、维护锁和账号校验；macOS 设置页通过文件选择与宿主 `save_export` 导入导出，独立原生面板的文件对话框协议保持原样。加载失败与空词库分别显示，错误码转换成登录或网络说明，不展示 provider。

## Historical audit

[macOS 账号回退](../bug-fix/2026-10-18-macos-cloud-dictionary-account-fallback.md)保留账号与快照协议；其中设置页隐藏独立面板入口的规则由本篇的页内云词库标签接管，未提供页内客户端时仍隐藏 macOS 旧入口。现有的[输入、标点与翻译顶部功能标签](../../implemented/feature/2026-10-13-desktop-input-expression-voice-tabs.md)规定桌面共享设置页复用 `useSettingsTabs`，并保持手机直列；本改动沿用该边界。现有的[正常候选设置入口标签](../../implemented/bug-fix/2026-10-13-macos-primary-settings-tabs.md)只约束共享桌面页面的标签交互和挂载方式，与词库的数据请求契约无冲突。

## Alternatives considered

- **继续把查询留在单页顶部**：改动最小，但导入、云端和学习数据仍会把查询结果推到很下面，不能解决用户找不到查询入口的问题。
- **新建独立的词库路由**：可以完全隔离查询和管理，但会增加导航页、路由与手机投影的契约；现有的词库宿主接口和移动端布局也不需要第二个页面，因此不采用。

- **把语言类型加进个人词库枚举**：能复用原有列表状态，但也会让不支持的编辑、导入与云同步类型进入个人协议。浏览类型单独建模，只在只读资源列表使用。


## Verification

实时查询回归先等待宿主收到当前条件，再检查返回行，避免把初始列表里的同名词条误当成防抖查询的结果。管理页已提供独立的类型选择框，回归检查查询与管理标签之间的类型同步及实际导出请求，不依赖已经移除的旧说明文案。

新增设置回归覆盖顶部标签的初始选择、标签切换后的内容可见性，以及实时查询发送中文条件；云词库入口回归覆盖桌面账号页切换到词库页的云词库标签，移动端仍调用原生面板。资源浏览回归覆盖日语读音、片假名与文字检索、数据库文字与编码检索、字面通配符、分页、缺失资源和不写入原文件；界面回归覆盖完整下拉、默认列出、只读操作、防抖和旧响应失效。前端构建、类型检查和真实 macOS 设置窗口验收覆盖可见界面。


## Consequences

桌面默认进入「查词库」，个人类型查询结果会明确显示内置来源，资源词库统一提示只读，管理操作需要切换到「管理词库」，账号页的云词库入口切换到「云词库」标签而不再另开设置窗口。标签选择是窗口状态，不写入用户偏好；云词库目录等子页仍保持在同一设置窗口内，避免跨窗口丢失登录会话和异步请求上下文。

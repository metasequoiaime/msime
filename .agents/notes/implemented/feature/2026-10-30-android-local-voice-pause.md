# Agent Note: Android 本地语音的停顿时间与识别灵敏度

Status: implemented

## Problem

#10310 希望工具栏或功能菜单开始的语音输入可以调整停顿时间和灵敏度。Android 本地识别在最后一次出字后等待固定的 1500 毫秒；整段模型的 Silero VAD 阈值固定为 0.5。系统识别自行判断结束，豆包流式与整句上传保留用户结束操作，不能仅凭服务暂未返回文字就判断用户没有说话。

## Decision

Android 语音设置的「识别」提供「本地停顿时间」和「判停灵敏度」，仅保存到 `AndroidLocalSettings`，不随账号同步。时间范围 500–5000 毫秒、步长 100，默认仍为 1500；灵敏度范围 10–90、默认 50，数值越大，Silero VAD 的判定阈值越高，越容易判定说完。共享 C++ 的 `LocalAsrOptions` 持有可选灵敏度，未传或非法值保持原阈值 0.5，其他宿主行为不变。

键盘每次开始本地识别时固定本次的参数；停顿时间只影响本地录音结束计时，长按空格仍由松手结束。灵敏度只作用于使用 Silero VAD 的本地整段模型，流式本地模型、系统识别和云服务不承诺支持。页面说明这一边界，不把音量动画的大小当作识别灵敏度。

## Alternatives considered

- 所有识别服务统一按最后一次出字计时，界面只需一个滑块；但整句流式在用户仍说话时可能长时间不返回文字，会重新引入长录音中断，因此仅让本地识别使用此计时。
- 把灵敏度做成麦克风音量增益，能够改变音量动画且适用于所有录音；但这会改变送给服务的音频，无法等同于语音活动判定，保留音频原样并调实际 VAD 阈值。

## Consequences

用户能按本机环境调整结束等待和 VAD 灵敏度，原来的计时默认值、长按松手语义与系统／云识别结束规则保持。高灵敏度更容易把背景噪声当作说话，长停顿会延迟最终上屏；这两项不改变送入识别器的音频增益。没有本地模型的设备无法仅凭设置控件验证识别质量，PR 保留真实模型与麦克风验收缺口。

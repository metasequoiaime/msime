# Agent Note: Android 社区资源获取显示忙碌进度

Status: implemented

## Problem

Android 社区皮肤、词库和短语的获取操作已经在网络线程上执行，但卡片只把按钮文字改成「获取中」或「添加中」。用户无法从控件外观判断请求仍在运行；这与资源包、iOS 社区页面已有的忙碌指示不一致。社区接口通过 `msime_client_community` 返回完整结果，没有向 Android 宿主暴露下载字节回调，因此不能在这里显示可信的百分比。

## Decision

社区卡片在 `Action.BUSY` 时保留原有中文状态文字，并在按钮旁显示主题色的不确定进度指示器。皮肤、词库和短语共用这一条绑定逻辑；回复模板没有获取动作，不显示指示器。请求结束时沿用现有的 `AVAILABLE`、`DONE` 状态重绘，进度指示器随之隐藏。实现不修改 Rust、网络协议或其他平台的下载接口，也不把不确定状态伪装成百分比。

## Alternatives considered

- **给社区接口增加字节级进度回调**：能显示真实百分比，但需要改动 client-services、host-api、JNI 和服务端传输边界，且当前接口的单次 JSON 下载没有稳定的总长度契约，超出本 issue 的可验证范围。
- **只保留「获取中」文字**：改动最小，但用户仍缺少明确的进行中视觉反馈，也无法与 iOS 社区页面和 Android 资源包页面保持一致。

## Consequences

社区卡片的进行中状态更容易被发现，且不会因为页面重绘误开放重复操作。用户仍看不到社区作品的百分比；需要真实下载进度时，后续应先定义跨宿主的流式回调和取消契约，再单独开 issue。视觉改动需要 Android API 28/35 设备截图验收；本分支在本机磁盘空间门禁下不启动新的完整设备构建，交由 PR 设备 job 或报告者复验。

# Agent Note: 主动开启的英文在线补全与纠错

Status: implemented

## Problem

#9015 要求在英文模式和临时英文中，用已经配置的 AI 或云服务补全、纠错，并携带前文。现有 `online_query` 同时拒绝专用英文和所有本地模式，回包又只写入拼音引擎的动态候选。仅删除查询入口的条件，回答仍不会进入正在显示的英文列表。

macOS 还有两条独立路径：专用英文候选由共享引擎管理，普通中英切换的英文则由 `InputController.mm` 直接把按键交给应用，隐藏候选窗。这意味着只改共享引擎不能让用户平常切到的英文模式得到补全。

## Decision

新增默认关闭的英文在线候选偏好。它是额外授权，仍需对应 AI 或云候选服务已经启用；旧配置缺字段时关闭，隐私模式、密码输入框和失焦继续禁止请求。偏好校验、默认值与持久化由共享 Rust 管理，原生设置只提供界面；每个对外显示开关的宿主都必须有实际输入路径。

查询显式区分英文与原有拼音模式，英文带原始字母串与前文，不假装它是完整拼音。模式加入查询身份、回包校验及缓存边界，旧 JSON 缺少模式时沿用拼音；切模式、改拼写、关闭授权或切服务后，旧回答失效。默认 AI 提示按模式分派补全与纠错，复用现有三个自定义提示词槽，用户消息提供 `mode: "english"`。

专用英文与临时英文把有效在线批次接入各自正在显示的候选列表，而非隐藏的拼音列表；输入变化清除旧批次，保留本地列表的次序与正常英文上屏语义。AI 仍交给 Runtime 的现有第一页最后一格规则，不新增占位格、不修改此前的本地候选。

macOS 普通英文开启授权时进入可管理的英文组字路径，保留英文状态显示、标点宽度、切回中文及宿主生命周期；关闭时保持英文直输。撤销授权或切回中文时先原样提交正在编辑的拼写，不能隐藏尚未上屏的文本。共享 React 设置页由 `english_online_candidates` 宿主能力控制，目前只在 macOS 显示开关；其他平台没有接通输入调度，不显示控件，macOS 回退设置窗口也不增加功能。

## Implementation boundaries

- 额外授权放在共享 `Preferences`，缺字段为 `false`，通过会话运行时 setter 传入，不因授权变化重建引擎。关闭授权属于即时状态变更：正在组字时也清理英文在线批次、作废查询，不等到下一次重建会话。
- `OnlineQuery`、引擎 Host 适配快照、Runtime 和 Host API 同步传递模式。英文身份包含专用或临时入口与字母串，不能仅用原中文方案编号区分；原拼音查询与缓存键保持兼容。
- 英文回包写入 `dedicated_english_candidates` 或临时英文的 `local_candidates`，按来源保留批次并去重。重建本地列表时仍保持本地行的次序；输入变化和清理在线来源必须同时处理英文批次，避免旧行留在列表里。Runtime 继续负责 AI 最后一格的呈现。
- `AiSuggestionRequest` 明确携带模式和英文原文，英文不经过完整拼音校验；默认提示按模式选择，自定义槽继续有效。云请求也必须有明确的英文语义，不能把英文原文当拼音交给只做拼音转换的提供者。
- macOS 普通英文的自动组字状态与用户主动切换的专用英文状态要能区分。开启授权后才把普通英文交给真实会话；关闭时先原样提交未上屏的英文，再退出自动组字。原生入口、候选显示、AI/云定时器及回包检查必须使用同一状态判断，不能只放开入口或只放开渲染。
- 对外开关按宿主能力显示：共享 React 只服务真实承载它的宿主；缺少相应普通英文输入路径的宿主保留偏好，但不显示一个无法工作的开关。macOS 冻结的回退设置窗口不新增控件。

## Alternatives considered

- 只增加本地编辑距离纠错：离线、延迟低，也能纠正常见错字；但不能满足已经配置 AI 服务后按前文给英文补全的明确需求，不能用作本项的完成条件。
- 只删除 `dedicated_english` 查询限制：改动最少，能让专用模式返回查询；但回包仍写错列表，普通 macOS 英文仍绕过引擎，临时英文也仍被本地模式条件拒绝。
- 始终对英文请求在线服务：无需新增设置，用户直接获得补全；但网址、命令和账号的隐私预期会变化，与默认关闭的明确要求冲突。

## Consequences

英文错拼可通过已有服务纠正，并在正常可选列表里出现；保留本地排序和 AI 座位规则，默认关闭与本机授权保持原有隐私预期。英文查询的引擎 `cloud_eligible` 属于规范身份，Host API 另以本次 `cloud_candidates` 表示服务能否接收英文：默认 Google 与超限的自定义请求只关闭云请求，不能把 AI 回答一并挡掉。

普通英文开启授权后由输入法维护 marked text，空格、标点、快捷键、失焦与词库维护多了一层生命周期状态。托管状态与用户主动选择的专用英文分开；词库维护只恢复后者，普通英文按最新授权重建。关闭时原样提交未上屏字母，失败则保留组字，避免丢字。IMK 结束组字、失焦或换客户端时，普通英文同样先提交原文，既不能自动采用尚未选中的词库补全，也不能让 Runtime 的失焦取消丢掉字母；专用英文与临时英文保留原有选词行为。

英文仅接受非空 ASCII 字母串，最长 256 字节；网址、数字和命令分隔符会结束普通英文组字。自定义云服务必须理解新增的 `mode`、`context` 字段，内置 Google 拼音转换不支持本功能。其他宿主今后接入时必须先补齐输入与在线调度，再启用设置能力；不能只显示开关。真实系统输入入口与编辑器验收仍需后续验证，不能用共享设置壳代替产品。

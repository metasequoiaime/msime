# Agent Note: Android 剪贴板固定角标

Status: implemented

## Problem

#7802 反馈剪贴板记录固定与未固定只能长按确认；原实现把「已置顶」写进第二行元信息，长文本和窄屏下容易被截断，固定状态不够醒目。

已检索现有剪贴板历史、固定存储、卡片渲染和设备测试。`ClipboardHistoryStore` 已提供固定状态与不可驱逐语义，本片只改变 Android 卡片视觉，不改存储协议、排序或操作入口；剪贴板历史上限的独立需求 #7787 不混入本片。

## Decision

在本地剪贴板卡片右上角绘制固定角标：角标独立于文字布局，固定时显示强调色角面和白色斜线，未固定时不占空间。角标不增加无障碍节点，卡片原有「已置顶」描述继续保留，读屏用户仍能知道状态。

## Alternatives considered

- **继续只显示「已置顶」文字**：改动最小，但长文本、双列和较小屏幕会截断元信息，正是 issue 反馈的可见性问题。
- **在卡片正文前加图钉字符**：能保持在文本行内，但字体、字号和不同系统 emoji 可能不一致，也会减少正文宽度。
- **给固定项换整张卡片底色**：区分明显，但会破坏皮肤和选中态层次；角标只增加一个稳定的视觉锚点。

## Verification

- 固定项在长文本、单列和双列卡片中始终显示右上角角标。
- 未固定项不显示角标且保留原布局宽度。
- 固定/取消固定、删除、长按操作和存储排序行为不变。
- Android JVM 231 项、宿主 Java/API 检查、签名 APK 构建、API 35 模拟器安装后的长文本剪贴板编辑/保存/返回回归、`git diff --check` 和笔记门禁通过。

## Consequences

角标采用皮肤强调色和白色斜线，极端自定义皮肤可能降低对比度；它不改变固定状态的语义化文本。

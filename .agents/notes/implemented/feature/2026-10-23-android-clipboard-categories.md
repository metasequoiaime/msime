# Agent Note: Android 剪贴板手动分类与返回顶部

Status: implemented

## Problem

#8637 要求用户设置最多五个分类、键盘直达管理、点击本机选择分类、移动条目、固定工具栏和滚动后返回顶部。分类必须与历史的去重、编辑、置顶和撤销规则兼容，不能由 Java 再保存一份历史。

## Decision

共享 `ClipboardHistoryStore` 的条目增加可缺省的 `categoryId`，旧数组和旧结构化历史缺字段时均为未分类。分类目录放在历史文件旁的有界私有文件，复用同一写锁、拒绝符号链接和原子替换；最多五项，名称去首尾空白后最多十二个 Unicode 字素，不允许空名、控制字符、重复名称和本机、云端、全部记录、未分类这些保留名；另有 1024 字节上界，避免单个字素携带无界组合字符。稳定随机 ID 不随改名改变，也不复用删除的 ID。删分类只删目录，旧 ID 读取时归未分类，不删除正文；下次写历史时清理失效归属，避免两个文件的事务要求。关闭历史或清空正文保留分类设置。

重复采集保留分类；编辑合并使用被编辑条目的分类；批量撤销保留仍存在的分类，已删分类归未分类。容量仍为整个历史的容量，不给每个分类另设容量。所有新操作经原 mobile clipboard JSON 入口，不增加 JNI 符号。

Android 设置增加分类管理页，名称校验和持久化交共享层；键盘点击本机在原面板内选择全部、未分类或自定义分类，条目操作行提供移动目标，不开会抢编辑器焦点的对话框。移动入口复用既有第二行，避免第三行把原有收起操作挤出可触摸范围。固定顶栏保留，窄屏操作横向滚动，右下返回顶部按钮仅在正文列表离开顶部时出现；分词页不显示此按钮。

## Alternatives considered

- 将目录和条目改为单个 JSON 对象可以一次原子提交全部数据，但桌面历史与现有宿主仍以数组格式读写。保留数组并使用稳定 ID，删目录后惰性清除失效 ID，可以维持现有格式的兼容边界。
- 只用 Android 本地偏好存分类能少改共享层，但编辑、去重和撤销不会一起维护归属，也违反业务逻辑共享边界，因此不用。

- 共享层及 C API 覆盖旧文件读取、Unicode 名称、五项上限、十二个并发创建者、改名、删除、去重、编辑合并、置顶、撤销、过时写者、坏目录和符号链接保护。三个 mobile clipboard C API 专项通过；client-core 与 host-api 全目标 Clippy（`-D warnings`）通过。
- API 28、35 的四个共享客户端 crate 全套设备测试均通过：client-base 36 项、client-core 517 项、client-providers 254 项、client-services 1240 项；原有 ignored 与 runner 的硬链接跳过策略不变。最终 Rust 源码在 API 28 再跑一遍，仍通过。
- 两版原生产品的分类专项通过实际设置页创建、键盘本机筛选、长按移动、不误上屏、管理快捷入口、改名保留 ID、重新绑定输入法后重读、删分类保留正文、固定顶栏、返回顶部及原文插入。320/600dp 的固定区域与返回顶部另由 `ToolbarEdgesDeviceSmoke` 验收。
- 最终原生 APK 在 API 28、35 均通过分类、320/600dp 固定区域、卡片滚动、全文插入与编辑专项。最终源码完整 quick 门禁通过（含 164 项 Windows 可移植测试、Rust workspace/Android/WASM、Android Java 与 macOS 原生编译）；pnpm、Docker、MinGW 和 DevEco 缺失的阶段由脚本明确跳过，本机另跑笔记门禁、Rust 格式与 diff 检查。
- 完整全文预览回归在 API 28 的“editor keeps focus”断言失败；同一专用设备安装此前已验证的旧 APK（提交 `0a241f3c`）也在相同断言失败，未把它记为本次回归，也未删除或放宽断言。API 35 的最终 APK 完整通过同一回归，覆盖浮层显示、外部触摸首次直达收起、切换输入框清理、列表滚动、左滑删除、跨行拖选与全文编辑动作。不把专项等同完整通用 smoke。

## Consequences

分类和正文只在本机持久化，不上传分类名称，也不扩大原本排除剪贴板历史的备份范围；导出仍是全部正文。目录和正文使用同一稳定写锁，改名只写目录，删除不重写正文，代价是原始文件可能暂留失效 ID，需要读取与所有后续写入统一清理。目录损坏时明确报错且不覆盖，也不引导用户清空正文。

旧数组和旧结构化历史可以直接读入。带 `categoryId` 的新记录不能由拒绝未知字段的旧版共享库读取，因此不保证降级兼容；分类目录本身可独立于清空正文保留。Android 只画原生设置和面板，校验与存储归共享层；移动写入在工作线程执行，关闭或重开选择器后旧回调只能刷新当前状态，不能清除新选择。

完整预览回归在全新设备上会被首次引导挡住编辑页，因此测试保存并临时标记引导完成，结束后恢复；焦点、正文和触摸断言不放宽。

固定顶栏仍占 32dp，增加的入口在窄屏可横向滚动；返回顶部浮在正文区域右下方，分词及分类选择器不显示。模拟器验证不代替厂商真机验收。

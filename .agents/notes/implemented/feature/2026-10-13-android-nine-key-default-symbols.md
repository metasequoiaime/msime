# Agent Note: Android 九键默认符号栏回到三项

Status: implemented

## Problem

用户在真机反馈默认九键左侧符号太多、键帽过密。现状字母键面默认九项，一屏五项，常规输入时左栏与三行数字网格不对齐。此前扩充符号和支持自定义的理由见[九键符号栏与数字键面](../../implemented/feature/2026-10-08-android-nine-key-number-pad.md)。

## Decision

默认字母符号表收回 `， 。 ？`，三个键均分左栏并与三行网格对齐；叹号已有右侧入口，其余标点从左上角符号面板或自定义表取得。数字键面继续使用算式表，自定义表的五行上限、滚动和解析规则不变。只改变缺省值，不覆盖显式保存的自定义内容；笔画、14 键共用该默认表。

## Alternatives considered

- **保留九项默认，只改成较小的文字或取消键帽**：常用标点都能直接找到，是原方案最强的理由；但一屏五项仍然过密，也不能与九键的三行对齐。
- **全局把符号栏改为不可滚动的三项**：最容易保持稀疏；但会丢掉自定义多项和数字算式表的既有能力。收简默认即可。

## Consequences

- 收益：默认左栏只有三个常用符号，与三行网格对齐；显式自定义内容和数字算式表继续可用。
- 代价：习惯扩充默认项的用户需使用符号面板或自定义；共用默认表的 14 键、笔画也采用三项。

## Verification

`scripts/verify-local.sh --quick` 通过，其中 `check-host.sh` 的 `NineKeySidebarPolicySmoke` 校验精确的三项默认、空值和空白回退、显式自定义保留、数字表和五行滚动行高。`pnpm run verify-notes` 通过。

原生 APK 编译、签名校验和覆盖安装成功。在 Android 12 真机打开试用编辑器，确认左栏只显示三个符号，与九键三行对齐；独立键帽下没有整列底轨。另确认符号面板标题移除、网格键帽有间距。本次未跑模拟器。

# Agent Note: Android 九键默认符号栏回到三项

Status: implemented

## Problem

用户在真机反馈默认九键左侧符号太多、键帽过密。现状字母键面默认九项，一屏五项，常规输入时左栏与三行数字网格不对齐。此前扩充符号和支持自定义的理由见[九键符号栏与数字键面](../../implemented/feature/2026-10-08-android-nine-key-number-pad.md)。

## Decision

数字页的一屏三项由[中文数字入口默认九宫格](2026-10-15-mobile-default-number-pad.md)部分取代，默认显示四则运算的四项；本篇字母侧栏三项、自定义内容保留和最小行高保护继续成立。以下记录当时选择与三行网格对齐的理由。

默认字母符号表收回 `， 。 ？`，三个键均分左栏并与三行网格对齐；叹号已有右侧入口，其余标点从左上角符号面板或自定义表取得。数字键面继续使用算式表，但一屏最多三项，与数字网格对齐；其他键面的自定义表保留五行上限。滚动和解析规则不变。只改变缺省符号和显示密度，不覆盖显式保存的自定义内容；笔画、14 键共用该默认表。

## Alternatives considered

- **保留九项默认，只改成较小的文字或取消键帽**：常用标点都能直接找到，是原方案最强的理由；但一屏五项仍然过密，也不能与九键的三行对齐。
- **全局把符号栏改为不可滚动的三项**：最容易保持稀疏；但会丢掉自定义多项和数字算式表的既有能力。收简默认即可。

## Consequences

- 收益：默认左栏只有三个常用符号，与三行网格对齐；显式自定义内容和数字算式表继续可用；数字左栏每键与三行网格等高。
- 代价：习惯扩充默认项的用户需使用符号面板或自定义；共用默认表的 14 键、笔画也采用三项；数字算式符号一屏从五项减少为三项，除法、等号等仍需滑动查看。

## Verification

`NineKeySidebarPolicySmoke` 覆盖三项默认、空值回退、自定义保留、数字三行与其他键面五行的行高，以及最小高度保护。`scripts/verify-local.sh --quick` 和 `pnpm run verify-notes` 通过；原生 APK 构建、签名校验通过。API 35 专用模拟器的合成编辑器中确认数字左列一屏三项，与数字网格等高，滑动后可点按除法符号，上屏 `1+2/3`。Android 12 真机覆盖安装返回 `Success`，本次未在真机执行点按验收。

# Agent Note: Android 世界时钟按国家名称搜索

Status: implemented

## Problem

添加世界时钟城市时，用户必须先选择洲，再在较长的国家列表中滚动查找目标国家。国家目录已经随包离线提供，但页面没有按国家名称定位的入口。

## Decision

在选择国家页增加国家名称输入框和「搜索」按钮。搜索只过滤当前洲的离线国家列表，保留现有国家排序和城市选择流程；空查询恢复完整列表，无匹配时显示明确提示。搜索不联网、不申请权限，也不改变城市持久化格式。

## Existing note audit

- [离线世界时钟](../feature/2026-10-23-offline-world-clock.md)：复用现有离线国家目录、城市选择和保存协议。

## Alternatives considered

- 每次输入都访问地理编码服务：不用，世界时钟的目录和功能应保持离线，联网会引入隐私和可用性问题。
- 将所有城市直接放进一个搜索列表：不用，会破坏现有按洲、国家再选城市的层级和城市排序。

## Consequences

国家页多一行搜索控件，输入国家中文名称后可快速缩小当前洲的列表；城市页和已保存城市不受影响。

## Verification

- 世界时钟设备用例增加使用合成国家名称搜索后添加纽约的路径。
- Android host、API 28/35 设备验收待磁盘空间恢复到仓库规定的 50 GiB 启动线后补跑。

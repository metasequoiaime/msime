# Agent Note: Android 反馈页插入设备信息

Status: implemented

## Problem

#9779：反馈页的设备信息入口只能复制到系统剪贴板。用户还要等待异步收集完成，再回到描述框粘贴，容易丢失光标位置。

## Decision

反馈页的「其他渠道」入口改为「插入设备信息」。点击后沿用 `DeviceInfoCollector` 的异步白名单收集，完成时把格式化文本替换描述框当前选区，并把光标放在插入文本末尾。页面销毁或目标输入框脱离窗口后丢弃结果，避免异步回调写入失效视图。关于页和键盘工具菜单继续保留原有复制行为。

## Alternatives considered

- **继续复制并自动打开粘贴提示**：实现简单，但仍要求用户执行粘贴，不能满足一键插入。
- **把设备信息作为反馈提交的诊断字段自动附加**：不需要修改编辑器，但用户无法在提交前检查或把同一段信息贴到其他渠道，且会改变现有诊断白名单契约。

## Consequences

反馈描述框中的选中文本会被设备信息替换，未选中文本则在光标处插入；异步收集期间不阻塞界面。入口不再复制剪贴板，因此用户若要复制设备信息仍可从关于页或键盘工具菜单执行。需要在 Android 原生宿主上确认按钮点击、异步完成后的插入和页面重建边界。

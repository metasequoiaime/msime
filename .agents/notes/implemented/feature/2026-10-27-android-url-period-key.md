# Agent Note: Android 英文网址框底键优先输入句号

Status: implemented

## Problem

#9891：英文网址框频繁输入域名中的点号，26 键底行只有一个标点键，原来点按逗号、长按才出句号。网址框是否默认进入英文已有独立决定，见[网址框按默认中英文进框](../bug-fix/2026-10-25-android-uri-follows-default-mode.md)。

## Decision

只在 `EditorPolicy.uri` 判定的网址框、当前是英文模式且 26 键单标点底键可见时，标点列表把 `.` 放在第一项、`,` 放在第二项。`MSIMEInputService` 同时把底键主键面与点按改为句号、右上角提示与长按改为逗号，并让读屏描述与实际动作一致。中文网址框、邮箱、密码、普通文本框，以及不是这套底行的布局保持原行为；切换英文模式只改键面，不改用户保存的默认模式。

## Alternatives considered

- **在底行另增一个句号键**：逗号保持原位置，两种标点都能点按；但底行已经承载空格、中英、回车、符号入口与切换键，再缩窄现有键会增加误触。复用单标点键更聚焦这个网址场景。
- **让所有网址框自动进入英文 26 键**：句号会更易触达，但会重现九键用户进入浏览器地址栏时被强制换布局的问题，违反已有的[默认模式决定](../bug-fix/2026-10-25-android-uri-follows-default-mode.md)。

## Consequences

英文网址框点按底键输入 ASCII `.`，长按仍能输入 ASCII `,`。普通文本、邮箱和密码框的标点位置不变。新增的纯策略 smoke 覆盖字段与模式门禁、键面和字符顺序；宿主检查可编译并验证 Java 路径。真实 Android 编辑器里的键面与点按仍需设备验收。

# Agent Note: Android 剪贴板详情操作按键对齐

Status: implemented

## Problem

剪贴板详情页底部的「插入」和「返回」按键固定从左侧开始排列，右手单手操作时触达距离较大。issue #11288 要求在剪贴板设置中让用户选择左对齐或右对齐。

## Decision

在 Android 本机设置中新增 `platform.android.clipboard_detail_action_alignment`，取值为 `left` 或 `right`，默认 `left`，不进入账号同步。剪贴板详情底部操作行按该值设置 `LinearLayout` 的水平重力；列表卡片、顶部工具栏和详情正文不改变。设置页在现有「工具栏 → 剪贴板」组中提供「详情操作按键」选项，损坏或缺失值按左对齐处理。

纯 Java 策略类负责取值判定和显示文案，JVM 冒烟覆盖默认值、允许值、拒绝值和损坏值回退；设备冒烟通过真实详情渲染检查左、右两种设置确实改变操作行重力。

## Alternatives considered

- 只把两个按钮固定到右侧：实现最简单，但无法满足 issue 要求的左右选择，也会改变现有用户的默认位置，因此没有采用。
- 为每个按钮单独增加左右开关：设置复杂且无法表达两个按钮作为一组的布局意图，未采用。
- 把该设置放进共享账号同步偏好：这是 Android 详情页的单平台触达偏好，跨设备同步会把手机单手习惯带到不同尺寸和平台，现有 Android 剪贴板排列等布局偏好也只保存在本机，因此不采用。

## Consequences

用户可以在 Android 剪贴板设置中选择适合单手操作的一侧，默认用户的现有左对齐布局保持不变。设置只影响详情底部操作行，减少了对其他剪贴板布局的回归风险；它增加一个本机设置字段和一个选项页入口，切换后键盘重读本地设置并在下次渲染详情时生效。

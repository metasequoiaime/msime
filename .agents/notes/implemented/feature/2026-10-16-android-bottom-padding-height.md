# Agent Note: Android 独立调整底部留白高度

Status: implemented

## Problem

#7633 需要独立调整键区下方空白，现有「键盘高度」改变按键本身的高度，「底部留白」只有固定 40 dp 的开关，不能满足不同握持距离。

已检索底栏、底部留白和内联高度调整。此决定部分取代[键盘底栏](../../implemented/feature/2026-10-08-android-keyboard-bottom-bar.md)中「先固定 40 dp」的选择；底栏的导航方式、系统按钮、浮动与横屏条件保持原有归属。

## Decision

在 Android 本机设置增加 `platform.android.bottom_padding_height`，范围 0–160 dp，默认 40 dp；保留原开关及默认关闭，旧用户打开后仍为 40 dp。原生键盘设置在开关旁提供「底部留白高度」滑块，独立于按键高度，数值以 dp 显示。

底栏高度计入用户选择的距离：底栏显示时额外空白为 `max(0, height - 40)`，否则为 `height`。底栏按钮保持在原位置；空白在键区与底栏之间，不把底栏推入手势区。浮动、外接键盘收起键区和手机横屏不增加留白，保持原来的空间限制。

## Alternatives considered

- **继续使用固定 40 dp**：设置更少，和底栏高度相同。现在已有明确的独立调节需求，改变整体按键高度不能替代调整下面空白，因此增加独立数值。
- **无论底栏是否显示都叠加用户高度**：开关效果直观，但 40 dp 设置加上底栏会把键区抬高 80 dp，改变旧用户的默认体验；将底栏算入目标距离能保留兼容性。

## Consequences

- 保留默认关闭和旧用户 40 dp 的体验；自定义高度只保存在本机，不参与云同步。
- 0、40、80、160 dp 与越界输入有界处理，底栏显示时不重复叠加；留白只抬高键区，不改变按键尺寸。
- 过高留白会减少应用可见面积，因此上限固定为 160 dp，浮动及手机横屏仍不应用。内联「键盘高度」拖动柄继续调整整体按键缩放，留白通过独立设置滑块调整。
- API 28、35 已安装原生宿主验证真实持久化和 IME 内边距；API 35 真实编辑器已验证独立留白不改变按键高度。
- 原生设置滑块测试在全新安装时通过界面跳过开屏及首次引导，再重发页面请求，避免把引导遮挡误报成设置页缺失。原生设置交互验证滑块范围 0–160 dp、80 dp 写盘和页面重开恢复。

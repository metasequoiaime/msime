# Agent Note: Android 英文当前词的一键清除

Status: implemented

## Problem

#9174 要求九键切换后的英文 26 键在读音行右侧提供清除入口。当前英文直接写入编辑器，候选来自光标前的当前词，取消引擎组字不会删除这个词。

## Decision

复用读音行最右侧的退出按钮：本地模式仍取消组字；普通英文在完整当前词末尾显示「清除」。通过真实 InputConnection 再读当前词、绝对光标和连接身份，只有与按钮渲染时一致才删除。选区、词中光标、密码框、读取失败或截断的长词不提供入口。删除沿用既有编辑器桥的选区回声追踪，作废旧英文建议，不自动采用纠错。

可清除的当前词只让读音行保持显示，不算候选栏有内容（#10479）。`render()` 把空闲拆成两层：`candidateIdle` 只看组字、本地模式和各类候选，决定工具栏、候选行、候选视口和光标旁候选；`idle` 另要求没有可清除的当前词，决定读音行、读音标题、收起「最近复制」和自动填充建议。收起「最近复制」与自动填充不能跟着换成 `candidateIdle`：无建议框（React Native、Flutter 关掉建议的聊天框）、网址、邮箱或关掉英文建议时打英文没有任何候选，`candidateIdle` 一直为真，当前词是唯一能说明用户开始打字的信号，换掉后「最近复制」会在打字时一直盖住工具栏，点它会把剪贴板接在半截词后面。没有补全的词点原文收起建议后，词仍在光标前，候选行无内容，此时读音行的「清除」在上、工具栏在下，不再留一整行空白候选栏。读音行显示时工具栏行高由 `updateCandidateViewportHeight` 的读音行分支扣除，与本地模式提示同路径，自定义工具栏尺寸同样按读音行加按钮高度取下限。

## Related notes

「清除」的字号大于读音，同行高度及按钮显示前的预留由[读音行尺寸](../bug-fix/2026-10-09-android-reading-font-size.md)统一计算，避免文字底部裁剪或输入时键盘跳高（#10057）。

检索 `独立英文`、`专用英文`、`英文工具栏`、`退出本地模式` 的活跃笔记。[手机英文纠错](../../implemented/feature/2026-10-16-mobile-english-correction.md)部分重叠，继续拥有直输和重新核对当前词的规则；本篇补清除入口。[专用英文切换](../../implemented/bug-fix/2026-10-16-dedicated-english-held-phrase.md)管理引擎组字，和此处已直输的当前词无关，其余候选算法与其他平台笔记无关。

## Alternatives considered

直接发送取消命令能复用本地模式按钮，但普通英文没有引擎组字，不会清除输入框的词。切换英文为托管组字可以统一取消语义，但会改变已有英文光标、边界、失焦和纠错行为，超出增加清除入口的范围。

## Verification

原生 APK 构建和 Android 宿主检查通过，含 254 项 JVM 冒烟及 202 个设备套件源文件编译。设备回归覆盖从中文九键切英文后清掉合成错词、前后文本、异步建议、继续输入、全角字母与撇号，以及空闲、中文、选区、词中光标、长词和密码框边界。API 28、35 的专用模拟器安装原生 APK 后，基础输入验收与完整 `NineKeyEnglishDeviceSmoke` 均通过。关闭英文建议时同样可清除。最终 `scripts/verify-local.sh --quick`、`pnpm run verify-notes` 和差异检查通过；未做手机真机验收。

本次 #10057 在 API 28 安装后的原生宿主隔离视图中覆盖 9.6/12/25.6sp 与系统字体 1/2 倍，六组均无裁剪，按钮显隐行高一致，合成截图完整；完整 `NineKeyEnglishDeviceSmoke` 同包重跑通过。首轮在清除用例之前的九键完整英文候选 `commit` 检查失败，原测试与产品逻辑均未为重跑改动。Java 宿主重新构建，未改的原生库和资源复用先前设备验证包；本次未重跑 API 35 或报告者的 vivo 真机。quick 重跑结果见[读音行尺寸](../bug-fix/2026-10-09-android-reading-font-size.md)。

#10479 只改 Java 宿主：`NineKeyEnglishDeviceSmoke` 增加无补全长词点原文后工具栏可见、建议与展开键消失、「清除」仍可删除当前词的用例。复核后 `EnglishCorrectionDeviceSmoke` 另加无建议框里复制后出现「最近复制」、打 `hello` 后它收起而「清除」仍在的用例。Android 宿主检查通过，含设备套件源文件编译；本次没有模拟器或真机，两个设备用例都未运行，需在设备上补跑。

## Consequences

当前词不再需要连续退格；代价是英文读音行在存在可清除词时保持显示，并增加编辑器读取。编辑器不支持读取时不显示按钮；当前词按已有规则识别 ASCII／全角字母及撇号，长度有界。已输入文字属于编辑器，入口必须在动作前重新核对，不能沿用迟到的候选文本。

# Agent Note: Android 剪贴板记录用右滑进入详情

Status: implemented

## Problem

剪贴板历史卡片同时有长按预览和卡片右侧的 `ⓘ` 详情按钮，长文本查看入口重复；长按还会在输入法窗口内打开额外的预览层。#11045 要求去掉长按详情和常驻按钮，改用横向手势进入详情，并在详情页提供编辑入口。

## Decision

关闭的本机剪贴板卡片向右滑，位移超过删除区宽度的一半或达到同样的快速甩动阈值时进入现有的记录详情页；斜向或未越过 touch slop 的移动继续交给列表滚动、点按和长按。已打开删除区的卡片仍只处理左滑删除区和右滑收回，选择模式不启用详情右滑。左滑删除逻辑保持不变。

长按仍保留已有的管理操作行（固定、删除、编辑、分词、分享和分类），但不再自动打开全文预览；详情页在「插入」和「返回」之间增加「编辑」。删除常驻 `ⓘ` 按钮，更新读屏描述和卡片说明。

## Existing notes audit

按剪贴板详情、长按预览、剪贴板横滑、`ClipboardSwipePolicy` 和编辑入口检索活跃笔记。既有剪贴板横滑笔记持有左滑删除区、纵向滚动让渡和动画边界，本篇只增加右滑详情方向并调整入口；详情页与编辑页的存储和返回规则继续由现有实现持有。

## Alternatives considered

- **继续保留 `ⓘ` 并新增右滑**：会保留重复入口和用户希望删除的视觉按钮，因此不采用。
- **右滑直接弹出对话框**：会重新引入输入法窗口焦点和系统 WebView 收起风险，继续使用现有面板内详情页。
- **用长按替代右滑**：与本 issue 要移除长按详情的目标相反，且长按已经承担管理操作行，保留其管理职责但不再打开预览。

## Verification

- `ClipboardSwipePolicySmoke` 增加关闭卡片右滑、打开卡片收回、左滑不进入详情和斜向让渡的策略断言。
- 设备冒烟把旧的「长按自动全文预览」契约改为长按管理行、右滑详情，并在详情页覆盖插入、编辑、保存和返回；常用语提示专项也改为直接操作长按管理行，不再寻找已删除的全文预览关闭按钮；重开编辑器时先收起再重新打开剪贴板入口，清掉上一轮面板状态；详情松手时按手势实际位移判定进入详情，必要时在未接管拖动的 `ACTION_UP` 再按同一判定兜底，避免按压反馈或布局动画复位卡片位移；工具栏布局检查同步移除对常驻 `ⓘ` 按钮的依赖。
- 长文本卡片的无障碍正文可能因 Android 节点传输上限为空，设备冒烟按卡片的「右滑查看详情」操作说明定位，再用卡片实际边界注入手势；短文本和详情正文断言仍保留。
- API 31 以上的短冒烟会复用输入法进程；右滑详情专项由 `smoke.sh` 在启动 instrumentation 前强停产品，再重绑输入法，避免旧会话保留关闭剪贴板历史或其它模式的快照。强停不能放在测试代码里，因为该 instrumentation 以产品进程为目标。
- 右滑详情的合成记录通过 `ClipboardHistoryStore.restoreMany` 写入移动端公开存储入口，不再由测试直接伪造历史文件，确保夹具与输入法实际读取的模式、容量和类别路径一致。
- 右滑详情专项的偏好通过 `HostStore.savePreferences` 发布，保留共享偏好锁和修订号校验，避免设置文件直写后 `:ime` 进程仍持有另一份快照。
- 真机阶段探针确认短路径在偏好和历史写入完成后、重启输入法之前卡住。`UiAutomation.executeShellCommand` 直接执行命令，不解释 `for` 和命令替换；原夹具把 shell 循环传给它，管道读取一直不结束。改为直接执行 `pidof` 并排空输出，再由同 UID 的 `android.os.Process.killProcess` 结束 `:ime`，不扩大产品权限或强停 instrumentation 本体。修复后同机走到原生编辑页，确认首启临时说明会遮住编辑框；夹具只实际点击这张已知说明的「知道了」，不写首启标记或跳过其他弹窗，沿用现有原生设置专项的做法。
- API 34 以上的无障碍树可能把滚动容器里的剪贴板卡片标成不可见；设备契约用 `awaitAny` 找到带「右滑查看详情」描述的卡片，先请求滚入视口，再等屏幕边界连续两次稳定后注入手势，详情正文仍在滚动到视口后用可见节点核对。
- 设备夹具写入主模式前显式保存 `ClipboardModeStore.Mode.MAIN`，避免复用设备状态时输入法服务从访客目录读历史而测试只准备了主目录。
- 同步新版详情布局时，保留 develop 已移除固定标题、正文顶部不穿透触摸、来源元信息不显示的断言；右滑专项改用底部返回入口识别详情，长正文先滚动到操作行再点编辑，保留原文逐行插入和修改后记录身份断言。真实设备截图、最终 quick 与 API 35 的结果记入 PR 验证段，全部成功前不合并。

## Consequences

详情入口从固定按钮变为手势，读屏用户通过卡片描述获知右滑，触摸不便用户仍可长按打开管理行中的「编辑」或使用点按插入。左滑删除和选择模式不变；本次不改变剪贴板存储格式、默认值或其它平台。

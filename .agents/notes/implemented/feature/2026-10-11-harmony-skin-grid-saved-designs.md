# Agent Note: 鸿蒙手机皮肤网格列出皮肤库里的设计和社区皮肤

Status: implemented

网格里列社区第一页的做法和「浏览更多皮肤」入口已被 [iOS 与鸿蒙手机皮肤页改为内置、我的、社区顶部分类](2026-10-16-mobile-skin-page-top-tabs.md) 取代：保存的设计改到「我的」分类，社区皮肤只在「社区」分类里。皮肤库读取与打勾规则仍成立。

## Problem

在「社区」里获取的皮肤存进本机皮肤库（`CustomSkins/library.json`），编辑器里命名保存的设计也在那里。鸿蒙手机的皮肤网格却只有内置主题、一张代表当前设计的「我的皮肤」和候选窗皮肤包，皮肤库里的设计一个都不列，用户找不到自己获取过的社区皮肤。Android 皮肤页一直有一组「我的设计」。

## Decision

- `SkinGrid` 接收 `savedDesigns`，每个设计一张卡片，排在「我的皮肤」之后、皮肤包之前，两种明暗下都列出。点一下用 `onCustomKeyboardChange` 把它设为自定义主题的键盘，和社区页的「使用」一样。
- 正在用的设计等于皮肤库里的某一款时，打勾的是那张有名字的卡片，「我的皮肤」不再同时打勾。
- 皮肤页在网格可见时读皮肤库：从别的标签页回来，或者从编辑器、AI 抽卡这两个子视图返回，都会重读，刚获取或刚保存的设计马上出现。读失败时只是少了这些卡片。
- 社区的第一页也列在网格里（`communitySkins.list`），排在皮肤库的设计之后；已经获取过的（皮肤库里有同一 id，大小写不论，或同一设计）不重复列出。与 Android 键盘皮肤面板列出社区目录缓存一致，不用先去「社区」标签获取。点一下走社区页「获取」的同一条路（`download` 后 `finishTrial(id, false)`，服务器计入一次下载，设计以社区 id 存进皮肤库），再经表单换上；获取失败时网格下方写明原因（未登录、皮肤库已满等），这次点击不计入换装统计。离线时只是没有这几张卡片。

## Alternatives considered

- **像 Android 一样另起一个「我的设计」分组。** 分得更清楚。不用它，是因为鸿蒙手机的皮肤页按设计稿只有一个网格，再加一组标题和卡片会显得重复；卡片标题已经是设计的名字。

## Consequences

- **收益**：社区皮肤、获取过的设计和保存的设计都能在皮肤页直接换上。
- **代价**：每次回到皮肤网格都会请求一次社区列表。
- **代价**：键盘里的皮肤面板仍然列不出它们：API 12 起键盘进程看不到设置应用的 `files/`，要等共享沙箱（`.agents/notes/implemented/architecture/2026-10-09-harmony-ime-shared-sandbox.md`）。
- 「社区」标签页后来去掉了，完整的社区皮肤图库改由网格下方的「浏览更多皮肤」在皮肤页上打开，见 [触屏设置去掉「社区」标签页](2026-10-11-touch-community-merged-into-feature-pages.md)。

# Agent Note: 只差「他/她/它」的读法由模型决定

Status: implemented

## Problem

「他」「她」「它」同音，词网格分不出来，只能按词频排，而词频反映的是语料里哪个字更常见，不是这句话指的是谁；该用哪一个只有上文知道。逐键重排挑整句时，把词网格逐字分和模型逐字分按 0.3 比 0.7 混合（`static_evidence_weight`）。两条读法只差代词时，这 0.3 的词频只会把结果往高频的「他」那边拉。2026-11-04 换上 [聊天上文训练的 rerank-v2](../bug-fix/2026-11-04-chat-context-rerank-v2.md) 后，单人聊天集里「你记得跟她说谢谢」「她说上次你修好的那个灯现在还好用」两句，模型都选对了，混合后分别以 0.002 和 0.004 的差距输给了「他」。

## Decision

`ordering::rerank_pick_within` 按混合分选出首选之后，再看整句池里只在第三人称代词上和它不同的读法（`differs_only_in_third_person`：字数相同、其余逐字相同、只差「他」「她」「它」）。这些读法里谁的模型分最高就选谁，词网格分不参与。其他情况仍按混合分选。比较逐字进行，不分配内存。

## 评测

2026-11-04，develop 引擎（d95ccc2be4）加一个只靠环境变量开关的诊断构建，配 rerank-v2，开纠错。6x256 用整句池 32 条，8x448 用 9 条。

| | 6x256 | 8x448 |
|---|---|---|
| 含代词、带上文的聊天句（366 句：合成聊天开发集 353 + 单人聊天集 13） | 203 → 216（+20 / −7，p = 0.019） | 226 → 235（+13 / −4，p = 0.049） |
| 整套单人聊天集（330 段） | +2 / −0 | +0 / −1 |
| sentences 四套（1,580 句） | 不变 | 不变 |

改错的那几句，是模型自己选错了代词，比如「他爸月底才能回来」被打成「她爸」。原来是词频碰巧把它拉对了。

## Alternatives considered

- **整体调低词网格权重（0.3 → 0.25 或更低）**：离线重算过。降到 0.25 时 6x256 合计净 +2，8x448 净为负；降到 0.2 及以下两个模型都变差，语气词集掉得最多。代词只是词网格帮不上忙的一种具体情形，调全局权重会连带伤到词网格本来管用的地方。
- **不改，等下一轮训练**：模型在代词上的判断已经比词频准，混合把它的正确判断抹掉了，这一步不依赖训练。

## Consequences

- **收益**：带上文的代词句子提升明显，两种尺寸在 366 句上的提升都显著；没有代词差别的句子完全不受影响。
- **代价**：模型在代词上的领先往往很小（每字 0.015 到 0.03），没有上文、或上文里看不出指的是谁时，结果接近随机。改错的 7 句都是这一类，例如上文是「我」的一串消息，下一句写到「他爸」。
- **评测集**：366 句里 353 句来自合成聊天开发集，和训练数据同分布，只是对话不重叠；真机上的效果要靠以后的验收确认。

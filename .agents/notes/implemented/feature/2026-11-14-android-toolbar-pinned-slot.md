# Agent Note: Android 工具栏右侧常驻按钮

Status: implemented

## Problem

#11427 希望 Android 键盘顶部右侧的收起键盘位可以改成用户选择的常驻工具栏按钮，并要求收起键盘仍可作为普通工具栏功能使用。现有工具栏把品牌键和收起键固定在滚动区外；最近复制出现时整行工具栏被替换，右侧只有一份收起键。

既有的[Android 工具栏排序与按钮身份分离](2026-10-15-android-toolbar-order.md)决定品牌键和收起键不参与中间排序。本次需求明确要把右侧收起位开放为配置槽位，因此在保留默认外观的前提下扩展这条决定。

## Decision

Android 新增本机设置 `platform.android.toolbar_pinned`，默认值为 `dismiss`。它从同一组稳定工具 ID 中选择右侧常驻按钮；缺失或非法值回到收起键盘，默认用户的顶部布局不变。工具栏排序新增 `dismiss` 项，收起键可以像其他按钮一样单独开关和排序；右侧槽位选中的按钮从中间滚动区移出，避免同一按钮出现两次。

右侧槽位不跟随最近复制预览消失：最近复制行出现时，当前常驻按钮视图移动到这一行最右侧，其他复制预览、历史入口和关闭复制预览按钮保持原有行为。右侧槽位仍受工具栏整体隐藏规则约束；工具栏隐藏时不额外强行显示它。

设置页在「键盘 → 工具栏」提供「右侧常驻按钮」选择，选择只写本机设置，不改变共享 `touch_toolbar` 开关，也不把任何既有开关默认改为开启。预览、排序、输入法运行时共用 `ToolbarOrderPolicy` 与常驻槽位策略。

## Alternatives considered

- **继续把收起键固定在右侧，只把文本编辑和语音另加快捷入口**：实现较小，但不能满足用户把右侧位置换成其他工具、且最近复制出现时仍保持该位置的要求，因此不采用。
- **把常驻按钮复制成一份独立视图**：最近复制行和普通工具栏可以同时持有各自按钮，但每个工具要维护两份选中状态、尺寸和可访问性，容易在面板切换时漂移；本次移动同一个按钮视图并保留原回调。
- **把常驻槽位写进共享 `touch_toolbar`**：Android 的文本编辑、浮动键盘和部分工具是本机设置，槽位只影响 Android 原生宿主，扩展共享偏好会让其他宿主看到却不消费的字段，因此保持本机设置。

## Consequences

默认配置的右侧仍是收起键盘，旧版本已有 `toolbar_order` 会在读取时补上 `dismiss`，旧用户不需要迁移。选择其他常驻按钮后，中间滚动区少一个按钮；若用户仍想保留收起键，可在排序页打开 `收起键盘`。最近复制预览出现时常驻按钮仍可点，但它替代了原来最近复制行右侧的收起键，用户可用系统返回收起键盘。

本次只改 Android 原生设置、工具栏和宿主逻辑；没有修改 iOS、HarmonyOS 或共享设置页，也没有改变工具栏整体隐藏、隐私框和剪贴板预览的现有规则。

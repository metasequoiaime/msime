# Agent Note: 内置宣传快捷键

Status: implemented

## Problem

#8482 需要一个直接把产品介绍插入当前编辑框的快捷入口。把内容加入常用语会要求用户先把常用语入口放进工具栏，也会把产品预置内容和用户自己的短语混在同一个存储里。

## Decision

移动端功能面板提供固定的「宣传」磁贴，点击后先结束当前组字，再插入内置宣传文本。文本包含产品名、简短特色介绍、官网和 Git 项目地址；它不会写入常用语文件，因此用户清空或修改常用语不会影响该入口。Android、iOS 和 HarmonyOS 各自复用本平台已有的原样提交接口，保持与常用语相同的编辑器边界。

## Alternatives considered

- **要求用户把宣传语加入常用语**：实现成本低，但入口依赖用户配置，不能满足 issue 要求的固定快捷键，也会污染用户自己的常用语列表。
- **通过官网或分享系统打开外部页面**：能提供完整介绍，但不能直接把宣传语插入当前文本框，且会打断输入。

## Consequences

固定文本随应用发布，修改文本需要更新各平台键盘代码；移动端功能菜单多出一个分页条目。宣传文本的插入属于本地输入，沿用已有统计和组字结束规则。桌面平台沿用已有入口：macOS 悬浮工具栏菜单、Windows 悬浮工具栏实用菜单以及 Linux 的 `Ctrl+Shift+P`。这些入口不改变桌面工具栏的固定布局。

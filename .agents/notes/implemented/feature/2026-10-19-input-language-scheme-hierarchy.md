# Agent Note: 输入语言与中文方案分层选择

Status: implemented

## Problem

输入页用两行外观相同的长分段控件分别选择语言与中文方案。选项较多时控件挤占说明宽度，且「输入模式」「输入方案」没有解释两者的从属关系。

## Decision

语言行改名为「输入语言」，复用系统下拉控件；当前选项直接显示在行尾，仅在宿主不支持某些语言时给出原因。中文输入的六种方案独立为「中文方案」三列选择卡片，保留原生单选按钮、键盘导航、能力过滤与当前方案选项。非中文语言继续隐藏中文选择；切回中文继续使用原有的 `last_chinese_scheme` 回退规则。

## Historical audit

- [精简输入与快捷键页](../../implemented/simplification/2026-10-16-macos-input-settings-prune.md)：部分重叠，继续保留单方案语言只显示说明、双拼与五笔按当前方案展示设置的规则。
- [桌面输入、表达与语音页标签](../../implemented/feature/2026-10-13-desktop-input-expression-voice-tabs.md)：属于页面分区，保留顶部标签；本次只改方案分组内的选择控件。
- 检索 `InputModeSection`、`InputSchemeSelectorSection`、中文方案和语言分段选择，未发现同范围提案。触屏「语言与方案」卡片归独立入口，不改动。

## Alternatives considered

**保留两条分段控件，只让它们换行**：仍能一眼看见全部选项，也能保持一次点击切换；但两级选择仍长得一样，说明与选项仍争用横向空间。

**两行都改成下拉菜单**：最紧凑，也符合设置页的普通参数形式；但常用中文方案的可发现性变差。语言使用下拉、中文方案保持直接选择，让两层有明确主次。

## Verification

相关组件、版本过滤、宿主能力、资源包与设置集成 105 项测试通过，包含语言往返保留中文方案、不可用选项禁用、单方案版本隐藏选择，以及日文保存和重载。

输入页分组顺序的两个宿主回归通过。前端类型检查、生产构建与本地 quick 门禁通过。合成 macOS 设置在浅色 1000×780、深色 800×600 下无横向溢出，实际操作验证语言往返、原生单选方向键与双拼选项联动。签名设置应用已安装到本机，窗口截图与无障碍树确认「输入语言」系统菜单与六个独立中文方案选项。

## Consequences

语言菜单需要先展开才能选择。方案网格比旧行略高，但不再挤压文字。仅验收共享设置页与 macOS，不把它描述为 Windows、iOS 或 Android 原生设置已改动。

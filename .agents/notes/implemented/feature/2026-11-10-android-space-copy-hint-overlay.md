# Agent Note: Android 上滑空格复制提示移到键盘浮层

Status: implemented

## Problem

上滑空格复制全文时，提示「松开复制全文」目前作为候选区诊断行的一部分显示。诊断行参与键盘列测量，提示出现和消失会改变工具栏位置并造成短暂抖动（#11112）。

## Decision

复制手势的状态提示和复制失败结果使用独立的 `SpaceGestureHintOverlay` 浮层，挂在覆盖输入法窗口的根视图上并居中放在屏幕上沿。浮层使用 `GONE` 隐藏、`wrap_content` 尺寸且不参与触摸，因此不会改变候选区、工具栏或按键区的测量；提示文字保留无障碍描述，手势结束、取消或重置时立即隐藏，失败结果沿用 4 秒自动消失。空格键恢复原有键面文字和读屏描述，不再把提示文字写进键帽。

浮层沿用现有诊断提示的黑色药丸和白色文字，位置由父视图固定，不跟随空格键移动，避免把提示误认为键面的一部分；显示时置于输入法根视图最上方。

## Alternatives considered

- **继续复用诊断行**：改动最少，但诊断行属于候选区竖向布局，无法满足提示出现时工具栏高度不变，因此不采用。
- **用 `PopupWindow` 脱离输入法视图**：可以完全脱离键盘测量，但需要额外处理输入法窗口坐标、生命周期和浮动键盘，容易在旋转或窗口重建时残留，因此不采用。
- **直接把文字画在空格键上方**：位置贴近手势来源，但会覆盖键区并随布局变化，仍可能遮挡其他键或面板；固定在输入法窗口上沿的浮层更稳定。

## Consequences

浮层显示不会再推动候选区和工具栏，空格键的常态标签在手势期间也保持稳定；TalkBack 仍能读到提示。代价是键盘表面多一个短生命周期视图，需在键盘视图重建和皮肤刷新时同步其颜色，并由设备测试核对提示位置与键盘布局稳定性。

## Verification

- `SpaceCopyDeviceChecks` 增加真实 API 设备断言：提示显示在键盘顶部、横向居中，空格键仍保持「空格」文字与描述，释放或取消后提示消失。
- 复制失败结果也由同一浮层显示，普通诊断提示路径保持不变。

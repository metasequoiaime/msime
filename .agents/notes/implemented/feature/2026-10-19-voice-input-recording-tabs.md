# Agent Note: 语音输入与录音行为拆成顶部标签

Status: implemented

## Problem

桌面语音页把输入法的识别设置、快捷键与录音提示音、静音行为连续排列。用户要求将输入法与录音行为拆成两个顶部标签。

## Decision

共享桌面语音页复用 `useSettingsTabs`，默认进入「输入法」，显示语音面板、识别设置与语音快捷键；「录音行为」显示提示音与录音时静音。服务配置保留原有子视图，进入后隐藏标签，返回后回到输入法。两个标签与子视图均保持挂载，切换不丢草稿，也不写入偏好。手机布局与设备读取时机保持现有行为。

识别与录音的双标签挂载契约继续保留；标签自然命名、结果提交与设备的最新归属由[设置搜索定位与桌面内容归位](2026-10-19-settings-findability.md)部分取代。

## Historical audit

- [精简 macOS 语音设置](../simplification/2026-10-16-macos-voice-settings-prune.md)：部分重叠，本次替代主页面不分标签的决定，保留服务配置下钻、平台能力与设备读取边界。
- [桌面输入、标点与翻译、语音标签页](2026-10-13-desktop-input-expression-voice-tabs.md)：部分重叠，曾有五个语音标签；本次只分主页面，不恢复旧五分区。
- [键盘与手写设置拆成顶部标签](2026-10-19-keyboard-handwriting-top-tabs.md)：独立页面，复用相同的挂载与键盘操作方式。
- 手机语音页整理与手机设置子视图笔记只涉及手机，此次不改。

## Alternatives considered

**保持一页顺序展示**：全部常用设置无需切换即可查看，但不能满足用户指定的两个入口。

**恢复五个语音标签**：服务、润色、设备可以直接进入，但会重新引入先前精简掉的导航负担，超出此次两个标签的需求。

## Verification

相关设置测试 36 项通过，覆盖桌面四种宿主投影的标签分组、方向键与 Home/End、录音草稿与服务配置节点保留、导航不保存偏好，以及手机保留原布局。前端类型检查、生产构建、格式与 lint、笔记门禁及 `MSIME_BUILD_JOBS=6 bash scripts/verify-local.sh --quick` 通过。

原有大设置页回归 399 项中，398 项首次通过；另一个旧剪贴板用例遗漏切换「历史记录」标签，补齐该操作后定向重跑通过。

本机 macOS 设置组件重新打包、签名验证并安装，通过实际窗口检查顶部两个标签、输入法中的识别与快捷键、录音行为中的提示音与静音；进入服务配置后标签隐藏，返回恢复输入法。截图确认标签与内容布局正常。未更改本机语音偏好，也未启动真实录音。其他平台仅核对共享页面投影，未在设备上验收。

## Consequences

录音提示音与静音需要先切换标签；主页面缩短。隐藏面板保持挂载；标签 Hook 在手机分支返回前调用，避免宿主能力变化时破坏 Hook 顺序。

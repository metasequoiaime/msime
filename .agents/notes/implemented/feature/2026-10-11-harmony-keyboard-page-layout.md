# Agent Note: 鸿蒙手机键盘设置页拆成「布局」和「尺寸」两张卡片

Status: implemented

## Problem

鸿蒙手机的「键盘」页把所有东西塞进一张「布局」卡片：中文键盘、26 键数字键盘、数字键盘顺序、双拼键位提示各挂两三行说明；中间夹着一段关于拖动预览的提示；三个滑块的标题和「0 dp」上下堆着，轨道只有 110px；「恢复默认」的标题、说明和红色按钮把同一件事说了三遍。预览又单独放在下面一张「屏幕键盘」卡片里，标题下还有一个「预览」小标签，和它调的滑块分在两处。

## Decision

只改鸿蒙手机（`TouchKeyboardGeometrySection` 收到 `layoutRows` 时），其他宿主不变：

- 「布局」只放中文键盘、26 键数字键盘、数字键盘顺序和双拼键位提示，只留标题和取值。
- 「尺寸」一张卡片：最上面是可拖动的预览（不带「预览」标签），下面一行小字说明可以拖；然后是三个整行滑块（`SliderRow` 的 `wide`，标题一行、轨道铺满下一行、数值在轨道右侧），高度为 0 时显示「标准」，间距不带 dp；最后一行是居中的「恢复默认」文字按钮，它照旧也重置工具栏按钮。
- 「手势」组的说明缩成一行。
- `wideRow` 在鸿蒙上标题和控件之间的纵向间距收成 6px，文本框那类整行控件也一样紧凑。

## Alternatives considered

- **保留单张卡片，只删说明。** 改动最小。不用它，是因为预览和滑块仍然分在两处，「布局」里混着选择和尺寸两类东西。

## Consequences

- **收益**：一屏能看完布局选项，预览和它调的滑块在一起，拖动和滑动的结果直接看得到。
- **代价**：鸿蒙手机上看不到各项的详细说明，例如「数字键盘顺序」里电话和计算器各指什么，要靠选项名和试用键盘理解。

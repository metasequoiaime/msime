# Agent Note: Android 键盘的「指令」入口和符号面板里的符号集插件

Status: implemented

## Problem

Android 键盘经 runtime option `preferences_directory` 读插件目录，启用的短语表进 K 模式、指令表进 `/` 模式都由 Engine 负责，可手机上进不了 `/` 模式：触屏键盘的本地模式都从功能面板「本地输入」进入（Shift+字母那一套在触屏上没人用），那里只有 Unicode、日期时间、超级简拼、快捷短语、英文补全、表情、颜文字、临时日语和拆字九项。符号集插件也一样：键盘的符号面板只有内置分类，装了符号集看不到。

## Decision

- `LocalInputMode` 加第十项 `COMMAND`（触发键 `/`、标题「指令」、偏好键 `command`），追加在末尾。`local_modes.command` 在 client-core 出厂关着，所以这一项缺省读作关（`enabledByDefault`），其余仍缺省读作开；`localModeEnabled` 在中文标点关着时也把它置灰，因为 Engine 只在中文标点下、没有组字时把 `/` 当作入口（`local_mode_for_symbol`），英文标点下点它只会打出一个 `/`。`openLocalInputMode` 对它不带 Shift 送 `/`，与实体键盘上直接按 `/` 相同；其余九项照旧按大写字母送。和其他本地模式一样，整组只在全拼、双拼下可用（`supportsLocalTools`）。「指令」只在 26 键下列出（`commandLettersTypable`）：进入 `/` 模式后键盘保持原来的键面，九键、14 键、18 键的键发的是数字或分组码，Engine 在 `/` 模式里不收，按第一个键就结束模式、把 `/` 原样上屏，指令字母打不出来。
- 「本地输入」九项时仍是三列三行；有了「指令」的十项排成四列三行，面板高度不变，不用上下滚动（#9873 刚把功能面板做成不滚动）。长按读音行弹出的本地模式菜单读的是同一份列表，自动多出「指令」。
- 符号面板每次打开后，在表情目录的工作线程上调一次 `msime_client_emoji_catalog_request` 的 `list_plugin_symbol_groups`（插件目录是偏好目录下的 `plugins/`），读完换进面板（`SymbolPanelView.setPluginCategories`）。排法与鸿蒙 2in1 的 `PluginSymbolGroupPolicy` 和 Tauri 面板相同（`SymbolPanelModel.pluginCategories`）：`symbols` 组以插件名为分类，每个插件一个，排在全部内置分类之后；`kaomoji` 组逐组成为一个分类，紧跟在「颜文字」之后——这个面板的「颜文字」就是那两处说的 All，颜文字插件组按颜文字的两列排、不记进「常用」。坏组跳过而不是整份作废。插件分类不进「符号分类顺序」：用户调整顺序时，它们跟着「颜文字」和末尾走。正在看的分类按 id 留在原处，被卸载时回到「常用」。

## 已核对的 Engine 行为

- K 模式的候选由 Engine 合成：词库短语在前，再是 `plugins.phrase_tables` 启用的短语表里编码以输入开头的短语，键盘不用改；在模拟器上用插件页新建并启用的短语表核对过。
- `/` 模式在移动端会话里同样打开：`local_mode_options.command` 来自 host-api 对偏好的通用映射，不分平台。在 API 35 模拟器上，26 键进入后打 `sig` 列出插件指令表里的 `/sig`；九键进入后候选栏列出全部指令，但按 PQRS 键时模式结束、`/` 原样上屏，所以这一项只给 26 键。

## Alternatives considered

- **九键也显示「指令」**：进入 `/` 模式时候选栏已经列出全部指令，九键用户可以直接点选，不用打字母，这是它最强的理由。不用它：只要按一个键就会把 `/` 上屏、模式结束，指令一多就只能翻页找，看起来像是坏了；九键要能打指令字母，得先让 Engine 在 `/` 模式里收九键的数字组码，那是另一件事。
- **符号插件分类只读一次、缓存到键盘进程结束**：省掉每次打开面板时的那次文件读取。不用它：设置进程里装上或卸载一个符号集，键盘进程不会收到通知，缓存会一直停在旧的样子；读几个 `plugin.toml` 在工作线程上，代价很小。
- **把插件分类也放进「符号分类顺序」让用户排**：用户可以把常用的插件排到前面。不用它：顺序表存的是固定 id，插件分类随装随卸，存进去的 id 会悬空；先与其他面板的排法一致，有人要再做。

## Consequences

- **收益**：手机上启用的指令表和装上的符号集在键盘里真的用得上，排法与鸿蒙电脑、桌面面板一致。
- **代价与已知上限**：功能面板「本地输入」多一格，十项时改成四列；符号面板每次打开多一次后台文件读取。插件符号没有逐项的名字，这个面板也没有搜索，组的关键词在这里用不上。

## Verification

- JVM：`LocalInputModeSmoke`（第十项、缺省关、不带 Shift）、`SymbolPanelModelSmoke`（按插件合成分类、坏组跳过、颜文字组紧跟「颜文字」、符号插件排最后、「常用」仍在首页）。
- API 35 自建 AVD（arm64，与插件页同一个 APK）：26 键在「本地输入」里点「指令」进入 `/` 模式，打 `sig` 首选是插件指令表的 `2026-10-26 Zhang San`（标题 Signature）；「快捷短语」里打 `dh` 出插件短语表的「电话」「电话号码」；符号面板分类栏里「颜文字」后面是插件颜文字组「开心」（两列），最后是插件符号分类「Fixture」；九键下「本地输入」回到三列三行、没有「指令」。API 28 自建 AVD：`/` 指令关着时「指令」置灰，符号面板末尾有插件分类。
- 没有在真机上跑过。

# Agent Note: 文本编辑面板实时显示最近复制

Status: implemented

## Problem

#8104：Android 的「最近复制」监听会在文本编辑面板点「复制」后收到系统剪贴板变化，但渲染条件把所有工具栏面板都当成不可显示区域。用户必须先关闭文本编辑面板，才能看到刚复制的内容。

## Decision

只对文本编辑面板放行最近复制行。该面板保留顶部工具栏作为操作上下文，复制结果就在这行显示；表情、皮肤、符号、剪贴板等其他面板继续隐藏最近复制，避免覆盖各自的工具栏状态。

最近复制行的收起键与普通工具栏一致：面板开着时读作「返回键盘」，点按只关闭面板；无面板时读作「收起键盘」。粘贴和关闭预览不主动关闭文本编辑面板。

### 历史笔记归属

- [最近复制工具栏](2026-10-08-android-recent-clip-toolbar.md) 部分重叠：本篇取代「所有工具栏面板都隐藏预览」中的文本编辑特例，其余开关、隐私和过期规则继续由旧篇持有。
- [文本编辑面板](2026-10-08-android-text-edit-panel.md) 和 [顶部文本编辑按钮](2026-10-09-android-toolbar-text-edit.md) 部分重叠：入口与编辑器动作不变，只增加复制后顶部预览与返回行为。
- [图片发送](2026-10-11-android-recent-clip-image-send.md) 无行为取舍变化，沿用同一行及既有 MIME 类型和敏感内容判断。

## Alternatives considered

- **关闭文本编辑面板后才显示** — 无需改变任何工具栏状态，保持所有面板统一隐藏的简单规则；但无法满足复制后立即看到结果的需求。
- **所有工具栏面板都显示** — 所有位置都能一步粘贴；但会让最近复制行覆盖或干扰表情、皮肤、符号和剪贴板面板的工具栏状态，因此只放行文本编辑面板。

## Consequences

- **收益**：复制或剪切后立即看到新内容，仍可继续编辑，键盘和面板高度不变。
- **代价**：预览显示期间替换原工具栏，返回按钮必须与面板状态联动。监听、隐私判断、剪贴板历史开关、超时和点按粘贴逻辑继续沿用原有规则。

## Verification

`RecentClipboardSuggestionSmoke` 覆盖空闲、其他工具栏面板和文本编辑面板三种可见性组合；Android host 检查编译宿主与 JVM 冒烟，原生 APK 构建通过。完整设备端 InputConnection 回归受本机模拟器节点缓存和磁盘空间限制，保留为后续设备套件工作。

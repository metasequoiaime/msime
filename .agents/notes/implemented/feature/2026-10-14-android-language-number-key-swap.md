# Agent Note: Android 语言键与数字键交换

Status: implemented

## Problem

#7751 的语言轮换、日语九键位置和中间帧闪烁已有修复，但用户还需要把语言键放回左侧。只交换中文底行会让英语和外语键盘继续跳位置。

## Decision

新增 Android 本机设置「交换语言键与数字键」，默认关闭。普通底行交换整个语言与数字入口，宽度跟随键；分离键盘共用同一底行。日语九键交换左列数字键与右列语言键（交换后语言键放在左列最下一格，见[日语九键交换后语言键在左下角](2026-11-02-android-japanese-nine-key-swapped-language-key-bottom-left.md)），注音九键交换网格数字入口与右列语言键，键的动作、手势和身份不变。英语键盘也使用该设置。26 键数字层自带底行，没有语言键；返回字母布局后保持交换位置。

设置是 Android 宿主的布局选择，沿用 AndroidLocalSettings，不扩展共享 Preferences 和账号同步字段表。改动时继续依据语言键是否实际紧邻回车决定误触让位，交换后不让回车向数字键转发。

历史检索：[语言切换修复](../../implemented/bug-fix/2026-10-14-android-language-switch.md)部分重叠，更新其后续功能状态；[手机语言键位置](../../implemented/feature/2026-10-09-mobile-language-key-beside-return.md)的默认位置与其它移动平台保留；九键数字页和中英键轮换记录涉及动作语义，保持原状。

## Alternatives considered

把语言键默认改回左侧最易实现，但改变所有用户的位置习惯；用默认关闭的设置保留现有布局。

加入共享 Preferences 可以让移动平台共用字段，但此 issue 只涉及 Android，其它平台没有接入，账号同步也没有对应字段，因此先采用本机设置。

## Verification

主机测试覆盖所有普通底行、地球键和宽度保持；设备测试构建真实键盘，覆盖默认、交换后和恢复，包含英语、日语九键与注音九键。API 28 的布局重建可能留下无障碍子树缓存，专项测试逐节点刷新后再查询，避免把旧键面当作新布局。API 28 的安装与打字验收、完整键位交换专项通过；专项运行时暂时停用 AVD 自带的崩溃键盘，结束后恢复，不改产品行为。

## Consequences

交换后语言键不再紧挨回车，回车的误触让位随实际位置关闭；设置只在本机保存。

# Agent Note: Android 设置页显示当前应用图标

Status: implemented

## Problem

#8033 反馈「我的 → 通用 → App 图标」仍用通用手机图标，无法直观看出当前主屏图标配色。

## Decision

设置行左侧复用当前选中的 launcher 图标资源，保留「App 图标」标题和配色名称作为文字与无障碍说明。图标资源映射集中到 `AppIconStyle`，选择面板和设置行共用同一映射，避免两处配色漂移；彩色图标不套用设置页的单色 tint。

## Alternatives considered

- 只改标题文字：仍看不出当前选中的配色。
- 在设置行另画一套预览：会复制资源映射，后续新增配色容易不一致。

## Consequences

设置页能直接看到当前主屏图标配色；标题和配色名称继续保留，文字浏览和无障碍不会丢失。图标映射由设置页代码集中维护，选择面板与列表不会显示不同资源。

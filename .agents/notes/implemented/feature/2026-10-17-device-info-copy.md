# Agent Note: 键盘设备信息复制反馈

Status: implemented

## Problem

更多工具里的设备信息复制入口使用剪贴板历史图标，复制完成后仍停留在工具面板，且复制文本没有说明用途。

## Decision

入口使用独立的复制图标并显示为「设备信息」。点击后立即关闭工具面板并重绘键盘，结果提示沿用输入法诊断行并以黑色胶囊呈现。复制文本在字段前说明用途和隐私边界，设备字段白名单保持不变。

## Alternatives considered

继续使用系统 Toast 能覆盖键盘不在屏幕上的情况，但输入法服务后台 Toast 在新 Android 上可能被吞掉，因此保留诊断行作为键盘内的主要反馈。

## Consequences

普通用户能区分入口、看到键盘内反馈，并理解文本用于反馈排查。设备信息仍只在用户点击时读取，未增加新的隐私字段。设备验收需要更新复制文本行数和面板关闭断言。

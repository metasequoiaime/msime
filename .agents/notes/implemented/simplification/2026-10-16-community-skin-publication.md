# Agent Note: 社区键盘皮肤发布对话框与状态独立复用

Status: implemented

## Problem

`CommunitySkinPublishDialog` 嵌在整页社区图库中，本机设计加载、选中设计、发布字段、重试 ID 与提交代次也由同一 JSX 函数持有。其他共享界面无法直接复用键盘皮肤发布流程；单独验证生命周期也必须加载整个图库。

## Decision

对话框位于 `community-skin-publish-dialog.tsx` 并从包入口导出；发布状态与动作由 `use-community-skin-publication.ts` 持有。页面只持有打开、关闭与成功刷新行为。hook 接收只含 `publish` 的社区客户端、只含 `load` 的本机库，以及发布成功回调；继续调用已有草稿、字段校验与异步操作工具。

名称、说明、所选设计和分类改变时的重试 ID 规则保持；授权勾选不改变 ID。加载与提交仍以社区客户端和本机库作为共同 owner。事件的 `preventDefault` 留在对话框，hook 提交无需 React 表单事件。所有文案、结构、原有按钮条件与回调顺序保持。

## 旧笔记归属

- [社区发布建议字段](2026-10-12-community-publication-suggestions.md)持有 Rust 打包器的默认字段生成，与本次 React 表单拆分无关。
- [社区皮肤库代次](2026-10-12-community-skin-library-generation.md)持有卡片获取、即时恢复与使用流程，与发布读取/提交 owner 不同，不合并。
- [社区发布回车](../bug-fix/2026-10-14-community-publish-ime-submit.md)持有候选皮肤和插件发布的输入法按键契约，本次键盘皮肤对话框仍用原表单提交，不改变该入口。
- [社区皮肤宿主桥接](2026-10-15-community-skin-host-bridge.md)持有跨宿主命令契约，不改变客户端方法与返回值。

[插件发布模块](../bug-fix/2026-10-16-community-plugin-publication.md)沿用此边界，独立持有目录筛选、打包预检与发布结果。

## Alternatives considered

- 只迁出对话框文件：能直接复用完整界面，但状态与 JSX 仍绑定，生命周期验证还得渲染表单；本次同时提取状态 hook，便于独立使用和测试。
- 把键盘皮肤、候选皮肤和插件发布统一成参数化表单：能减少一些字段接线，但候选皮肤和插件还涉及打包预检、授权补写和不同发布返回值；本次保持各自业务边界，复用现有基础工具。

## Consequences

独立 hook 承担加载、字段、选择、校验和提交的生命周期，界面只接线与处理表单事件；包入口可直接渲染对话框，不需要创建整页图库。代价是页面、对话框与状态形成三个显式模块，跨模块接线由类型检查、既有图库测试和直接使用包出口的对话框测试覆盖。

独立状态测试覆盖读取/提交 owner 替换、卸载、同步防重复、实例隔离、授权与重试 ID；对话框测试覆盖选择设计/分类、提交参数、阻止表单默认行为和空库关闭。原有源码门禁迁到真实持有者，并检查对话框调用 hook、图库委托对话框。保留此前所有界面行为测试。

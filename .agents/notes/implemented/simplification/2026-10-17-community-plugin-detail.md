# Agent Note: 社区插件详情独立复用

Status: implemented

## Problem

社区插件图库页面同时渲染插件详情的摘要、安装替换确认、评分、下架和举报控件。图库页面还负责分页、客户端动作、详情代次和安装预检，其他宿主无法复用详情布局，详情 JSX 也容易与候选皮肤和资源详情出现条件分支漂移。

## Decision

`packages/ui/src/community/community-plugin-detail.tsx` 持有插件详情的展示与回调契约，公开 `CommunityPluginDetail` 和 `CommunityPluginDetailProps`。组件接收插件、详情状态、安装状态和动作回调，继续复用公共详情框架、摘要、安装、评分、下架和举报控件，保留插件类型、授权、包大小、同类型同标识替换提示及插件专用下架文案。

[插件图库 hook](2026-10-17-community-plugin-gallery.md) 持有客户端、列表筛选、详情状态、安装预检、安装成功通知、评分和下架请求；`CommunityPluginsPage` 只负责将这些状态接线到详情组件。组件不读取客户端、不启动请求、不持有确认状态。举报能力通过可选 `onReport` 注入，客户端不提供举报时详情入口隐藏。此边界沿用[社区皮肤详情独立复用](2026-10-17-community-skin-detail.md)的展示与图库分层，并继续复用[社区图库状态](2026-10-17-community-skin-gallery.md)和[社区安装操作](2026-10-12-community-install-actions.md)的状态归属。

## 旧笔记归属

按插件详情、图库状态、安装动作和发布对话框检索活跃笔记：

- [社区图库适配器](2026-10-12-community-gallery-adapter.md)继续持有列表和详情请求的通用适配，不把插件字段塞进详情组件。
- [社区插件发布](../feature/2026-10-11-windows-settings-community-tabs.md)及插件发布对话框继续持有本机插件目录和发布流程，本片不改变发布行为。
- [社区安装操作](2026-10-12-community-install-actions.md)继续定义安装完成和替换确认的公共控件；本片只接线插件专用文案。

未发现完全相同的插件详情提案或需要拒绝的旧决定，无需归档。

## Alternatives considered

- 继续把详情 JSX 留在插件图库页面：改动最小，但共享宿主仍需复制插件专用的安装、评分和下架条件。
- 让详情组件直接接收 `CommunityPluginClient`：调用更短，但会让展示组件重新持有请求、错误、代次、列表刷新和安装预检边界。
- 将插件详情与候选皮肤详情合成一个带大量条件分支的组件：文件更少，但插件的包类型、授权、安装参数和下架文案与皮肤不同，会允许无效 props 组合。

## Verification

新增详情组件测试覆盖摘要与一键安装、作者下架确认；插件图库已有安装替换、评分、下架和错误测试继续运行。源码契约测试改查新的详情 owner，并保留共享详情框架、标题和审核控件断言。提交前运行完整社区测试、桌面生产构建、Harmony 类型检查、lint、笔记门禁和 `git diff --check`。

## Consequences

其他共享宿主可以直接复用插件详情布局并注入平台动作；详情组件不会自行操作客户端或修改图库状态。插件图库 hook 是插件客户端和异步生命周期的唯一 owner，调用方必须提供动作回调。此片不改文件读写、权限、网络协议或原生资源，不声明设备验收。

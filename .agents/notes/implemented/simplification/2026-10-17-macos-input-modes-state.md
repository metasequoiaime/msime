# Agent Note: macOS 输入法入口复用公共模型与状态

Status: implemented

## Problem

`macos-input-mode-entries-section.tsx` 同时持有宿主读取契约、版别入口表、缺失项筛选与语言分组、异步读取、焦点订阅、限时轮询和展示。其他展示无法独立复用完整状态，`SettingsClient` 的纯类型还反向依赖界面文件。

更换客户端时旧列表没有清空，打开系统设置留下的两分钟轮询窗口也跟到新客户端；旧窗口卸载后的设置打开失败仍调用展示错误回调。这些生命周期边界需要随状态抽取一起封住。

## Decision

纯 `macos-input-modes.ts` 持有宿主契约、入口与分组类型、版别入口表、缺失项计算和语言分组；`useMacosInputModes` 持有读取、当前方案缺失项、焦点订阅、三秒轮询与两分钟窗口，以及打开设置动作。公共入口完整公开模型和状态，旧模块转导出已有符号，调用者类型依赖改指向纯模型。

读取继续复用 `useAsyncGeneration`，打开动作复用 `useAsyncActionRunner`；客户端是异步所有者，版别、方案、展示回调变化只更新计算或当前回调。客户端变化清空列表并停止旧轮询，旧请求与卸载后的失败不写回。组件只保留描述、语言分组展示及展开状态。

## Existing notes audit

- [共享间隔 hook](../../implemented/simplification/2026-10-15-shared-interval-hook.md) 部分重叠：继续复用已有间隔工具，本片只承接输入法入口的业务启停条件，不接管验证码或其他页面。
- [首次安装提示](../../implemented/bug-fix/2026-10-09-macos-first-install-login-required.md) 是相邻的原生安装与注册表决定；本片不改注册、安装或缓存刷新。
- [设置界面归属](../../implemented/architecture/2026-10-15-settings-ui-ownership-by-platform.md) 继续生效：本片只处理共享 React 设置页，不给 macOS 回退原生窗口加功能。
- 其他命中的缓存目录祖先句柄、脚本授权和 Windows 输入源笔记属于各自的宿主边界，不合并。

## Alternatives considered

- **只公开现有组件和表**：改动少，但请求、轮询和缺失项计算仍绑在展示中，不能独立复用或测试客户端生命周期。
- **沿用客户端变化时的已显示列表和轮询**：可以减少切换时的空白，但旧入口会被当成新宿主的状态，旧窗口打开设置也会继续触发新宿主读取。客户端变化明确重置，焦点恢复仍按原规则刷新。

## Verification

- 纯模型保持原版别名称、模式后缀判定、宿主方案筛选、菜单顺序和语言分组。
- 公共 hook 可独立读取与刷新，正常焦点和轮询频率不变；重叠请求只接受最新回答。
- 更换客户端清空旧状态并停止旧轮询，旧失败和卸载不会触发展示回调，同批打开动作互斥。
- 原组件交互、公共 hook 和纯模型测试三文件共 24 项通过，新增界面回归在旧实现下按预期失败；请求代次复用契约跟随新状态文件。类型、构建与本地 quick 仍由仓库规定的门禁验证。

## Consequences

共享入口表、分组和状态不再依赖展示组件，客户端切换不会显示旧列表、延续旧轮询或触发旧错误。打开动作同批互斥，展示回调变化不取消进行中的动作，只接受当前回调；公共 runner 清空错误时的空串不传给展示层，保留只报告失败的原契约。

公共状态 API 增加维护面；原生系统设置能否打开仍由宿主负责，React 测试只覆盖注入客户端和界面契约，不构成真实输入源注册或装机验收。

# Agent Note: 主题模式选项模型

Status: implemented

## Problem

主题页把“跟随系统、浅色、深色”三个选项直接写在页面模块中。需要复用主题模式的宿主只能依赖页面实现，选项顺序和文案也没有独立的契约测试。

## Decision

`theme-mode-options.ts` 公开 `themeModeOptions` 常量，并复用已有的 `ThemeMode` 类型。主题页继续把同一常量传给分段控件，包入口公开该模型供其他宿主使用。三个选项的顺序、中文文案和取值保持不变。

## Alternatives considered

- **继续保留页面内数组**：改动最小，但共享宿主无法脱离页面模块复用和验证主题模式选项。
- **重新定义一份主题模式类型**：可以让模型完全独立，但会造成与 `theme-settings-section.tsx` 的公共类型重复，增加类型漂移风险。

## Consequences

主题模式选项现在可以在无 React 页面依赖的情况下导入和测试，页面行为保持不变。模型通过包入口公开；修改主题模式文案或顺序时需要同步更新模型测试。没有改变主题解析、持久化或平台能力判断。

验证包括模型测试、主题页回归测试、前端类型检查、构建、lint、笔记门禁和仓库 quick 门禁。

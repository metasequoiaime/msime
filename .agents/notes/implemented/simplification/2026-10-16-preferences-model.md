# Agent Note: 偏好文档与快照模型脱离设置入口

Status: implemented

## Problem

完整 `Preferences`、`Snapshot` 与 `ExternalSkinCatalog` 仍定义在 React 设置入口。52 个内部消费者通过入口取得偏好或快照，其中包括偏好投影、脏状态判断、订阅和持久化 hook。各领域偏好已归入独立模块，完整文档也需要独立的归属，避免纯模型依赖页面聚合入口。

## Decision

`core/preferences-model.ts` 只通过类型导入组合现有领域偏好，并原样持有完整偏好、快照及随快照提供的皮肤目录元数据。包入口兼容转导出三个名字，内部消费者直接引用模型。所有字段、交叉类型顺序、可选性、空值、数组可变性和快照信封保持原样；Rust 继续拥有配置语义、默认值、校验、未知字段保留与持久化。

偏好字段门禁已经扫描整个共享 UI 类型树，保留其生产实现；补充总偏好在叶子模块时的解析及缺字段失败用例，证明迁移后门禁没有绕过完整文档。

## Historical audit

检索活跃笔记的偏好聚合、`Preferences` 类型归属、`Snapshot`、`ExternalSkinCatalog` 与入口依赖：

- [候选偏好叶子契约](../../implemented/simplification/2026-10-15-candidate-preferences.md)、标点、预编辑、五笔、主题、AI、语音、工具栏等领域笔记拥有各自偏好模型；本篇只持有完整文档的组合位置，全部保留。
- [偏好未知字段保留](../../implemented/architecture/2026-10-15-preferences-keep-unknown-fields.md)持有 Rust 文档与信封的运行时边界，本片不改变规则、不增加 TypeScript 索引签名或默认值。
- [偏好快照订阅](../../implemented/simplification/2026-10-14-preferences-snapshot-subscription.md)和[设置持久化订阅](../../implemented/simplification/2026-10-14-settings-persistence-subscription.md)持有异步顺序与 revision 采纳，保留并复用回归测试。
- 宿主能力与词库契约笔记提供同类依赖收敛做法，契约独立；其他命中是原生设置或字段行为，不拥有总模型归属。没有完全吸收或过时提案。

## Alternatives considered

- **只迁移纯逻辑的导入，页面继续引用入口。** 改动更少，但同一内部模型仍有两套引用来源，继续增加入口依赖；一起迁移全部 52 个内部消费者，外部宿主仍使用包入口。
- **每个消费者改用字段级 `Pick` 或独立局部类型。** 依赖更窄，但会把现有完整文档参数拆成许多重复契约，并改变泛型对象和返回值推断；本片保持现有完整类型。
- **顺便重组字段或统一皮肤目录模型。** 能进一步减少声明，但 `ExternalSkinCatalog` 是快照附带的扫描元数据，与具体皮肤包模型不同；保留现有结构，只改变归属。

## Verification

三个模型声明去除注释与空白后和旧入口逐字一致；52 个消费者去掉类型导入后和原文一致。临时 TypeScript 探针在新模块不存在时失败，迁移后真实编译器确认新模型与独立保留的旧声明、旧公开导出完全一致。字段门禁继续检查 35 组结构；六项解析回归覆盖交叉类型、叶子模块总偏好、缺字段、缺基类型与循环。叶子模块用例删除 `scheme` 后准确失败，没有改生产门禁实现。

## Consequences

偏好投影、快照 hook 和页面直接依赖共同的类型模块，包入口只保留兼容导出。代价是完整文档需要显式导入领域类型；它不拥有默认值、校验或序列化步骤。领域 helper 与完整偏好之间保留原有类型引用，运行时不加载总模型的类型依赖。

不新增 TypeScript 索引签名、不重组字段，也不改变快照 revision 的生命周期。纯类型迁移容易被运行时类型擦除掩盖，因此编译器探针对照独立基线；临时探针与基线不进入产品或测试源码。本片不改变文件 I/O、原生资源或设备行为。

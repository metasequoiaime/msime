# Agent Note: 语言词典共用数据库验证步骤

Status: implemented

## Problem

笔画、粤拼、注音词典的验证函数重复打开引擎词典与只读 SQLite 连接、将查询计数转为 `usize`、按顺序检查统计下限。相同的错误上下文和下限诊断散落在三个模块中。

## Decision

`crates/dict-builder/src/language_verify.rs` 提供打开、计数和下限检查方法。三个词典仍分别声明查询项目、下限项目与顺序，并保留各自的音节及候选检查。原有的路径错误文案与第一个不达标项的报告顺序保持一致。

## Alternatives considered

- 统一三个 `verify` 函数：笔画额外检查固定五音节，其他两个词典的期望候选格式也不同，统一完整验证会把独立的规则变成复杂参数。
- 只共用 SQL 计数：仍会留下相同的打开和下限诊断流程。

## Consequences

共用数据库验证的机械步骤只有一个维护点；各方案特有的查询与候选规则仍在方案模块。现有测试覆盖读取、统计下限、候选检查与错误文案。

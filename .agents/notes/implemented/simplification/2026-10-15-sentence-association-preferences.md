# Agent Note: 整句联想偏好与级别规则独立于 React 展示层

Status: implemented

## Problem

`SentenceAssociationPreferences` 定义在包入口，读取开关缺省值、HarmonyOS 手机级别读写却在 `sentence-association-section.tsx`。纯偏好与展示模块互相依赖，其他消费者复用级别规则时要经过 JSX 组件。

已按类型、组件名、级别函数、整句联想和神经联想检索活跃笔记。[九键句子设置](../../implemented/feature/2026-10-09-nine-key-sentence-options.md) 持有引擎选项如何生效，[静态重排证据](../../implemented/bug-fix/2026-10-14-rerank-static-evidence.md) 与[被否的词网格覆盖调整](../../rejected/bug-fix/2026-10-14-lattice-rerank-path-coverage.md) 讨论引擎覆盖；本片不改这些决定。其余命中属于平台设置或模型资源，不持有公共偏好模块的归属。

## Decision

纯模块 `sentence-association-preferences.ts` 持有原四字段可选类型、级别类型及原级别读写函数，并集中两个开关的缺省状态和移动版本能力门控。包入口继续导出原偏好类型，组件继续重导出原级别类型与两个函数。组件负责文案、布局、事件和模型下载，不把显示状态写回偏好。

## Alternatives considered

- **只移动级别函数**：改动最少，复用级别不再加载 JSX。但偏好仍归包入口，两个开关的缺省和能力规则仍散在组件里，完整抽出已有偏好规则能解除这一依赖。
- **读取时补齐四字段并按版本清除神经开关**：控件只需接收完整对象，状态更简单。但旧文档缺键和隐藏的其他平台选择要保持，显示投影不能改变存储，因此不采用。

## Consequences

- 默认词网格开、两个神经开关关，显式 false 保留；桌面和键盘神经开关独立。
- 词网格关闭优先于键盘神经开关；级别写回只改两个字段，保留桌面与去重选项。
- 移动版本不带模型时隐藏神经开关并将级别显示为标准，不清除已存选择；桌面下载与资源行保持。
- 原公开类型和组件路径导出兼容。新增一个纯模块，控件状态只供显示，不作为完整偏好写回；文案、选项和下载时序仍归组件。

## Verification

抽取前后运行 HarmonyOS 表达页与桌面资源下载回归；纯模块用例覆盖缺键、全部级别组合、桌面与键盘开关独立、能力门控、不可变读写和其他字段保留。类型探针核对包入口四字段可选类型和旧函数签名，另跑桌面构建、Harmony 类型检查、偏好字段契约、笔记与 quick 门禁。

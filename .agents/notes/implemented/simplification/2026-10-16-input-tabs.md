# Agent Note: 输入页标签模型

Status: implemented

## Problem

输入设置页把六个标签及其字符串标识直接写在页面模块中。其他宿主需要复用输入设置导航时必须依赖页面实现，标签顺序和标题也没有独立的契约测试。

## Decision

`input-tabs.ts` 公开 `inputTabs` 和从数组推导的 `InputTab` 类型。输入页继续使用同一数组，并通过 `@msime/ui` 公开模型。标签只描述固定顺序和标题，移动端是否启用标签仍由页面现有逻辑决定。

## Alternatives considered

- **继续保留页面内数组**：改动最少，但输入页导航契约无法脱离 React 页面复用和验证。
- **把移动端显示规则也放进模型**：会把平台状态和页面渲染策略耦合到静态标签数据，扩大模型边界并降低复用性。

## Consequences

输入页标签现在可以独立导入和测试，页面的移动端展示、选中状态和各面板逻辑保持不变。修改标签顺序或标题时需要同步模型测试；此片不改变输入偏好或路由。

验证包括模型测试、桌面类型检查、构建、格式检查、lint、笔记门禁和仓库 quick 门禁。

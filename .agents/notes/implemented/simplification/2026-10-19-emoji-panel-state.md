# Agent Note: 表情与符号面板集中管理状态和动作

Status: implemented

## Problem

`EmojiPanel` 把目录加载、分类分页、最近使用、剪贴板读取与修改、通知和焦点恢复混在 JSX 前后，视图事件还直接组合多个 setter。状态归属与订阅、操作代次的关系难以单独验证和复用。

## Decision

由公共 `useEmojiPanel` 管理这些状态和动作，返回显示数据、导航绑定和语义动作。剪贴板记录由受控的 [EmojiClipboardEntries](2026-10-19-emoji-clipboard-entries.md) 消费条目和动作，最近符号、符号目录和通用目录共用受控的 [EmojiItemButton](2026-10-19-emoji-item-button.md)，面板统一把原文和关键词交给既有选择动作；`EmojiPanel` 保留其他 JSX、宿主能力控制和按钮文案，搜索框、记录与目录按钮使用内部样式模块；搜索、重载、激活模式、更多入口和分页使用 hook 动作。保留现有 effect 顺序、请求代次、400 ms 可见轮询、宿主订阅补读、剪贴板修改守卫和删除后的焦点恢复。

目录响应中的 `unavailable` 只标记内置目录读取失败。桌面宿主仍独立追加已安装插件组，因此成功响应中每类带 `pack` 的组都是本次插件完整快照。hook 在内置可用时采用整类响应；不可用时保留当前无 `pack` 的内置组，并采用本次带 `pack` 的插件组，空插件列表也替换旧列表，以反映插件更新和卸载。整个请求拒绝时没有新快照，保留当前完整目录。内置失败提示和重试入口仍显示，不因插件可用而清除；请求代次保护和客户端替换时重置目录保持不变。

通用目录先按既有顺序跨组去重，再用同一份去重结果计算各组最大页数和每页切片，每组每页仍为 48 项。合法插件组允许跨组重复；若显示按去重后的 48 / 12 项切片、页数却取原始的 48 / 60 项，就会多出空末页。分页状态仍由 hook 持有，符号专用网格不走这条分页路径。 插件也参与跨组去重的范围由[颜文字插件组身份](../bug-fix/2026-10-21-kaomoji-plugin-group-identity.md)取代：详情页保留插件各组完整项目，首页与内置组继续去重；页数和切片仍使用同一展示集合。

展示集合的总页数变化时，在布局 effect 中把当前页索引约束到最后一个有效页，绘制前完成纠正；仍有效的页索引保持不变。目录重试可以在其他分类仍不可用时更新当前分类，插件更新或卸载也会减少当前分类项目数，因此总页数缩短不能继续切旧页。纠正写回分页状态，后续目录扩充也不会跳回先前越界的页码。

## Existing notes audit

[剪贴板订阅](../../implemented/simplification/2026-10-14-emoji-clipboard-subscription.md)部分重叠，原有句柄释放与刷新时序仍归公共工具和面板状态，本片把组件归属同步为 hook；当时放弃整体抽取是为了限制那一片范围，本片集中迁移状态与动作，不翻转订阅决定。[临时通知](../../implemented/simplification/2026-10-14-ui-timed-feedback.md)和[桌面符号目录](../../implemented/feature/2026-10-14-desktop-symbol-directory.md)约束提示时长、分类、搜索和最近使用，不改变它们的行为。桌面宿主面板与客户端笔记只管理桥接与主题，原生平台笔记只管理各自宿主，与本片状态归属无关。

## Alternatives considered

- 只抽剪贴板 effect：可明显缩短组件，但它与删除、同步、清空共用请求代次和修改守卫，拆开后需要传递多个可变引用，状态边界不完整。
- 只搬 JSX：能减少单文件长度，但组件仍持有所有状态，调用方无法单独使用或验证面板动作。采用完整面板状态 hook，与已抽取的手写、语音和云词库面板一致。
- 保留原始目录长度计算页数：可直接反映服务端组大小，但与已经去重的显示集合不一致，会让下一页进入空态。页数与切片共用去重结果，避免改变目录加载和既有展示顺序。
- 内置失败时保留整类旧目录：可最大限度保留上次可见内容，但会丢弃宿主成功返回的有效插件快照，首次加载隐藏插件，重试也无法反映插件更新和卸载。回退只覆盖无 `pack` 的内置组，插件使用当前响应。
- 每次重试都回到第一页：最容易避免旧页越界，但会丢掉仍有效的浏览位置，且请求失败、目录未变时也会跳页。按当前展示集合的总页数约束页索引，保留仍有效的位置。
- 只在切片时临时使用较小的页索引：不增加状态更新，但旧索引仍藏在状态中，目录重新扩充就会跳回旧页。把纠正后的索引写回状态，避免下一次加载恢复错误位置。

- 内置失败与插件快照回归分别覆盖颜文字、符号：首次失败仍能在面板中选择插件项目并重试；已有目录重试依次验证插件替换、整个请求拒绝后保留、插件卸载和内置恢复。修复前 4 项因插件消失或仍显示旧插件失败，修复后相关 10 文件、97 项测试通过。

## Consequences

状态与动作可以独立复用和验证，视图不再组合 setter；代价是排查目录或剪贴板问题需从 JSX 跳到 hook。保留已有语句与 effect 次序；内置失败时按组来源选择回退，使独立可用的插件继续显示并保持最新。hook 内的 DOM 导航仍依赖面板标记，返回绑定必须挂在同一根节点。

# Agent Note: 安卓剪贴板详情移除来源元数据

Status: implemented

## Problem

#11285 反馈 Android 剪贴板详情页同时显示“来源 App：系统未提供”和“包名：系统未提供”。这两项对当前历史记录没有可用信息，只增加视觉噪声。它们来自键盘面板内的详情渲染；剪贴板导出文本是独立格式，仍保留原有字段。

## Decision

剪贴板详情只显示记录正文和记录时间，移除来源 App 与包名两行及其专用的 `sourceLabel` 文案策略。导出功能继续使用原有固定格式，不借此次界面精简改变导出文件内容。Android 设备冒烟改为确认详情的时间节点存在且不含这两项元数据。

## Alternatives considered

- 保留两行并把“系统未提供”换成更短的占位符：仍然展示无用信息，不能解决 issue 描述的杂乱问题。
- 同时删除导出文本中的来源和包名：会改变已有导出格式，超出“详情界面”的范围，也可能破坏用户依赖的备份内容，因此不采用。

## Consequences

详情页更紧凑，读屏树中不会再出现两项无效元数据；导出文件的格式和内容保持兼容。`ClipboardDetailPolicy` 不再提供来源文案策略，相关单测随之收窄；真实设备验收仍需在 Android 原生宿主中确认布局与读屏顺序。

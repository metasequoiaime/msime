# Agent Note: iOS 可见页面共用异步请求代次

Status: implemented

## Problem

云词库的“应用到本机”和“导入与导出”页面各自维护 `visible` 与 `requestID`，并重复在离页时使代次失效、在异步续点检查取消及代次、只让当前请求收尾。两份守卫一旦有一处漏掉，旧请求就可能在页面重新出现后覆盖新状态。

## Decision

在主 App 层增加值类型 `ViewRequestGeneration`，统一页面出现、开启请求、离页失效、当前请求判断与 `Task.checkCancellation()`。两个页面用 `@State` 持有代次值；仍自行持有与取消 `Task`，管理忙碌状态、会话身份、临时文件、业务数据和错误文案。

社区资源列表、内嵌回复模板区、资源详情与编辑页随后也改用该工具。回复模板的逐项添加仍由独立的 `addGeneration` 管理；共享工具只替换原来的页面可见性与列表或操作请求代次。

皮肤社区的列表、详情与发布页也复用同一工具。列表仍分别维护登录刷新和逐项获取皮肤的任务代次；排队加载在实际启动时会检查先前取得的请求 ID，防止旧任务重新成为当前请求。详情页三个操作闭包明确接收 `run` 传入的 ID，供异步续点检查使用。

## Alternatives considered

- 使用共同 `View` 基类或将整个异步动作封装为视图修饰器：会把不同页面的业务状态与 `Task` 所有权耦合起来，难以保留各自的清理顺序。
- 只提取 `ensureCurrent` 的静态函数：仍需每页分别协调 `visible` 与 `requestID`，离页失效容易遗漏。

## Consequences

两个页面共用请求代次语义。旧请求在新请求开始或页面离开后不能再更新页面，重新出现也不会使旧代次复活。原有的两份页面生命周期契约测试改为检查共享工具和调用路径；新增合成测试覆盖替换请求、离页与返回。构建和门禁结果以本次 PR 的验证记录为准。

社区四处调用点同样复用该语义，原有的四份社区生命周期契约测试随调用路径更新，逐项添加任务的取消与错误处理顺序保持原样。

皮肤社区三处页面共享同一请求守卫，迟到的分类加载失败不会回滚更新后的筛选状态；列表的登录与获取皮肤任务仍使用各自的代次。皮肤社区生命周期契约测试随调用路径更新。Swift 源码解析、iOS Simulator SDK 类型检查、契约测试和 notes 校验通过；本地 quick 的 Rust 阶段受 `origin/develop` 已有的 `Fixture.first_page_rows` 缺失字段错误阻塞，与本次 Swift 改动无关。

设置同步页的加载、下载应用与上传也改用该工具。三个操作仍各自保留会话校验、业务错误提示和数据写入顺序；共享代次只负责离页失效、取消检查和旧收尾隔离。

AI 皮肤抽卡页的生成任务也复用该工具。进度回调、结果和错误提示只接受页面可见期间的当前请求；取消按钮仍取消任务，保存与发布流程不变。

背单词设置页的词表导入与复习操作也改用同一代次。文件读取和状态计算仍在后台执行，页面只接收当前操作的结果；离页时继续取消等待任务。

云剪贴板页的统一操作入口也复用请求代次。加载、开关、保留期限、条目及设备操作仍遵循原来的会话和加密流程；离页或取消后不接收旧结果，错误类型对应的页面处理保持原样。

账号设置主页与发布流程里的登录区也复用页面请求代次。资料刷新、账号操作和登录状态检查统一进行离页失效与取消检查；云同步原有的独立操作代次继续处理开关和状态刷新。

云词库主页复用相同代次，并给共享工具增加可见期内失效与当前代次快照。切换词库类型会废弃旧请求后立即加载新类型；编辑器与导入页的直接刷新沿用现有代次，异步删除和下载也在写入本机状态前检查请求是否仍有效。

服务设置页的模型列表、连接测试、普通发送、豆包实时语音与本机语音也复用页面请求代次。后台或离页取消使旧结果和局部识别文本失效，录音准备完成后与润色完成后都重新核对代次再继续；豆包协议使用的 `voiceGeneration` 继续独立递增。

个人资料页的资料加载、账号操作和昵称保存也复用页面请求代次。退出、注销和昵称更新只有在当前页面请求仍有效时才触发回调或关闭页面，离页时继续取消任务。

常用语和辅助码设置页也把重复的可见性、生命周期 UUID 与待处理任务 UUID 交给共享代次工具。两页仍自行取消任务；常用语专有的读取与写入互斥继续由 `CommonPhrasesRequestState` 处理。

后续的生命周期胶水收敛见[页面请求生命周期修饰符](2026-10-17-ios-view-request-lifecycle-modifier.md)：它只封装 SwiftUI 的出现、离开失效和 pending 任务取消，不接管页面自己的业务清理。

`MSIMEKeyboardTests` 显式列出辅助码页及其 `ViewRequestGeneration` 依赖；App 的目录自动收集不能替代测试目标的源码列表。辅助码生命周期契约检查同时核对两项来源，防止共享守卫重构后测试目标漏编依赖。XcodeGen 从 `project.yml` 重新生成测试工程进行编译与模拟器验收。

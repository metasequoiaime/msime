# Agent Note: 设置材质限于活动窗口侧栏

Status: implemented

## Problem

#8869 报告整个设置窗口透明，在应用切换预览和调度中心背景变暗，失焦后仍透出背景。现有宿主只检查系统版本与减少透明度，没有检查窗口焦点；共享 CSS 还把正文和工具栏设成透明。

## Decision

正文与工具栏使用同一实色背景，只有侧栏透出原生材质。宿主在窗口取得或失去键盘焦点、应用激活状态变化时刷新材质；非活动窗口与减少透明度模式使用原有实色回退。WebView 继续归属玻璃的 `contentView`，不恢复背景兄弟视图。

## Historical audit

- [设置窗口玻璃](../../implemented/feature/2026-10-19-macos-settings-liquid-glass.md)：部分取代，其整窗透明决定由本篇收窄；系统版本、辅助功能和设置归属约束继续成立。
- [玻璃内容归属](../../implemented/bug-fix/2026-10-19-macos-glass-content-containment.md)：保留真实内容放入 `contentView` 的要求。

## Alternatives considered

- **保留整窗透明，只让系统自行降低失焦透明度。** 改动更少且保留原有材质，但无法满足正文实色的要求，当前系统也未自动提供报告期望的失焦回退。
- **在 WebView 后添加独立侧栏玻璃。** 原生区域边界更明确，但玻璃与实际内容分离，重新引入已修复的内容归属问题，并需要跨层同步响应式侧栏宽度。

## Verification

- 真实 `WKWebView` 原生测试通过，覆盖合成窗口焦点、应用激活通知、减少透明度、同一 WebView 的归属、明暗切换与页面重载。
- 共享设置页类型检查和生产构建通过。

## Consequences

应用切换器与调度中心的具体采样由系统控制，自动化原生视图测试不替代真实桌面视觉验收。

# Agent Note: Android 平板分离键盘按窗口限制键区宽度

Status: implemented

## Problem

平板分离键盘的中缝固定占窗口宽度的 25%。大屏横屏下，五列字母随着屏幕无限拉宽，键帽的宽高比例失衡，内侧键离握持边缘越来越远；同样的键高和字号因此显得挤在宽条中间。

## Decision

分离键盘保留至少 25% 的中缝，两侧原始键区合计最多占 720 dp，与完整平板键盘已有的限宽一致。窗口宽度不超过 960 dp 时保留原比例，再宽时把增加的宽度分给中缝。重复 G/V 仍从中缝借一个键宽，字母、数字、符号和底行使用同一计算。这里限制的是份额计算中的键区，不包含各键自己的外边距；重复键所在行仍比首行多一个键宽。

键行缓存记录当前窗口宽度，分离状态相同但窗口变宽或变窄时也重建；底行的布局签名包含宽度，避免字母更新后底行仍使用旧中缝。双拼宽键按实际字形宽度判断中央主标签能否与右上角标横向错开；足够宽时只为底部提示预留高度，恢复主字母的可读字号。窄键继续为角标保留顶部区域，缩小后的主标签不能与提示相交。测量宽度变化时重算，保持旋转后的结果一致。窄空格放不下完整的「双拼 · 小鹤」时优先显示「小鹤」等方案名，避免只留下无辨识度的「双拼 ·」。方案短名的完整状态保留，只缩短绘制文字。用户高度、基础字号和分离开关的默认值保持原有规则。

检索 proposed、implemented、rejected 的分离和平板记录：[数字行与分离重复键](../feature/2026-10-09-android-number-row-and-split-duplicates.md)部分重叠，本篇取代其中固定 25% 中缝的宽屏计算，保留重复键和数字行行为；[竖屏分离](../feature/2026-10-23-android-portrait-split.md)部分重叠，方向覆盖和窄外屏回退不变。[双拼键面提示](../feature/2026-10-13-android-shuangpin-compact-keyfaces.md)部分重叠：保持字形不重叠的约束，宽键不再为右上角标浪费整行高度。没有其他相同提案。

## Alternatives considered

- 只增大字号或键高：能改善视觉比例，但不能缩短两侧拇指到内侧键的距离；高度还有用户独立设置，不随屏幕宽度放大。
- 把整个分离表面限宽居中：可以复用完整键盘外框，但左右两半随之离开握持边缘，失去分离布局的目的。

## Consequences

大平板两侧保持稳定的输入范围，宽度变化主要体现在中缝。大屏的中间留白会增加，这是保留两侧握持输入的取舍。非分离键盘与手机布局继续沿用已有策略。

## Verification

纯 Java 回归覆盖 960 dp 临界点、窄窗口、宽平板、未知宽度和重复键借宽。设备验收扩展已有竖屏分离专项，在多个横屏窗口之间往返，测量字母、数字行和符号键的实际宽度，并保留原有组字、竖屏设置和外屏回退检查。

- 设备回归同时检查 28/62/72 dp 宽键、46 dp 默认键高、系统字体 1 倍和 2 倍的实际像素，宽键主字母至少为 18 sp，主字母、角标和底部提示仍互不重叠。

- 旧固定中缝 APK 在扩展后的 `KeyboardHeightDeviceSmoke -e portrait-split true` 确定失败：1600×1000 窗口的数字键超过 74 dp。旧排版在新增的 `NineKeyShuangpinDeviceSmoke -e faces_only true` 确定失败：62×46 dp、普通字体的 W 只有约 11.05 sp。
- 当前分支经 `build-apk.sh` 构建 Rust、JNI 与原生 Java 宿主，使用开发证书。API 28、35 的最终布局专项均报告 `MSIME_DEVICE_SMOKE_PASSED`，覆盖 1600×1000、2000×1600、2800×1800 后再缩回的窗口、字母/数字/符号实测宽度、底栏边界、双拼提示、既有组字与竖屏设置/外屏回退；测试退出恢复偏好与显示配置。
- API 28、35 的键面像素专项均通过 44 种尺寸/字体组合：窄键仍无重叠，宽键在默认 46 dp 键高下主标签至少 18 sp，关闭提示恢复原字号。
- API 35 起初使用旧 APK 遗留的运行时选项文件，专项复制这份旧默认值后显示共享运行时未就绪；清空专用 AVD 的合成应用数据、重新初始化后通过。这里的布局验收基于干净初始化，不将旧包升级路径记为已验收。
- quick 首轮发现上游 `crates/mcp-server/src/plugins.rs` 对新增 `PluginError::Exists`、`NotEditable` 缺少穷尽分支；独立提交补齐错误映射后，Rust workspace 编译通过。随后合入的最新 `develop` 已包含等价修复，本 PR 的最终差异不再包含 MCP。`cargo fmt -p msime-mcp-server --check` 通过；全仓 fmt 仍报告未改动的桌面 `lib.rs`、共享 `preferences.rs` 两处既有格式差异，本次不批量格式化。

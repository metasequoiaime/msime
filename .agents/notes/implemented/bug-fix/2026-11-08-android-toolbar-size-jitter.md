# Agent Note: Android 独立工具栏尺寸切换抖动

Status: implemented

## Problem

Android 触屏键盘把独立工具栏按 90%–150% 设置计算空闲行高度，组字时则显示读音行和候选行。90% 与 100% 下按钮触摸区仍有 44 dp 最小高度；原实现只在组字状态把读音行加按钮高度纳入 `idleHeight`，导致空闲与组字两种状态的总高相差 2 dp，九键全拼切换界面时键盘上沿抖动。问题由 #11108 报告。

## Decision

把独立工具栏目标高度与组字候选区高度统一取较高值。空闲行和候选行仍各自按用户设置计算，较矮的一侧继续由 `candidateHeightSpacer` 补顶部预留；不再只在读音行可见时用按钮最小高度抬高总高。这样 90% 与 100% 保持 56 dp 的稳定总高，150% 保持 84 dp，按钮最小触摸区和现有尺寸选项不变。

## Alternatives considered

只把 `idleHeader` 分支的按钮最小高度去掉，仍让 90% 的空闲总高为 50 dp；这样带常驻模式标题的空闲状态仍会与组字状态跳高，无法覆盖完整切换路径。

把按钮最小高度降到 42 dp，保持 90% 与 100% 的目标总高；这会缩小既有触摸区并违反 Android 按钮的最小点击尺寸约束。

## Consequences

独立尺寸仍控制工具栏行和按钮图标；90% 的键盘总高会按组字候选区稳定在 56 dp，100% 行为不再在两种界面间跳 2 dp，150% 的 84 dp 行为不变。新增策略冒烟覆盖 90%、100%、150% 的稳定总高。报告者的 vivo Android 11 真机和九键全拼长时间输入仍需在 PR 验收时复验。

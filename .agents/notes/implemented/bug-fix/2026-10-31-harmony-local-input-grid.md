# Agent Note: 鸿蒙手机本地输入模式网格按三列排布

Status: implemented

## Problem

鸿蒙键盘的「更多 → 本地输入」把触屏本地模式固定排成两列。默认九项模式因此占五行，最后的「拆字」单独落在左侧；打开「/ 指令」后仍会继续增加空白，手机横屏时尤其浪费键区高度，也与 Android 同一面板的紧凑网格不一致。

## Decision

触屏本地模式按条目数量选择列数：默认九项使用三列，正好排成三行；开启「/ 指令」后为十项，使用四列，仍保持三行。列数规则放在 `LocalInputMode.touchColumns`，ArkUI 页面只负责把规则映射为 `Grid.columnsTemplate`，模式顺序和进入行为保持不变。

## Alternatives considered

- 继续使用两列并让最后一项跨列或居中：可以保留较宽的卡片，但需要依赖 ArkUI `GridItem` 的跨列布局，且十项模式仍要单独处理，触控区域和不同屏宽下的行为更难保持一致。
- 所有情况固定三列：九项最紧凑，但十项会多出一格，不能保持插件开启时三行的整齐排布，因此采用按数量切换为四列。

## Consequences

九项模式在手机上不再出现孤零零的末项，十项模式也不会增加第四行；每格横向空间会比原两列略窄，但标题和触发字仍在同一格内，触屏点击动作与可访问性文本不变。纯逻辑测试锁住九项三列和十项四列的规则；ArkUI 真机布局仍需设备验收。

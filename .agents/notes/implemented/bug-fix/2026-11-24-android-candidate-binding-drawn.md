# Agent Note: 安卓候选点按、数字键和长按都作用于画出来的那个候选

Status: implemented

## Problem

候选栏的内容会异步换代：停顿重排、云/AI 候选到达、释义和译文回包、放出暂扣的尾部，都会换上一张新的候选列表，而屏幕上画的可能还是上一张（[安卓候选按住时不换代](2026-11-22-android-candidate-update-timing.md) 只让按住期间不重画，视图照样换了）。各处选词按「按钮当时的位置」或「当前视图里同一个槽位」取候选：

- 竖排候选、实体键盘的候选条、读音行拼音、硬件数字键都按槽位从 `view` 取；
- 横向候选条按按钮绑定时闭包里的候选取，但换代后 `candidateVersionIsCurrent` 为假就静默 `return`；
- 展开面板同样在换代后静默返回。

用户点的是屏幕上那个词，换代以后同一个槽位上却可能是另一个词（上屏错词），或者身份过期被静默丢掉（点了没反应）。这就是 #11816 里「点按、数字键、长按都按画出来的候选选词」那一条。

## Decision

只改安卓宿主。

- **渲染时记下每个按钮画的是哪个候选。** 竖排候选走 `updateCandidateButton`，在 `drawnCandidates` 里记下按钮与候选的对应；横向候选条每次重画都重新绑定闭包里的候选，本来就记着画出来的那一个。硬件数字键另记一份按可见顺序排列的 `drawnVisibleCandidates`，换代没重画时数字键也按这一批。
- **身份能直接用的就不查列表。** 画出来的候选与当前视图同会话、同代次时，它的 `session/generation/index` 就是引擎现在的身份，直接交给引擎，省掉一次重新取。
- **换了代次再按文字和来源找回。** 找不到就提示「候选已更新，请重新选择」，不静默丢弃，也不按槽位顶替。找回的范围是 `displayedCandidateSnapshot()`：展开面板开着时是整代，否则是候选条当前放出来的这一段（`candidate_range(0, MAX)`；`start=0` 不会放出暂扣的尾部，也不换代，所以点一下不会连带改变列表）。横向候选条本来就可能滚到页外，只查当前这一页会漏掉大部分画出来的词。
- **以下这三处一起改。** 点按（竖排和候选条）、硬件数字键、长按（候选条、竖排、展开面板和释义卡片里的词条操作）。
- 策略写成纯类 `CandidateBindingPolicy`：`sameGeneration` 判断身份能不能直接用，`find` 在一个列表里按 `CandidateScrollAnchor.key(text, source)` 找回同一个词；同一会话的限制留在 `find` 里，换会话时按文字找回也不成立。

## Alternatives considered

- **只让按住期间不换代、不动绑定。** 按住候选已经由 [安卓候选按住时不换代](2026-11-22-android-candidate-update-timing.md) 处理，但云/AI 候选在松手之后、下一次按下之前到达仍会换代，槽位选词照样错；而且上次改动明确把绑定留给这一次。
- **只在当前这一页里按文字找回。** 改动最小，但横向候选条画的是从 0 起的一段（每键取一批、滚近尾部再追加），页外那些候选在这一页里找不到，点上去会变成「候选已更新」，等于把一个能修的缺陷换成另一个。
- **换代后仍按槽位选，只在身份过期时提示。** 槽位对应的新词照样上屏，错词没有修掉。
- **在引擎里让同一个词的位置在换代后不变。** 根上更干净，但会改所有平台的排序和候选身份规则，不属于「只改安卓宿主」的范围。
- **找不到时直接丢给编辑器（让数字落到输入框里）。** 数字键在组字中不该把数字写进编辑器，提示并吞掉这一下更接近用户意图。

## Consequences

- 点按、数字键、长按在换代以后选的是画出来的那个词；它已经不在列表里时提示一次，不再静默丢弃。
- 换代以后点候选会多一次 `candidate_range` 取列表（展开面板时是整代查询），只在身份过期的那一下发生；同代点按不受影响。
- 展开面板开着期间的晚到结果仍会换上新的那一代（按 #11816 的清单，那是「等收起再换上，并提示有新的云/AI 候选」另一条），这次只保证点的是画出来的词。
- 旧的行为用例跟着改：`StaleCandidateDeviceSmoke` 的过期点击换成当前一代一定没有的文字，继续覆盖「找不到就只提示、不上屏」；`CandidatePanelRefreshDeviceChecks` 断言过期按钮上屏的仍是刷新前那个词，而不是同一个座位上的新词。
- 验证：`CandidateBindingPolicySmoke`（同代直接用、换代后按文字和来源找回、来源不同、换会话、空列表和空项占位）；`CandidateExpansionDeviceSmoke` 按新签名点按；安卓设备冒烟本轮未在本机跑，见 PR 的验证段。

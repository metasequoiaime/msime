# Agent Note: 移动端账户退出后按代次清理快照预览

Status: implemented

## Problem

Android 与 iOS 在账户命令成功时才清理云词库快照预览。`BackendAccountSession::logout` 会先清除本地会话，再请求服务器；服务器请求失败时，命令返回错误，但旧预览及其文件仍留在内存和磁盘。若直接在命令返回后清空全部预览，又可能删除这段时间内新账户发布的预览。

## Decision

预览记录包含发布时的账户代次。账户命令返回后，在会话锁内读取当前用户 ID 与代次，同时筛出不属于当前身份的预览；释放锁后删除这些预览文件。清理与账户命令的远端返回结果无关，因此本地会话已失效时，即使远端退出失败也会清理旧预览；删除账户失败且本地会话仍有效时会保留预览。

## Alternatives considered

- 仅在命令成功时清理：会漏掉先本地退出、后远端失败的路径。
- 无条件清空预览表：可能误删命令执行期间新会话发布的预览。
- 先读取当前账户再锁预览表：检查与清理之间仍有账户切换窗口。

## Consequences

清理操作与预览发布按同一会话锁排序。预览文件在锁外删除，避免文件 I/O 延长账户锁持有时间。

## Verification

共享测试覆盖退出后旧预览被取走，以及当前用户与代次匹配的预览得到保留；账户测试覆盖同一用户重新登录后代次变化。跨目标编译与本地 quick 门禁见对应 Pull Request。

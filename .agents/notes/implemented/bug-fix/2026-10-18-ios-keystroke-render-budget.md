# Agent Note: iOS 连续输入按键路径的主线程预算

Status: implemented

## Problem

iOS 键盘连续输入时，普通字母键也会重复重写整套字母键配置、重复刷新九键拼音条，并在候选栏已经位于起点时再次设置滚动位置。这些操作都在主线程的按键回调中执行，UIKit 的布局和配置更新会积累成卡顿和漏帧。短词的全拼桥接耗时不能代表九键长句；引擎、控件与真实文档代理必须分别测量，不能预先排除其中一层。

## Decision

按键路径只在对应状态真正变化时更新 UI：

- 缓存字母键面的输入状态，候选内容变化不再重写 26 个键；
- 缓存九键/十四键拼音条的词列表和摆放位置，连续输入没有拼音条变化时不再逐个写按钮配置；列表部分变化时也复用同位置的相同拼写，隐藏过的格子先恢复显示再判断配置是否可复用；
- 候选和拼音条的滚动位置只有不在起点时才归零；
- 拼音侧栏的出现与消失单独切换拼音、标点和数字侧栏可见性，不使整套网格及底行布局缓存失效；
- 按键自行维护阴影路径，仅在尺寸或圆角改变时重建，控制器不再逐次递归整棵视图树补写阴影；
- 计算 iPad 分离键盘前先判断设备、方向和开关，手机与竖屏不读取本地模式状态。

缓存键只覆盖绘制所依赖的状态；方案、语言模式、大小写、辅助码提示、滑动符号开关、本地模式和拼音条内容发生变化时仍会完整刷新。

## Alternatives considered

- **只调低延迟测试阈值或关闭候选释义**：不能减少真实设备上的 UIKit 主线程工作，也会掩盖用户仍能看到的卡顿，因此不采用。
- **把整个候选栏渲染移到后台线程**：UIKit 视图和配置必须在主线程更新，后台绘制还会引入代次和竞态；本次先减少可安全跳过的重复主线程更新。

## Consequences

连续输入复用不变的键面和拼音条配置，减少布局请求与候选滚动视图的无效更新；方案切换、大小写变化和候选内容变化仍按原路径重绘。延迟测试继续覆盖全拼、九键和高候选量输入，模拟器安装验证仍只能代表模拟器运行层级，不能替代真机输入法验收。

## Verification boundary

`KeystrokeLatencyTests` 的九键长句基准使用六组固定合成拼音，覆盖 5–31 键的组字，并在同一设备上分别测量独立状态目录的桥接调用与控制器按键回调加布局。每轮之间消耗剩余组字；桥接不启用学习、使用隐私会话，计时使用单调时钟。测试宿主的文档代理没有连接真实编辑器，因此该结果不包含跨进程文本同步，也不代表触摸到画面显示的端到端延迟。

系统键盘 UI 用例另行验证组字、候选选择与汉字上屏。XCTest 的普通点按会等待界面空闲，不能将该功能测试通过解释为快速连按达标。使用临时探针测量真实扩展时，测试只输入固定合成拼音、仅收集耗时，最终产品移除探针。

## Real-device follow-up

真实扩展279键合成连按中，阴影缓存单独对照组的布局均值4.59 ms、P95 16.12 ms，整键均值27.05 ms、P95 41.61 ms。阴影缓存不足以解决卡顿。逐键高布局耗时集中在组字开始，侧栏拼写有无是整套布局缓存的输入，导致每句首尾重新切换所有行约束及菜单。侧栏可见性不影响网格、底行或键面，移出完整布局依赖，只在侧栏路径同步。回归检查连续三次输入/删除时拼音条正确出现/消失、数字键几何不变，标点菜单不被重新构造。修复后3项侧栏/布局回归通过，但相邻真机对照整键均值27.05→27.09 ms、P95 41.61→40.99 ms，布局均值4.59→4.69 ms；只能证明消除完整布局重写，不能证明总体卡顿已解决。

九键侧栏内部排列方式的后续取舍与真机对照见[拼音侧栏隔离排列约束](2026-10-19-ios-spelling-sidebar-layout.md)。

## Synchronous baseline latency

固定线程异步查询的决定、性能取舍与后续真机对照见[会话拥有线程](2026-10-19-ios-nine-key-owned-thread.md)。下列数据保留同步阶段的基线，不代表异步后的现状。

真实扩展按键事件加同步布局的279键合成脚本共做多轮对照，每个数字间隔至少40 ms，不是触摸到画面的端到端测量。相邻多轮整键P95约40–42 ms；词典查询均值约12.6 ms，其中词网格均值约6.1 ms，仍在主线程同步执行。局部缓存与阴影改动未让整键达到16 ms。独立测试宿主的低耗时不能用于排除真实扩展引擎开销。

词块布局保留试验的两轮整键P95为40.40/40.28 ms，布局P95为15.55/15.33 ms，没有稳定的总体改善，已撤回。词典的完整音节条件已经由 `query_series` 在调用 `merge_sentences` 前核对；重复加一层守卫不影响真实按键，已撤回。[静态参考行](../../rejected/bug-fix/2026-10-19-lattice-personal-reference-rows.md)、[个人模型散列](../../rejected/bug-fix/2026-10-19-personal-count-prehashed-key.md)与[冷页投影](../../rejected/bug-fix/2026-10-19-nine-key-cold-ranked-projection.md)试验分别保留否决记录，临时诊断条件和Rust数值探针从正常构建删除。


## Current validation

正常模拟器构建的31项相关回归通过，包含候选字号、十四键、九键/数字页切换、工具栏与候选切换、阴影尺寸、拼音侧栏缓存以及长句基准。本地 `verify-local.sh --quick` 退出0。模拟器基准在主机构建并发时运行，只检查功能与记录耗时，不与真机数值比较，也不据此收紧或放宽性能门槛。

正常Release真机包已去掉全部临时探针后重新编译、签名和安装。在真实系统键盘和原生试用编辑器中，`testNineKeyRepeatedChineseInputOnDevice` 三轮共12组输入通过，交替使用空格和首选候选提交，断言无剩余组字且整段仅含汉字。该用例依赖XCTest等待空闲，只证明功能链路和上屏正确，不把通过解释为快速输入延迟达标。

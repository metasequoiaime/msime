# Agent Note: 鸿蒙手机和平板隐藏快捷模式入口

Status: implemented

## Problem

鸿蒙手机和平板的共享设置页和触屏键盘仍显示快捷模式入口。V、T 等实体键盘快捷模式不适合手机触屏，功能面板里的「本地输入」及其下一级模式列表也会让触屏界面出现不应提供的入口。

## Decision

仅按鸿蒙设备形态隐藏界面入口：共享设置页在 `mobile_settings` 为真时不渲染「快捷模式」组，功能面板在手机和平板上不列「本地输入」磁贴；2in1 继续保留设置和实体键盘相关能力。共享偏好字段、模式定义和引擎路由不删除，避免清理已有配置并保持 2in1 行为。

## Alternatives considered

- 删除或清空 `local_modes` 偏好：会破坏已有配置，也会把实体键盘能力和 UI 隐藏混在一起，因此不采用。
- 仅把磁贴置灰：用户仍会看到不适用的入口，不能满足手机和平板不出现快捷模式 UI 的要求。

## Consequences

鸿蒙手机和平板的输入设置不再出现「快捷模式」，功能面板也不再出现「本地输入」及其子面板；2in1 的快捷模式设置和实体键盘能力保持不变。未安装前端依赖，Vitest 与 Harmony 类型检查无法在本机启动；已完成差异检查和 Harmony 测试脚本的静态门禁检查。

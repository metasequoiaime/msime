# Agent Note: Android 十八键去除侧栏并铺平第二排

Status: implemented

## Problem

Android 十八键沿用了十四键的左侧符号栏和第二排半键缩进。真机上这会在字母区左侧形成一条连续的高底轨，`A` 与 `L` 同时向内缩，三排字母看起来像拼在两个不同网格里。十八键本身已有第三排「符」键，不需要再占一列放空闲符号。

## Decision

十八键字母层不再创建左侧符号栏，三排从同一左右边界铺开；第二排的六个键按整行宽度分配，因此 `A` 与首排 `Q` 左对齐，`L` 与首排 `P` 右对齐。十八键的拼音选择挂到候选行，十四键继续保留左侧拼音栏和原有几何。设置页与皮肤预览按同一规则画十八键，避免预览和真机分叉。

这项决定部分取代[Android 十八键全拼入口](../feature/2026-10-24-android-eighteen-key-quanpin.md)和[Android 十八键双拼](../feature/2026-10-24-android-eighteen-key-shuangpin.md)中“复用十四键侧栏、第二排居中”的布局描述；组码、候选、长按和底行行为不变。

## Alternatives considered

- 保留侧栏，只把底轨收进三行范围：能修正上下边界，但侧栏仍让十八键多出一列，无法解决截图中的整体拥挤和 `A/L` 缩进。
- 保留侧栏并把第二排铺满：可以让 `A/L` 对齐，但左侧连续底轨和三排不属于同一网格的问题仍在。
- 只在空闲时隐藏侧栏：组字前后键位会横向移动，拼音选择出现时还会改变触摸区域；因此十八键始终不创建侧栏，拼音选择固定放候选行。

## Consequences

十八键字母区的三排边界一致，第二排键宽会因只有六个键而比首排宽，触摸区域随可用宽度完整铺开。符号入口统一由第三排的「符」键提供；十八键不再显示左侧 `，/。/?`。十四键和九键的侧栏行为不变。设备几何断言改为检查第二排左右边界与首排对齐，不再要求三排字母键等宽或第二排居中。

## Verification

- 真机截图必须同时包含完整十八键三排、底行和工具栏，确认没有左侧符号栏且 `A/L` 与首排边界对齐。

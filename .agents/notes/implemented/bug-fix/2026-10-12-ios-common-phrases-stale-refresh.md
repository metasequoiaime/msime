# Agent Note: iOS 常用语页丢弃过期刷新结果

Status: implemented

## Problem

常用语页在出现和回到前台时都可能启动读取任务。读取期间用户添加或删除常用语，较早任务返回后会把旧列表写回界面；连续刷新逆序返回时，较早结果也会覆盖较新的列表。

## Decision

共享 UI 增加请求状态，以递增代次标记读取。每次新读取、开始写入和写入完成都会推进代次；写入期间跳过新的读取。异步读取完成后只有仍属于当前代次的结果才能更新列表或失败状态，成功写入继续直接采用存储返回的列表。

## Alternatives considered

- 只用 `busy` 阻止写入期间刷新：不能处理连续读取逆序返回。
- 每次返回都重新读取：会增加磁盘访问，且仍无法保证旧任务不再覆盖当前列表。

## Consequences

生命周期触发的并发读取不会覆盖更新后的常用语列表；写入期间界面保持忙碌，写入成功返回的快照仍即时显示。旧读取任务仍会完成底层磁盘读取，但其结果会被丢弃。

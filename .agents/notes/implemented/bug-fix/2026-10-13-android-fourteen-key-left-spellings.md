# Agent Note: Android 14 键拼音与九键共用左侧栏

Status: implemented

## Problem

读音行里的横向拼音条难以点按。此前将它改成候选下方的独立换行区，但用户明确要求沿用九键左侧的交互；独立区域还增加了组字时的键盘高度。

## Decision

14 键的三行字母键左侧增加与九键相同宽度比例的侧栏，直接复用九键的符号栏、纵向拼音列表、按钮尺寸与带代次选择回调。空闲时显示符号，有拼音可选时覆盖符号栏。候选词和完整读音保持可见，字母键行高与原来的底行保持一致，不再增加独立拼音行。

14 键的 123 层仍是 26 键数字设计层，左侧拼音栏只随字母键面显示。展开候选继续由已有三栏面板选择拼音。

历史检索：[全拼 14 键](../../implemented/feature/2026-10-10-fourteen-key.md) 持有初版的读音行位置决定；[独立换行拼音区](../../implemented/bug-fix/2026-10-13-android-fourteen-key-spelling-grid.md) 是刚完成的替代方案。本笔记取代两者在 Android 上的拼音位置决定并互链；其他平台暂不改变。

## Alternatives considered

- 保留独立换行区：选项更宽且可同时展示多列，但增加键盘高度，也不符合用户明确选择的九键交互。
- 只在组字时临时插入左栏：空闲键面可以更宽，但第一次输入会横向移动所有字母键。侧栏固定占位，空闲显示符号，可保持键位稳定。

## Consequences

拼音、符号和纵向滚动与九键一致，读音与候选仍独立显示，组字不增加额外拼音行。代价是三行字母键约 15.6% 宽度让给侧栏；小屏字母键变窄，行高与底行维持原样。

原生 APK 构建、Android 宿主检查、本地 quick、笔记检查，以及专用 API 35 AVD 的核心打字、14 键、九键面板均通过。键盘高度套件在前序交互测试后两次未能在重启输入法时弹出键盘；重新安装后单独运行，旧版与侧栏版均通过整套高度验证，包括 14 键与 26 键等高检查。14 键用例另检查组字前后键位与键区高度稳定、侧栏符号恢复、36dp 拼音行和窄屏纵向选择。测试偏好仅写入专用 AVD，窄屏验证后恢复显示尺寸。

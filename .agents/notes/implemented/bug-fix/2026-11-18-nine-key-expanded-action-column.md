# Agent Note: 九键展开候选面板功能键改为单列

Status: implemented

## Problem

九键、14 键全拼在展开候选面板时，右侧功能区把六个按钮排成两排三列。右栏只占面板的一小部分，每个按钮的宽度不足以显示「返回」「重输」「拼音」「全部」「单字」等完整键面，窄屏和大字号时会截断键面文字。

## Decision

右侧功能区保持现有三栏面板的宽度分配，把六个功能按钮按一个按钮一行竖直排列：返回、删除、重输、拼音/笔画、全部、单字。按钮继续使用各自现有的点击动作、无障碍描述和选中状态；只改变容器层级和每个按钮获得的宽度，不改变筛选或编辑行为。

## Alternatives considered

- **保留两排三列并缩小字号**：能维持面板高度，但窄屏上仍依赖每个按钮的最小宽度，且会让功能键难以阅读；没有解决报告中的截断根因。
- **扩大右栏并保留两排三列**：可缓解一部分截断，却继续把六个语义不同的入口压在同一行，字号放大时仍会回归；也会挤压中间候选区。

## Consequences

单列让每个功能键获得完整右栏宽度，键面文字不再被三列布局切掉，选中状态仍能直接看见。六个按钮均分右栏高度，单个按钮高度会比原来的两排更小；这保留了候选区和左栏的可用空间，若未来需要改变面板高度，应另行评估而不是恢复三列压缩布局。测试覆盖布局构建所依赖的功能键顺序和数量；本次未进行 Android 真机或真实编辑器验收。

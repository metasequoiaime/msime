# Agent Note: macOS 系统翻译语言刷新按请求顺序生效

Status: implemented

## Problem

macOS 设置页在打开和窗口重新聚焦时都会读取尚未下载的系统翻译语言。两次读取共用客户端生命周期代次，焦点刷新本身不推进代次。较早读取若在较新的读取之后完成，会把已经更新的语言列表覆盖为旧结果；较早读取失败时也会把列表清空。

## Decision

为系统翻译语言读取单独使用异步请求代次。每次打开或聚焦刷新都推进代次，只接受最后一次读取的成功或失败结果。该代次继续随客户端切换和组件卸载失效，不影响双拼键位提示的读取。

## Alternatives considered

- 继续使用共享客户端代次并在每次聚焦时递增：会使同页尚未完成的双拼键位提示读取失效。
- 只阻止并发读取：窗口重新聚焦时新状态可能要等旧读取完成才能出现。

## Consequences

系统翻译语言提示以最新焦点刷新结果为准，较早请求仍会完成，但不再改写界面。

## Verification

新增逆序完成的界面回归测试，先确认旧实现把较新的 `ja` 覆盖为 `en`，再确认修复后维持 `ja`。相关翻译设置测试、TypeScript 类型检查和仓库 quick 门禁见 PR 验证记录。

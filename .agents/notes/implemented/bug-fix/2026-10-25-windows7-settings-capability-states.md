# Agent Note: Windows 7 设置页能力状态表达

Status: implemented

## Problem

Win7 实机验收发现，设置页在能力缺失或由其他资源接管时仍只显示灰色控件或空下拉框。没有麦克风时语音录音设置看起来仍可用，插件特效包接管样式后用户看不出灰色控件原因，键盘皮肤库为空时下拉框没有状态，切换到非中文输入语言时中文方案残留旧选择，关于页更新按钮和统计页云端上传的不可用状态也缺少明确说明。

## Decision

Win7 原生设置页在控件旁明确表达能力状态：麦克风列表未读取或为空时显示原因，只禁用启动录音和设备选择，快捷键、提示音及服务参数仍可预先配置，连接设备并刷新后恢复；插件页在特效包、背景音乐目录或打字统计不可用时把原因写入已选插件说明；键盘皮肤库为空时显示可执行的创建提示；非中文输入语言清空中文方案的视觉选择并显示适用范围；更新和云端统计在尚未具备可用来源时说明下一步或兼容版限制。偏好值仍由共享存储保留，不因页面状态变化而重置。

## Alternatives considered

- **只调整灰色控件颜色或改成普通提示。** 这不能说明哪项能力缺失，也不能告诉用户恢复条件，因此保留禁用状态并补充原因。
- **删除所有相关设置。** 麦克风、插件目录和云端服务可能在用户补齐环境后恢复，删除会丢失本机配置和已支持能力，所以只收窄当前不可达的交互。

## Verification

已用 MinGW 对语音、插件、键盘皮肤和关于页 Win7 UI 测试源做语法检查；新增的状态逻辑需在 Windows 构建及 Win7 SP1 实机上复验，确认无设备、空皮肤库、非中文方案和不可用更新/上传来源时的文案与禁用状态。

## Consequences

Win7 页面不再把环境限制伪装成半成品控件，用户能知道何时刷新或连接设备；已有服务配置、皮肤设计和云端状态不会被清空。页面增加少量说明文字并占用滚动高度，现代 Windows 设置页和共享模型不受影响。

# Agent Note: 删除词书时原子更新背词进度和选择

Status: implemented

## Problem

删除用户词书后，背词会话先单独清除这本书的复习记录，再用删除前读取的快照判断并写回词书选择。两次进度写入之间存在已删除词书仍被选中的状态；另一宿主在此期间改选词书，也可能被旧快照覆盖。

## Decision

进度存储增加 `remove_wordbook_progress`：在同一把进程间文件锁内读取当前文档，删除目标词书的卡片记录，仅在当前选择仍是目标词书时清空选择，然后原子发布一次。会话保留删除前的进度可读性检查，以免损坏的进度文档导致词书先被删而操作仍返回错误。

## Alternatives considered

- 删除记录后再单独写设置：两次发布之间的中间状态和旧快照覆盖风险仍存在。
- 始终清空当前选择：另一宿主已选择其他词书时会错误清除它。

## Consequences

目标词书的记录和选择在同一次进度写入中更新；当另一宿主已经换书时，新选择保持不变。词书文件与进度文档仍分属两个存储，文件删除和进度更新之间的崩溃窗口不由此改变。

## Verification

新增测试先因缺少 `remove_wordbook_progress` 编译失败，随后通过。其他门禁见 PR 验证记录。

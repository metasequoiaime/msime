# Agent Note: Android 统计页按设备认证配置放行

Status: implemented

## Problem

[原统计页认证决定](../feature/2026-10-25-android-statistics-auth.md)将没有锁屏凭据的设备也挡在统计页外，只提示没有可用系统认证。聚合计数和按键分布因此无法查看，维护者要求「有认证就用认证，没有就不认证」。

## Decision

统计页通过 `KeyguardManager.isDeviceSecure()` 判断设备是否设置 PIN、图案或密码。未设置时直接读取统计，不弹认证不可用提示；已设置时沿用系统认证，成功后才读取，取消、失败或临时不可用均不放行。每次回到页面重新检查配置，授权不持久化。系统服务读取失败仍提示重试，不能把查询失败当成未配置。

`StatisticsAuthenticationPolicy` 同时接收本次授权状态和设备锁屏配置，保留原来的成功回调、离开后重新认证、跨越暂停的回调规则。其他功能的认证策略不变。

检索结果：原统计认证笔记被本篇部分取代，已互链；剪贴板操作认证笔记只共享认证方式和暂停跟踪器，不涉及本次统计页的无凭据放行。

## Alternatives considered

- 完全移除统计页认证：最直接、没有系统能力分支，但不能满足维护者澄清后的「有认证就用认证」，因此不采用。
- `canAuthenticate()` 任何失败都直接放行：分支更少，但会把已配置设备的临时硬件故障或认证不可用也当成未配置，因此仅在系统明确未设置锁屏凭据时免认证。

## Consequences

未配置凭据的手机可以查看统计；已配置时仍需认证。新增系统锁屏配置查询，读取失败不绕过验证。纯 Java 策略检查覆盖无凭据、已配置未授权和已授权状态；真实设备验收结果随验证记录补充。统计记录、上传设置、数据格式和默认值均不改变。

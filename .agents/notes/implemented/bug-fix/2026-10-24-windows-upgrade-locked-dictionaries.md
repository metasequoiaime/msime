# Agent Note: 升级时保留内容相同的已占用词库

Status: implemented

## Problem

Win7 完整产品升级在 `msime-others.db` 替换时以错误 32 回滚。关闭本任务设置预览仍能复现；Restart Manager 只读查询确认占用者是加载着 TIP 的记事本，而 Server 与看门狗均已停止。词库连接属于应用内的引擎会话，只停止独立 Server 不能释放它。现有安装器对所有资源使用 `ignoreversion`，即使内容相同也会删除重写；默认占用检查只覆盖 EXE、DLL 与 CHM，漏掉词库。

## Decision

资源文件仍由既有锁与暂存校验决定。Inno 预处理器逐项生成资源安装条目，将打包时的 SHA-256 固定到条目的检查参数中；运行时只有已安装文件摘要相同时才跳过替换。文件不存在、内容不同或读取失败都继续正常安装，不能将时间戳或文件存在当作内容证明。检查结果不缓存，因为准备阶段可能已经清掉了未占用的旧资源。

Server 的其余文件继续递归安装，并排除由上述条目处理的 `resources`，避免通配条目再次覆盖。占用检查过滤器补入 DB、BIN 与 DAT；资源变化时由正常 Restart Manager 流程处理宿主应用，保留关闭提示，不使用强制结束进程。静默安装的调用者仍应先保存文档并遵循 Inno 的关闭应用选项。

本修复不改变资源路径、用户默认值、数据目录或 TSF／Server 边界。它同时适用于现代与 Win7 安装包。

## Verification

合成安装器直接提取产品的 `ResourceNeedsReplacement` 函数，实际编译、运行 Inno：以只读共享方式持有相同文件时升级通过，内容不同与缺失文件正确安装；不同内容被锁定时安装失败且原内容保持，不能静默跳过真实更新。Windows 构建机与 Win7 实际运行均通过。跨平台 ISPP 子集解释器同时支持资源条目的子程序、循环、文件枚举与摘要计算，用两个真实合成文件及空目录展开各版本的现代、Win7 和轻量包，逐项核对生成条目与摘要；不能略过不认识的指令使检查假绿。完整产品升级的结果写入[完整产品构建](../feature/2026-10-24-windows7-product-build.md)。

## Alternatives considered

- **每次安装使用独立的资源代次目录。** 旧会话可继续读取完整旧词库，资源变化时也无需关宿主，是更完整的在线切换方案；但它同时需要更改资源定位、现存 `runtime-options.json`、相邻可选资源与旧代次回收契约。当前同内容覆盖缺陷可以通过摘要判断修复，因此本次不迁移这些路径。
- **关闭所有加载输入法的应用。** 可以释放连接，但不应为了安装完全相同的资源而要求用户关闭文档，更不能按映像名强杀。仅对确实要更新的资源保留正常关闭流程。

## Consequences

内容相同的词库不再阻止升级，已有宿主文档可以继续打开。检查需要读取已有资源计算摘要，增加安装准备阶段的磁盘读取。真实资源变化且仍被应用占用时，依然需要正常关闭相关应用；本修复没有承诺所有词库更新均能在原会话中热切换。

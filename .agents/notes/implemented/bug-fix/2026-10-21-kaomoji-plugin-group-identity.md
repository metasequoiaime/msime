# Agent Note: 颜文字插件组保留自己的全部项目

Status: implemented

## Problem

`docs/plugins.md` 和 `symbol_set` 清单契约承诺安装后追加插件组，不与内置目录或其他包去重。宿主返回完整分组及 `pack`，共享颜文字页却用全局 `seenDisplayItems` 删除后续组的同文项目；插件完全重叠时整个组消失，搜索关键词相同的两个包也只能看到先出现的组。macOS 原生 `kaomojiSections` 已按组独立展示。

## Decision

通用详情页对带 `pack` 的插件组保留原项目，不参与其他组的去重集合。首页是合并预览，继续按文本去重；无 `pack` 的内置组保持现有首次出现规则。总页数和切片继续共用经过展示策略处理的组，按各组 48 项取最大页数。

## Existing notes audit

- [面板状态归属](../../implemented/simplification/2026-10-19-emoji-panel-state.md)部分重叠：保留状态归属、显示集合与页数一致的规则，本篇取代插件也跨组去重的范围。旧笔记与本篇互链，保留原理由。之前的跨包分页回归错误地断言插件项目被去重，随本修复改为验证每组完整及末页非空。
- [桌面符号目录](../../implemented/feature/2026-10-14-desktop-symbol-directory.md)保留符号专用侧栏及网格规则，本片只涉及通用颜文字展示，无需变更该决定。
- 插件脚本权限、拼音符号候选、移动宿主表情等命中均无关；没有可吸收或过时的活跃提案。

## Alternatives considered

- 继续所有组共享文本去重集合：避免重复按钮，但违背插件目录的独立组契约，能把安装后的插件全部隐藏；仅修总页数不能恢复这些分组。
- 详情页全部取消去重：实现更简单，插件可完整显示；但会扩大到内置目录及其既有去重行为。本片只在已有 `pack` 边界保留插件组，首页继续提供紧凑预览。

## Verification

- 组件回归覆盖与内置完全重叠的插件组、同包不同组、不同包的同文项目，检查完整标题和按钮。
- 同一组件回归验证按组关键词搜索仍保留所有命中插件组，首页合并预览不重复。
- 两个 hook 回归覆盖 48 项共同项目加 12 / 60 项新增项目，检查每个插件组独立完整、各页非空、末页停止并可返回。旧实现三项回归均失败：插件标题消失，长组末尾少一页。

相关表情与桌面面板测试共 10 个文件、93 项通过；桌面生产构建、HarmonyOS 类型检查、改动文件 lint / 格式及笔记校验通过。

## Consequences

插件详情可能出现相同文本的多个按钮，这是目录分组契约要求；只使用清单已有的包标识，不新增格式、宿主接口或依赖。此处共享前端验证不代表原生宿主装机验收。

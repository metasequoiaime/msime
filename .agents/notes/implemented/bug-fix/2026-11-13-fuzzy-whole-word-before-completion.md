# Agent Note: 全拼模糊整词先于更长补全词

Status: implemented

## Problem

#11048：开启 c/ch 模糊音后，输入 `chiku` 的「词库」排在「吃苦耐劳、吃苦在先、吃苦头」之后。当前锁定词库可复现。模糊行最后合入，覆盖长度排序稳定保留了补全词在前的位置。

## Decision

只在覆盖全部输入的组内、已有更长补全词时，把该组模糊整词稳定移到第一条补全词之前。补全词以词库来源、非模糊、完整拼音在匹配读音后多出音节识别；模糊整词用键入覆盖与完整读音的音节数识别，不能比较字母数，因为 `chi` 和 `ci` 长度不同。第一条补全词之前的精确首选与整句块保留，其他非模糊行相互顺序保持。部分输入的模糊前缀不提升，不同覆盖长度不跨组，不删除候选或改变学习拼音。

## Alternatives considered

- 把所有同长度词条都排到补全之前：规则简单，但会撤销「苹果电脑」先于冷僻同音词的既有取舍，见[精确首位](2026-10-12-exact-reading-keeps-first-seat-over-longer-phrase.md)，因此仅提升本次遗漏的模糊整词。
- 将模糊与精确词按原始权重混排：可能让高频模糊词抢走精确首选，而且词频不能直接与整句分数比较，因此保留精确首选和已有整句让位规则。

## Verification

合成词库覆盖精确首选、双向 c/ch、多个模糊整词、前缀不提升、无补全时顺序不变、冷热缓存一致，断言保留模糊标记与学习用完整读音。两个词库回归用例在修复前均失败。全拼模块 237 项通过，5 项性能测试按原配置跳过，原有精确补全、替补整句与字段共享测试不改前提通过；金样套件 31 项通过；引擎库与测试 Clippy（`-D warnings`）通过。

用锁定词库与合成会话重放，`chiku` 的「词库」由第 5 位升到第 2 位，`ciku` 的「吃苦」同样由第 5 位升到第 2 位；关闭模糊音的 `chiku` 与 `pingguo`、`qishi`、`dacuozi`、`zongguo` 对照列表逐行不变。原生 macOS 候选栏渲染器读取这两组实际引擎结果生成前后图，只使用合成输入、隔离偏好，不把离屏渲染声称为真实编辑器装机验收。

## Consequences

开启模糊音且命中整词时，补全词后移，第一条补全后的低频精确行也可能被模糊词挤后；这是为用户选择的模糊规则腾出整词位置。不开模糊音或没有更长补全词时顺序不变。

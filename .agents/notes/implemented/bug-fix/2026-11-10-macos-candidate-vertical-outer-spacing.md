# Agent Note: macOS 候选项固定垂直外间距

Status: implemented

## Problem

Issue #11073 反馈 macOS 候选窗口的候选项垂直外间距无法按需要保持固定。现有 `itemSpacing` 会同时受皮肤和用户候选项间距偏好影响，不能表达 macOS 竖排候选项之间的固定距离；候选项垂直内边距只改变文字与高亮背景的内部留白。

## Decision

macOS 竖排候选项之间固定保留 6pt 外间距，并随候选窗口整体缩放比例一起缩放。真实候选窗的竖排布局、旧 IMK 面板、展开候选网格的行间距和设置页预览采用同一固定值。横排候选项之间仍沿用皮肤或现有用户偏好中的 `itemSpacing`。

固定间距不新增用户设置，也不覆盖皮肤的窗口内边距或候选项内边距。竖排模式下忽略 `itemSpacing` 对行间距的覆盖，保证所有皮肤的垂直候选列表有一致的间隔。

## Alternatives considered

- **把 `CandidateVerticalInset` 的最小值改成 6pt**：这会改变窗口上下内边距，语义不是候选项之间的外间距，并会覆盖用户明确设置的 0–5pt 值，因此没有采用。
- **继续让竖排间距跟随 `itemSpacing`**：无法满足 issue 要求的固定间距，且不同皮肤会出现不同的竖排候选列表节奏，因此没有采用。
- **新增可调的候选项垂直外间距设置**：需要扩展共享偏好、多个桌面宿主和设置界面，超出本 issue 已确认的固定间距范围，因此没有采用。

## Consequences

竖排候选项和展开网格的相邻行始终相隔 6pt（按整体缩放比例计算），横排布局和窗口边缘留白保持原有行为。设置页预览与真实 macOS 候选窗保持一致。

## Verification

`CandidateSkinTest` 检查固定间距在 50%、100% 和 200% 缩放下分别为 3、6、12pt。`CandidateRowLayoutTest` 通过真实宿主布局断言竖排行间距为缩放后的 6pt、横排仍使用现有 5pt 偏好。由于本机磁盘剩余不足 50GB，未启动新的 macOS CMake 构建；提交前需在 macOS CI 完成编译和测试。

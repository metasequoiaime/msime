# Agent Note: 鸿蒙电脑跟踪候选贴图资源更新

Status: implemented

## Problem

选中的皮肤包和偏好版本不变时，鸿蒙电脑只检查普通候选背景图和装饰图的文件身份。canvas 面板或自由挂件原地更新、删除或恢复时，键盘下一次获得焦点仍可能沿用旧快照。

## Decision

候选贴图加载与文件身份检查共用当前明暗模式所需的面板、挂件路径，去重并保留暂时缺失的路径。读取图片前记录文件身份；若读取期间资源发生变化，下次焦点检查仍能发现变化并重新应用外观。触屏模式保持现有文件检查范围。

## Alternatives considered

- **每次获得焦点直接重新读取整个包**：可以看到变更，但没有变化时也反复读取与解码图片。
- **只看包目录和清单的身份**：安装器整包替换能被发现，原地更新单张图片时这两者可能都不变。

## Consequences

合成测试执行实际会话资源加载和重新检查方法，覆盖浅深色、更新、缺失恢复、加载时变化和更换主题；未进行 ArkUI 设备视觉验收。文件身份由 inode、修改时间和大小组成，三者均不变的内容改写不能由此发现。相关的同名替换思路见 [macOS 候选包刷新](2026-10-20-macos-replaced-skin-package-refresh.md)。

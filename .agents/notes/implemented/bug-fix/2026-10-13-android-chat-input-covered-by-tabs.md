# Agent Note: Android 对话输入框在键盘弹出时让开底部导航

Status: implemented

## Problem

应用的全屏布局下，`HomeActivity` 的底部导航和 `home_content` 是重叠的兄弟视图。在 Android 12 真机上，对话 tab 弹出输入法后，输入框仍然存在，但底部导航盖在它上面，用户看不到“打字试试”输入框，只能看到键盘。

## Decision

本篇隐藏导航的决定已由[键盘弹出时保留 Tab](2026-10-13-android-chat-keyboard-keep-tabs.md)取代；以下保留原方案的理由和验证记录。

当前可见的对话页收到输入法可见的 `WindowInsets` 时，通知 `HomeActivity` 隐藏底部导航，并把对话页的底部避让从标签栏高度切换为输入法 inset；输入法收起后恢复底部导航和标签栏避让。切换离开对话 tab 时也立即恢复导航，隐藏的对话页不更新导航状态；只有当前选中对话且没有详情页时才隐藏导航，避免键盘收起动画期间把其他页面的导航一起隐藏。

## Alternatives considered

- **只给 `home_content` 增加固定的底部标签栏内边距**：它能避开覆盖，但会让对话页在键盘收起时重复计算标签栏高度，还要同步修改所有详情页的全屏布局；现有页面已经各自通过 inset 计算底部避让，改动面更大。
- **把底部导航移动到 `home_content` 内部**：它能从布局结构上消除兄弟视图重叠，但会改变所有 tab、详情页和返回栈的层级关系，超出这个缺陷的范围。

## Consequences

键盘显示时对话输入框紧贴键盘上方，底部导航不再遮挡它；键盘收起后四个 tab 恢复显示。代价是用户打字期间暂时看不到底部 tab，需要先收起键盘再切换页面，这与输入框和系统输入法的可用空间保持一致。

## Verification

- `platforms/android/check-host.sh` 通过。
- Pixel 3 XL（Android 12）安装修复后的 `0.4.0` APK：键盘显示时输入框位于键盘上方、底部导航隐藏；按返回收起键盘后，输入框仍可见且底部导航恢复。没有发送对话内容。

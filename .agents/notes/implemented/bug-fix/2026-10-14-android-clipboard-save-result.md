# Agent Note: Android 剪贴板编辑跨视图保留保存结果

Status: implemented

## Problem

剪贴板编辑的后台保存已提交给共享存储，视图重建不能取消它。`HostTask` 却把结果绑定到旧视图并丢弃迟到回调；`onContentDestroyed` 同时清除 `saving`。新视图允许重复提交原文已经被替换的保存，无法收到第一次成功，重建 Activity 时还可能按旧条目键重新读取而报告记录不存在。

此前不清除 `saving` 会让同一 Fragment 的新视图永久禁用按钮；清除它只能解除忙碌，不能恢复丢失的结果。API 35 的合成回归阻塞真实共享任务队列，提交保存后 detach/attach 编辑页，旧实现没有继续显示不可重复提交的「正在保存…」，按预期失败。

## Decision

现有 `Draft` ViewModel 同时持有已加载原文、加载状态、保存忙碌状态和一次性保存结果。共享存储仍通过 `HostTask.run` 的串行队列执行；工作函数把成功或固定失败结果发布到 ViewModel 的 LiveData，界面在 `onColumnReady` 用当前 view lifecycle 订阅并消费一次；消费后清空事件，失败对象与没有事件分开表示。ViewModel 不持有 Activity、Fragment 或 View。重建时直接显示已加载草稿，待保存结果交给新视图；视图销毁只清理控件引用，不解除已提交保存的忙碌状态。

## Related decisions

检索剪贴板编辑、`HostTask`、ViewModel 和视图生命周期的活跃笔记：

- 旧 `2026-10-11-android-clipboard-edit-view-lifecycle.md` 的重试决定被本篇完全吸收：旧回调不能恢复忙碌状态，只在内容重建时重置又模糊了生命周期边界。本篇保留其永久禁用风险，移除旧笔记及只断言保存状态源码字符串的守卫及列所有权检查中无关的状态断言，入站引用改为本篇。
- [编辑功能](../feature/2026-10-09-android-clipboard-edit.md)部分重叠，原有共享存储替换、草稿保留与返回原应用的契约继续保留，更新其保存生命周期引用。
- [外部编辑器验收](../testing/2026-10-14-android-clipboard-edit-external-route.md)覆盖进入、保存和返回，不含队列阻塞与视图重建，保留并互链。它未确认 vivo 真机 #7806 的后台启动原因，本篇不声称解决该报告。

## Alternatives considered

只在销毁视图时重置忙碌状态，改动局限于一行，可以修复永久禁用。但后台写入仍会完成，允许重试会丢失第一次结果或重复写入，因此保留业务操作状态并跨视图交付。

重建后重新读取存储，可以直接获得最新历史。但条目键包含原文散列，保存已完成时旧键失效，无法区分成功替换与外部删除，也不能恢复已丢弃的失败原因。

把公共 `HostTask` 结果生命周期整体改成 Fragment 或 Activity，可以统一保留更多请求。但已有调用方在结果中操作具体视图，不宜扩大其交付边界。本页在工作函数中只发布数据到已有 ViewModel，公共任务的视图守卫保持原职责。

## Testing

设备回归阻塞真实 `HostTask` 队列，通过实际页面动作提交保存，不增加生产测试入口。Android 9 的 Toast 出现后，无障碍窗口可能保留旧的按钮快照；等待失败恢复时对同一个 `AccessibilityNodeInfo` 调用 `refresh()`，以当前按钮是否启用为准。普通 `smoke.sh` 把这条需要重启宿主的回归放在键盘套件之后，`--core` 在打字验收后运行，避免下一条键盘用例沿用已被强停的输入法绑定。

专用 API 28/35 AVD 上，保存待完成时重建视图或 Activity 仍保留草稿且禁用重复保存；成功后正常返回并保留历史条数、时间戳和置顶状态。保存失败跨视图交付后可重试。现有外部编辑流程、Android 宿主检查、笔记与 quick 门禁通过。

## Consequences

保存中的重复提交被禁止，重建视图仍能收到成功或失败结果，Activity 重建不用按失效旧键重读。维护代价是显式持有并消费完成事件；仍沿用现有串行队列，不增加执行器或依赖。

保存不会因退出页面而取消，和原有持久化契约一致；页面永久退出后 ViewModel 不再有界面观察者。进程死亡不保留草稿或保存结果，不把长文字写入 Bundle。结果在主线程的当前视图生命周期消费一次，失败不保存原始异常或输入日志。测试只用合成历史，并在成功和失败后恢复设备数据。

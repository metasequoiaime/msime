# Agent Note: 鸿蒙皮肤目录导入与完成反馈

Status: implemented

## Problem

鸿蒙文件选择器返回文件 URI，而原生导入器需要绝对路径；设置桥立刻应答后丢弃了实际导入结果，用户无法判断是否完成。

## Decision

设置宿主打开选中的目录 URI 和私有暂存目录，异步 NAPI 在返回前复制两个目录描述符。工作线程以已打开的目录为根逐层调用 `openat`，不打开也不跟随链接；符号链接和特殊文件与共享导入器一样跳过，不导致整个导入失败；拒绝硬链接，限制树深、条目数与实际写入字节；原文件增长或缩短时拒绝。暂存完成后由原有导入器验证安装。成功和失败向用户报告，取消不发布数据。文件提供方不支持目录访问时报告失败，不退回路径遍历。

## Alternatives considered

- **直接传入文件 URI**：原生导入接口要求绝对路径，无法处理文件 URI。
- **将 URI 转成路径并递归复制**：父目录可能在检查后被替换，路径遍历不能固定用户选择的目录。
- **立即回复成功即代表导入完成**：同步桥的返回发生在选择和复制之前，不能反映结果。

## Consequences

合成测试覆盖描述符独立生命周期、单段子项、父目录及文件替换、文件增长、层数和条目数及大小限制；NAPI 排队失败、取消及描述符关闭由实际工作代码的模拟调度测试覆盖，完成与取消反馈由实际桥接方法的合成测试覆盖。鸿蒙终端的合成原生测试在 fdsan fatal 模式下通过；文件提供方的子目录授权、应用沙箱和应用内描述符交接仍需验证；不支持时提示用户，不能认为所有提供方均已兼容。测试文件系统禁止创建硬链接和 FIFO，硬链接的拒绝路径和 FIFO 的跳过路径尚需其他文件系统验证。硬链接被拒绝时用户看到的仍是通用的读取失败提示，没有单独说明原因。

# Agent Note: 全屏编辑器显示悬浮工具栏

Status: implemented

## Problem

电脑用户反馈切换到全屏窗口后工具栏消失；上游主动隐藏全屏状态面板的策略会阻止全屏编辑器使用工具栏。

## Decision

编辑器绑定时不查询窗口是否全屏，直接请求显示已启用的工具栏。焦点代次阻止解绑或换面板后的排队请求生效，显示操作保持串行，一次失败不会阻止之后重新聚焦的请求。

本决定部分取代[首帧与重聚焦](2026-10-13-harmony-floating-toolbar-first-frame.md)中保留全屏隐藏的决定；首次挂载刷新和重新聚焦恢复的目标继续保留。

## Alternatives considered

- 沿用全屏隐藏，可避免覆盖全屏应用内容；但用户实际在全屏窗口中编辑时也需要工具栏，并已反馈该行为造成工具栏消失。

## Consequences

- 全屏编辑器聚焦时可以请求显示，工具栏可能覆盖部分应用内容。用户仍可使用现有工具栏开关关闭它。
- 5004 自签 0.5.0 混合构建由用户确认全屏时可见；该构建实现不同，不能作为本独立 PR 的官方签名构建或完整设备验收。
- 测试模拟显示、排队与失效，不能保证系统窗口层级和显示状态；若系统操作始终不返回，串行队列仍会等待。

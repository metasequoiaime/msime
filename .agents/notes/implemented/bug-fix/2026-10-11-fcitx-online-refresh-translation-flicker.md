# Agent Note: Fcitx5 已显示在线查询不重复请求

Status: implemented

## Problem

Fcitx5 的 `refreshOnline()` 每 250 ms 运行一次，空闲防抖到期后仍反复请求同一份云候选和 AI 候选。每次成功回包都经 `msime_client_apply_online_candidates` 推进候选代次，`Runtime::refresh()` 清空译文；翻译重新完成后下一份在线回包又清空它，形成出现、消失、反复出现的循环。Omarchy 上同时开启在线候选与英文释义时能走到这条链路。

## Decision

原决定在分发前比较当前查询与该来源的 `online_display_queries_`，以成功显示为去重条件，失败和空结果保留重试。此条件与重试策略由[网络分发身份](2026-10-11-fcitx-online-dispatch-identity.md) 部分取代：仍由 Fcitx5 编排同来源查询去重，新组合、配置与 provider 切换继续刷新；现在以网络任务已分发而非已显示为准，缓存探测不占用网络身份。

## Alternatives considered

- 无条件保留跨代次译文，能避免 UI 出现空白；但真实输入变化也推进代次，直接保留会混入旧上下文，而且不能停止重复请求。[在线候选释义保留](2026-10-11-online-candidate-gloss-retention.md) 接受的是受限候选交集保留，不是本项否决的无条件保留。
- 将同文在线批次视作共享 runtime 的幂等更新，能避免多个宿主重复推进代次；但不会停止网络请求，仍应先在分发处去重。后续交集保留继续推进代次并拒绝旧 ID/回包，补足显示行为，不采用本项的批次幂等决定。

## Verification

原生 Fcitx5 测试先显示真实翻译 socket 的合成译文，再执行三轮已过防抖的在线刷新；旧版本重复分发时回放同一份成功回包，断言捕获译文消失。修复后相同查询不再发请求、推进代次或清掉译文；提交后再输入相同拼音仍能发起新的在线请求。

以 `ce0865afa` 为基线时，`ctest --test-dir target/linux-ibus -R '^fcitx5-native-(context|ai)$' --output-on-failure` 在本机已安装的 Host API 库和源码编出的库上均复现失败；修复分发后云和 AI 两条路径均通过。Linux 原生全量 `ctest` 共 81 项通过，包括隔离 daemon/frontend 验收。

`ee2ab5a80` 基线上的两项提前失败来自测试夹具：切换偏好目录会清空快照，恢复目录后必须等下一次偏好重读，不能拿没有修订号的快照调用偏好更新；取消语音的夹具必须使用产品的 `detachedJob`，`std::async` 的最后一份 future 析构会等待，不能模拟非阻塞取消。修正这两处夹具后，上述两项测试执行到翻译断言并通过；仅撤掉请求去重判断、保留修正后的夹具时，两条路径都在「重复在线候选刷新使已显示的译文消失」断言失败，恢复判断后通过。当前 Linux 全量 `ctest` 共 83 项通过，`scripts/verify-local.sh --quick` 和笔记校验通过。

独立 D-Bus 会话中的真实 Fcitx5 daemon/frontend 也覆盖云候选、AI 候选、云回包延迟 400ms 与 AI 回包延迟 2s 四个场景。每个场景连续观察稳定译文、清缓存、再输入同一拼音：两个组合只产生两次网络请求，稳定期间译文不反复消失，清缓存后译文恢复且候选仍在；AI 两次空缓存探测均继续请求网络。输入、服务回包和状态目录全部是合成夹具，不使用真实账号配置。

完整资源验收的 CapsLock 透传会在翻译夹具准备前重建会话；随后只改 runtime options 中的套接字地址，旧会话仍持有原地址，合成服务因没有连接而提前失败。夹具在写入新配置后主动关闭旧会话，再经真实按键重建，并断言已加载新地址；套接字的等待、连接、读取及协议格式失败只输出固定阶段名，不输出请求内容。该调整使翻译协议及在线候选刷新断言重新可达，不改变生产路由规则。

## Consequences

同来源查询去重归宿主，不修改共享 ABI。初版仅阻止成功显示后的重复请求，失败重试与缓存探测共用身份的缺口由网络分发身份决定补足；不再以显示状态承担网络去重。本条只决定请求分发；真正的新候选到达时，未变化词条的释义保留及后续任务合并由[在线候选释义保留](2026-10-11-online-candidate-gloss-retention.md) 补足，不能把两项修复的效果混为一谈。原生上下文和隔离系统入口的通过不等同于替换当前桌面插件后在真实编辑器验收。

# Agent Note: 指定词库的导出只读取一页

Status: implemented

## Problem

通用 Host API 的 `export` 按 1000 条反复读取混合日志页，再在内存筛选词库并保留从开头到 `offset + limit` 的全部匹配项。大偏移重复打开数据库、重复扫描前缀，且持有的词条随偏移增长。其他词库仍有行时，即使指定词库已导完，也可能返回 `has_more: true`。

## Decision

引擎提供指定 `PersonalDictionaryKind` 的导出入口，在 SQL 中用 `dictionary = ?5` 筛选后应用 `LIMIT/OFFSET`，复用现有主键 `(dictionary,key,value)`，每次请求只打开一次只读连接并读取一页。通用 Host API 直接序列化该页。混合列表与快照等既有调用保留原入口，不改变分页契约。拼音导出仍包含学习权重并排除单字；无中文主词库的版本仍只允许英文行。路径验证、锁、错误映射和线程连接释放保持现有机制。

共享 React 层的桌面管理和手机拼音导出都通过 `dictionary-export.ts` 的 `loadDictionaryExportText` 读取宿主分页：每页请求 1000 条，偏移按响应文本 `trimEnd().split("\n")` 的行数递增，空文本或 `has_more: false` 终止，偏移大于百万后按既有规则返回已读文本。直接调用原对象的 `export`，保留方法接收者。桌面显式传入 32 MiB 原始文本上限；手机保留拼音单字过滤后才检查最终文件上限的顺序。

个人拼音导出的完整操作由 `dictionary-export-action.ts` 的 `exportPersonalPinyinDictionary` 持有，只依赖可选的 `export` 能力和宿主保存回调。它组合公共分页、文件名与内容生成，保留空词库、取消保存、错误提示及无宿主保存能力时的公共 Blob 下载路径，返回提示文字；手机页面只将它接到详情按钮。桌面管理继续持有自己的保存反馈和请求代次，因为它展示保存位置、取消提示和分类型导出，不能直接套用个人拼音导出的返回语义。该操作不依赖 React、设置表单或 toast 上下文，也不扩大包入口。

## Alternatives considered

只限制 Host API 的累积向量到当前窗口，改动最少且能控制内存。但仍重复打开数据库并扫描混合词库的前缀，不能消除根因，因此将筛选下推到引擎。用可选参数和 `(?5 IS NULL OR dictionary = ?5)` 统一 SQL 可省一条查询文本，但直接等值条件更明确地利用主键前缀，因此保留混合与指定种类两条静态 SQL，共用读行与验证流程。

把两处循环统一为强制原始文本上限可简化参数，但手机原本允许原始文本较大、过滤后文件仍可导出，这会改变行为，因此上限由调用方传入。只传裸 `export` 回调可缩小形参，却会丢失可能依赖的 `this`；选择仅要求 `Pick<DictionaryClient, "export">` 的对象，不要求完整客户端。

让两种设置入口共用保存和提示操作可以进一步减少重复，但桌面需要过期请求守卫、保存路径与明确的取消反馈，手机取消时返回空串；统一这些语义会夹入策略分支。因此只抽取个人拼音这一完整领域操作，桌面继续复用底层分页与内容生成。把操作放进纯内容模块可少一个文件，但会让只需要文件名、内容生成和分页的消费者引入浏览器下载依赖，因此交付操作单独成模块。

## 合成 SQL 对照

同一 SQLite 文件含 2000 条英文、2000 条拼音和 60000 条快捷短语，导出快捷短语 `offset=50000, limit=1000`，三次中位数：旧循环 55 次查询、4.0217 秒、Python `tracemalloc` 峰值 13052830 字节；指定词库单查询 1 次、0.0280 秒、188122 字节；SQLite 虚拟机约从 14190000 步降为 465000 步。`EXPLAIN QUERY PLAN` 显示主键索引的 `SEARCH ... (dictionary=?)`。这是模拟两种分页算法的 SQL 层对照，Python 对象内存不是 Rust 分配测量，也不是完整宿主耗时。

## Consequences

收益是一次请求只打开一次数据库、只持有当前页词条，且末页状态不受其他词库影响。代价是两条静态 SQL 的共同谓词需要同步维护。`OFFSET` 仍须扫描指定词库的前缀，但只扫描一次；此次不引入游标接口或新索引，也不修改落盘格式。Android 个人词库队列有独立导出实现，此次只改变通用 Engine 日志导出。

共享分页消除了两处循环的独立维护；代价是读取函数需要显式接收可选原始文本上限，调用方仍须对最终文件限流。本次不改变分页协议或百万偏移的历史截断行为；将来若改变上限或响应行数契约，需同时复核两个消费者。

个人拼音操作从设置页迁出后可独立调用与测试，页面不再拥有导出业务规则。代价是操作有意返回这一入口的中文提示；它不是所有词库种类的通用保存器。宿主文件实现、文件权限和 Android 原生导出入口保持原契约，公共 Blob 下载仍只由既有 `downloadBlob` 执行。

# Agent Note: macOS 中英文切换提示使用紧凑尺寸

Status: implemented

## Problem

#7778 的中英文切换提示跟随悬浮工具栏字号与缩放，默认高度 44pt 且固定带标志，显著大于用户期待的短暂提示；候选窗口已经隐藏图标时，提示仍然显示。

## Decision

macOS 切换提示独立使用 18pt 字号和 32pt 高度，保持原主题和位置策略。标志遵循已有「显示水杉图标」设置 `show_app_logo`，默认不显示；显示标志时使用 16pt 图，不改变高度。悬浮工具栏字号和缩放不再影响这个提示。

历史检索：[Windows 中英文模式对齐](../../implemented/feature/2026-10-10-windows-input-mode-parity.md)部分重叠，补充 macOS 尺寸边界并互链；Windows 随后也改用同样的紧凑尺寸和淡出，见[工具栏、提示与托盘对齐 macOS](../feature/2026-10-20-windows-toolbar-hud-tray-mac-geometry.md)；菜单栏状态项和候选窗口层级记录是其它反馈与定位机制，保持不变。

## Alternatives considered

继续用工具栏缩放能让两个浮窗保持一致，但放大工具栏是为了更容易点击，鼠标穿透且只显示 0.6 秒的提示不需要同样尺寸，因此采用独立固定尺寸。

另加隐藏提示图标开关可以分别配置，但已有显示图标设置能表达用户要求，避免增加偏好字段。

## Verification

原生测试覆盖工具栏最大和最小缩放不影响提示尺寸、隐藏和显示图标时的宽度变化、切换中英文宽度稳定、主题和屏幕边界仍正常。

## Consequences

之前借用工具栏设置放大提示的用户会得到统一紧凑尺寸；显示水杉图标设置同时控制候选窗口与切换提示。

# Agent Note: 逐键模型只在和首选同样多字的读法之间换

Status: implemented

## Problem

Mac 上自动打字验收，「要上线」「今晚上线」每轮都被打成「要上西安」「今晚上西安」。只用引擎时首选是对的，是逐键模型把它换掉的。

整句池里除了 `xian` 的读法，也有把它切成 `xi'an` 的读法。那种切法多出一个音节，词网格分已经说明它不像，可模型只看字，「西安」又是常见词，混合分就翻了过来。

typing-chat-v1 test 上，8x448 配 9 条时，模型改错的 6 段里有 2 段是这种情形。

## Decision

`rerank_pick` 静态证据分支（`fill_static_rerank_inputs`）只比较和第一条回答按键的读法同样多字的读法。全拼整句一个字一个音节，字数不同就是同一串字母的另一种切法。

比较窗口不变，仍是前 `limit` 条回答按键的行，只在窗口里跳过字数不同的那些。第一版跳过之后让窗口往后延伸，原本排在窗口外的读法（「我国垃」「项目把」）因此补了进来，语气词集掉了 1 个点。

没有词网格分、走 `best_where` 的那条路不变：它比较的是词典词和各种来源的行，长短不同是常态。

## 评测

2026-11-03，同一台 Mac，锁定词库，资源里去掉随包模型，`convert_eval --onnx-model … --sentence-pool …`。聊天集是从 typing-chat-v1 按标点切出、带会话上文的句段。首选准确率，括号里是改对 / 改错：

| 集合 | 8x448 配 9 | 6x256 配 32 |
|---|---|---|
| typing-chat dev（110） | 62.7% → 62.7%（0 / 0） | 68.2% → 67.3%（0 / 1） |
| typing-chat test（220） | 73.6% → 75.0%（3 / 0） | 79.5% → 80.5%（2 / 0） |
| sentences-v1（60） | 83.3% → 83.3% | 83.3% → 83.3% |
| sentences-neutral-v1（1105） | 83.2% → 83.1%（2 / 3） | 83.9% → 84.2%（7 / 4） |
| sentences-v2（312） | 78.8% → 79.8%（3 / 0） | 76.9% → 76.6%（1 / 2） |
| sentences-particles-v1（103） | 81.6% → 83.5%（4 / 2） | 81.6% → 85.4%（5 / 1） |

合计：8x448 配 9 改对 12、改错 5；6x256 配 32 改对 15、改错 8。

改错的有两类：

- 首选本身切错了。规则以首选的字数为准，模型就救不回来，例如「处理啊」成了「出俩」。
- 同样字数的读法之间重新比较后换了，例如「原则同意」成了「原则统一」。

## Alternatives considered

- **按读音的音节数比，而不是按字数。** 更准，英文、儿化这类字数和音节数对不上的行也能处理。但 `OrderRow` 里没有读音，要从引擎快照一路带过来，改动跨 engine、runtime 两层。整句池里的行都是全拼读法，按字数比在这里够用。
- **字数不同时要求领先一个余量才换，而不是不比较。** 能保住少数正确答案是另一种切法的情形（真要打「西安」时首选已经是它）。余量要另外调，这次先用最简单的规则，量出来是净收益。

## Consequences

- **收益**：两种配置在 6 个集合上都是净收益，聊天 test 高 1.0–1.4 个点，语气词集高 1.9–3.8 个点。
- **代价**：首选切错时，模型不能换成另一种切法来救。如果「出俩」这类情形变多，要改成带余量的比较。

## Verification

`crates/input-runtime/src/tests/static_evidence.rs`：

- `readings_of_another_length_are_not_compared`：模型更喜欢另一种字数的读法时不换。
- `readings_of_the_same_length_mix_static_means_with_the_model`：同样字数时照常混合比较。
- `skipping_other_lengths_keeps_the_comparison_window`：窗口外的读法不会补进来。它替换了原来的 `static_means_compare_complete_readings_of_different_lengths`，那条测试守的正是这次推翻的行为。

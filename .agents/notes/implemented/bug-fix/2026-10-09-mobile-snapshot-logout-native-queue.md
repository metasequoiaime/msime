# Agent Note: 移动端账户退出时取消待激活的原生快照

Status: implemented

## Problem

Android 与 iOS 的 Tauri 账户退出、删号和忘记会话命令只清理快照预览。快照一旦进入原生队列，键盘 worker 即使在账户退出后仍可认领并激活它。Android 原生宿主的退出流程已经按账号取消队列，Tauri 入口遗漏了同一动作。

## Decision

在 `BackendAccountSession` 本地身份失效期间运行宿主清理回调，并在刷新锁与会话锁内先清存储、再取消队列，防止同一用户重新登录后旧退出请求误删新请求，也避免等待队列锁时旧令牌仍留在磁盘。退出或忘记会话先保存旧身份和代次：即使过期令牌刷新失败清空了当前身份，也能取消旧账号的待激活快照；代次变化时拒绝旧请求。删号在远端成功并核对原代次后清理。Android 调用已有 `cancelSnapshot` 插件入口，iOS 调用已有快照桥接取消入口；iOS 队列遇到键盘 worker 短暂占用状态锁时按 Android 已有策略重试。预览清理保持原流程。

## Alternatives considered

- 账户命令返回后按用户 ID 取消：远端请求期间同一用户可重新登录并提交新快照，旧请求会误取消新任务。
- 只清理预览表：已入列请求不在预览表中，键盘 worker 仍会处理。

## Consequences

待激活的旧账号快照在本地身份失效时被取消。已经完成激活的请求不能撤销；原生取消入口失败时仍沿用宿主现有的尽力而为策略。iOS 取消最多等待约一秒的状态锁交接；账户会话的本地失效与存储清理由同一锁序列化，避免新登录的会话被旧退出清除。

## Verification

`client-core` 回归测试覆盖远端退出失败、同一用户重登竞态、令牌被拒绝后的旧身份清理、清理回调执行前删除本地令牌，以及删号与忘记会话回调；iOS 队列测试覆盖状态锁短暂占用时取消继续完成。移动端目标编译和本地 quick 门禁见对应 Pull Request。

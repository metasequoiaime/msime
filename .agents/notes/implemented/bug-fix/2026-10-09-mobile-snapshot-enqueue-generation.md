# Agent Note: 移动端快照入列绑定预览账户代次

Status: implemented

## Problem

Android 与 iOS 的云词库快照入列命令先从预览表取走令牌，再调用账户接口检查用户 ID 与云端修订。预览取走后，退出登录的清理流程再也看不到它。若同一用户在检查期间退出并重新登录，用户 ID 仍相同，旧预览可能通过检查并被送进原生快照队列。

## Decision

入列前先核对预览记录的账户代次，避免对已经失效的预览继续发起远端检查。远端与本机版本检查完成后，再在 `BackendAccountSession::with_generation` 持有账户锁期间调用原生入列入口，使最终队列写入与退出或重新登录按顺序发生。iOS 的桥接结果保留原有快照错误码，账户代次失效仍返回账户取消错误。

## Alternatives considered

- 只在远端检查后再核对一次代次：核对与原生队列写入之间仍存在账户切换窗口。
- 依赖退出流程清理预览表：入列命令已经取走令牌，清理流程无法再找到它。

## Consequences

退出或重新登录后，旧代次预览不能再进入原生队列。原生入列可能复制大文件，因此这段操作会暂时持有账户锁；已在退出前入列的任务仍由现有队列生命周期管理，本次修复不改变其行为。

## Verification

`client-core` 现有回归测试覆盖同一用户重新登录后旧代次本地写入被拒绝；Android 与 iOS 目标编译以及本地 quick 门禁见对应 Pull Request。

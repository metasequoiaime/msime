# Agent Note: HarmonyOS 手机的皮肤页只有网格，皮肤编辑器是单独的视图

Status: implemented

## Problem

HarmonyOS 手机的「皮肤」页是缩略图网格，设置项收在「更多选项」里。「设计我的皮肤」把整个触屏皮肤编辑器就地展开在「更多选项 → 自定义主题」这一组里：分类标签、预设网格、取色器、预览和三颗按钮都塞进分组卡片内，按钮行和分类标签贴着卡片边缘、被截掉一截，编辑器下面还接着「高级」等设置。用户要先展开「更多选项」、找到按钮，编辑完再「收起自定义编辑器」，系统返回手势不会关掉它，而是直接离开皮肤页。

「更多选项」里另外还有颜色模式、在线皮肤、自定义主题（我的皮肤卡片）和「高级」里五个界面的明暗覆盖。用户看过之后的要求是手机上不要这一整块。

同一页的「AI 皮肤抽卡」已经是另一种做法：从网格的 AI 图块打开的是一个全屏视图，标题前带返回按钮，同时在 WebView 历史里压一条 `skinSubpage: "ai"`，系统返回手势关掉它。

## Decision

- `TouchKeyboardSkinEditor` 新增 `fullScreen`：以页面背景覆盖整个设置界面（与 `AiSkinGeneration` 的 `fullScreen` 同一套 `fullScreenSurface` / `fullScreenColumn`），顶部是返回按钮和标题「设计我的皮肤」，下面一行说明；返回按钮调用 `onClose`，所以不再画「完成」。说明下方是吸顶的键盘预览卡片和「AI 皮肤抽卡」入口，「保存设计」在预览卡片里，见 [皮肤编辑器改用设置页的平台控件](../feature/2026-10-12-skin-editor-platform-controls.md)。外层是 `role="dialog"`、`aria-label="设计我的皮肤"`。
- 鸿蒙手机的皮肤页（`phoneGrid`）只有网格，不再有「更多选项」：颜色模式和各界面的明暗覆盖在手机上不提供，在线皮肤在「社区」标签页，我的皮肤本来就是网格里的一张卡片。「键盘」页底部指向「主题 › 高级」的「屏幕键盘外观」一行随之在鸿蒙手机上不画。
- 编辑器的入口是网格里的「我的皮肤」卡片：没选中时点一下选中它，选中后再点一次打开编辑器（`SkinGridCustomDesign.onEdit`，走卡片的 `deselect`），选中时标题后画一个 › 提示。打开时压一条 `{ page: "skin", skinSubpage: "editor" }` 再显示全屏编辑器；返回按钮在这条记录还在时 `history.back()`，否则直接关掉。`popstate` 时编辑器的开关取自历史记录里的 `skinSubpage`，与 AI 视图共用同一个处理函数。
- 「我的 → 社区作品 → 我的设计」照旧通过 `showTouchSkinEditor` 打开编辑器，鸿蒙手机上它直接以全屏视图出现，没有对应的历史记录。用返回手势离开时，回到的那条记录里没有 `skinSubpage`，编辑器随之关上，下次进入皮肤页不会再自己打开。
- 其他宿主（桌面、Android、iOS、HarmonyOS 2in1）不变：仍有颜色模式、自定义主题和「高级」，编辑器仍在原处就地展开。

这取代了 [手机设置页按宿主画键盘预览，并收起电脑上的皮肤选项](2026-10-10-mobile-settings-touch-previews.md) 里「打开了触屏皮肤编辑器时，『更多选项』以 `defaultOpen` 展开」这一条在鸿蒙手机上的做法——鸿蒙手机上已经没有「更多选项」；那篇其余决定不受影响。

## Alternatives considered

- 新增一个设置页路由（例如 `skin-editor`），用 `selectPage` 打开，像「词库 → 背单词」那样成为真正的子页。理由最强的一条：标题栏、返回、页面切换都由设置外壳统一处理，搜索和深链也能直达。没采用：编辑器的设计状态、撤销栈和 `showTouchSkinEditor` 都挂在皮肤页和设置表单上，拆成独立路由要把这些状态搬到页面之外；而同一页的 AI 视图已经用历史记录加全屏视图解决了返回手势，照它做改动面小，两个视图的行为一致。
- 保留「更多选项」，只把编辑器挪出去。理由：颜色模式和各界面的明暗覆盖仍可调，改动更小。没采用：用户明确要求手机上不要这一整块；这些设置在手机上很少有人动，在线皮肤与「社区」标签页重复，我的皮肤与网格卡片重复。
- 只修排版，让编辑器在分组里不再贴边、不被截断。理由：改动最小，也保留「改完立刻在网格里看到效果」的就近关系。没采用：问题不只是边距——编辑器是一整套带分类标签和预览的工具，放在「更多选项」的一个分组里本来就挤，返回手势也关不掉它；用户要的是不放在根页面里。

## Consequences

- 鸿蒙手机用户不能再单独强制设置页或各界面用浅色、深色，只跟随系统；「设计我的皮肤」的入口从一颗按钮变成再点一次已选中的卡片，不如按钮直观，选中时的 › 是唯一的提示，「我的 → 我的设计」也能进入。
- 鸿蒙手机上编辑器有整屏宽度，分类标签和按钮不再被截断，系统返回手势关掉它而不是离开皮肤页。
- 编辑器盖住了网格，改设计时看不到网格里「我的皮肤」卡片的变化；编辑器顶部吸着键盘预览，所以不缺即时反馈。
- 以后给鸿蒙手机皮肤页加新的子视图，沿用 `skinSubpage` 这条历史记录约定，并在同一个 `popstate` 处理函数里按它设置开关，否则返回手势会把皮肤页一起带走。
- 上面说的「在线皮肤在『社区』标签页」已经不成立：「社区」标签页去掉了，完整的社区皮肤图库是皮肤页上的又一个子视图，由网格下方的「浏览更多皮肤」打开，记录标记是 `communityGallery`，见 [触屏设置去掉「社区」标签页](../feature/2026-10-11-touch-community-merged-into-feature-pages.md)。

## Verification

- `apps/desktop/tests/settings/skin-grid.test.tsx`：鸿蒙手机皮肤页没有「更多选项」、颜色模式、自定义主题和「高级」；选中「我的皮肤」后再点一次打开名为「设计我的皮肤」的全屏视图并压入 `skinSubpage: "editor"`，皮肤页里不再有编辑器和「收起自定义编辑器」，视图里没有「完成」，点返回后视图关闭。全部测试通过。
- HarmonyOS 模拟器（6.0.0.130）上用本分支的 HAP：皮肤页只有网格，选中「我的皮肤」后再点一次，编辑器全屏打开、两侧留边、按钮和分类标签完整；系统返回键关闭编辑器回到皮肤页。没有在真机上验证。

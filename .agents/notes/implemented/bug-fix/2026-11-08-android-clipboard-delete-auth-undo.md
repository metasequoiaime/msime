# Agent Note: Android 剪贴板认证删除后恢复撤销入口

Status: implemented

## Problem

#11105 报告 Android 剪贴板单选或多选删除通过指纹认证后看不到「撤销」入口。认证 Activity 会让输入法窗口暂时收起；删除回调仍在输入法服务里保存撤销快照，但原来只重画已隐藏的剪贴板面板，用户返回键盘时看不到刚才删除的记录和撤销按钮。

## Decision

删除开始前记录剪贴板面板是否处于打开状态。认证成功并完成删除后，如果认证过程让原面板收起，就重新打开剪贴板面板；如果面板仍可见，则沿用原地重画。多选删除先退出选择模式，再恢复面板，保证面板进入本机列表常态后才显示浮动「撤销」按钮。认证取消、认证失败或删除没有实际移除记录时不退出多选，并保留现有错误提示。

撤销快照、倒计时、认证策略和剪贴板存储格式不变；只修复认证 Activity 的窗口生命周期与删除后 UI 恢复之间的接线。

## Alternatives considered

- 仅在认证成功后重新渲染隐藏面板：不能把面板重新显示，返回键盘后用户仍看不到撤销入口。
- 无论认证前面板状态如何都强制打开剪贴板面板：会改变从其他入口触发删除时的界面状态，因此只在删除前面板确实打开且认证后已收起时恢复。

## Consequences

删除认证返回后，用户能在原来的剪贴板面板中立即看到浮动「撤销」按钮；认证取消不会误退出多选。实现增加了删除路径对面板可见状态的记录，但不扩大认证范围，也不让撤销跨输入法进程保留。

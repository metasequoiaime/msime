# Agent Note: 全拼合法备选切分补查前缀与整句

Status: implemented

## Problem

#8975 中，全拼连续输入的默认切分与目标读法不同。现有备选路径只批量查完整词，目标由短词组成时既没有对应整句，也没有可逐词选择的前缀。切换默认切分只能把缺失移到另一条合法读法。

## Decision

完整词合并与保护座位保持原规则，在其后补查字母与原始输入完全相同、音节完整的备选系列。复用普通路径的前缀查询、长词补全与词网格，但不在备选路径上叠加额外纠错整句。按真实覆盖字母数稳定合并，词面去重，同覆盖保持完整词及原路径优先，不比较词频与整句概率分。

一次查询内各条字面路径共享已查过的音节前缀及其行数，避免重复复制大页。共享前缀仍按原行数计入每条路径的稀疏回退门槛，不能因为省掉重复行而额外触发 `dia` 等读法回退。

手动分隔符仍固定边界；纠错备选仍走原成本层级；完整音节图沿用最多四个主音节、32 条路径的预算。单音节主路径也可能包含多音节备选，生成系列缓存登记这类个人模型依赖。模糊音合并同样先比较覆盖字母再去重，避免新增的字面短前缀遮住同词面的模糊整词；关闭模糊音时，该短前缀仍合法，但不带模糊标记，也不覆盖整个输入。

## Alternatives considered

- 修改默认切分：改动小，能让目标路径立即复用所有查询；但不同输入需要相反边界，固定选择仍会排除其他合法读法。
- 只在没有完整备选词时组句：减少冷查询；但某条备选存在整词，不代表其他读法的前缀和组句都已覆盖，无法满足多种合法读法同时可选。
- 把所有词频和整句分数统一排序：容易取得单一列表；但两者单位不同，会破坏已有完整词优先和纠错层级。

## Verification

原实现运行 `20261020-210600`，五项新增回归全部失败，覆盖前缀、整句、合法音节边界与单音节主路径。新增合成回归检查冷热查询、完整词优先、手动边界、词网格关闭、按覆盖去重，以及个人模型学习后的缓存失效。会话回归检查整句上屏、逐词选择、光标前缀选择和标准读音日志。

旧优化测试只同步新增的个人模型依赖，继续对照字段、容量、顺序与原分配差值；完整词合并的独立冻结对照改为直接调用 `merge_alternative_full`。两项学习复制预算改用显式音节边界，隔离新增备选冷查询，原预算不放宽。

最终运行 `20261020-213034` 通过 2,383 项单测，49 项按既有约定忽略，并通过全部 31 项 golden、全目标 clippy（`-D warnings`）、Host API 构建和笔记校验。18 个 scripted 场景新增备选前缀或整句，只更新 `snapshot.candidates` 与数量；逐项核对原有候选的所有字段和相对顺序，其他快照字段、上屏结果和最终学习日志完全一致。其余 282 个 scripted 场景不改。未设置 `MSIME_EVAL_RESOURCES`，因此真实词库评测集没有执行，实际词库另由下述 C ABI 探针验证。

固定随包词库经 macOS Host API C ABI 验证五组合成歧义串，分别沿 `fan/ou/er`、`qian/ou/er`、`qi/e/fei/hong`、`shan/an/fei` 和 `qu/xi/an/qie` 选出整句，全部输入被正确消耗且无诊断。另验证「帆」只消耗前三个字母，保留 `ouer`，随后选「偶尔」结束。宿主运行时原有整句读法展示数量限制仍保留，额外生成读法可能在完整候选列表后部；不把引擎内部按覆盖排序等同于宿主首页顺序。

同一台远端 macOS 机器、debug Host API、固定词库及临时状态下，最终常规组合的 620 次冷会话按键 p50/p95/max 为 1.912/6.474/13.068 ms，1,860 次热会话按键为 0.594/3.753/14.847 ms；重复歧义音节的 320 次冷按键为 5.004/22.548/31.850 ms，960 次热按键为 1.477/2.014/5.330 ms。这是逐键 C ABI 调用总耗时，含 JSON，不能直接等同发布包或系统输入法界面延迟。

对照库来自已验证提交 `3012ec9d33` 的 Host API，而非本分支精确基线 `f194735294`；其英文改动在上述中文组合中未启用。对照常规冷/热 p95 为 3.943/3.730 ms，重复歧义冷/热 p95 为 2.892/1.164 ms，因此新增路径有明确冷查询代价。共享前缀前，重复歧义冷 p95 为 30.494 ms；共享后降至 22.548 ms，仍保留全部合法路径，不以热结果掩盖冷成本。分配对照逐字段等价，另检查共享行数不改变稀疏回退门槛。

提交前 quick 门禁 `20261020-213612` 通过（12 分 45 秒）：Rust 工作区、Android Java、WASM、Linux 设置壳与原生 94 项、macOS 配置/编译及 Apple bridge 通过；Windows/MinGW、pipe-only 和 HarmonyOS HAP 因环境前置缺失明确跳过。

## Consequences

不同合法读法不再依赖完整词库条目才能出现，可逐词选择或直接选生成整句。每条备选解码会增加冷路径成本，不能用热缓存结果代替冷路径测量。默认切分不变时，候选可能来自另一条切分，选择必须以候选匹配键消费原始字母。系统输入法界面若未验收，应明确保留这一验证缺口。

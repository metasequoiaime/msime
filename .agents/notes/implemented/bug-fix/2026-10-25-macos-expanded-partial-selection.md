# Agent Note: macOS 部分选词后保留展开候选

Status: implemented

## Problem

#9602：双拼长句打开多行候选后，选中一个前缀词就收起网格，剩余拼音需要反复展开。`selectExpandedCandidateAtIndex:pointer:` 在选词前无条件丢弃网格；原先只覆盖整句上屏，没有区分引擎仍保留组字的部分选词。

## Decision

仅在展开网格主动选词成功、没有整句上屏、同一会话仍聚焦且留有组字时，读取新一代候选并恢复网格。剩余候选只有一页也继续展开，光标按新视图高亮重新定位；普通候选只有一页时仍不提供展开入口。旧候选身份不复用，过期选择失败仍收起。

恢复前检查应用回复的代次和客户端未被重入调用替换。用户打字、退格、显式收起、切换焦点及异步组字变化继续沿用现有生命周期。

历史检索：[展开网格](../../implemented/feature/2026-10-12-macos-expanded-candidate-grid.md)部分重叠，本篇只替代主动部分选词后立即收起的决定；[收起时交回高亮](../../implemented/bug-fix/2026-10-22-macos-expanded-collapse-highlight.md)与[原生滚动](../../implemented/bug-fix/2026-10-23-macos-expanded-native-scroll.md)各自保留导航和视口契约。

## Alternatives considered

- 所有组字变化都保留展开：实现统一，连续编辑时也省去展开操作；但会改变打字、退格及异步回复的既有关闭规则，范围超过报告，只在主动选词的回复中恢复。
- 选词后重新调用普通展开入口：复用入口最直接；但入口要求多页，剩一页时仍提前收起，因此把允许展示与多页入口条件分开。

## Testing

- 数字、空格、回车与鼠标的部分选词均保留网格，按新一代身份继续选择；剩一页继续展示，整句结束收起。
- 过期候选、失败回复、重入客户端变化和普通组字编辑不恢复旧网格。
- 新增原生控制器回归已覆盖四种入口、剩一页、整句结束与 marked text 回调重入；`-Wall -Wextra -Werror` 语法检查和笔记校验通过，完整 quick 与 macOS 原生运行结果待收取。

## Consequences

连续选词不再反复展开；代价是部分选词会重新构建网格和读取完整候选。系统输入源及真实编辑器中的连续选词仍需运行验收。本机空间不足以新建完整构建树，验证使用可用远端与 CI。

# Agent Note: iOS 分页网格反向滑动后的整页对齐

Status: implemented

## Problem

iOS 输入方式和功能面板使用 `UIScrollView` 分页。拖动结束、减速或布局重排交错时，滚动位置可能停在两页之间；下一次反向滑动便从半页继续，表现为面板滑不动或图块与页码不一致。

## Decision

`KeyboardPagedGridView` 在拖动未减速结束和减速结束时统一根据最终偏移计算最近页，并立即把 `contentOffset` 对齐到该页。带动画的程序翻页完成时也走同一条对齐路径。对齐期间复用布局保护标记，避免人工写入偏移再次触发页码回调。

## Alternatives considered

直接在 `layoutSubviews` 中无条件写入当前页偏移可以掩盖半页状态，但会在用户拖动或减速过程中抢回滚动控制，导致手势跳动，因此保留现有的拖动保护，并在手势生命周期结束点收敛状态。

## Consequences

分页网格在布局重排和反向手势后都保持整页基准，下一次滑动可以从正确页继续。新增回归测试覆盖被中断拖动后向前、向后两次对齐；对齐逻辑同时适用于输入方式、功能和皮肤等复用该网格的面板。

# Agent Note: iOS 九键按压反馈直接跟随触摸状态

Status: implemented

## Problem

用户在所有输入框的九键连续汉字输入中都感觉按键和候选粘手。当前九键按下及松手各用 60 ms 缩放、遮罩动画，25 ms 的短点按在按下动画结束前已经开始恢复；仅测量输入动作到 `render` 耗时不能验证按压反馈是否仍在继续。

## Decision

九键网格的按压反馈直接应用当前高亮状态，取消这九个按钮的过渡时间。保留按下的缩放和遮罩样式、抬指输入、取消触摸及长按语义；其他按钮沿用现有时长。`KeyboardKeyButton.animatesPressFeedback` 默认为真，只在九键网格创建时关闭；零时长路径同时取消变换与遮罩的图层动画，不在外层禁用动画的事务中重新启用动画。

本改动只消除代码设定的按压过渡，不把它解释为候选查询或触摸传递变快。真机 A/B/B/A 的按压呈现图层复原对照仍未完成，不能把本地无残留动画检查视为真机手感验收。CADisplayLink 观测也只能说明图层动画状态，不能证明像素已经显示。

## Historical audit

[主线程绘制预算](../../implemented/bug-fix/2026-10-18-ios-keystroke-render-budget.md)、[九键会话线程](../../implemented/bug-fix/2026-10-19-ios-nine-key-owned-thread.md)及[拼音侧栏](../../implemented/bug-fix/2026-10-19-ios-spelling-sidebar-layout.md)持有查询与布局的决定，本篇只处理按压动画，部分重叠且不翻转原决定。[离窗动画清理](../../implemented/simplification/2026-10-13-ios-keyboard-window-animation-cleanup.md)处理工具栏生命周期，与九键动画时长无关；[移动反馈契约](../../implemented/simplification/2026-10-15-mobile-feedback-contracts.md)处理共享设置类型，与本次运行时反馈无关。没有被吸收或过时的提案。

## Alternatives considered

- **合并积压的中间快照**：能在主线程落后时减少重复绘制，但四轮 70 ms 间隔、25 ms 按住的真机对照每轮 117 个数字均为 117 次绘制，没有触发合并，也没有稳定收益，撤回该试验。交叠触摸批次存在注入数量异常，不能据此采用生产优化。
- **只缩短按下、保留松手动画**：保留平滑恢复，但抬指之后仍有恢复过程，不能满足反馈直接跟随触摸的目标。
- **所有按钮取消动画**：实现集中，但会改变工具栏和候选等与本次九键场景无关的手感，先限定在九键网格。

## Consequences

消除九键在主线程收到松手之后仍继续恢复缩放和遮罩的固定过渡，代价是失去这九个按钮的平滑动画。输入动作仍发生在原来的抬指路径，不提前提交或改写长按。引擎查询、候选渲染与系统触摸传递仍有耗时，尚无证据证明用户报告的全部粘手已消失；需要完成真机对照并让用户复验。

## Verification

模拟器 `MSIMEKeyboardTests/NineKeyKeyboardTests` 共 116 项：115 通过、1 跳过、0 失败。新增回归对九个真实网格按钮连续按下/松手，检查变换和遮罩没有残留动画、尺寸位置保持、空格键仍保留原时序。最终源文件调整后，新增回归和既有中断清理回归另跑 2 项通过。`bash scripts/verify-local.sh --quick` 与 `npm run verify-notes` 通过。

真机已有四轮 117 键短按数据可排除本次快照合并试验的收益；交叠触摸的实际收到数量异常，不能将该批次作为性能证据。按压反馈的真机对照被系统键盘注册和应用切换打断，尚未产生有效新数据。临时探针、测试专用入口、保亮改动与工程噪音从源文件移除；正常 Release 编译、严格签名校验和真机安装通过，扩展二进制确认不含 `TouchLatencyProbe`。正常包已替换设备上的探针包；本次修改后的汉字连续输入与按压反馈对照仍须在可用的真机窗口完成。

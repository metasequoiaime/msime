# Agent Note: Android 大千注音按四行分配键高

Status: implemented

## Problem

大千注音有四行、41 个注音及声调键，却被 `ImeLetterRows` 压在三行键高里；键面沿用 14sp 默认字号。用户反馈键盘看着杂乱、很小且容易误触。

历史检索：[底行同高](../../implemented/feature/2026-10-10-android-equal-bottom-row.md)规定普通键区四行总高，本次只取代其中「大千四行压三行」的事实，双方互链；[数字行](../../implemented/feature/2026-10-09-android-number-row-and-split-duplicates.md)已允许增加实际键行时键盘变高，属于部分重叠；注音字符串缓冲笔记与键面几何无关。

## Decision

大千字母层的四行各占标准 52dp 键高和一份行距，底部功能行保留，因此总高比原来增加一行。注音主符号使用 22sp，窄屏在 18–22sp 范围内自动适配，保持单行、已有字体缩放上限及普通字重。声调符号按实际墨迹居中并放大，避免细小声调贴在键帽上沿。键位、41 个键、四个声调、删除和引擎 ASCII 输入映射不变。其他布局及大千符号层沿用现有高度。

## Alternatives considered

- **只把字号放大，保留四行挤三行**：切换时总高不变。但每键只有约 37dp 可见高度，字号变大不能扩大点按区域。
- **重新分组到更少的列，声调另设侧栏**：每键更宽，适合手机。但会改变大千的熟悉键位，本次先改善高度和辨认。

## Consequences

每个注音键的默认可见高度从约 37dp 增加到 52dp，符号更大、纵向落点范围更宽。代价是键盘增加一行高度，编辑器可见区域相应减少。最矮高度偏好仍会缩小键高，11 列的横向密度不变。

## Verification

`build-apk.sh`、`scripts/verify-local.sh --quick` 和 `pnpm run verify-notes` 通过。API 35 专用模拟器用现有 Windows 注音合成词库夹具启用大千布局，截图确认四行等高、主符号放大且声调墨迹居中；点按 ㄋ、ㄧ、三声转换为「你」，删除可清空编辑器。测试后恢复原偏好并移除合成词库。Android 12 真机覆盖安装返回 `Success`，未在真机执行注音输入验收。

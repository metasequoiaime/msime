# Agent Note: Linux 聚焦提示与中英文切换提示分开控制

Status: implemented

## Problem

#9154 中，QQ 每次进入输入框或切换会话都会弹出模式提示。两个 Linux 宿主把新焦点也作为提示触发器，这是 #2589 要求的行为，但现有设置只有「中英文切换提示」，无法只关闭聚焦提示而保留真正切换模式的提示。

## Decision

新增默认关闭的 `input_mode_focus_hud` 偏好，只由 Linux 的 IBus 与 Fcitx5 读取。新装与缺字段的旧文档均不在聚焦时提示；需要 #2589 行为的用户可在 Linux 输入设置页重新开启。`input_mode_hud` 只控制真正的中英文切换，两项独立生效。延迟等待光标后的聚焦提示仍检查聚焦偏好，不能借 `FocusSettled` 绕过它。

本决定取代[Linux 切换提示与菜单](../feature/2026-10-20-linux-mode-badge-and-menu-mac-parity.md)中“焦点进入总是跟随切换提示开关”的规则，保留该篇的等待光标、取消过期提示、敏感输入框限制与绘制位置规则。[空视图回调](../bug-fix/2026-10-10-linux-glib-callback-null-view.md)处理的是销毁与回调安全，继续保留。检索活跃笔记后没有其他同归属决定。

## Alternatives considered

- **彻底取消聚焦提示**：状态最少，符合本次报告人的期望；但会移除 #2589 已提供的能力，不能让需要它的人自行选择。
- **沿用一个总开关**：配置兼容、实现简单；但只想避免点输入框弹窗的用户必须同时放弃切换时的提示，不能表达两个 issue 的不同需求。

## Testing

- Rust 覆盖旧文档缺字段、新默认、保存往返和恢复默认；Linux 设置页测试两个开关独立保存，其他平台隐藏聚焦选项。
- 真实 IBus 宿主在私有 D-Bus 和 Xvfb 中验证缺字段及显式关闭不提示、只开聚焦仍提示；原有安全与光标生命周期用例显式开启聚焦偏好。
- 带锁定词库的 `engine_smoke.cpp` 也显式开启聚焦偏好，以保留页码等专项入口前的提示生命周期断言。legacy 运行时验收复用这个入口，因此其改动同时触发两个架构的 legacy 包检查；产品的默认关闭及缺字段断言仍由 `mode_hint_lifecycle.cpp` 独立覆盖。
- 发布前对照中，旧验收二进制在锁定词库上以 `Focus did not show the input mode` 失败；显式开启后，同一词库的 `--page-number` 专项通过，完整 quick 门禁通过（3 分 42 秒）。
- 真实 Fcitx5 5.1.23 开发库和运行库、GTK 编辑器及 Xvfb 验证反复聚焦默认不弹窗、切换仍提示、两个开关独立热更新，并继续组字上屏。撤回两个生产宿主的判断后，三项回归均因意外显示提示而失败，恢复后全部通过。
- Fcitx5 低于 5.1.11 的开发库不编入自定义提示，因此这项真实窗口测试只在有对应生产能力时登记；专用验收脚本在有能力时要求该项实际运行。默认 Shift 是框架的临时输入法切换，用例将框架快捷键另设为合成组合，确保测试经过插件自己的中英文切换。

- Rust 偏好测试 165 项、严格 Clippy、前端相关测试 51 项、类型检查与生产构建通过。同步后的完整 quick 通过，包含 Linux 111 项 CTest、Windows 本机原生测试 176 项和 macOS 原生构建；Windows 完整 MinGW 构建与 HarmonyOS ArkTS 工程因环境未就绪跳过。

macOS 偏好覆盖表明确记录聚焦提示仅适用于 Linux，与设置页的显示条件一致。CI 的 macOS 覆盖检查还指出基线已有三个 `keybindings.toggle_*` 字段尚未被消费；该缺口与聚焦提示无关，不能以本次 Linux 验证代替它。

同步 `develop` 后，偏好测试文件已有一个缺失的函数闭合和相邻 `#[test]` 标记，导致 `cargo fmt` 无法解析；补回边界后，两个原有测试均实际运行通过。字体与聚焦验收共享的 GTK 夹具保留两个独立入口，五项真实窗口回归通过。

## Consequences

用户能保留切换提示而避免点击输入框弹窗。升级后原来依赖聚焦提示的人需要重新开启新开关。两个宿主保留等待光标、取消过期提示、敏感框限制等既有保护。

隔离 X11 编辑器验证不能代替报告人的 QQ 与 GNOME／niri Wayland 环境验收；未现场验收时 PR 使用 `Refs #9154`。

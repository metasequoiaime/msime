# Agent Note: Android 剪贴板编辑页使用安装级授权令牌

Status: implemented

## Problem

Android 的 `HomeActivity` 对外导出，剪贴板编辑页从深链参数读取条目标识。现有标识由时间戳、`String.hashCode()` 和文字长度组成，外部应用可以枚举时间窗口、猜测常见文字并读取本机剪贴板历史原文。参数没有秘密，因而不能承担跨应用的条目选择授权。

## Decision

使用安装级 AndroidKeyStore HMAC-SHA256 密钥为时间戳、文字和长度生成不可伪造的编辑令牌。深链只携带时间戳、十六进制标签和长度；应用进程与 `:ime` 进程通过同一包名下的 AndroidKeyStore 别名取得密钥。密钥不可用时安全失败，不回退到旧的可预测散列。纯 JVM policy 只负责令牌格式，Android 辅助类负责密钥存取和 HMAC。

## Alternatives considered

- **继续使用时间戳、`String.hashCode()` 和长度**：实现最小，现有测试和调用点无需变化；否掉，因为这些值都可枚举或猜测，不能阻止外部应用读取历史原文。
- **把剪贴板文字直接放入深链**：编辑页无需再次查找，逻辑简单；否掉，因为 Intent 参数会扩大敏感文字的跨进程暴露面，也受深链长度限制。
- **为每条历史写入随机 ID 文件**：随机 ID 具有真正的不可预测性；否掉，因为要改变共享历史落盘格式、迁移旧记录，并在两个进程间维护额外的 ID 生命周期，而 HMAC 可以在现有时间戳和文字上无状态生成令牌。

## Verification

- 未持有安装级密钥的调用者不能从猜测的时间戳、文字和长度构造有效编辑参数。
- 主进程和 `:ime` 进程对同一条记录生成相同令牌；不同文字、时间戳或长度生成不同令牌。
- 令牌长度低于 `HostDeepLink.MAX_STRING_ARG`，密钥读取或生成失败时不回退旧算法。
- JVM 冒烟覆盖格式与 HMAC 输入；API 28 和 API 35 设备冒烟覆盖跨进程读取、保存、错误令牌不可读。

## Consequences

AndroidKeyStore 在设备损坏或密钥丢失后会让已有编辑深链失效；页面显示条目不存在，用户仍可从剪贴板历史页重新打开。旧的深链令牌不兼容，需要由当前页面重新生成。

# Agent Note: Android 功能菜单按使用场景排列并去重

Status: implemented

## Problem

logo 打开的功能菜单把 22 项放在三页四列两行里：第一屏混合输入开关、词库和设置，单手、浮动等布局操作散在后两屏，每屏下半段空白较大。表情、剪贴板、浮动和文本编辑也可能同时出现在顶部工具栏与菜单，用户反馈布局乱且入口重复。

## Decision

菜单采用四列三行，最多两页。第一页依次放输入开关、输入工具与设置、键盘布局操作；第二页放按键反馈、词库、反馈和关于。语音结果不作为常驻工具；仅识别文字仍有效、尚待插入时提供「插入语音文字」，沿用原结果存储的有效期和安全读取，不自动把旧文字插入另一个编辑器。统一标签字重，开关用颜色和勾标表达状态。「隐私模式」键面改为「无痕输入」，含义是暂停学习、输入记录和剪贴板历史，联网功能仍按各自开关控制。「AI 回复与润色」键面缩为「AI 辅助」，完整无障碍描述和子页不变。

功能菜单入口集合未变化时复用已有磁贴，只更新状态；输入会话因无痕输入重启时保留菜单容器，避免切换时整块闪烁。

顶部工具栏启用表情、剪贴板、浮动或文本编辑时，菜单过滤同一入口；工具栏整体隐藏或对应按钮关闭时保留菜单后备。过滤只改变条目呈现，不删功能和点击接线。结果文件读取失败时不显示语音插入入口，下次打开菜单重试。

## 历史决策审计

- [工具栏文本编辑](../feature/2026-10-09-android-toolbar-text-edit.md) 部分重叠：菜单入口改为工具栏关闭时的后备，两篇互链。
- [文本编辑面板](../feature/2026-10-08-android-text-edit-panel.md) 部分重叠：只重排入口，面板行为保持不变。
- 浮动键盘和其他平台的菜单笔记只记录功能或平台布局，没有同一菜单排列的独立决定，继续保留。

## Alternatives considered

- 删除菜单中的表情和剪贴板入口，界面最精简；用户关闭顶部工具栏按钮后会失去这些入口，因此按可见配置过滤。
- 单页长列表可以避免翻页，也方便放分组标题；在键盘有限高度里需要更长的滚动距离，所以复用现有分页网格，增加第三行并按场景排序。

## Consequences

常用输入与布局操作集中在第一页，菜单最多两页。顶部开关启用时过滤重复入口，关掉后仍有菜单后备。条目位置会随工具栏配置变化，过滤会让后续项目前移。横屏或降低键盘高度时仍沿用外层滚动容器，不修改其他面板共用的分页网格。

## Verification

JVM 冒烟覆盖全部 16 种快捷按钮组合的去重和后备入口；设备验收代码同步为两页三行。quick、原生 APK 构建与手机两页验收尚待执行；新增验证需覆盖无痕输入切换时菜单不重建。

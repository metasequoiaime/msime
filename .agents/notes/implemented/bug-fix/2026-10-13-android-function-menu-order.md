# Agent Note: Android 功能菜单按使用场景排列并去重

Status: implemented

## Problem

logo 打开的功能菜单把 22 项放在三页四列两行里：第一屏混合输入开关、词库和设置，单手、浮动等布局操作散在后两屏，每屏下半段空白较大。表情、剪贴板、浮动和文本编辑也可能同时出现在顶部工具栏与菜单，用户反馈布局乱且入口重复。

## Decision

菜单采用四列三行，最多三页。第一页依次放输入开关、输入工具与设置、键盘布局操作；第二页放按键反馈、词库、反馈、关于、打开官网和[复制设备信息](../feature/2026-10-08-android-device-info-copy.md)，第三页承载因新增入口后移出的条目。官网磁贴使用外链图标，直接调用系统默认浏览器打开 `https://msime.app/`，成功后收起键盘。语音结果不作为常驻工具；仅识别文字仍有效、尚待插入时提供「插入语音文字」，沿用原结果存储的有效期和安全读取，不自动把旧文字插入另一个编辑器。统一标签字重，开关用颜色和勾标表达状态。「隐私模式」键面改为「无痕输入」，含义是暂停学习、输入记录和剪贴板历史，联网功能仍按各自开关控制。「AI 回复与润色」键面缩为「AI 辅助」，完整无障碍描述保留。AI 辅助与本地输入子页也复用主菜单的 `FunctionPanelView`，使用紧凑的 44dp 返回栏；本地输入三列三行，AI 辅助为回复、润色两个图标入口。子页入口不变时复用视图并只更新状态，去掉整行返回按钮、通用文字图标前缀、厚底色卡片和重复说明段落。

功能菜单入口集合未变化时复用已有磁贴，只更新状态。官网入口不依赖宿主设置页，避免为了打开一个公开链接先离开键盘。无痕输入点击时先立即启用 Java 隐私门禁，学习会话重建延到键盘窗口收起后执行，避免切换时整块键盘闪烁。

顶部工具栏启用表情、剪贴板、浮动或文本编辑时，菜单过滤同一入口；工具栏整体隐藏或对应按钮关闭时保留菜单后备。过滤只改变条目呈现，不删功能和点击接线。结果文件读取失败时不显示语音插入入口，下次打开菜单重试。

## 历史决策审计

- [工具栏文本编辑](../feature/2026-10-09-android-toolbar-text-edit.md) 部分重叠：菜单入口改为工具栏关闭时的后备，两篇互链。
- [文本编辑面板](../feature/2026-10-08-android-text-edit-panel.md) 部分重叠：只重排入口，面板行为保持不变。
- 浮动键盘和其他平台的菜单笔记只记录功能或平台布局，没有同一菜单排列的独立决定，继续保留。

## Alternatives considered

- 删除菜单中的表情和剪贴板入口，界面最精简；用户关闭顶部工具栏按钮后会失去这些入口，因此按可见配置过滤。
- 单页长列表可以避免翻页，也方便放分组标题；在键盘有限高度里需要更长的滚动距离，所以复用现有分页网格，增加第三行并按场景排序。

## Consequences

常用输入与布局操作集中在第一页，菜单最多三页。顶部开关启用时过滤重复入口，关掉后仍有菜单后备。条目位置会随工具栏配置变化，过滤会让后续项目前移。官网入口直接交给系统浏览器处理，没有在输入法内嵌网页。无痕输入的学习开关在当前可见会话结束后生效，统计、日志和剪贴板门禁立即生效。横屏或降低键盘高度时仍沿用外层滚动容器，不修改其他面板共用的分页网格。

## Verification

JVM 冒烟覆盖全部 16 种快捷按钮组合的去重和后备入口，设备验收代码同步为三页三行。官网入口的模型、图标生成物和默认浏览器动作均由 Android host 检查覆盖。quick 与原生 APK 构建通过，Android 12 真机覆盖安装成功。`MoreToolsDeviceSmoke` 进一步检查本地输入三列布局、子页返回按钮宽度，以及 AI 回复、润色和官网入口并返回主菜单；该套件在 API 35 专用模拟器运行通过，测试配置使用合成编辑器和全拼 26 键，结束后恢复原偏好。

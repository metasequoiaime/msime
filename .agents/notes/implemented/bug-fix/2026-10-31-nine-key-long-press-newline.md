# Agent Note: 九键空闲回车长按插入换行

Status: implemented

## Problem

九键键盘的回车点按会随编辑器动作显示为发送、搜索等语义，用户在多行文本里需要换行时没有顺手的入口；文本编辑面板虽能插入换行，但必须先打开工具面板。

## Decision

保留回车点按的编辑器动作和组字确认语义，在没有组字时把回车长按绑定为字面换行。回车键面右上角显示「换行」，无障碍长按动作也读作「换行」。组字中的长按继续优先用于已有的译文上屏；没有译文时继续执行原来的点按确认。

## Alternatives considered

- **多行输入框点按回车一律插入换行**：实现简单，但聊天输入框等多行控件可能把点按回车定义为发送，会改变现有行为。
- **增加常驻独立换行键**：入口更直观，但九键底行空间固定，会挤压空格和其他功能键；长按不改变布局。

## Consequences

多行编辑器与聊天输入框仍可用原有点按动作，空闲长按回车可直接插入 `\n`。换行入口仍依赖用户发现长按；键面角标和无障碍动作提供提示。验证需要在真实编辑器中确认字面换行，并确认组字长按行为没有回归。

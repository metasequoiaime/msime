# Agent Note: 词库撤回与保持自动更新的手动回退

Status: implemented

## Problem

官方词库发布被标为预发布时，客户端直接过滤掉它，已安装该版的用户继续停留在被撤回的版本。手动恢复上一版又会关闭自动更新，之后发布的更高修复版无法自动到达。[#10879 的 M5 与 4.6](https://github.com/metasequoiaime/msime/issues/10879)明确要求修复这两处行为；不改变自动更新的出厂值，也不替用户打开已有关闭的开关。

## Decision

检查任务持有原有跨进程更新锁，在过滤预发布前核对当前选择的原始 tag。API 明确将当前版本标为预发布时，只有上一槽版本更低、仍在本次 API 的正式版本列表、通过当前基线的选择校验，且桌面与语言代次的实际文件完整通过 SHA-256 校验，才交换两个槽。版本列表请求返回后先复核开关；检查期间用户关闭自动更新时取消，不交换槽。本次检查不下载、不改变输入法已加载记录，下次建会话时采用旧代次。没有上一槽、列表未覆盖该 tag、网络失败或旧槽损坏时不推断、不下载修补，继续等待更高修复版。

手动回退将当前版本记入独立的 `rollback.json`，字段为 `skipped_version`，然后原子发布槽交换。配置文件及开关保持原样；手动和自动检查均跳过该语义版本，更高版本照常安装。单独文件避免旧客户端因 `deny_unknown_fields` 丢失整个配置或选择，也避免取消下载时的配置写入与回退互相覆盖。先写跳过记录再发布选择，中断最多多跳过一个版本，不能导致立即重装问题版本。存在却损坏的跳过记录使检查报错，不能当作从未回退。调开关不清除跳过记录。

现有 Android、Windows/Win7 和共享设置的说明同步改为跳过一版；iOS 的该按钮没有旧的关闭说明，保持已有布局。不新增共享设置项或 WebView。行为主体放在 `dictionary_updates/withdrawal.rs`，入口文件只接入。只实现本仓库 M5 及其已有文案修正；M1–M4、M6–M12、词库/云服务/离线裁判和仓库权限配置仍归 #10879 总设计，不启用闭环、不部署、不发版。

## Alternatives considered

把 `skipped_version` 放进 `Config` 最直接，但旧版严格反序列化遇到新字段会丢弃用户原来的关闭配置，而且配置开关本来允许在下载过程中独立写入，回退读改写容易覆盖用户操作。把字段放进 `Installed` 能一次发布选择与跳过记录，但旧版会因同样的严格反序列化丢失整份选择及随包目录定位。因此采用独立的私有原子文件，接受崩溃时少更新一次的保守结果。

只交换清单、不校验旧槽文件速度最快，但被删除或损坏的旧槽会把有效的当前选择换成不可用选择，因此先在后台完整校验，输入线程不参与。对 API 未列出的旧 tag 视为未撤回能扩大回退覆盖，却无法区分列表截断与撤回，因此只接受本次明确的正式条目；仍沿用前 100 条官方 Release 的现有检查范围。

## Verification

旧实现在合成传输器的五项测试中有两项失败：回退关闭开关，以及当前版本被撤回后仍停留在当前槽。新增行为测试还覆盖旧槽缺失/同长度损坏/非法基线/不低于当前版本/被撤回/草稿/未列出、网络失败、语言资源校验、符号链接、无法保存跳过记录、跳过记录损坏、手动恢复下载槽、开关两种状态及接收更高修复版。
测试核对已加载代次与随包定位保持，无下载的回退只请求一次版本列表。仍允许显式第二次恢复从随包基线换回下载槽，保留 Host API 已有的恢复/损坏兜底回归前置条件。
最新快照的 providers 词库更新 47 项通过、1 项原有忽略，Host API 词库更新 8 项通过，providers 全目标严格 Clippy 通过；API 28/35 两台专用 AVD 各跑同一最终词库更新专项，均为 47 项通过、1 项原有忽略。补充请求返回后取消保护之前的快照还跑过两台 AVD 的完整核心套件：base 44、core 824、providers 329、services 1500 加四项独立项，以及 engine 的 13 项维护租约测试。不能把旧快照的全量运行称作最终快照的全量运行。

最终 quick 第一轮因两个无关语音目录导出示例冷编译超过 120 秒而失败；不改测试，先按相同锁版本完成示例构建后重跑，`20261114-223828` 的完整 quick 通过。该轮随后完成共享设置、同源 arm64 NAPI 原生库、词库与语音运行时暂存，`hvigorw assembleHap --no-daemon` 退出 0，产出完整 unsigned HAP；签名设备验收未完成。Android 原生 GroupCard 的改前/改后文案渲染已留图、上传并回下载逐字节核对；这不是整个设置页或整包验收，Windows 与共享设置页的完整前后图仍缺。

## Consequences

单个跳过版本不是多版本黑名单。旧客户端读不到新的跳过记录，降级后仍采用旧逻辑。上一版在前 100 条 Release 之外或资源已丢失时不自动回退；等待更高修复版。完整旧槽摘要校验会增加后台检查的磁盘读取，但只在当前版明确被撤回时发生。本 PR 不代表 M5 已进入任何平台正式版或达到闭环启用覆盖率。

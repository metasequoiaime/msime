# Agent Note: macOS 偏好修订号只在会话更新成功后记为已应用

Status: implemented

## Problem

macOS 输入控制器每秒读取共享偏好文档，并按修订号跳过已应用的快照。原先在调用会话的 `updatePreferencesSnapshot` 前就记录修订号；如果该调用失败，窗口与运行时保持旧设置，下一次轮询却把同一修订号当作已应用而跳过。用户只有再次保存设置、产生新修订号后才能重试。

## Decision

控制器在会话返回成功结果且没有错误后，才把修订号交给 `MSIMEPreferenceLoadState::applied`。失败的更新不修改已应用修订号；下一次轮询仍会尝试同一份文档。成功更新后的去重规则不变。

## Alternatives considered

- 失败后重置整个 `MSIMEPreferenceLoadState`：也会允许重试，但会同时推进读取代次并忘掉上一次成功应用的修订号，影响正在完成的其他读取。只延后成功标记即可保持现有读取生命周期。
- 继续提前标记以避免无效文档每秒报错：可以减少重复日志，却把暂时性的会话失败变成持久的设置失效。偏好文档的读取失败已有独立处理路径；会话更新失败需要保留重试机会。

## Consequences

暂时失败的会话更新可在文档修订号不变时自行恢复。若同一文档始终无法被会话接受，控制器会按每秒轮询继续尝试并写诊断记录，直到文档改变或控制器失焦。

## Verification

`shortcut` 测试用合成会话让第一轮更新失败、第二轮读取同一修订号；旧实现断言失败，成功标记移到返回成功的分支后通过。

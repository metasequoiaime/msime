# Agent Note: 神经整句重排统一使用自然对数

Status: implemented

## Problem

继续调查 #7583 时发现，`edge_log_prob` 用 `ln` 生成词网格分，二元、三元与个人加分也使用自然对数；`SentencePath.log_prob` 直接传给 `NeuralReranker`。九键由相同分数扣除音节长度奖励后传入，也没有变换对数底数。`rerank_order` 却把它当成常用对数，再乘 `ln(10)`，静态分差因此被放大约 2.303 倍，名义上各占一半的静态与神经信号实际偏向静态词网格。

## Decision

混合评分两侧均使用自然对数，去掉静态分的重复换算。保留 0.5 的混合权重、12 条评分上限、稳定排序与候选展示规则。回归直接使用 `edge_log_prob` 产出的两条合成词频分，验证神经信号能跨过其自然对数差距。

## Historical audit

检索活跃笔记的 `log10`、`LOG10_TO_NATS`、自然对数、神经评分，没有相同单位决定。[神经路径原地重排](../../implemented/testing/2026-10-08-neural-paths-inplace.md)部分重叠，只约束排序与分配方式，继续保留；[负二元分截断](../../implemented/bug-fix/2026-10-13-lattice-negative-bigram.md)只约束静态转移，不改变本次单位判断。[扩大默认路径试验](../../rejected/bug-fix/2026-10-14-lattice-rerank-path-coverage.md)已被评测否定，不混入此修复。

## Alternatives considered

- 将生产端全部改为 `log10`：可以沿用原重排公式，但会改变二元、三元、个人学习和九键之间的评分契约，需换算所有加分与阈值；消费者已拿到自然对数，直接修消费者更局部。
- 把混合权重改为更偏向模型的数值：能抵消这个放大系数，但把单位错误藏进参数，日后调权重仍会理解错；先修单位，再单独评估任何调参。
- 维持重复换算：可能守住某些已因静态偏重而正确的句子，但违反生产端与消费者的单位契约；需报告质量取舍，不能以现有错误行为解释单位。

## Verification

使用 `edge_log_prob(100, 2)` 和 `edge_log_prob(50, 2)` 的生产端评分、神经分差 1 nat 的合成回归，在旧实现下保留第一条而失败，新实现提升第二条而通过。完整 engine/runtime 测试通过，含 1,980 条 engine 单测、31 条 golden、260 条 runtime 单测，15 条已有 ignored 测试仍保持 ignored；键盘模型测试从实际锁定资源运行。

`convert_eval --keyboard-neural` 显式启用这层模型评分；默认仍关闭，原质量基线不改。对照使用同一提交、同一锁定资源、学习关闭，分别保留改动前后独立二进制。双拼与全拼调用相同的 `NeuralReranker`，九键与十四键也经过同一消费者。

词库中的日文模型比 `real_model_loads` 指定的 `dict-v2.0.1` 多 211 条词条；把该新资源传给旧模型专用测试会失败，已改用 `MSIME_NEURAL_MODEL_DIR` 只配置此任务实际用到的键盘模型，不改历史日文模型断言。

## Consequences

修复让神经评分相对静态分更强，会改变已有模型的选择；它只修评分契约，不能声称整体词库质量或 #7583 的所有情况均已解决。

保留评分路径数、模型调用数与分配结构，没有增加模型推理；未测量本次改动的设备端延迟，不能据此声称输入更快。原 vivo 诊断配置未开启这层模型，本修复不能解释其当前全部排序现象。

静态词网格增加每词代价后的路径变化见[共享词网格插入代价](2026-10-14-lattice-phrase-insertion-cost.md)；本篇的自然对数契约和混合权重保持。

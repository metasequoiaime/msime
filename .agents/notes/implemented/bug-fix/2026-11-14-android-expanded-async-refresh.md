# Agent Note: Android 展开候选跟随异步候选刷新

Status: implemented

## Problem

[#11454](https://github.com/metasequoiaime/msime/issues/11454) 要求等待或滑动时展开候选不要自行关闭。普通网格绑定打开时的候选代次，停顿重排和在线回包接收新视图后没有同步完整快照，下一次绘制因此将面板收起。

## Decision

`ImeCandidatePanelRefresh` 在停顿重排与在线回包两个异步视图接收入口同步展开快照。只有面板已打开、旧快照仍属于当前会话与视图、接收前后同会话且非空 `editing_text` 完全相同时才跟随；继续打字、清空组字、换会话和主动关闭沿用现有生命周期。

同步必须重取共享运行时的完整候选，沿用 `currentCandidateSnapshot` 的代次追踪，不能只改快照代次。旧格子继续按旧身份拒绝选择；刷新不经过 `apply`，不得重复写编辑器。主体放进独立宿主文件，巨型服务只保留两个接入点。

## Existing notes audit

- [移动端部分选词保留面板](../../implemented/bug-fix/2026-10-25-mobile-expanded-partial-selection.md)部分重叠，其中为限制 #9193 范围而保留的“普通网格异步回包时收起”在本 issue 的授权范围内被取代；部分选词、打字与退格规则保留，双方互链。
- [完整候选同步视图](../../implemented/bug-fix/2026-10-15-android-expanded-candidate-view.md)部分重叠，沿用全列表会推进代次的契约。
- [过期候选回调](../../implemented/bug-fix/2026-10-14-android-stale-candidate-callbacks.md)保留身份围栏，不能因保留面板而放宽。
- [异步停顿重排](../../implemented/bug-fix/2026-10-21-async-settled-rerank.md)保留任务有效性和共享排序所有权，本项只处理宿主展开面板。
- 其他网格、皮肤、跨平台布局和词库笔记不持有该异步生命周期，无需删除或归档。

## Alternatives considered

放宽网格的代次检查可少改接收端，但旧格子的下标和身份可能指向另一候选，不能采用。完全停止面板打开期间的重排和在线候选可避免换代，但会隐藏本已启用的候选能力，且仍不能覆盖其他合法刷新，因此保留刷新并同步完整快照。

## Verification

新增 `CandidatePanelRefreshDeviceChecks` 接入既有 `CandidateExpansionDeviceSmoke`，使用真实共享会话接受合成候选并推进代次，经停顿发布和在线接收两个入口检查网格、候选身份、旧回调、主动关闭与继续打字。关闭测试实例的在线传输执行器，避免合成回包引发真实传输。旧安装包与修复 APK 的所有原生库逐文件 SHA-256 完全一致，产品 Java 分别对应修复前后。API 28/35 上旧 APK 均在“异步更新后面板保持打开”断言失败，修复 APK 两端均通过；原有首道双拼展开、释义与连续选词用例继续执行。

真实系统编辑器的 `CandidatePanelDeviceSmoke` 在 API 28 通过。API 35 最初出现布局切换与选词断言间歇失败，受控新旧包交替运行时旧包也在组字断言失败，随后旧包一次、修复包两次通过；保留全部失败与复跑记录，未修改该套件前置条件或断言，不以反复重试替代故障解释。完整远端 quick `20261114-235738` 通过；正式回归移除效果图夹具后，远端 `20261115-001921` 再次通过全部 353 项 JVM 冒烟、288 份设备测试源编译，以及 API 28/35 的最终 `CandidateExpansionDeviceSmoke`，两端均返回 `MSIME_DEVICE_SMOKE_PASSED`。

效果图将同一产品键盘视图挂入临时前台测试窗口，用合成会话注入候选刷新，旧包自动回到字母键盘、修复包保持完整候选网格；图像按真实像素与产品背景保存，已上传 sugi 并下载逐字节核对。此图是产品视图夹具，并非系统输入法窗口截图；系统触摸验收另行报告。截图工具留在忽略的验收目录，正式回归只保留行为断言。

## Consequences

重取完整候选可能再次推进代次，必须沿用已有同步入口；换代时网格仍按既有规则回到顶部，以免重排后把旧位置解释成同一候选。报告者的实际系统版本未提供，模拟器不能冒充其真机验收。

# Agent Note: 正常候选设置入口显示顶部四标签

Status: implemented

## Problem

macOS 输入法菜单的 `showAppearance:` 先调用 `MSIMEOpenDesktopSettings`，打开共享 React 的 `settings:appearance`，失败才打开 AppKit 备用窗口。此前只给备用窗口增加标签，把用户截图误判为备用窗口，正常入口仍显示四组长列表，重装不能解决。

## Decision

共享桌面候选设置页用布局、字体与大小、窗口样式、预编辑四个标签，位于共用预览的下方。预览共用，分区保持挂载，仅隐藏未选中的分区，保留修改与返回页面时的选择。方向键、Home、End 同步焦点和当前面板。桌面预览不再按竖排最大九项放不可见占位，而是随当前排列与数量伸缩，避免横排也占整页高度。手机布局和原有预留策略保持。

## 后续取代

[macOS 主题页与候选窗口页精简](../simplification/2026-10-16-macos-appearance-settings-prune.md) 取代本篇「共享桌面候选设置页用四个标签」的决定：共享页改成一列，进阶项收进一个「更多选项」。本篇关于入口判断、预览随样例伸缩、横竖切换时的预览生命周期和外部皮肤预览 logo 的部分仍然成立。

## 历史审计

[原生候选设置标签](../../implemented/feature/2026-10-13-macos-candidate-settings-tabs.md) 部分重叠：备用窗口的实现仍保留，本篇取代其“改共享页面不能完成请求”的入口判断。输入法的原生宿主是安装和验收对象，共享组件由它正常拉起。[候选预览 token](../../implemented/bug-fix/2026-10-11-macos-candidate-preview-native-tokens.md) 与入口无关，保持预览组件原有行为。[展开候选](../../implemented/feature/2026-10-12-macos-expanded-candidate-grid.md) 部分重叠，只改变桌面设置所在分区。

共享页目前没有逐行搜索跳转，原生备用页已有的跨标签搜索仍由原生实现负责。

## 横竖切换的预览生命周期

保存返回的新 revision 会重扫皮肤目录。重扫期间保留同一扫描宿主、皮肤 id、显示状态和手动刷新代次的已有预览，避免移除后重建图片造成闪烁。排布改变但皮肤支持新排布时，等待宿主解析期间保留相同主题和明暗的配色；不同扫描宿主、皮肤、主题与明暗不能复用旧结果，不支持的排布仍不显示皮肤。异步响应继续用请求代次隔离。手动刷新保持重新读取图片的原有语义。

[外部主题请求代次](../simplification/2026-10-12-external-theme-generation.md) 部分重叠，沿用请求守卫，增加同一皮肤更新期间的展示连续性。

## 外部皮肤预览的 logo

`brand` 从候选设置页的 `show_app_logo` 经普通预览和外部皮肤预览传到同一个候选样例。此前外部皮肤分支丢了这个参数，所以关闭开关仍显示 logo；切换不需要重扫皮肤或重新读取装饰图。

## Alternatives considered

- 用固定最大高度压住切换：可以让页面位置不动；但横排会留下整页空白，也不能解决自动保存时移除预览导致的闪烁。保留 DOM 和图片，只根据当前布局改变高度。
- 仅重装原生输入法：可以刷新备用窗口；但正常菜单优先打开共享页，不能改变截图中的长列表。
- 强制所有设置入口进入 AppKit：可以直接使用已有标签；但会改掉现有共享设置入口，绕开正常使用的页面。修复共享组件符合实际入口，保留原生备用窗口。

## Verification

共享页测试覆盖四标签、键盘导航、草稿和预览保留；手机设置仍能直接访问原有控件。本机沿用已安装且包含默认输入源修复的原生 bundle，编译共享设置组件并重新安装。真实窗口由 `DesktopSettingsLauncher.h` 的生产启动函数打开，确认 tab 位于预览下方，横排预览高度由此前 595 缩为 151 个逻辑像素；安装前后读取原生 `--enabled-input-modes`，只有 `.Hans` 启用。原生宿主沿用已安装 bundle，本次没有重新编译原生宿主。

共享 UI 全量 569 个文件、3021 项通过；随后修复横竖切换闪烁和 logo 参数遗漏，27 项候选预览与标签回归通过。前端类型检查与构建、设置组件编译打包、签名完整性、quick 门禁与笔记门禁通过。

## Consequences

设置组件包内必须放修复了默认注册行为的原生输入法，避免刷新时退回旧版本。顶部标签属于桌面共享页面，其他桌面宿主的控件测试必须选择对应标签。取消桌面最大占位后，切换横竖排时下面标签会随当前样例高度移动，这是紧凑显示的代价。

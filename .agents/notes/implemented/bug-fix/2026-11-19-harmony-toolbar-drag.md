# Agent Note: 鸿蒙悬浮工具栏的拖动命中与窗口移动

Status: implemented

## Problem

鸿蒙电脑悬浮工具栏的细线只有 2.5 vp 宽，实际手势也绑定在细线上，鼠标很难命中；逐条异步调用窗口移动时，旧位置可能积压，拖动容易滞后。窗口跟随指针移动后，相对窗口的偏移也不适合作为稳定的屏幕位移。

## Decision

普通工具栏保留原细线尺寸，在周围提供透明手势区域，并在窗口宽度中计入该区域、分隔线和各间距。图片工具栏沿用已有的图片手势区域。两种工具栏使用屏幕坐标计算手势位移，读取面板的实际位置作为新一次拖动的起点；无法读取时回退到最近请求的位置。窗口移动串行执行，进行中只保留最新请求，面板销毁时丢弃旧队列。

## Alternatives considered

- 直接放大可见细线：实现简单，但改变用户选择的外观；透明命中区能保留视觉尺寸。
- 直接调用系统窗口移动循环：理论上可由系统跟随指针；当前尚未确认状态栏面板对该 API 的支持及结束后的位置同步行为，因此沿用已有的 `moveTo` 接口并限制积压。

## Consequences

- 较宽的透明区域改善命中，工具栏窗口也需要为它留出空间。
- 图片皮肤保留自己的命中形状，但与普通工具栏共用坐标和移动队列。
- 项目 TypeScript 检查、拖动队列专项测试和键盘逻辑测试覆盖位置合并、重新按下、失败恢复及布局尺寸；含其他修复的 5005 组合版本经用户实机确认，独立 PR 尚未单独安装或实机验证。

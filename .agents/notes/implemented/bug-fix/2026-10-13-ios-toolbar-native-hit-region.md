# Agent Note: iOS 工具栏原生内容与系统命中

Status: implemented

## Problem

[工具栏比例调整](2026-10-13-ios-keyboard-proportions.md)后，iPhone 17 上表情、皮肤、方案和品牌按钮经常不响应。只挂自绘图层的按钮在本地视图树中能被 `hitTest` 命中，模拟器也能点，但真机 `isHittable` 为 false，按钮没有收到触摸；同一键盘中的普通九键可以收到触摸并产生候选。品牌按钮打开菜单时又出现圆底外叠加圆角底板的视觉问题。

## Decision

工具栏与品牌按钮通过 `UIButton.setImage` 提供原生内容，仍由官方 `KeyboardIcon` 与 `MSIMELogo` 路径绘制。图像画布覆盖整个按钮，图标居中、边缘透明；不能只提供图标尺寸的图像，否则真机边缘点按不能打开面板。普通与高亮图像使用相同画布，高亮只将内部图形缩小到 .92，保持 `imageView` 与按钮的命中边界不变。工具栏按压底板可以缩放，品牌按钮只保留原有 36pt 圆底，不再叠加 40pt 激活底板，菜单状态仍通过辅助功能 selected 表达。

原来的 `primaryActionTriggered` 事件契约不变。回归测试在系统宿主编辑器中切到九键，逐一从左侧 2%、中心与右侧 98% 打开、关闭品牌、表情、皮肤和方案面板。在专用 `--keyboard-toolbar-ui-test` 启动参数下，测试编辑器临时禁用 idle timer，离开编辑器后恢复，避免一轮真机验收中自动锁屏。

## Alternatives considered

- 保留纯自绘图层，只扩大按钮或父视图的命中：能保持矢量图层并通过模拟器验收，但真机所有祖先可交互且本地 `hitTest` 正常时仍没有触摸；补原生图像后同一按钮可命中并打开面板，因此采用原生内容。
- 只提供 26pt 图标图像：实现简单且中心真机点按有效，但透明边缘之外的按钮空间不可点，改为整格图像。
- 缩放 `imageView` 提供按压反馈：能直接复用现有动画，但会缩小系统命中区域，改为同尺寸高亮图像。
- 开启 `allowsSelfSizing`：能让约束拟合高度影响系统键盘尺寸，但真机顶部按钮仍点不动，撤回。
- 增加触摸转发：可绕过主操作路径，但现有事件在提供原生内容后正常，转发可能双触发，因此不增加事件入口。

## Consequences

季节颜色、官方路径、图标尺寸与普通工具栏激活底板保持既有设计。布局尺寸或皮肤变化重新绘制图像；常规工具栏图像以模板模式使用当前强调色，品牌图像保留多色。系统命中边界由原生内容与真实设备回归共同验证，不能以模拟器或 `sendActions` 通过替代真机结论。

验证：去除品牌外层底板后的九键与设备布局 109 项单测通过。iPhone 17 上品牌、表情、皮肤与方案四个按钮的左侧 2%、中心、右侧 98% 各开关一次，移除诊断代码后的完整回归通过。首轮曾在品牌按钮右边缘失败，后续两轮整套回归通过，保留边缘回归防止间歇问题复现。新增语言入口修复后共 117 项相关单测通过，quick、notes 与签名校验通过。最终 App 由真机 UI 测试安装。

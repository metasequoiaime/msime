# Agent Note: Windows 语音浮层隐藏时释放鼠标捕获

Status: implemented

## Problem

Windows 语音浮层的取消和确认按钮按下后会把鼠标捕获到浮层窗口。录音结束、输入法切换或状态更新可能在鼠标按键尚未收到释放消息时隐藏浮层；隐藏路径原来只调用 `ShowWindow(SW_HIDE)`，没有释放捕获。隐藏的浮层因此仍可能成为桌面鼠标事件的目标，表现为其他窗口暂时无法点击，直到切换输入法或其他窗口状态触发系统重新整理输入。

## Decision

所有让浮层停止接收操作的路径都先释放自己的鼠标捕获，再清除按下状态：隐藏浮层、动作按钮被状态更新收起、窗口收到 `WM_CANCELMODE` 或销毁时都调用同一辅助函数。辅助函数只释放仍由该浮层持有的捕获，不干预其他窗口的捕获；释放操作先于状态清除，确保同步投递的 `WM_CAPTURECHANGED` 不会留下错误状态。

回归测试在现有 Windows Server smoke 中直接发送合成的按钮按下消息，确认浮层取得捕获，然后分别走“动作消失”和“隐藏”路径，断言捕获已归还。测试不包含真实用户输入或账号数据。

## Alternatives considered

- **只在按钮抬起时释放捕获**：无法覆盖录音结束或焦点变化导致的中途隐藏，正是本 issue 的触发条件，因此不采用。
- **仅在 `WM_CAPTURECHANGED` 中清除布尔状态**：该消息只会在系统已经交还捕获后到达，不能主动交还仍被隐藏窗口持有的捕获，因此不采用。

## Consequences

动作按钮在状态切换或浮层隐藏期间不会把桌面鼠标事件留在不可见窗口上；正常的按钮抬起和其他窗口捕获行为保持不变。新增的 smoke 断言覆盖两个隐藏入口，但未在本机 Windows 桌面或报告者的预览版环境运行，需由 Windows CI 和报告者复验周期性触发场景。

# Agent Note: 跟踪 Windows 安装后中文输入复测

Status: proposed

## Problem

`#11668` 报告 Windows 11 26H2 安装预览版后，输入源菜单能看到水杉，但切换后只能输入英文，无法进入中文组字。报告者随后确认图标可见，症状仍是只能输入英文字母。现有报告没有给出可复现的构建号、输入源 profile 状态或诊断事件。

## Proposal

建立独立 Draft PR 跟踪报告者在包含 `#11669` 的 Windows 构建上复测。`#11669` 已修复重装后当前用户输入法 profile 未真正启用的问题，但还没有证据证明它覆盖本 issue 的现场。复测需要记录构建号、输入源菜单状态、合成拼音是否出现候选，以及去除私人信息的诊断摘要。若复测后仍只能输入英文，再在本 PR 中加入针对剩余路径的最小修复和回归测试。

## Alternatives considered

- **直接复制 `#11669` 的 profile 修复代码**：最强理由是两个 issue 的症状相似，但该修复已经合入，重复提交会掩盖本 issue 是否属于同一根因，因此不采用。
- **现在关闭 issue**：最强理由是已有相似修复，但报告者尚未在包含该修复的构建上复测，不能把相似症状当成验证结果，因此不采用。

## Acceptance criteria

- 报告者在包含 `#11669` 的构建上确认中文候选可出现，或提供复测后的新诊断证据。
- 若仍有故障，在本 PR 中加入对应代码、行为回归和实际 Windows 验收记录。

## Risks

当前 PR 只有调查记录，不宣称已经修复报告者环境。过早修改共享 Windows 输入源生命周期可能重新影响其他 TSF 宿主。

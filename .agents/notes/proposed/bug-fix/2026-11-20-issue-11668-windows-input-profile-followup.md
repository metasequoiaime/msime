# Agent Note: 跟踪 Windows 安装后中文输入复测

Status: proposed

## Problem

`#11668` 报告在 Windows 11 专业版 26H2 上安装水杉 0.6 预览版后，切换到水杉无法输入中文，多次卸载重装仍然如此。报告者随后补充截图，确认输入源菜单里能看到水杉图标，但切换后只能输入英文字母，无法进入中文组字。现有报告没有给出具体构建号、输入源 profile 状态或诊断事件。

症状与 `#11657`（输入源可见、实际仍由系统输入法处理）一致。`#11669` 修复了升级或重装后当前用户输入法 profile 没有真正启用的问题，已合入 `develop`，`#11657` 随之关闭；`windows-v0.6.1` 是第一个包含 `#11669` 的 Windows 发布。报告者使用的 0.6 早于这次修复。维护者已在 issue 中请报告者安装包含 `#11669` 的构建后复测，并在仍有问题时补充构建号、输入源菜单状态和不含真实输入的诊断摘要；截至 2026-11-22，issue 中还没有报告者在新构建上的复测结果，因此没有证据证明 `#11669` 覆盖本 issue 的现场。

## Proposal

维护者决定把这份 proposed note 合入 `develop`，作为 `#11668` 的跟踪记录。复测需要记录构建号、输入源菜单状态、合成拼音是否出现候选，以及去除私人信息的诊断摘要。若报告者在包含 `#11669` 的构建（`windows-v0.6.1` 或更新）上复测后仍只能输入英文，再另开 PR 加入针对剩余路径的最小修复和回归测试，并在该 PR 中写 `Fixes #11668`。

## Alternatives considered

- **直接复制 `#11669` 的 profile 修复代码**：最强理由是两个 issue 的症状相似，但该修复已经合入，重复提交会掩盖本 issue 是否属于同一根因，因此不采用。
- **现在关闭 issue**：最强理由是已有相似修复，但报告者尚未在包含该修复的构建上复测，不能把相似症状当成验证结果，因此不采用。
- **保持 Draft，等复测后在同一 PR 中加入修复**：最强理由是调查记录和修复放在一起便于审阅，但跟踪记录会一直游离在 `develop` 之外，主干上也看不到这条待复测的线索，因此不采用。

## Acceptance criteria

- 报告者在包含 `#11669` 的构建上确认中文候选可出现，或提供复测后的新诊断证据。
- 若仍有故障，在单独的修复 PR 中加入对应代码、行为回归和实际 Windows 验收记录，该 PR 写 `Fixes #11668`。

## Risks

本 note 只是调查记录，不宣称已经修复报告者环境。过早修改共享 Windows 输入源生命周期可能重新影响其他 TSF 宿主。若报告者一直不复测，issue 会长期缺少可执行信息，届时需要维护者决定是否按现有证据关闭。

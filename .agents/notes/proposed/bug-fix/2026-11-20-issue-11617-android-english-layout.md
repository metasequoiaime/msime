# Agent Note: 跟踪 Android 英文 26 键布局复测

Status: proposed

## Problem

`#11617` 的报告包含两个现象。键盘底栏在 0.8.0 已修正系统零高度占位误判后恢复显示，报告者确认可以关闭它。中文输入模式下 26 键样式也已在当前 develop 的 API 35 模拟器中验证生效，剩余现象是英文模式仍使用标准英文底行，不能随中文 26 键样式切换。

## Proposal

建立独立 Draft PR 跟踪英文模式 26 键布局是否需要与中文布局共享样式设置。先在 0.8.3 真机中文和英文模式分别选择四种布局，记录完整构建号、设备型号和键面结果。若产品范围确认英文模式也应跟随设置，再在本 PR 实现共享状态和定向设备回归，不改变中文模式已经生效的行为。

## Alternatives considered

- **直接让英文键盘跟随中文 26 键样式**：最强理由是能消除报告截图中的视觉差异，但英文键盘可能有独立布局契约，未经产品范围确认会改变现有英文输入手感，因此不采用。
- **恢复旧版本隐藏底栏的行为**：最强理由是可以让升级后的画面接近报告者旧版本，但会撤销 `#11322` 修复并重新隐藏可用的键盘底栏，因此不采用。

## Acceptance criteria

- 完成报告者设备上的中文、英文模式四种布局复测。
- 明确英文模式是否应消费中文 26 键样式设置。
- 若确认需要，加入 Android 逻辑回归、设备冒烟和设置兼容说明。

## Risks

当前 PR 只有范围和复测记录，不宣称英文键盘布局已经修复。未经产品确认的共享布局改动会影响已有英文用户。

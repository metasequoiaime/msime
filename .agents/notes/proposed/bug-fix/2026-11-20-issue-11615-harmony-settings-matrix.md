# Agent Note: 跟踪 HarmonyOS 设置与键盘状态对齐

Status: proposed

## Problem

`#11615` 报告 HarmonyOS 设置中的方案、键盘布局、工具栏按钮、振动和标点选项没有体现在正在显示的键盘中。代码调查表明这不是一个单一状态字段故障，语言方案、外观快照、候选翻页、多行组字、窗口切换、皮肤导入和设置保存后的同步分别由多个行为 PR 处理。

## Proposal

建立独立 Draft PR 作为 issue 的总跟踪入口，列出各独立行为 PR 和未完成的 HAP、签名设备及 Mate 80 Pro Max 真实验收。继续保持一个行为一个代码 PR，新的未覆盖设置字段另开独立 PR，不在本 PR 合并重复实现。

当前关联切片包括 `#11640`、`#11635`、`#11633`、`#11632`、`#11649`、`#11634`、`#11636` 和 `#11638`。这些 PR 的静态检查或合成测试不能替代报告设备上的 HAP 安装与键盘验收。

## Alternatives considered

- **把所有设置字段集中改进一个 HarmonyOS PR**：最强理由是能一次覆盖报告中的多个现象，但会违反一个 issue 一个 PR 的边界，也无法按字段隔离设备回归，因此不采用。
- **依据模拟器和 ArkTS 测试关闭总 issue**：最强理由是现有测试能覆盖部分状态链路，但报告设备和签名 HAP 尚未验收，不能把合成证据当作现场结论，因此不采用。

## Acceptance criteria

- 每个关联 PR 完成适用的 HAP 构建和签名设备验收。
- 报告者在 Mate 80 Pro Max 的 HarmonyOS 7.0.0.111 上确认方案和键盘设置按选择生效。
- 发现新的未覆盖字段时，建立只对应该字段的独立 PR。

## Risks

当前 PR 只提供总跟踪，不宣称已经修复所有设置字段。把不同状态链路合并会让缺陷定位和回滚边界不清楚。

# Agent Note: 跟踪 macOS 输入源变灰复测

Status: proposed

## Problem

`#11464` 报告 macOS 26.7.1、水杉 0.59.4 下输入法偶尔变灰，无法切换或重新加入。当前 develop 已包含 `#11231` 的进程退出收尾修复，但没有报告者环境的最新构建复测和输入源状态证据。

## Proposal

建立独立 Draft PR 跟踪包含 `#11231` 的 nightly 或预览版复测。记录双拼和五笔是否同时变灰、复现前后是否发生输入法进程重启，以及 `check_input_source.swift` 的注册和启用状态或脱敏诊断时间点。若最新构建仍复现，再在本 PR 加入针对 `imklaunchagent` 或输入源注册路径的最小修复和回归测试。

## Alternatives considered

- **重复提交 `#11231` 的退出收尾改动**：最强理由是报告症状与输入法被系统置灰相似，但该修复已经进入报告版本，重复提交无法证明覆盖本 issue，因此不采用。
- **直接重置所有输入源启用状态**：最强理由是可以让图标重新出现，但会改变用户的输入源选择并掩盖进程崩溃根因，因此不采用。

## Acceptance criteria

- 完成包含 `#11231` 的最新构建复测并收集输入源状态。
- 若仍复现，明确责任路径并加入 macOS 宿主回归和实际编辑器验收。

## Risks

当前 PR 只有调查记录，不宣称输入源变灰已修复。未经现场证据的注册表改动可能影响用户输入源配置。

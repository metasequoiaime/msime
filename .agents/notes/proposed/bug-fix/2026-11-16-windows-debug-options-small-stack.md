# Agent Note: Windows 调试宿主配置解析适配系统编辑器的小栈

Status: proposed

## Problem

Windows 真实编辑器验收中，512 KiB 主线程栈的系统记事本加载同源调试版宿主库后，在 `HostOptions` / `Preferences` 的 serde 反序列化路径退出。改前与改后原生 TIP 均复现；WER 记录分别落在 serde 访问者与 `___chkstk_ms`。不能把找不到编辑器窗口当成焦点问题，也不能通过扩大系统编辑器的栈或删减完整偏好绕过。

## Proposal

先在子进程内以完整出厂偏好和 512 KiB 工作线程重现。拟仅对 `msime-host-api` 的 dev profile 开启一级优化，让宿主 ABI 的泛型反序列化避免未优化的大量栈临时值；保持调试断言、溢出检查、发布配置、设置默认值与宿主线程模型。

## Alternatives considered

- 在专用大栈线程创建会话，最强理由是能明确预留足够栈。暂不选：宿主会话注册表具有线程归属，把创建移到临时工作线程会改变既有契约；只转移反序列化也给每次配置解析增加线程与等待。
- 只换 release 库，最强理由是发布构建本来就优化。不选：仓库也用 dev 构建进行本机安装，不能留下同一开发构建在系统编辑器启动即崩溃的问题。

## Acceptance criteria

- 原配置的小栈子进程确实失败，保留原退出码；修复后同一完整偏好与非法 edition 检查通过。
- 只改变 dev profile 中这个包的优化级别，保留原有断言和输入。
- 用最终同源库在未改栈大小的真实系统记事本复验；没有完成前不记作设备通过。

## Risks

这个包的 dev 编译可能变慢；优化后的栈用量仍要在真实 Windows 进程里确认。原始 dump 和日志只在本地保留，公开材料不包含私人配置或路径。

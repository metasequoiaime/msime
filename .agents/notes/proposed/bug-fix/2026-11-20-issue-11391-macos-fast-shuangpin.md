# Agent Note: 调查 macOS 快速双拼输入异常

Status: proposed

## Problem

`#11391` 报告 macOS 26.6、水杉 0.59.4、微软双拼下快速输入时字母被错误分词、进入英文候选或候选窗口不显示。现有报告没有最小按键串、异常时预编辑文本、编辑器和输入源切换上下文，无法区分会话方案读取、输入源上下文重置和候选窗口重绘问题。

## Proposal

建立独立 Draft PR 收集合成复现证据。需要记录具体按键串、异常预编辑文本、编辑器类型、是否刚从其他输入源切回、是否使用 Caps Lock/Fn/Shift，以及当前 develop 或 nightly 是否仍复现。必要时启用诊断日志，仅保留按键延迟、候选窗口状态和输入源状态行。确认根因后在本 PR 加入最小修复和 macOS 回归测试。

## Alternatives considered

- **直接扩大双拼按键超时或修改分词规则**：最强理由是可能缓解快速输入，但会改变所有用户的组字边界，且没有复现按键串支撑，因此不采用。
- **回退现有输入源上下文修复**：最强理由是 issue 可能与切换输入源后的会话状态有关，但回退会重新引入已修复的跨输入源问题，因此不采用。

## Acceptance criteria

- 获得最小合成按键串和受影响编辑器信息。
- 在当前 develop 或 nightly 上确认是否仍复现。
- 根因明确后加入 macOS 宿主回归和真实编辑器验收记录。

## Risks

当前 PR 只有调查记录，不宣称快速输入问题已修复。未经复现的超时或分词改动会影响所有双拼用户。

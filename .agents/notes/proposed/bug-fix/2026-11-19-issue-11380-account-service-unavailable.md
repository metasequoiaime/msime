# Agent Note: #11380 macOS 账号与同步服务调查

Status: proposed

## Problem

#11380 报告 macOS 0.59.4 打开设置中的“账号与同步”时服务不可用，报告只附了一张截图，没有完整构建号和 macOS 版本。维护者核对截图后确认：设置页已显示“水杉账号已登录”，但账号页、设置同步和 QQ 群助手同时显示“账号服务暂不可用，请稍后再试”。这条提示由账号 Rust 服务统一返回，仅凭截图无法区分网络请求失败、账号服务 5xx、令牌刷新失败，还是设置应用与输入法会话不一致。

维护者在 2026-11-13 的评论中请报告者补充五项信息：0.59.4 完整构建号和 macOS 版本、点击“重试”后的结果、账号页能否打开昵称/退出登录、换用其他网络（如手机热点）是否相同、“维护与诊断”中删掉令牌邮箱等私人信息后的账号诊断日志。截至 2026-11-22，issue 评论区只有维护者的两条评论（上面这条请求和 2026-11-19 关联跟踪 PR #11685 的说明），报告者尚未补充其中任何一项；也没有其他 PR 引用 #11380，未找到重复 issue。

报告者在期望结果里另提了“macOS 端也提供 WebDAV”，这是独立的功能请求，不在本调查范围内。

## Proposal

本笔记作为 #11380 的跟踪记录落在 develop 上，记录账号错误阶段的调查边界，本身不改产品代码。拿到上述构建号、重试结果、账号页状态、网络对照和诊断摘要并确认失败阶段后，另开 PR（正文写 `Fixes #11380`）加入对应的错误处理或诊断，并补回归测试。证据不足前不凭截图改统一错误提示或重试逻辑。

## Alternatives considered

- 直接修改统一的“账号服务暂不可用”提示或增加重试：无法区分服务端、网络和本地会话故障，可能掩盖真实错误。
- 让跟踪 PR #11685 一直保持 Draft、等证据到齐再在同一 PR 里加修复：跟踪记录长期不进 develop，其他人看不到调查边界；维护者决定先把笔记合入作为跟踪记录，修复单独提 PR。

## Acceptance criteria

- 明确失败发生在网络请求、服务端响应、令牌刷新还是本地会话绑定。
- 修复 PR 带服务层或宿主回归测试，并通过 macOS 验收。

## Risks

未经区分的账号错误改动可能让登录状态、同步设置或隐私边界出现错误提示。报告者若一直不补充信息，本笔记会停留在 proposed，需要在 issue 关闭时同步处理。

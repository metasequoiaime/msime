# Agent Note: #11380 macOS 账号与同步服务调查

Status: proposed

## Problem

#11380 报告 macOS 0.59.4 账号与同步服务不可用，但截图只显示统一错误提示，无法区分网络、服务端错误、令牌刷新或设置应用与输入法会话不一致。

## Proposal

将本 issue 作为 Draft PR 跟踪账号错误阶段的最小复现。需要完整构建号、重试结果、账号页昵称/退出登录状态、网络对照和删除令牌邮箱等私人信息后的账号诊断摘要。确认具体错误阶段后，在本 PR 加入对应错误处理或诊断回归；证据不足时保持 Draft。

## Alternatives considered

- 直接修改统一“账号服务不可用”提示或增加重试：无法区分服务端、网络和本地会话故障，可能掩盖真实错误。

## Acceptance criteria

- 明确失败发生在网络请求、服务端响应、令牌刷新还是本地会话绑定。
- 修复有服务层或宿主回归测试，并通过适用平台验收。

## Risks

未经区分的账号错误改动可能让登录状态、同步设置或隐私边界出现错误提示。

# Agent Note: 调查 iOS 键盘界面重叠

Status: proposed

## Problem

`#11157` 报告 iOS 27.2、iPhone17,1 上水杉键盘偶尔与另一层输入法界面重叠。现有截图无法区分键盘扩展高度没有收回、宿主没有结束上一段 `inputView`，还是聊天应用自身的消息预览叠加。

## Proposal

建立独立 Draft PR 跟踪最新 nightly 的最小复测。记录发生问题的 App 及版本、是否切换过输入法或打开系统面板、收起再唤起是否恢复、构建号和不含真实聊天内容的截图。确认责任路径后，再在本 PR 加入键盘扩展生命周期修复和 iOS 模拟器或真机回归。

## Alternatives considered

- **直接调整键盘扩展高度或强制结束 `inputView`**：最强理由是可能消除截图中的重叠，但没有宿主和生命周期证据，容易破坏其他编辑器的键盘切换，因此不采用。
- **依据截图认定是水杉界面绘制错误**：最强理由是截图能看到重叠，但无法排除宿主应用叠加层，因此不采用。

## Acceptance criteria

- 获得最新 nightly 的最小复现和具体宿主信息。
- 确认重叠来自键盘扩展生命周期后，加入对应代码、回归测试和真实设备验收。

## Risks

当前 PR 只有调查记录，不宣称已修复报告者的 iOS 环境。未经定位的窗口尺寸改动可能影响所有 iOS 编辑器。

# Agent Note: #11592 macOS 输入法失效调查

Status: proposed

## Problem

#11592 报告 macOS 27.2.1 上输入法不定时失效且无法切换，但没有构建号、受影响编辑器、输入源状态或诊断事件。当前代码同时包含 IMK 会话生命周期、输入源注册和失效恢复路径，缺少复现信息时无法判断责任边界。

## Proposal

将本 issue 作为 Draft PR 跟踪证据收集。先记录具体构建号、输入源菜单状态、系统输入法对照、受影响 App，以及删去输入内容和私人路径的 `focus_in`、`keyboard_loaded`、输入源切换日志。拿到复现路径后，在本 PR 加入针对对应生命周期的修复和回归测试；当前不改重启或重注册逻辑。

## Alternatives considered

- 无条件重启输入法或重新注册输入源：可能掩盖 IMK 客户端、输入源状态或宿主崩溃的真实原因，且会影响所有 macOS 用户。

## Acceptance criteria

- 报告者提供可定位到会话生命周期、输入源注册或特定宿主的最小复现。
- 修复覆盖该路径并有 macOS 回归测试及适用构建验收。

## Risks

未经复现的恢复逻辑可能破坏正在进行的组字、输入源选择或其他 App 的 IMK 会话。

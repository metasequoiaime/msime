# Agent Note: Android 中文数字九宫格临时随机排列

Status: proposed

## Problem

#10254 希望按需打乱中文数字九宫格，点击数字后再次打乱。工具栏设置只控制入口是否可见，不能等同于开启随机功能；离开数字页仍保留开关状态，但不应在拼音页继续计算随机排列。英文数字页保持原有布局。

## Proposal

Android 本地设置增加默认关闭的「随机数字」工具栏入口，沿既有排序、预览与尺寸规则显示「随」。运行时开关只属于输入法服务，点击仅切换高亮，不自动切页。中文数字九宫格启用时对 0–9 做 Fisher–Yates 排列，数字按其当前键面原样上屏后重新排列；符号、退格、空格与回车的位置和动作保持。离开九宫格保留开关与上次排列，不取新随机数；关闭时恢复标准键序，英文页不显示该入口且不应用排列。

## Related notes audit

检索活跃笔记中的「随机数字」「打乱数字」没有已有决定。[工具栏按钮排列](../../implemented/feature/2026-10-15-android-toolbar-order.md)的稳定身份和缺项补尾规则继续沿用；[中文默认数字九宫格](../../implemented/feature/2026-10-15-mobile-default-number-pad.md)的数字上屏、底行 0 与统计身份继续沿用；侧边数字键盘与语音启动不改变。

## Alternatives considered

- 把随机开关保存到共享偏好：可以跨服务重启保留，但本需求的设置项只是入口可见性，自动恢复开启会改变普通数字输入，先限定为用户本次服务内主动选择。
- 每次 render 都打乱：实现简单，但换肤、候选刷新与按压重画也会搬动键位，离开数字页仍有额外计算，不采用。

## Acceptance criteria

默认入口关闭；设置打开仅显示「随」且不跳页；点击后只有中文数字页重排，0–9 完整且不重复，每次数字上屏后重排，其他键保持；离开数字页保持开启，关闭恢复，英文页保持固定。JVM 排列不变量与真实专用模拟器入口、按键上屏通过，quick、notes 及 PR CI 通过。

## Risks

重排不能在按压释放之前重建整个键区，否则可能丢失事件或误触。仅更新数字键的标签、无障碍描述与对应动作，避免改变其他键和键盘高度。随机排列用于用户选择的输入体验，不作为抵御录屏等攻击的安全承诺。

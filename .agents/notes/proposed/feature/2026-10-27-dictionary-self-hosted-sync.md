# Agent Note: 自建存储个人词库同步方案

Status: proposed

## Problem

#9880 要求在多个平台之间同步个人词库，并明确需要先评估 WebDAV、OneDrive 或 S3 中的一种或多种后端，定义同步对象、冲突合并、删除传播和凭据保管。现有账号云词库和云剪贴板自建中继都不等价：前者绑定水杉账号，后者只保存端到端加密剪贴板，不提供个人词库的离线合并语义。

## Proposal

首版只支持 WebDAV，个人词库仍由本机 Engine 和维护锁负责读写；同步层只传输有界的操作记录，不直接让远端覆盖正在使用的数据库。

- **同步对象**：用户词条、编码、权重、词库类别和删除标记；不上传主词典、模型、皮肤、剪贴板、输入内容日志或凭据。导入词库先在本机展开成同一批操作。
- **记录格式**：每条操作有随机 `operation_id`、词库标识、词条键、值、权重、操作类型、设备标识和单调序列；删除使用墓碑，直到所有已登记设备确认游标后才可压缩。远端只保存版本化的追加记录和设备游标，不能按文件名替换本地数据库。
- **冲突规则**：同一 `(词库, key, value)` 的新增或修改按 `(logical_time, device_id, operation_id)` 稳定排序，最后一条生效；删除与修改使用同一排序键，较新的操作胜出。不同词条并行合并。发生冲突时本机生成合成值测试所需的可审计状态，但不把冲突文本发送到诊断日志。
- **应用时机**：拉取和合并在后台进行；真正写入前取得现有词库维护锁，复用 `QuiescedHosts`，批量提交后刷新当前会话。锁忙只返回 `dictionary_busy`，不在输入线程等待网络。
- **凭据**：WebDAV 地址可进入共享偏好，用户名和密码只进各平台已有的安全凭据存储，不进设置导出、账号同步、诊断包或同步记录。Android 使用 Android Keystore，桌面使用平台钥匙串/凭据管理器。
- **后端边界**：共享层定义无网络的同步状态和操作格式；WebDAV 驱动只负责 HTTPS、认证、分块上传/下载和响应大小限制。S3、OneDrive 与剪贴板中继保持独立适配器，不在首版混入。

## Alternatives considered

- **直接同步现有词库数据库或 Rime `sync` 目录**：实现最快，但数据库版本、并发写入和删除传播都不可控，跨平台无法保证回滚，拒绝。
- **复用水杉账号云词库 API**：已有认证和分页代码，但违背用户自建存储的需求，也会把未授权的词库内容发送到水杉服务，拒绝。
- **首版同时支持 WebDAV、S3、OneDrive**：覆盖面更大，但会把认证、重试和错误语义同时扩散到所有宿主；先用 WebDAV 固化无网络契约，再增加适配器。

## Acceptance criteria

- 合成词条在两台设备上分别新增、修改、删除，离线交错后最终得到相同结果。
- 同一词条并发修改和删除按稳定排序合并，重放操作不重复写入。
- 输入会话持锁时同步返回 `dictionary_busy` 或延期，不阻塞输入线程；同步失败不破坏本地词库。
- 凭据不会出现在设置导出、账号同步、诊断包、日志或远端操作记录中。
- WebDAV 响应、单条操作、批次和本地队列均有明确大小上限，并覆盖断网、认证失败、远端回滚和重复提交测试。

## Risks

操作墓碑需要设备游标和压缩协议，首版不能随意删除远端历史；设备丢失或长期离线会增加存储。不同平台的安全存储能力不一致，必须让凭据适配器在不支持安全存储时拒绝保存，而不是降级成明文。

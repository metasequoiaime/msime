# Agent Note: 自建存储个人词库同步方案

Status: proposed

## Problem

#9880 要求在多个平台之间通过自选存储同步个人词库，先评估 WebDAV、OneDrive 或 S3，明确同步对象、冲突合并、删除传播和凭据保管。现有账号云词库绑定水杉账号；已有的 [WebDAV 云剪贴板](../../implemented/feature/2026-10-26-cloud-clipboard-webdav.md)和自建中继处理加密剪贴板，不提供个人词库的离线合并语义，不能把它们当作词库同步已经实现。

## Proposal

首版评估 WebDAV，S3、OneDrive 留作后续独立适配器。个人词库仍由本机 Engine 和维护流程负责读写；同步层只传输有界操作，不直接用远端文件覆盖使用中的数据库。本篇确定需求和待决边界，不把尚未定案的字段与排序规则称为可互操作协议。

- **同步对象**：候选范围为用户词条、编码、权重、词库类别和删除标记；不上传主词典、模型、皮肤、剪贴板、输入日志或凭据。实施前区分个人学习词、显式新增词和命名集合的身份与所有权，确定导入、改编码或改词条内容应产生哪些操作。
- **操作记录**：拟采用随机 `operation_id`、稳定词库标识、词条键和值、权重、操作类型、设备标识、设备序号和删除墓碑；远端只保存版本化的操作与必要检查点。记录、时钟、确认和压缩的完整契约见下列待决项，不能据此直接宣称已具备离线收敛。
- **应用时机**：网络拉取和校验在后台完成，不跨网络请求持有词库维护权。写入接各平台已有队列和有界 Engine 批次；桌面可参考 `QuiescedHosts`，但它遇忙会请求宿主释放输入会话，并以 50 毫秒间隔在 2500 毫秒预算内重试，租约有效期为 30 秒，不是立即只返回 `dictionary_busy`。该阻塞流程必须在工作线程调用；自动同步何时允许请求会话退出、何时只保留队列延期，以及应用后的会话重建或刷新，仍须按平台定案。
- **凭据**：既有 WebDAV 偏好凭据的脱敏、导出过滤与账号安全存储不等于各平台已有可直接复用的自建同步安全凭据适配器。本方案要求新增或明确复用的适配契约、能力检测及失败语义；不支持时拒绝保存，不降级。用户名、密码不进设置导出、账号同步、诊断、日志或操作记录；地址是否为本机配置及其导出边界一并定案。
- **后端边界**：共享层定义无网络的状态与操作格式，WebDAV 传输负责 HTTPS、认证和有界读写。已有剪贴板 WebDAV 的独占发布与能力探测可供参考，但不复用其条目语义或存储命名空间；不能假设所有服务都可靠支持条件 `PUT`。

### 落地前必须定案

- **时钟与冲突**：若保留 `(logical_time, device_id, operation_id)` 排序，必须把 `logical_time` 纳入记录格式，定义本地生成、接收后的推进、持久化、重装或设备身份更新、溢出及非法记录处理；设备本地单调序号不能直接当跨设备时间。词条身份规范化、修改与删除的排序和并发结果需给出合成示例。
- **发布与恢复**：确定不可变操作的路径、独占发布条件、重复操作判定、远端回滚检测和格式版本协商；定义本机应用、去重回执与游标落盘的顺序，防止崩溃后漏用或重复应用。必须写出响应、操作、批次和队列的具体上限。
- **设备与压缩**：定义设备登记、退出或丢失、确认游标的因果范围及墓碑回收条件；明确长期离线设备在历史已压缩后如何重新加入。收到记录不等于已经持久应用，不能提前确认或回收。

## Alternatives considered

- **直接同步数据库或 Rime `sync` 目录**：可复用现成文件同步工具，但数据库版本、并发使用和删除传播无法因此获得一致契约，不作为首版路径。
- **复用水杉账号云词库 API**：已有认证和分页代码，但不能满足用户自选存储，也不能把个人词库自动改发到账号服务。
- **首版同时支持 WebDAV、S3、OneDrive**：覆盖面更大，但会同时扩散认证、发布、重试和错误语义；先评估一个后端，协议定案后再扩展。

## Acceptance criteria

- 先补齐上述协议及各平台维护、凭据能力表，再进入实现；合成设备分别新增、改编码、修改权重和删除，离线交错及重复重放后得到已定义的同一结果。
- 覆盖并发修改与删除、时钟恢复、设备退出、压缩后旧设备重连，以及本机提交与游标落盘之间崩溃重试；不得只验证最后列表相同。
- 输入会话持锁时按已定的平台策略延期或在维护预算内退出会话后重试，不能在输入线程等待网络；失败保持本机词库与待处理队列可恢复。
- 不支持安全凭据适配时拒绝保存；凭据不出现在导出、账号同步、诊断、日志或远端记录中。
- 按具体上限验证认证失败、超大响应、发布争用、远端回滚和断网恢复；文档与笔记校验通过不等于上述行为或设备验收已完成。

## Risks

设备退出、墓碑回收和压缩后重新加入尚未定案，不能承诺无限离线仍自动收敛。安全凭据适配与各平台维护策略是实施前置，不是现成的跨平台能力。本提案不改变已有同步、凭据存储或输入默认行为。

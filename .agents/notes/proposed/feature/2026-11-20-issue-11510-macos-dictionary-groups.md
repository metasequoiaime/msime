# Agent Note: 跟踪 macOS 词库分组与批量管理

Status: proposed

## Problem

`#11510` 希望 macOS 词库列表支持自定义分组、按组管理和批量删除。现有反馈没有明确分组与同步、导入、排序和删除事务之间的交互边界。

## Proposal

建立独立 Draft PR 记录 macOS 原生词库页面的产品设计与实现入口。先确定分组模型、词库跨设备同步语义、批量删除的确认和回滚行为，再把共享 Rust 规则、macOS 设置页面和回归测试拆成可独立验证的提交。界面改动在实现 PR 中补改前改后截图。

## Alternatives considered

- **直接在现有列表中加入多选和文件夹控件**：最强理由是改动入口少，但会在没有确认同步和删除语义时锁定数据模型，因此不采用。
- **只在 macOS 本地保存分组**：最强理由是实现简单，但用户的词库在多设备和云端之间会出现分组丢失或分叉，因此不采用。

## Acceptance criteria

- 明确分组的持久化、同步、导入、删除和回滚契约。
- 建立 macOS 原生设置实现和共享业务测试。
- 完成真实设置应用验收并上传界面前后截图。

## Risks

当前 PR 只有设计跟踪，不宣称 macOS 已支持词库分组。未经契约确认的页面改动可能造成用户词库操作不可逆。

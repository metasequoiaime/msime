# Agent Note: 粤语整词与整句的分阶段评估

Status: proposed

## Problem

#10222 要求先评估粤语词库扩充与整句模型，再决定实现。普通话高频词的文字可作为候选词面，但拼音键、逐字粤拼和上下文词频不能直接互换；本次以固定发布库和固定来源做离线分析，不改产品词库或引擎。

## Proposal

先核对当前已授权的 rime-cantonese 字表、词表、essay 与 HKCanCor 词频表，量化保守单读音补词与逐字选最常见读音的覆盖差异；使用已有明确注音词条做一致性对照，报告抽样偏差，不称为独立质量测评。对新增条目的 SQLite 体积做同环境比较。分开给出整词扩充和任意整句组词的能力边界、许可证、验收样例与上线门禁建议。是否实现由评估审阅后决定。

## 固定输入与许可

评估基线是 `dict-v2.0.41` 的 `msime-cantonese.db`，7,237,632 字节，SHA-256 `b6dbfdec9e920ce54dd96d0000655105213458dcf68ea6568a6790938fb6bc0a`，与本仓语言词库锁一致。发布说明区分两个提交：词库源数据 `8e8b7817c91600913625edb7995a7397fbb6899a`，构建器 `09a69f20b4726f75d4aa318975e3e891c1135aaf`；不能把后者当作词库仓提交。实际远端默认分支是 `main`，评估时头为 `fc14db6ee29260fcda2f1f86d5ce38388d7e19ff`，本次采用发布对应的固定源数据，而非邻仓未提交内容。

- rime-cantonese `259f0e48bba840c3a2e0d117539e96937f3d89bc` 的字表、词表与 essay，许可为 [CC BY 4.0](https://github.com/rime/rime-cantonese/blob/259f0e48bba840c3a2e0d117539e96937f3d89bc/LICENSE-CC-BY)。保留 CanCLID 署名、来源、许可及去声调、补注音等修改说明。排除 `maps` 的 ODbL 数据、来源不清的 `phrase` 和未纳入当前锁的 `lettered`。

- 本轮没有引入新的普通话词库来源；优先评估已有授权的 essay 词面。其他普通话词表、社区粤语词表和无许可证参考仓库均未纳入，不能把词面可互用当作再分发授权。

六个输入的 URL、字节数与 SHA-256 在 [`inputs.json`](../../../../tools/cantonese-evaluation/inputs.json)，分析器还核对词库仓 `upstream.lock.json` 与本仓两份锁。当前基线有 139,400 条键／词面记录：31,948 条单字、107,452 条词条，共 133,934 个不同词面。

## 覆盖与注音实验

[`report.json`](../../../../tools/cantonese-evaluation/report.json)是可复现的统计输出，记录具体读音与权重。现有 words 文件有 101,811 个词面，essay 有 246,295 个多汉字词面。按去声调后的字表注音，对照 words 的已标注读音集合：

| 策略 | 可比较词面 | 不匹配词面 | 同源不一致比例 |
| --- | ---: | ---: | ---: |
| 每字只有一个单音节读音才注音 | 41,992 | 382 | 0.9097% |
| 每字选最高读音份额，平局按字典序 | 101,088 | 8,202 | 8.1137% |

这是同源字表和词表的一致性筛查，不是独立错误率，也没有母语者审校。即便单读音方案也存在标注分歧，不能把它当成绝对正确。逐字最常用读音把「銀行」变成 `ngan haang`，已有词条为 `ngan hong`；把「長大」变成 `coeng daai`，已有词条为 `zoeng daai`。「行路」「長度」则与各自词条一致，说明不能按字选一个读音覆盖所有语境。

| 缺词补充门槛（essay 分数） | 缺失词面 | 通过单读音筛选的新条目 | 实验 SQLite 字节 | 对同环境空增量对照的增长 |
| --- | ---: | ---: | ---: | ---: |
| ≥1000（当前门槛） | 5,407 | 0 | 7,249,920 | 0 |
| ≥100 | 160,086 | 68,136 | 10,883,072 | 3,633,152（3.465 MiB） |
| ≥1 | 179,787 | 76,039 | 11,300,864 | 4,050,944（3.863 MiB） |

essay 是排序分数，不是可解释为语料出现次数的原始计数。实验只补基线没有的多汉字词面，要求逐字恰有一个去声调后的单音节读音；不改已有词条、权重和读音。所有 SQLite 副本在 SQLite 3.54.1、4096 字节页的同一环境 ANALYZE、VACUUM，空增量对照比发布原文件多 12,288 字节，因此增长必须相对该对照计算，不能混用两个基线。版本及页大小记录在报告的 `measurement` 中，其他 SQLite 版本可能产生不同的压实体积。这些实验库留在 `target/`，未替换或发布产品资源。

## 两个例子与整句边界

| 合成验收例子 | 期望粤拼 | 基线与实验结论 |
| --- | --- | --- |
| `sxcr` → 上傳 | `soeng cyun` | 基线无词，essay 分数 444；存在多读音字，降低门槛且坚持单读音仍不会补入，需逐词明确注音 |
| `vodanz` → 我打你 | `ngo daa nei` | 基线、essay 和 HKCanCor 词频表均无这个完整词面；仅降低门槛不能补出，整句需组合能力或作为经审校的短语显式收录 |
| 我打／打你 | `ngo daa`／`daa nei` | 基线均无，essay 分数分别为 1173／1，均有多读音限制，不能把缺口只归因于分数门槛 |
| 你好／我哋／食咗 | `nei hou`／`ngo dei`／`sik zo` | 基线已有，作为扩充后不退化的口语与常用词对照 |
| 銀行／行路、長大／長度 | 见上文 | 检查词级多音字，防止新增自动注音挤掉正确词条 |

普通话词面可以复用来提出「哪些词值得补」；拼音编码不能复用为粤拼编码。现有中文 n-gram 的文本统计也不能直接当成粤语口语上下文分布。本轮没有训练粤语模型，未测 `sxcr`、`vodanz` 在新模型上的排序或设备延迟；这里只核对固定库是否含词和字表可否注音。

## 建议路线与体积预算

1. **先做经审校的高频词／短语小批扩充**。复用当前授权的词面，优先覆盖报告例子与口语，逐词写粤拼，不全量取逐字首读音。建议首批不超过 2,000 个新条目、压实增量不超过 512 KiB；这是待审的上线预算，不是已实现结果。完整支持「我打你」可先显式收录该短语，但必须说明还不是任意整句组词。
2. **再做有界的粤语词图组句，先验证词级成本，再决定 n-gram**。任意短句由已有词和单字拼接，需要粤语独立评分、未知词回退和双拼覆盖映射，不能把普通话组句入口简单改为查询另一张表。候选质量先建立母语者确认的开发集及独立盲测集。
3. **n-gram 是后续独立实验，不随本次评估直接上线**。已锁的 HKCanCor 原转写有 58 个会话文件、160,806 个标注；现有二字以上汉字词频表只有 5,102 个词面、36,979 次计数，且丢失句序，不能从这个计数表重建 bigram/trigram。应从原转写按完整会话划分训练／开发／测试，保留分句和读音，不随机拆同一会话的相邻句。语料是 1997–98 年香港对话，现代网络和软件词的质量仍需另测。建议模型作为独立可选资源，压缩下载增量上限 8 MiB；上线还要求真实低端设备的峰值内存和首候选 p95 不超预先确定的预算。本轮未训练，8 MiB 只是资源预算，不是模型大小实测，也不承诺单靠该语料能满足质量要求。

实施前的质量门槛建议：报告例子进开发集；另取至少 200 个未参与挑词的词面／短句，由粤语母语者固定读音与可接受候选，分口语、多音字、现代术语和未登录词报告 top-1、top-5、完整覆盖率及平均改选次数；基线已有正确词不得被新增误注词挤下首选。独立盲测集不得来自本轮同源一致性表。首批数据、组句实现和模型训练分开审阅，并各自记录来源、体积和设备结果。

## 复现与验证范围

```sh
python3 tools/cantonese-evaluation/evaluate.py --fetch
cmp tools/cantonese-evaluation/report.json target/cantonese-evaluation/results/report.json
```

Python 3.10+，只用标准库。首次 `--fetch` 下载约 13.7 MB 固定公开输入并验证摘要；已有输入时离线运行同样校验。脚本在输出目录产生三个实验 SQLite 与 JSON，不改发布锁或原始输入。重复运行 JSON 相同；空增量对照必须没有新增条目。此验证覆盖离线数据与 SQLite 体积，不覆盖模型质量、母语者审校或真实编辑器输入。

## Alternatives considered

- 全量把普通话词表逐字转粤拼：复用词面和高频排名，覆盖增长快；同源对照中逐字最高份额读音已有 8.1137% 的词面不匹配明确注音，不能据此自动发布全量结果，也不能把普通话词频当粤语句子频率。
- 只降低单读音补词门槛：不需要新训练流程，读音歧义比逐字首读音少；门槛降到 100 时增加 68,136 条和约 3.465 MiB，仍不能覆盖两个目标例子，因此不作为首批路线。
- 直接上粤语 n-gram：可以组合库中不存在的整句；现有词频表已丢句序，原转写规模有限，尚未完成训练和独立盲测。先以审校词表和有界词图建立基线，再判断模型带来的增益。

## Acceptance criteria

来源与固定提交、数据文件 SHA-256、许可证和排除项可追溯；量化基线、补词覆盖与体积；明确 `sxcr`、`vodanz` 等例子的现状和目标，区分词面复用、注音和整句排序；所有结论标明实测或建议，不声称未做的原生设备验收或独立粤语专家审校。

## Risks

同源字表与词表的一致性不能代表真实错误率；体积实验不能当作未来模型大小或移动性能实测。缺少明确再分发授权的第三方词表不进入实验产物或产品。

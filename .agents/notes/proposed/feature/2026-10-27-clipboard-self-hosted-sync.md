# Agent Note: 自建存储云剪贴板同步方案

Status: proposed

## Problem

#9989 希望在 Windows、Android、Linux 等设备间同步常用词库和剪贴板，并提出 WebDAV、S3 或自建服务器。仓库已经实现账号云剪贴板、自建 HTTP 中继和 [WebDAV 虚拟中继](../../implemented/feature/2026-10-26-cloud-clipboard-webdav.md)。WebDAV 已有设备批准、端到端加密、不可变事件、压缩和回滚检测；不能把它描述为尚未实现的后端。本篇记录现有文本同步之外的待评估扩展，不改变现行协议。

## Proposal

自建云条目继续限于用户明确发送的内容，不自动上传全部本机历史。[文本加密 v1](../../../../docs/cloud-clipboard-e2e.md)与 [WebDAV 存储布局 v1](../../../../docs/cloud-clipboard-webdav.md)是既有契约：当前驱动的新增操作只有文本，明文上限为 4000 个 UTF-16 单元，现行列表上限为 50 条。S3、图片及离线合并扩展需要另行定案，不能写成只更换存储驱动就已支持。

- **对象范围**：保留当前文本、置顶和保留期语义。本机历史、应用来源和窗口信息不因扩展自动上传。图片、内容版本和墓碑是待评估的新能力，不是既有信封已经支持的字段。
- **加密与元数据**：沿用现有设备批准与密钥建立的边界；既有威胁模型允许服务端看到条目数量、写入时间、置顶状态和设备信息等元数据，不能承诺服务端只见版本、大小、随机名字与密文。新增内容及控制字段是否加密或认证，须随格式扩展明确；导出、诊断和日志不包含密钥、凭据或正文。
- **凭据前置**：现有配置的凭据过滤与账号安全存储，不能直接等同于各平台已有可用的自建后端安全凭据适配器。若扩展要求平台安全存储，需先补适配契约、能力检测、失败及既有配置迁移；不支持时拒绝保存，不静默降级。本篇不改变现有配置或密钥存储。
- **复用边界**：既有 `clipboard_log` 是无网络状态核心，`clipboard_webdav::VirtualRelay` 在本机回答现行中继接口；该方案已落地，继续沿用。S3 需单独评估等价的发布、重读和条件竞争能力；不默认把 WebDAV 改成可覆盖清单，也不默认新后端只需列举、读写和删除四类操作。
- **本机并发**：网络一律在后台；WebDAV 缓存和设备状态复用其 `cloud-clipboard-relay.lock`，不是词库维护锁。偏好写入与本机历史分别使用已有锁，涉及两者时保持偏好先于历史的顺序；接收云条目不默认写入本机历史。新队列、检查点与凭据操作的锁顺序和失败恢复须定案。
- **用户选择**：现有账号、HTTP 中继和 WebDAV 选择及数据边界保持原状。新后端不自动搬迁旧条目；首次启用说明发送范围，关闭后保留或删除远端数据由单独确认决定。

### 落地前必须定案

- **身份、时钟与合并**：如扩展引入 `item_id`、`logical_time`、`device_id`、`version_id`，需定义完整记录、逻辑时钟生成和推进、设备恢复、字段级冲突规则及具体大小上限。不能只给出排序元组就称已定义离线一致性。
- **清空的因果范围**：不同设备的本地序号不能直接比较，单个「带设备序号的全局墓碑」不能说明清空覆盖哪些条目。实施前决定清空与并发新增、离线未提交内容、置顶和保留期的关系，再确定表示及重放规则；不在本篇凭空选一种新协议。
- **设备与压缩**：定义设备退出或丢失、确认游标、墓碑回收、压缩后旧设备重连及远端被用户删除后的处理。既有 WebDAV 的 epoch、链头与回滚保护不能在改格式时悄悄丢掉。
- **图片与迁移**：若纳入图片，先定义带类型和大小约束的内容格式、认证范围、上传中断恢复、旧文本客户端行为及存储版本或命名空间迁移；沿用密钥建立不等于沿用文本载荷格式。未完成前不承诺现有 v1 已能同步图片。

## Alternatives considered

- **同步所有本机历史**：可减少手动操作，但会越过现有明确发送的隐私边界，不作为默认行为。
- **重写既有 WebDAV 为单份可覆盖清单**：可以让不同存储看起来更统一，但破坏已发布布局与并发、回滚语义，不在本提案中默认替换。现有虚拟中继是已采用的方案，不列作被否方案。
- **为新后端复制一套独立合并规则**：可让适配器自成一体，但会使设备批准、删除和压缩行为漂移；先明确共同状态契约，再评估传输适配。

## Acceptance criteria

- 先完成上述待决项与兼容策略；既有 WebDAV 文本同步保持协议兼容，合成设备重复拉取或提交不产生重复条目，未发送的本机历史不进入请求。
- 按已定义的因果范围验证离线新增与清空、并发置顶或保留期变更、设备退出、压缩后旧设备重连，以及远端回滚和被删除后的恢复。
- 图片方案定案后另验合成图片、超限拒绝、中断续传及文本旧客户端兼容；不能把既有文本驱动或 WebDAV 测试通过当成图片已实现。
- 安全凭据能力缺失时拒绝保存；正文、凭据、密钥和本机应用来源不进入日志、诊断或设置导出。
- 对新后端验证响应、索引、密文和批次的具体上限、认证失败与发布竞争；文档和笔记门禁不替代后端或设备行为验收。

## Risks

S3、图片格式和新增离线合并仍是未实现的提案，不影响现有 WebDAV 可用性。存储服务的独占发布支持不一致，必须按能力探测和争用验收决定是否支持，不能假设条件请求头在各后端具有相同语义。格式迁移、设备退出和压缩未定案前，不承诺旧设备或旧客户端可无条件加入。

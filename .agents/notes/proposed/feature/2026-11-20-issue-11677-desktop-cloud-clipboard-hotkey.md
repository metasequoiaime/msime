# Agent Note: 跟踪桌面云剪贴板全局快捷键

Status: proposed

## Problem

`#11677` 希望在 macOS、Linux 和 Windows 上通过可配置全局快捷键快速调出云剪贴板。现有反馈没有定义快捷键冲突、输入法焦点、密码框保护和面板打开后的目标编辑器行为。

## Proposal

建立独立 Draft PR 记录桌面三端的快捷键设计入口。先复用共享偏好和现有 `cloud-clipboard` 面板路由，定义冲突检测、启停生命周期、未登录行为、密码框拒绝和面板打开时的焦点归属，再按 macOS、Linux、Windows 宿主分别实现和验证。每个平台保持独立代码切片和真实桌面验收。

## Alternatives considered

- **只注册一个固定快捷键**：最强理由是实现简单，但会与系统和用户应用冲突，也无法满足可配置需求，因此不采用。
- **只在输入法菜单中增加入口**：最强理由是能复用现有菜单，但没有实现 issue 要求的快速全局唤起能力，因此不采用。

## Acceptance criteria

- 共享偏好、冲突校验和路由契约完成。
- macOS、Linux、Windows 分别完成宿主接线、冲突和安全输入保护测试。
- 三端真实桌面验收和界面截图齐全。

## Risks

当前 PR 只有设计跟踪，不宣称三端已有快捷键实现。全局按键处理若没有焦点和密码框边界，可能干扰用户正在使用的应用。

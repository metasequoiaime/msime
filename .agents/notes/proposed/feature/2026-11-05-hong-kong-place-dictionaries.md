# Agent Note: 香港街道与地方名称进入粤拼和普通话词库

Status: proposed

## Problem

[msime#10911](https://github.com/metasequoiaime/msime/issues/10911) 要求把香港街道和地方名称录入词库。维护者在本次任务中确认同时补粤拼和普通话拼音。现有粤拼词表缺少砵典乍街、彌敦道、窩打老道等整词；普通话主表虽有弥敦道，却没有覆盖同一批名称。

## Proposal

名称使用香港特别行政区政府地政总署通过 CSDI 提供的 Road Centreline 和 Place Name 数据。2026-11-05 取得的快照分别有 4,575 条中英文街名组合和 2,826 条地方名称记录；中文名排除空值后合计去重为 6,997 个。这里的数目是原始记录覆盖，不是可输入词条数，不能把它写成验收通过的数量。

- 原始名称、来源和摘要固定在 msime-dictionary；生成器与发布构建接入留在 msime 的 `crates/dict-builder`。不复制邻仓未提交内容。
- 粤拼保留香港繁体字形，普通话按既有拼音库的简体字形输入契约生成。英文街道名称只作核对依据，不直接当作粤拼。
- 读音使用已有的固定字词表和明确的香港地名读音审校表。多音字未消歧、未知字、非汉字和超出引擎可输入长度的记录必须输出待审清单；不能默认取字表第一音后声称已核对。
- 补充表不覆盖既有同键同词的权重。新增地名使用低权重，避免替换日常同音词的首选。
- CSDI 名称仍遵循其原有使用条款，不能把整个派生库继续声明成只有 CC BY 4.0。随库的现有许可证附件补入政府、地政总署与 CSDI 的署名、来源、改动说明和条款；不新增客户端需要下载的附件。

## 历史笔记审计

- [人工审校粤语词表](../../implemented/feature/2026-10-31-cantonese-reviewed-word-list.md)：部分重叠。继续复用逐字音节合法性校验，但批量官方数据不伪装成人工投稿，也不采用投稿默认的 1000 权重。
- [粤语分阶段评估](2026-10-30-cantonese-word-sentence-evaluation.md)：部分重叠。香港地名扩充不等于整体降低 essay 补词门槛。
- [香港字形](../../implemented/feature/2026-10-31-cantonese-hong-kong-forms.md)：部分重叠。官方名称应保留，不顺手翻转全局字形转换规则。

## Alternatives considered

- **复用 Rime 的 `jyut6ping3.maps.dict.yaml`**：现成的 4,000 多条街名表，来源提交与项目正在用的粤拼表一致。但该表从 OpenStreetMap 提取于 2020 年，没有读音、采用独立的 ODbL 许可，而且不能替代官方地方名称集。选择官方当前快照，仍明确处理其署名和许可义务。
- **只追加 issue 中列举的街名到 custom**：能沿用现有导入和验证流程，很快补齐举例。但不能实现要求的香港街道与地名覆盖，也不适合今后重复更新。

## Acceptance criteria

- 固定来源快照和条款，记录原始、去重、可输入、已有、新增和待审数量；每个原始中文名称都能追到明确去向。
- 两种方案都覆盖 issue 列举的街名，以及港岛、九龙、新界、离岛的代表地名；多音字、异体字、已有词和非汉字记录有行为回归测试。
- 用干净的固定词库基线构建两种词库，对比新增条目，确认原有同键同词不被改权。
- 执行相关测试、格式与静态检查、笔记校验和本地 quick 门禁；两个仓库的 PR 互链，说明合入与后续发布顺序。

## Risks

官方数据没有粤拼或普通话读音；通过字表校验只能证明音节是该字的合法读音，不能代替地名的读音核对。现场街牌、历史读法与通用字音有差异时要保留审校证据。非汉字标记、内嵌换行和私用区字不能悄悄删掉后变成另一个地名。

# Agent Note: 单候选模型分数的跨批复用调查

Status: rejected — 单候选缓存没有比整批缓存增加覆盖，且实际出现分数位差

## Problem

九键 16 ms 预算仍未通过。[整批缓存调查](../../rejected/testing/2026-10-23-lattice-column-score-cache.md)只测量有序整批是否相同，不能回答更早批次的单候选是否重复。上游已复用上一批和本批的完整命中，新增缓存不能把这些算成收益。

## Proposal

先在实际静态证据重排调用返回后观察分数，不改变模型调用、候选顺序和状态。按固定模型的真实字符到 token 映射、有效上下文 token 和截断候选 token 模拟 16/64/256/1024 槽 LRU；上下文改变清空，单独统计上一批、本批与更早批次的命中。比较缓存原分与本次分的 `f32::to_bits`，只输出计数、差值和 ULP，不输出文本。回退分支只计调用，不额外运行模型。临时构建用 `finally` 恢复源码，独立二进制和脚本保留哈希。

## Historical audit

[完全命中](../../implemented/bug-fix/2026-10-15-runtime-rerank-complete-cache.md)、[同批前缀](../../implemented/bug-fix/2026-10-15-runtime-same-batch-cache.md)部分相关，保留上游现有完整状态寿命。[状态缓冲](../../implemented/testing/2026-10-16-runtime-rerank-resume-buffer.md)属于容器复用。[整批缓存调查](../../rejected/testing/2026-10-23-lattice-column-score-cache.md)保留否决，本篇补单候选粒度，不翻转列缓存决定。没有完全吸收或过时提案。

## Alternatives considered

- **直接实现标量缓存**：每条占用远小于完整 KV 状态，但可能改变浮点累加历史，跳过评分也使下一批缺少续跑状态；先取证。
- **保存更多 `TailRun`**：既能省完全命中，也能继续扩展；常驻 KV 与隐藏状态显著增大，必须先证明跨批覆盖值得这份成本。
- **沿用现状**：不增加失效和容量策略；如果重复主要已由上游覆盖，或出现不等价评分，则保留现状并记录原因。

## Acceptance criteria

固定来源 `ed24a0a800f026ca5e2ee912603f9c3956136034`、锁定资源代次 `7356c4a452d8ba15475c0e57f134fccf7b7cbe267440461541c74d09b11b6ffe`，完整 81 条、每臂 1791 键与五条预热。报告新增覆盖和位差；探针计时不作性能成绩。只有证据支持才另行确定生产方案和红绿回归、完整质量与性能门槛；否则恢复生产源码，交付可复现调查。笔记、格式、差异与本地 quick 通过后单独 PR，按既有授权合并及清理。

## Risks

`TailRun::joined` 用 `carried + rest`，历史分段可能使同一 token 序列分数末位不同。标量缓存不能简单假定模型是逐位纯函数。探针以指针区分重排器，未观察析构，必须记录实际实例数并限制结论。模型词表从同一已校验资源读取，不修改 Cargo 上游缓存。此轮仅诊断，不能宣称产品加速或 16 ms 达标。

## Rejection evidence

完整公开合成集的两轮诊断均观察到 843 次静态评分、7587 个候选；16/64/256/1024 槽分别命中 0/0/81/504 项。上一批及本批没有完全命中；最大容量只有 56 次整批九项一起命中，没有一至八项命中。与先前整批 128 槽的全部 843 次观察逐次对照，命中位置完全相同。因此该集合未显示单候选粒度增加覆盖；不能据此外推任意输入下都无收益。

1024 槽的一次命中与真实评分相差 1 ULP，最大绝对差为 `4.76837158203125e-7`。这验证了不能默认相同上下文和候选的标量分逐位不变；没有声称该差异造成首选改变，也没有通过额外模型调用改变状态。延迟只属于带大量诊断分配的探针，退出 1 不作产品回退或达标成绩。

本篇不实现生产缓存，也不增加完整状态缓存。详细数据、预热分界、位差的数值位模式、诊断源码、构建恢复与复现方法见[证据目录](../../../../docs/measurements/2026-10-23-model-scalar-score-reuse/README.md)。没有为撤回方案扩大运行质量、端到端 ABBA、完整引擎/golden/runtime 或设备验收；九键 16 ms 目标继续未解决。

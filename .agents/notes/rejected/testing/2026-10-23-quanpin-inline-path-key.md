# Agent Note: 全拼路径缓存短键内联存储

Status: rejected — 三种局部对照均未证明淘汰插入净收益，长键控制回退，全部原型恢复。

## Problem

固定 `e7fa91f121e0b071bddfaa96917f87869e37018e`、公开九键合成集合 81 例及 5 例预热，两臂诊断共有 183332 次路径页未命中、165888 次空页。每次未命中都会复制拥有型路径键，即使没有候选行。该统计包含预热、关闭及开启模型两臂；受系统负载和诊断输出影响，不作为延迟成绩。

## Proposal

只将私有路径缓存的键改为安全 Rust 的短字节数组或长 `String`。短键在节点内保存完整 UTF-8 字节和长度，长键回退拥有型字符串；查找、哈希和相等比较统一使用完整 `[u8]`。容量仍为 128，插入年龄、空页和重插规则不变，不增加共享可变状态或第三方依赖。内联上限为 31 字节。完整诊断中 162834 / 183332 个键（88.82%）落在该范围，超过 31 字节保持堆字符串。阈值从 23 增至 31 字节，每个键枚举预计增加 8 字节，覆盖率由实测键长支持，最终尺寸由测试确认。未命中入口使用借用键插入；首字母展开保留拥有型 `String` 插入接口，测试用同一接口对照旧入口的实际申请。

## Historical audit

检索活跃笔记中的 `SmallString`、内联键、紧凑键及路径缓存，没有相同实现。[前缀组装](../../implemented/testing/2026-10-16-quanpin-prefix-row-stream.md)继续持有热短前缀的行所有权；[首字母局部键](../../implemented/testing/2026-10-14-quanpin-initial-row-key-stack.md)针对另一个行缓存；[淘汰页复用](../../implemented/testing/2026-10-23-quanpin-evicted-page-reuse.md)继续只覆盖外层系列缓存。本次不修改这些决定，无完全吸收或过时提案。

## References

标准库 [Borrow](https://doc.rust-lang.org/std/borrow/trait.Borrow.html) 要求拥有值与借用值的相等和哈希语义一致；实现均转接完整 `[u8]`，查找同样传入 `str::as_bytes()`。固定 [lru 0.18.5](https://docs.rs/lru/0.18.5/lru/struct.LruCache.html) 已通过 `FifoCache` 保持 FIFO，本片不修改其淘汰实现。

## Alternatives considered

- 内联字节再实现 `Borrow<str>`：可直接复用现有字符串查找，但安全转换会反复校验 UTF-8。首轮 63 格配对线程 CPU 试验中多处目标和控制回退，31 字节热读取比为 3.21–3.23。弃用该版本，保留源码及原始结果；完整字节借用无需校验，也不需不安全转换。


- 将现有淘汰页复用扩到路径缓存：已有实现且不增加容量，但完整诊断的 3505616 次页复制申请中只有 62932 次可复用，仅 1072 次查询受益，覆盖率低。保留该实验计数，本片不采用这项扩展。
- 删除或跳过空页缓存：能省掉键存储和大量淘汰，但负结果会再次读库，也改变原 FIFO 契约，不采用。
- 增加缓存容量：能缓解九键大量路径的淘汰，但增加长期候选页存储，不能由本次计数确定合适上限，不采用。
- 新增紧凑字符串依赖：成熟库能提供与 `String` 相同尺寸的内联表示，避免维护自定义布局。后续确实独立比较 `compact_str 0.10.0`，但长键控制回退，故未将依赖加入项目。

## Verification

真实 SQLite 红测退出 101，1 字节空页旧查询 2 次申请，没有满足少一次的预算；首版两个专项转绿，字段、容量和 FIFO 对照通过。原型完整引擎 2517 通过、5 个既有精确申请断言观察到少 1/2 次而失败、56 忽略。未改断言，未声称完整通过。原型生产与 fixture 改动全部恢复，产品及依赖逐字回到固定基线。

63 格局部线程 CPU 对照中，`Borrow<str>` 原型的 31 字节热读取比为 3.21–3.23；`Borrow<[u8]>` 原型消除该显著回退，但短键淘汰插入未稳定改善，32/64 字节插入比仍为 1.1307–1.2353。独立 `compact_str 0.10.0` 探针的短键淘汰插入基本持平，32/64 字节插入比为 1.1274–1.2776。三组均不采用，项目没有新增紧凑字符串依赖。

完整条件、未采用源码、原始配对值、计数、红绿及失败日志、资源与恢复摘要在[测量目录](../../../../docs/measurements/2026-10-23-quanpin-inline-path-key/README.md)。线程 CPU 与简化页只用于局部否决，不代表宿主、真实行深复制或默认九键预算；共享负载干扰仍存在。

恢复后的最新基线采样共 44405 样本、逐键内 42527，分配释放 7739、模型线性层 7963、词典 8640、BigramMemo 5459。203 次观察全部存在外部工具，不能用受扰动的模型 p95 76.21 ms 推断空闲表现。默认九键 16 ms 目标保持未验证。

最终只提交笔记及测量文档，完整本地 `--quick` 在 1431.522 秒后退出 0；原生平台阶段按文档范围跳过，Rust 工作区及共享 Apple 桥接层检查通过。Python 语法、格式、冻结函数及证据摘要通过，没有降低原门槛或修改已知失败基线。

[工作集诊断](../../implemented/testing/2026-10-23-quanpin-path-cache-working-set.md)进一步记录完整访问顺序，量出重复未命中和容量估计；本篇三种键表示仍不采用，重放收益不替代真实执行或首字母展开边界验证。

## Risks

安全枚举比 `String` 本身大，需报告节点尺寸和固定 128 槽的额外存储，并与省去的堆键分开。短键增加复制固定数组的指令，长键额外经过枚举分支；局部配对计时用于发现回退，不能代替完整按键预算。缓存键类型变化需要严守 `Borrow<[u8]>` 的哈希和相等契约。

# Agent Note: Windows 沉浸式进程读取用户数据目录

Status: rejected — 整目录授权超过运行时选项所需边界

## Problem

报告者补充目录 ACL 后，沉浸式设置搜索能够读取运行时选项。这证明读取权限是独立问题，但不能证明整个用户数据目录都适合公开给所有应用包。

## Proposal

为普通和受限应用包递归授予整个数据目录读取权限，可以沿用当前文件布局并直接解决报告者的读取失败。

## Alternatives considered

- **整目录递归读取授权**：实现简单，报告者的对照实验也支持其效果；但目录包含私人状态，不接受扩大其可读范围。
- **只开放当前运行时选项文件**：范围更窄，但当前快照嵌入完整偏好，也不满足最小可读边界。需要先建立单独的脱敏快照契约，再考虑授权；本次不实现新的跨进程数据格式。

## Consequences

撤回安装器和测试中的递归应用包授权。[宿主库加载修复](../../implemented/bug-fix/2026-11-04-windows-immersive-host-delay-load.md)只处理 DLL 查找；AppContainer 读取权限与开始菜单提交异常继续保留为未解决问题。

已安装预览包的显式授权不会随删除安装器命令而消失；后续[权限清理](../../implemented/bug-fix/2026-11-04-windows-data-appcontainer-boundary.md)在重装时递归移除两组允许项，并验证根目录与合成子文件。

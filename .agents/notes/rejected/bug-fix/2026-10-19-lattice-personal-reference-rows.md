# Agent Note: 词网格按前词复用个人评分的静态参考概率

Status: rejected — 真机整句计算没有改善，新增数组还违反原有分配预算

## Problem

真机九键连续输入的词网格计算占查询主要耗时。同一列的多个假设可能以同一词结尾，现有二元分已经按前词共享一行，但个人评分仍为每个假设、每条出边重复计算 `reference_probability * exp(static_bonus)`。该参考值与更早的词和假设分数无关。

## Proposal

沿用二元评分行的前词索引。仅在有个人模型且该前词置信度大于零时，为该行计算一份参考概率数组；相同前词的假设共用该数组。没有静态二元表时参考值就是配置值，不计算 `exp(0)`。个人上下文、概率、对数、截断、评分加法与遍历顺序保持不变。数组只活到本次解码结束，不跨模型、配置或查询保存。

## Historical audit

[二元评分行缓冲](../../implemented/testing/2026-10-11-lattice-bigram-lazy-reserve.md)与[小行前词索引](../../implemented/testing/2026-10-19-lattice-small-row-index.md)部分重叠，继续持有按前词复用行与原索引顺序；本提案只为有个人数据的行增加派生值。已检索个人概率、个人评分与 `personal_transition`；此前[前词散列试验](../../rejected/testing/2026-10-15-lattice-bigram-prefix.md)处理静态表查键，不替代其否决。无完全吸收或过时提案。

## Alternatives considered

- 跨查询缓存完整个人转移分数：复用范围更大，但需要绑定个人模型版本、配置、静态表及上下文身份；本次解码内复用无需失效协议。
- 减少束宽、关闭个人词频或整句联想：可减少计算，但改变用户输入结果，不采用。
- 保留逐假设计算：额外存储为零，但会重复计算已经由前词与出边唯一确定的指数。

## Acceptance criteria

完整词网格旧新对照保留逐路径评分及候选顺序；无个人模型、未知前词、有个人模型、三元上下文和配置变化均覆盖。同一真机重复比较，在没有实际收益时撤回。临时探针不进入产品。

## Risks

有个人数据的解码会增加短期参考值数组；没有个人数据时不分配。置信度只依赖前词与只读模型，不能将更早上下文决定的概率一并按前词缓存。

## Experiment result

同一真机每轮279个合成数字输入，参考行复用加阴影缓存后，词网格均值6.25 ms、P95 16.80 ms；此前基线6.12 ms、P95 16.06 ms。整次按键P95 40.22 ms，基线41.14 ms，不能把混入界面修改的波动归因于指数复用。词网格133项通过、3项原有分配/峰值预算失败，未发现路径输出差异；收益不足以支持新增存储，因此撤回，不放宽预算。

# Agent Note: 跟踪平台 issue #9008

Status: rejected — issue #9008 已在 #9640 修掉一条可致此现象的内存路径并向报告者索要日志后，由维护者关闭，无需再单独跟踪。

## Problem

issue #9008 报告 iOS 输入法 0.52.0（iOS 27.0.1）在各应用里点输入框后，水杉键盘先出现，约一秒后变回系统英文键盘，且反复出现。这种表现通常是键盘扩展刚启动就被系统结束，最常见的原因是内存超限。

#9640（`Refs #9008`，2026-10-25 合并）修掉了其中一条有实测的路径：启用「候选栏使用主题配色」并选了带图片的候选皮肤时，`msime_client_skin_resource` 把图片逐字节编码成 JSON 数字数组，读一张 1 MiB 图片的共享层峰值约 64 MiB；改为 base64 后约 5.3 MiB。该 PR 明确说明无法证明这就是报告者遇到的原因。维护者随后在 issue 下列出需要报告者提供的 JetsamEvent、键盘崩溃记录和诊断日志，并于 2026-10-25 关闭 issue；截至 2026-11-22，issue 下没有新的复现材料。

## Proposal

为 #9008 建一个独立 Draft PR 作为跟踪入口，等拿到复现和平台验收证据后，再在其中加入代码、回归和验收。

## Alternatives considered

- **直接复制相邻平台修复**：最强理由是可能快速覆盖相似症状，但没有该 issue 的独立复现，容易把无关改动带进 iOS，因此不采用。
- **只在 issue 下追加调查评论**：最强理由是无需创建分支，但不能形成可审查的代码交付边界，因此不采用。

## Acceptance criteria

- PR 关联 #9008，记录平台、复现和验证边界。
- 确认责任路径后，加入代码、回归和 iOS 真机验收。

## Risks

没有报告者日志时，跟踪 PR 只能长期停在 Draft，成为无人推进的过期提案；若报告者之后补充日志并确认问题仍在，应重开 #9008 或新开 issue，而不是复用这条跟踪记录。

# Agent Note: 跟踪平台 issue #3841

Status: rejected — issue #3841 已由维护者以已完成关闭，维护者判断的可能原因（与 #4288 相同的方案回退）已由 #5081 修复，无需单独跟踪

## Problem

issue #3841「[Bug] 无法切换到全拼」报告在 macOS 27.0.1 的水杉 IME 0.52.0 上，设置里的输入方案是全拼，实际却在用笔画，菜单栏选「中」也切不回全拼。维护者在 issue 下说明：方案专属输入模式未添加时菜单栏用「中」显示当前方案、再选「中」不换方案是有意设计；设置是全拼但实际用笔画，很可能和 #4288 是同一个原因，即 0.52.0 的输入法进程重启后先用本地残留的旧方案，有时还把它写回设置。这个原因由 PR #5081（`Fixes #4288`，2026-10-07 合入）修复，输入法启动后改为以设置里的方案为准。PR #5754 在正文里记录了同样的分析（`Refs #3841`，针对 #3841 未改代码）。报告人没有回复维护者关于笔画方案最初如何被选上的追问，维护者于 2026-10-09 把 #3841 以已完成关闭。

## Proposal

为 #3841 单独开一个 Draft PR 作为交付跟踪入口：补齐最小复现、版本与环境证据，确认责任路径后再加入代码、回归和 macOS 平台验收。

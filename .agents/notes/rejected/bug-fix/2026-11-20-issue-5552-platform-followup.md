# Agent Note: 跟踪平台 issue #5552

## Problem

issue #5552 报告 macOS 版 0.52.0 开启简繁切换快捷键后，按 Control+Shift+F 不能切到繁体输出，报告人随后补充 Option+Shift+H 也不能切换全半角。#5754 对照 `macos-v0.52.0` 与 develop 的代码并用合成按键测试排查过，没有找到缺陷，未改代码（`Refs #5552`）；维护者随后在 issue 中指出唯一没排除的是键盘布局。#6474 让 macOS 的字母快捷键按当前键盘布局的字符认键，正文写 `Closes #5552`，2026-10-09 合并后 issue 随之关闭（stateReason 为 COMPLETED）。

关闭后报告人在 2026-10-14 回复：使用 ABC 布局，Control+Shift+F 已能切换简繁，但说不清当初为什么不行（ABC 与美式布局的字母位置相同，#6474 按布局认键的改动在这个布局上不改变行为，所以不能据此认定是 #6474 修好的）；Option+Shift+H 能切换数字和字母的全半角，但标点不变，Control+Shift+Space 完全无效。这部分残留现象不在本 Note 的跟踪范围内，截至 2026-11-22 没有找到单独跟踪它的 issue 或 PR。

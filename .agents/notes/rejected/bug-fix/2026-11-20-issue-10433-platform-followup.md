# Agent Note: 跟踪平台 issue #10433

Status: rejected — issue #10433 与 #9815 是同一问题，已由 #9817 和 #9842 修复并随 macOS 0.56.0 发布，无需单独跟踪。

## Problem

issue #10433 报告 macOS 上水杉输入法 0.55.0 下载万象模型后校验不通过。维护者在 issue 下确认它与 #9815 是同一个问题：万象上游于 2026-10-26 在同一个 LTS 地址原地替换了模型文件，而 0.55.0 固定的仍是旧文件的长度和 SHA-256，因此下载完成后校验失败。

#9817 更新了锁文件中的长度和 SHA-256，合并后以 `Fixes #9815` 关闭 #9815；#9842 将万象模型改为按实际下载内容校验 `.gram` 格式，并按实际字节记录摘要，此后上游原地替换文件不会再导致校验失败。两者都包含在 macOS 0.56.0 中。维护者在 #10433 下说明它会作为 #9815 的重复处理，随后关闭了该 issue。

## Proposal

建立独立 Draft PR 作为该 issue 的交付跟踪入口。先保留报告原始范围和平台边界，补齐最小复现、版本与环境证据，再按确认的责任路径加入代码、行为回归和目标平台验收。历史 issue 也保留一条可审查的 PR 记录，避免用相邻修复推断它已经完成。

## Alternatives considered

- **直接复制相邻平台修复**：最强理由是可能快速覆盖相似症状，但没有该 issue 的独立复现和验证，容易把无关改动带入目标平台，因此不采用。
- **只在 issue 下追加调查评论**：最强理由是无需创建分支，但不能形成可审查的代码交付边界，因此不采用。

## Acceptance criteria

- PR 正文关联 `#10433`，并记录该 issue 的平台、复现和验证边界。
- 责任路径确认后，在本 PR 或后续同一 issue 的实现切片中加入代码、回归和平台验收。
- 历史已关闭 issue 也能追溯到对应 PR，不把相邻 PR 当作本 issue 的完成证据。

## Risks

当前 PR 只建立交付跟踪，不宣称已经修复该 issue。未经平台复现的改动可能影响其他宿主或用户设置。

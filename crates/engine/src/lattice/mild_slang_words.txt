# 流行的轻度粗口（`lattice::offensive::is_mild_slang`）。本项目自写，与引擎代码同为 MPL-2.0。
#
# 这些词照样拼进整句，在 26 键上整段打出来时照样可以当首选：维护者 2026-11-04 定的粗俗内容政策里，牛逼、卧槽 这类流行口语保留。表只管一件事：九键、14 键这类一个键几个字母的键盘上，它们不进歧义码的首屏（`offensive_placement`），因为同一串数字用户更可能是想打别的词。往后翻页、或者换 26 键打完整拼写照样打得出来。`offensive_words.txt` 里的词比这一档更重，不要两边都放。
#
# 按子串查，规则与 `offensive_words.txt` 相同：词本身或其中任何一段在表里都算命中，`!` 开头的行是豁免写法。
#
# 收词标准：现代口语里最常见的义项是带性器官字眼的口头禅或骂人话，而常见程度高到不宜整词压到首选之后；`offensive_words.txt` 文件头列为「不收」的轻度骂人话里只收带 逼、屌、操 的这几个。不收：不带这几个字眼的口语（笨蛋、狗屁、你妹），也是常见人名的写法（尼玛 是藏族常见的名字）。加词之前先确认评测集（`resources/eval`）的金标准里没有含它的句子。
#
# 格式：一行一个词或一条豁免写法，`#` 开头的行和空行不算。

牛逼
装逼
卧槽
我操
屌丝
牛屄

# 豁免：为我操心 是 为 + 我 + 操心，马跳卧槽 是象棋术语。
!我操心
!马跳卧槽

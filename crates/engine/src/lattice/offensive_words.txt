# 不拿来拼整句的粗俗词（`lattice::offensive`）。本项目自写，与引擎代码同为 MPL-2.0。
#
# 这些词照样是词库里的词：读音单独打出来（整段输入恰好是这个词的读音）时它和别的词一样按权重排序，也可以在候选里选它、用它分段上屏。表只管一件事：词网格拼整句、纠错整句换词、上屏后的联想都不用含这些词的词，用户打的是别的意思时，它们不会被拼进句子当首选。2026-10-29 九键打 我们走路去（966369685878）首选是「我们有巨乳」：巨乳 只有 3174 的权重，靠多字词的音节奖励压过了同码的单字。
#
# 按子串查：词本身或其中任何一段在表里都算命中，所以 个鸡巴、吃屎了、是傻逼 这些长词条也不拿来拼句。`!` 开头的行是豁免写法：命中的那一段如果被一条豁免写法整个盖住，这一段不算（水乳交融 里的 乳交、口交换机 里的 口交）。豁免写法只收词库里实有、常见义项不粗俗的词或固定说法，写到刚好能区分开为止（`!口交换` 同时放行 口交换机 和 多口交换机），而且必须含一个表里的词。
#
# 收词标准：dict-v2.0.39 的 msime-pinyin.db 里有、至少两个字，而且现代口语里最常见的义项属于下面两类之一。
# - 色情或粗俗的性描写：性行为、性器官和排泄器官的俚语说法、色情片和约性用语。
# - 以性或性别辱骂人的脏话（婊子、贱人、骚货），以及常见的粗口骂人话（傻逼、他妈的、吃屎）。
# 不收：解剖与医学用语（阴道、阴茎、乳房、精子、月经、包皮、手淫、射精），法律与新闻用语（强奸、鸡奸、卖淫、嫖娼、色情、淫秽、淫乱、性奴隶），有常见字面义或常见的非色情义项的词（打飞机、打炮、吹箫、后庭、野鸡、杂种、龟头、小穴、烂货 指劣质货、美乳 是美容用语），中性的标准说法（做爱、性交、自慰），不涉及性的轻度骂人话和流行口语（笨蛋、白痴、王八蛋、瘪三、狗屁、牛逼、装逼、屌丝、尼玛、你妹），单字（单字边不拿多字词奖励，压不过同码的词）。专门领域或方言里的别义不妨碍收词（内射 在数学里是单射，奶子 在方言里指奶）：这类别义出现在复合词里时用豁免写法放行（内射函数、马奶子酒）。加词或豁免写法之前，先确认评测集（`resources/eval`）的金标准里没有含它的句子，再在词库里列出含它的长词条，常见义项不粗俗的补豁免写法。

# 不拿来拼整句的粗俗词（`lattice::offensive`）。本项目自写，与引擎代码同为 MPL-2.0。
#
# 这些词照样是词库里的词：读音单独打出来（整段输入恰好是这个词的读音）时它和别的词一样按权重排序，也可以在候选里选它、用它分段上屏。表只管一件事：词网格拼整句、纠错整句换词、上屏后的联想都不用它，用户打的是别的意思时，它不会被拼进句子当首选。2026-10-29 九键打 我们走路去（966369685878）首选是「我们有巨乳」：巨乳 只有 3174 的权重，靠多字词的音节奖励压过了同码的单字。
#
# 收词标准：dict-v2.0.39 的 msime-pinyin.db 里有、至少两个字，而且常见义项只有下面两类之一。
# - 色情或粗俗的性描写：性行为、性器官的俚语说法、色情片用语。
# - 以性器官或性行为辱骂人的脏话，以及常见的粗口骂人话。
# 不收：解剖与医学用语（阴道、阴茎、乳房、精子、月经、包皮、手淫、射精），法律与新闻用语（强奸、卖淫、嫖娼、色情、淫秽、淫乱），有常见字面义的词（打飞机、打炮、吹箫、后庭、野鸡、杂种、龟头、小穴），中性的标准说法（做爱、性交、自慰），轻度的骂人话和流行口语（笨蛋、白痴、王八蛋、瘪三、狗屁、牛逼、装逼、屌丝、尼玛、你妹），单字（单字边不拿多字词奖励，压不过同码的词）。加词之前先确认评测集（`resources/eval`）的金标准里没有它。
#
# 这是临时放在引擎里的最小表。长期应当由词库仓库 msime-dictionary 维护（像 `sources/symbols/symbol-names.tsv` 那样作为唯一的编辑入口同步过来，或由 `msime-dict-build` 在 msime-pinyin.db 里给词条打标记），见 `.agents/notes/implemented/bug-fix/2026-10-29-offensive-words-out-of-sentences.md`。

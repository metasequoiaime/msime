# Gradle wrapper

The wrapper JAR and launch scripts were generated by the pinned Tauri CLI 2.11.4 Android template and moved here, unchanged, when the Tauri Android project was removed. The launch scripts retain their upstream copyright notices. These Gradle build-tool files are licensed under Apache-2.0; the license is included in LICENSE-2.0.txt. The selected Gradle distribution is 8.14.3, verified using its official SHA-256 in wrapper/gradle-wrapper.properties. These build tools are not bundled into the application APK.

Upstream sources: https://github.com/tauri-apps/tauri and https://github.com/gradle/gradle.

# now：指令里的本地时间的参考样板

在 `/` 指令里打 `/now`，给出当前的日期和时间的五种写法。它是 `command` 事件里四个本地时间字段（`LOCAL_DATE`、`LOCAL_MINUTE`、`WEEKDAY`、`UTC_OFFSET_MINUTES`）的最小样板；输入法内置的日期、时间指令（`/rq`、`/sj`）固定几种格式，想要别的写法时照着这个目录改 `src/lib.rs` 就行。

| 项 | 值 |
| --- | --- |
| 钩子 | `command` |
| 能力 | `provide_commands`（读你在它的触发词后面打的字母，给出候选行）；读时间不需要能力 |
| 指令 | `/now`（标题「现在」） |
| 许可证 | MIT |
| 模块 | 约 4.1 KiB，内存 2 页 |

插件读不到你平时打的字、上屏文本和候选窗口，也不改写任何文字；它只在你打了 `/now` 时给出几行，由你选中才会输入。

## 用法

1. 构建并导入（见[合集的 README](../README.md)），在「插件 → 脚本插件（实验）」里打开「现在」，授予「提供 / 指令」。
2. 打开「输入 › 快捷模式」里的 / 指令（默认关），并使用中文标点。
3. 没有输入时按 `/`，再打 `now`：

| 候选 | 注释 |
| --- | --- |
| `2026-10-26` | 日期 |
| `2026年10月26日 星期一` | 中文 |
| `14:05` | 时间 |
| `2026-10-26 14:05` | 日期时间 |
| `2026-10-26T14:05+08:00` | ISO 8601 |

按序号、点选或空格选中一行就输入那一行；按回车输入原文 `/now`。

## 规则

- **时间从哪来**：只有 `command` 事件带本地时间，四个字段都不需要能力，用 `event::scalar` 读，偏移可以为负，用 `event::signed` 读。时间只给到分钟，也只在你刚打完触发词的那一次给，插件自己没有时钟。
- **没有时间时不给行**：宿主读不出系统时钟时四个字段都是 `ABSENT`，插件不给任何行，输入法只显示原样的 `/now`，日志写 `skip: absent`。
- **参数**：`/now` 后面还有字母时（`/nowx`）不给行。
- **同一次组字里不变**：输入法按预编辑串缓存插件给出的行，翻页、移动高亮时不再问插件；删掉一个字母再打回来才会按新的时间重新给。
- **不用 `core::fmt`**：五行都用固定大小的缓冲手工拼。格式化机制会让模块大好几倍，在解释器里也贵得多。

## 夹具与核对

`fixture.jsonl` 覆盖东八区、负的半小时偏移（-03:30）、零偏移、+05:45、+14:00 和 -12:00，闰日、年初年末、一天的第一分钟和最后一分钟，年份 1 和 9999，没有时间，以及参数不为空的两种情况（含 64 字节的最长参数）。`scripts/test-script-plugins.sh` 除了按 `expected.jsonl` 逐行核对，还跑 `check_output.py`：它用 Python 的 `datetime` 从夹具的时间独立算出五行，并核对夹具里的星期和日期对得上。

## 最坏情况的 fuel

工作量是常数：读参数一次、读四个字段、拼五行、交出五行、写一行日志。实测（rustc 1.97.1、wasmi 2.0）每次约 8 700，`command` 单次上限 100 000，测试断言不超过一半。
